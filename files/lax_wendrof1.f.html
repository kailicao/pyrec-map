Explanation

Purpose. LAX_WENDROF1 is the first (half) step of the two-step Lax–Wendroff scheme that GRSETT uses for the explicit, gravitational-settling term of the diffusion equation. It returns the change in the hydrogen abundance at the midpoints of an equally spaced radial grid over half a time step, and the same for the metals when metal diffusion is on.

How it fits.

  • Who calls it: GRSETT (helium settling) and MICRODIFF_RUN (the microscopic-diffusion driver), each followed by LAX_WENDROF2.
  • Arguments: DT (time step, s), ECOD1 (on the equal grid: the first term's coefficient, which SETUP_GRSETT builds as $d\ln P/dr$ times a function of $X$, so it acts as a flux), EM (the mass at each grid point), NPT, STOT (total mass), LDOLI; output EX_H.
  • COMMON blocks: CONST1 ($4\pi$); GRAVS3 (the switch LDIFZ for metal diffusion); GRAVEZ, the metals' arrays on the equal grid (ECOD1Z in, EZ_H out), shared with GRSETT, LAX_WENDROF2, MODEL_TO_EQUAL and EQUAL_TO_MODEL.

The method. With $F_i$ = ECOD1(I), $m_i$ = EM(I), $M$ = STOT:

$$\Delta X_{i+1/2} = \frac{\Delta t}{2}\,4\pi\,\frac{F_{i+1}-F_i}{m_{i+1}-m_i}\quad (i = 1..N-1),$$

stored in EX_H(I), where at the centre ($i = 1$) the code takes $F_1 = 0$, $m_1 = 0$, and at the surface ($i = N-1$) $F_N = 0$, $m_N = M$: so the flux is taken as zero at the centre and at the surface. The same formulas, with ECOD1Z and EZ_H, are applied to the metals when LDIFZ is true and LDOLI is false.

Questions for the experts

  1. Only the flux difference. The half step of the textbook Lax–Wendroff scheme (as the GRSETT comment writes it) also averages the neighbouring values, $X_{j+1/2}^{n+1/2} = \tfrac12(X_j + X_{j+1}) - \dots$; here only the increment is computed, and GRSETT uses it to update the coefficients. Is this the intended variant?
  2. Index placement. The central formula uses $m_2$ (the mass between points 1 and 2 when $m_1 = 0$), but the surface one uses $M - m_{N-1}$, which spans two intervals if $m_N < M$. Are the boundary masses consistent with the midpoint grid?
