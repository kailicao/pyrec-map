Explanation

Purpose. STARIN provides the starting model of each run of a job: it reads the initial stellar model from a file, or keeps the one in memory, then prepares it for evolution. Along the way it can change the model's composition, extend the model toward the centre, rescale it, move the envelope's fitting point, and it computes the shell masses, the rotation quantities, the surface composition and the first convection-zone quantities.

How it fits.

  • Inputs: the model file on the unit IFIRST (COMMON LUNUM), opened by the set-up routines; its first four characters say its format, NMOD (YREC7) or MOD2 (MODEL2). The run's settings come through COMMON blocks filled by PARMIN and SETUPS: CKIND (per run NK: LFIRST, IRESCA), CORE (LCORE, MCORE, FCORE), CENV (LSENV0, SENV0), NEWMX (the mixture controls), ROT (LROT, LWNEW, WNEW), CTOL (HPTTOL), SPOTS, VNEWCB and others.
  • Who calls it: the main program, main.f, at the start of each run (two calls).
  • What it calls: the readers GETYREC7 and GETMODEL2; RSCALE (rescaling); for a new envelope base, the physics MEQOS, EQSTAT, GETOPAC, TPGRAD and the envelope integration ENVINT; for rotation, FPFT and MOMI; then SURFOPAC, SETSCV, PHYSIC, OVROT and GETTAU.
  • Outputs: the model in the arguments (HS, HR, HL, HP, HT, HD, HCOMP, LC, OMEGA, M and the rest), and many COMMON blocks: the surface composition in COMP and COMP2 (XENV, ZENV, ZENVM, AMUENV, FXENV, YENV, Y3ENV), read by the equation of state and opacity routines; the previous model in OLDMOD (HPO, HTO, HRO, HLO, TEFFLO, MO), read by HTIMER and others to limit the time step; OLDROT (WOLD); and OVRTRN (TAUCZ0, PPHOT0, FRACSTEP).
  • COMMON blocks: 36 of them; the widest are the constants (CONST, CONST1–CONST3), LUOUT, COMP, ROT, SCRTCH and the envelope's ENVSTRUCT (filled by ENVINT, shared with STITCH, GETTAU, TAUINT and others).

The method, in order.

  1. Stop on failure. If LARGE is set (the previous model failed to converge), the run stops.
  2. Read or keep. If LFIRST(NK) is false, the model in memory is kept (rescaled with RSCALE when IRESCA(NK) ≠ 1), and the reading is skipped. Otherwise the format keyword decides the reader. After reading: $\Delta t$ in seconds, DELTS = CSECYR*DDAGE (the step DDAGE is in years); for an evolved model (MODEL > 0), a warning if the model's mixing length differs from the run's by $2\times10^{-3}$ or more, or its "extended composition" switch differs (the run is no longer stopped, since 1/92). The envelope is always recomputed (LNEW = .TRUE.). If LWNEW, the model is set to solid-body rotation at WNEW; without rotation, the distortion factors FP, FT are 1.
  3. Change the mixture (MHP 10/24), only for a model read from file, and only if it is chemically homogeneous (every species within $10^{-6}$ of its central value). With LMIXTURE, the C, N and O isotopes are scaled so that each element's share of $Z$ (HCOMP(3,·)) becomes FRAC_C, FRAC_N, FRAC_O: $$X_i \to X_i\,\frac{f_\mathrm{C}}{(X_{^{12}\mathrm{C}} + X_{^{13}\mathrm{C}})/Z}\quad (i = {}^{12}\mathrm{C}, {}^{13}\mathrm{C}),$$ and likewise for N (indices 7–8) and O (9–11). With LISOTOPE, the ratios $^{12}$C/$^{13}$C = R12_13 and $^{16}$O/$^{18}$O = R16_18 are imposed at fixed sums, and $^3$He, $^2$H, $^6$Li, $^7$Li and $^9$Be are set to their …_INI values. (The order of HCOMP's 15 species, from the printed labels: X, Y, Z, $^3$He, $^{12}$C, $^{13}$C, $^{14}$N, $^{15}$N, $^{16}$O, $^{17}$O, $^{18}$O, $^2$H, $^6$Li, $^7$Li, $^9$Be.)
  4. Extend the core (LCORE, for a model read from file; MHP 9/98, 9/14). MCORE points are added inside the innermost shell, spaced by HPTTOL(2) in $\log m$, with MCORE = INT(DLOG10(FCORE)/HPTTOL(2))+1; FCORE (COMMON CORE) is then overwritten with MCORE*HPTTOL(2), a log offset rather than the factor it was. Inward, at constant density $\rho_c$ (HD(1)), constant energy generation and constant $\nabla$: $$\log r = \tfrac13\left(\log m - \log\tfrac{4\pi}{3} - \log\rho_c\right),\qquad L = L_1\,\frac{m}{m_1},$$ $$\frac{d\ln P}{d\ln m} = -\frac{G m^2}{4\pi r^4 P},\qquad \Delta\log T = \nabla\,\Delta\log P,$$ with the pressure step taken at the midpoint (two evaluations), and the density from $\log\rho = \log P - \log T - $ const (FACD, fixed at the first old point; MHP 4/12 replaced a "broken" EOS call).
  5. Rescale with RSCALE if IRESCA(NK) ≠ 1.
  6. Move the envelope's fitting point (LSENV0), to SENV0, the log of the fitting point's mass fraction, $\log_{10}(m_\mathrm{fit}/M_\star)$ (as SENV = HS(M) - HSTOT): a small negative number, at most $-10^{-12}$ ("τ = 2/3"), which puts the fitting point a fraction $\approx 2\times10^{-12}$ of the mass below the surface. For a deeper point, shells beyond it are dropped and the new last shell is interpolated linearly in $\log m$; if it lies between a convective and a radiative shell, the physics routines decide whether it is convective. For a shallower point, an envelope is integrated with ENVINT from the surface (at the model's $L$ and $T_\mathrm{eff}$, or the spotted star's ambient temperature, below), shifted to match the last interior point, and its points down to the new fitting mass become interior shells (constant $L$). With rotation the new shells rotate at the old surface rate, with $j = \tfrac23\,\Omega r^2$.
  7. Shell masses. With $m_i = 10^{\texttt{HS}(i)}$ (HS1), each shell's mass HS2 is $$\Delta m_i = \tfrac12\,(m_{i+1} - m_{i-1}),\quad \Delta m_1 = \tfrac12\,(m_2 + m_1),\quad \Delta m_M = M_\star - \tfrac12\,(m_{M-1} + m_M).$$
  8. Rotation. FPFT and MOMI give the distortion and moments of inertia $I_i$; then $J_i = \Omega_i I_i$, $j_i = J_i/\Delta m_i$ (HJM), $K_i = \tfrac12 \Omega_i J_i$ (HKEROT), and the totals SJTOT, SKEROT, printed beside the previous ones.
  9. Surface composition (first run only, NK = 1): from the relative mass fractions V of 12 elements (VNEW from the parameters unless the old LLAOL opacities are used), with H and He set from $X$ and $Y$, the number fractions $f_k = (V_k/A_k)/\sum_l (V_l/A_l)$ (FXENV, atomic weights ATOMWT), and $Z$ without C, N and O (ZENVM). With the mass fractions $X_k$ of all 12 elements, H and He included, $$\texttt{AMUENV} = \sum_{k=1}^{12} \frac{X_k}{A_k},$$ the inverse mean atomic weight per ion (as CHECKC's comment says). Then the surface opacity tables (SURFOPAC) and, with LSCV, the SCV equation of state (SETSCV).
  10. Save the old model in OLDMOD/OLDROT, then compute the physics of all shells (PHYSIC), the convection and overshoot zones (OVROT) and the convective turnover time and photospheric pressure (GETTAU), kept as TAUCZ0, PPHOT0; FRACSTEP = 0.5.

Spots (G. Somers 10/14). For a spotted star (SPOTF the covering fraction, SPOTX the spot-to-ambient temperature ratio), the envelope is integrated at the ambient temperature $$\log T_\mathrm{amb} = \log T_\mathrm{eff} - \tfrac14 \log_{10}\!\left(f\,x^4 + 1 - f\right).$$

Design. Many paths print to the screen (WRITE(*,…)) as well as to ISHORT. Errors end the run with bare STOP 9999 or STOP 9998 (too many points, coincident masses). A large commented-out block (G. Somers 8/17) computed the gradients of every shell; PHYSIC does that now.

Questions for the experts

  1. No equation of state without MHD. When the new last shell of a deeper envelope base is between a convective and a radiative shell, the code calls MEQOS and then EQSTAT, both inside IF (LMHD) THEN … END IF. When LMHD is false, no equation of state is called, and GETOPAC and TPGRAD get undefined T, P, D and derivatives. The usual pattern elsewhere is IF (LMHD) … ELSE … EQSTAT … ENDIF. Is an ELSE missing?
  2. JSON too small, but no stop. In the core extension, when M + MCORE > JSON the code writes "RUN TERMINATED", but does not stop, and then writes beyond the arrays.
  3. The density in the core extension. The loop that shifts the old points outward by MCORE moves HS, HR, HL, HP, HT, LC, HCOMP and OMEGA, but not HD. So the whole density profile above the new core is misaligned by MCORE shells (every old density stays at its old index), PHYSIC then reads HD, and FACD is taken from HD(MP1), which is not the density of the shifted first point. Is HD meant to be shifted too?
  4. The warning's variable. Format 1040 prints LEXCP0, which is never set; the model's value is LEXCOM0 (after "MHP 9/03 FIXED TYPO").
  5. A sign in the envelope interpolation. For the first envelope point (JM = 1), HCOMP(1,J) = HCOMP(1,M) + FX*(HCOMP(1,M) - ENVX(JM)), and likewise for HCOMP(3,J); the other quantities use (new - old). Is the sign reversed?
  6. Unused isotope ratios. R14_15 and R16_17 (and XB10_INI, XB11_INI) are in COMMON NEWMX but not applied; the comment says $^{15}$N, $^{17}$O and B are not used. Should PARMIN warn when they are set?
  7. The surface composition only for the first run. Step 9 is skipped when NK > 1 (GOTO 630), so a later run that reads a new model from file (or changes the mixture) keeps the first run's XENV, ZENV, FXENV. Intended?
  8. The mixing-length check. A mismatch of mixing length or composition switch now only warns. Should the run still stop, as the commented-out STOP did?
  9. Loop-invariant assignments. TEFFLO = TEFFL and MO = M sit inside the loop over shells (label 710); harmless, but probably meant before it.
  10. The comment on AMUENV. STARIN's comment says "AMUENV = MEAN ATOMIC WEIGHT OF SURFACE Z", but the code computes $\sum_k X_k/A_k$ over all 12 elements, H and He included (the inverse mean atomic weight per ion, as CHECKC's comment says). A comment to fix?
  11. 0/0 with one core point. With MCORE = 1 (for example the default FCORE = 1.0, which gives INT(0)+1 = 1), after the shift HT(2) = HT(1) and HP(2) = HP(1), so DEL = (HT(2)-HT(1))/(HP(2)-HP(1)) is 0/0. Should DEL be taken from the first two shifted points (MP1, MP1+1)?
