Explanation

Purpose. EQ2MOD maps a change in specific angular momentum, computed on an equally spaced grid, back onto the model's own mass points. It is the last step of the angular momentum transport by rotational instabilities: the diffusion equation is solved on the equally spaced grid for each unstable region, and this routine applies the result to the run of $j = J/M$ in the model.

How it fits.

  • Who calls it: only SECULR, after it has solved the diffusion equation for one unstable region (shells IBEG to IEND).
  • Inputs: the change DJ and the angular momentum EJ before redistribution, both on the equally spaced grid; the shell masses HS2; the convective flags LCZ; the total change SUMDJ across the grid.
  • What it calls: OSPLIN, a shape-preserving osculatory quadratic spline (ACM Algorithm 574).
  • Output: the array HJM (specific angular momentum at each model point), updated in place.
  • COMMON blocks: /EGRID/ holds the grids: CHI (the model points' coordinate, $\chi = \log M/\Delta M + L/(L_\mathrm{tot}\Delta L) - \log P/\Delta P$ in GETGRID's comment; here CHI(1..NMOD) are the region's points, from IBEG on), ECHI (the equally spaced points), NTOT; it is filled by GETGRID and shared with SECULR, ROTGRID, MIXGRID, MIXCOM and CHECKJ. /SPLIN/ is scratch space for the spline, shared with MIXCOM, MIXGRID and ROTGRID.

The method.

  1. If the region's first or last shell is convective, it is extended (indices I0, I1) to the edge of that convection zone.
  2. The fractional change $y = \Delta j / j$ (DJ/EJ) is interpolated with OSPLIN from the equally spaced points ECHI to the model points CHI, giving YVAL.
  3. Each shell's $j$ is multiplied by $(1 + y_i)$. Shells in the extended convective parts take the value at the nearest edge (YVAL(1) or YVAL(NMOD)).
  4. Conservation check. With $m_i$ the shell mass (HS2), $$S_J = \sum_i j_i m_i, \qquad S_{\Delta} = \sum_i y_i\, j_i m_i .$$ If $|S_\Delta - \Delta J| > 10^{-5}|\Delta J|$, where $\Delta J$ is SUMDJ, every shell from I0 to I1 is rescaled by $$\frac{S_J + \Delta J}{S_J + S_\Delta},$$ so that the region's total angular momentum changes by exactly $\Delta J$.

Questions for the experts

  1. The extended convective shells. In step 3, shells outside IBEG..IEND but in the same convection zone get the edge value of $y$, so their $j$, and their $\Omega$, scale by one common factor. That keeps the zone in solid-body rotation only if it already was; the code does not check it. Is that assumption safe here?
  2. The tolerance. The rescaling is applied only when the mismatch exceeds $10^{-5}|\Delta J|$. When $\Delta J = 0$ (no surface loss, as the comment says), any mismatch triggers it. Is that intended?
  3. A comment's name. The comment before the check speaks of DUMDJ; the variable is SUMDJ.

Review (round 1)
  1. Unclear (question 1 rests on a false premise). "Is a uniform fractional change in $j$ what solid-body rotation in the zone requires, or should $\Omega$ be uniform instead?" Multiplying every shell's $j$ by the same factor multiplies every shell's $\Omega$ by that factor too, so a zone already in solid-body rotation stays so. Fix: rewrite the question to ask whether the extended shells are assumed to be in solid-body rotation already (the code does not check it).
  2. Missing. CHI is described only as "the model points' coordinate". GETGRID's comment defines it, $\chi = \log M/\Delta M + L/(L_\mathrm{tot}\Delta L) - \log P/\Delta P$. Fix: add a short phrase. Also note that XVAL(I) = CHI(I) for I = 1..NMOD, so CHI holds only the region's points, starting at IBEG.

Revised: question 1 rewritten; CHI described.
