Explanation

Purpose. This file integrates the outer layers of the star, which the interior model does not contain: first the atmosphere, from small optical depth to the photosphere, then the envelope, from the photosphere down to the interior's outermost mass point. The result is the pressure, temperature and radius at that fitting point, which SURFBC turns into the surface boundary condition of the interior; the run of the envelope is stored for output, the acoustic depth and the convective overturn time.

How it fits.

  • Inputs: the arguments B ($L$), TEFFL, GL ($\log g$), RL ($\log R$), HSTOT ($\log M$), X, Z, FPL, FTL (rotational corrections), PLIM (the expected end pressure), IE (which point of the envelope triangle), LSBC, LPRT, LPULPT. From COMMON: the atmosphere choice KTTAU (/ATMOS/: 0 Eddington gray, 1 Krishna Swamy, 2 the HRA $T$–$\tau$ relation, 3 Kurucz, 4 Allard, 5 Castelli–Kurucz 2004); the integration controls /INTATM/, /INTENV/, /INTPAR/; SENV ($\log$ of the fitting point's mass fraction) and STOTAL (/COMP/); TENV (/CTLIM/); LCALCENV, LNEWTCZ (/OVRTRN/); output switches in /CCOUT/, /PULSE/, /ACDPTH/.
  • Who calls it: SURFBC (the boundary condition), CALCAD, GETNEWENV, GETTAU, STARIN, STITCH and WRTMOD.
  • What it calls: for tabulated atmospheres SURFP, KCSURFP or ALSURFP; for gray ones HRA, MEQOS or EQSTAT, GETOPAC; for both integrations BSSTEP with the derivative routines QATM and QENV; at the end TAUCAL.
  • Outputs:
  • arguments: PS(IE), TS(IE), RS(IE) (the fitting point's $\log P$, $\log T$, $\log r$), ESTORE, ISTORE (the state where $T$ first reaches TENV), all set only when LSBC; counters KATM, KENV, KSAHA;
  • /ENVSTRUCT/: the envelope profile ($\log P$, $\log T$, $\log m$, $\log\rho$, $\log r$, $X$, $Z$, convective flag, gradients, velocities, $\beta$, $\Gamma_1$, $c_P$, ionization, opacity, $L$, $\rho_T$), reordered from the centre outward; read by CALCAD, GETNEWENV, GETTAU, STARIN, STITCH, TAUINT;
  • /ATMSTRUCT/ (the atmosphere profile, for STITCH); PPHOT (/OVRTRN/, the photospheric pressure, for AMCALC); ENVRCZ (/ENVCZ/, the radius of the convection zone's base when it lies in the envelope, for WRTOUT);
  • text: the atmosphere and envelope tables to ISTOR, summaries to ISHORT, pulsation files IOPATM, IOPENV.

The atmosphere.

  • Tables (KTTAU = 3, 4, 5): the routine reads $\log P$ (and $\log T$) at the photosphere from the table; if the Allard table fails, it switches the run to the gray atmosphere (it sets KTTAU = 0 for good).
  • Gray (KTTAU = 0, 1, 2): start at a small optical depth, with the temperature from the $T$–$\tau$ relation at $\tau \to 0$ (Eddington: $\log T = \log T_\mathrm{eff} - \tfrac14\log\tfrac43 + \tfrac14\log\tfrac23$, that is $T^4 = T_\mathrm{eff}^4/2$; Krishna Swamy: $T^4 = \tfrac34 T_\mathrm{eff}^4 \times 0.550$; HRA: its own value at $\tau = 2/3$ shifted by HRAS) and the pressure $P = \rho\mathcal{R}T + aT^4/3$ at a chosen density ATMD0. Then, with $\log\tau$ as the variable, $$\frac{d\log P}{d\log\tau} = \frac{g\,\tau}{\kappa P},$$ up to $\tau = 2/3$ (Eddington; $\tau = 0.312$ for Krishna Swamy). If the starting $\tau$ lies beyond the end, the density is divided by 10 and the start retried.

The envelope. With $\log P$ as the variable and $y = (\log(m/M), \log T, \log r)$, QENV gives $$\frac{d\log m}{d\log P} = -\frac{4\pi r^4 P}{G m^2 f_P}, \qquad \frac{d\log T}{d\log P} = \nabla, \qquad \frac{d\log r}{d\log P} = -\frac{P r f_P}{G m \rho},$$ integrated with BSSTEP from the photosphere until $\log(m/M)$ reaches SENV; the step is shortened or reversed to land on it, and, when LSBC is false, the first step past PLIM is cut to end on it. The end point is interpolated linearly to SENV. If the envelope mass is negligible (SENV > -1e-12), the photosphere is the fitting point.

After the integration. The profile is reversed; for TAUCAL the masses are passed in grams (ENVS1) and as differences in units of the total mass (ENVS2, used only as weights in an average, so the unit cancels); the base of the convection zone is found by linear interpolation of $\nabla_\mathrm{rad} - \nabla$, and TAUCAL computes the overturn time (unless LNEWTCZ). With LCALCENV false, the routine stops after the atmosphere, having set PPHOT.

Design. The routine mixes physics with output for several purposes (the .store tables, pulsation files, acoustic-depth arrays), and each output path keeps its own copies of $\Gamma_1$ and related values. Failure to finish in 2000 steps stops the run. LDERIV is set by the pulsation test and then forced to .TRUE. on the next line.

KC's changes. 2025-05-30: the elements of /ENVSTRUCT/ and /ACDPTH/ reordered. 2025-05-31: the call to MEQOS no longer passes LDERIV, LATMO, KSAHA; ENVX removed from the call to TAUCAL.

Questions for the experts

  1. A broken swap. In the loop that reverses the envelope profile, ENVL is swapped without the line ENVL(I2) = DUM1 (added with "08/25 JVS"). The first half then gets the second half's values and the second half keeps its own, Since every entry of ENVL is B (the luminosity is constant in the envelope), nothing goes wrong now; the swap would fail only if ENVL ever varied.
  2. ENVG never set. The local array ENVG is passed to TAUCAL as HG (gravity) but never filled here. TAUCAL computes HG itself at the two points it needs when LROT is false; with rotation it uses HG as passed, so the overturn time of a rotating model would use an unset $g$. Should ENVINT fill ENVG?
  3. A computed overturn time not kept. TAUCZENV ($\sum \Delta r/v$ in the convection zone) is computed in the loop but never stored or returned. Dead code, or meant to feed TAUCZ?
  4. Wrong $c_P$ in a print. At the first atmosphere point, the printed $\Gamma_1$ uses QCPP ($\partial c_P/\partial\ln P$) in place of QCP. It affects only the .store output.
  5. Pulsation variables on other paths. The block run when LCLCD or LSTCH (not only for pulsation output) uses TAUP, OP, DP, which are set at the start only when LPULPT.AND.LPRT; otherwise they keep values from an earlier call.
  6. Two ways of storing the atmosphere. ATMOP, ATMOT, … are stored when LPRT.AND.LSTATM, but ATMOR, ADELS and NUMATM when LCLCD, LSTCH or pulsation output is on. Can the two be out of step for STITCH?
  7. No limit on retries. The retry with ATMDX/10 has no limit.
  8. A global switch. On an Allard failure, KTTAU is set to 0 in /ATMOS/, so the rest of the run uses gray atmospheres, even if a later model would fit the table.

SUBROUTINE ENVINT(B,FPL,FTL,GL,HSTOT,IE,LPRT,LSBC,PLIM,RL,TEFFL,

Integrates the atmosphere (gray $T$–$\tau$ or tabulated) and the envelope (in $\log P$, with BSSTEP and QENV) down to the fitting mass, returns the fitting point's $P$, $T$, $r$, stores the envelope profile in /ENVSTRUCT/, and finds the convection zone's base and overturn time.
