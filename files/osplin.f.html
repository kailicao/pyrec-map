Explanation

Purpose. Interpolation by a shape-preserving osculatory quadratic spline, from ACM Algorithm 574 (D. F. McAllister and J. A. Roulier, ACM Transactions on Mathematical Software, September 1981), as the header says. It interpolates the table (XTAB, YTAB) of N points to the K abscissas XVAL, and returns the values in YVAL.

How it fits.

  • Who calls it: the routines that move quantities between the model grid and an equally spaced grid: MIXCOM, MIXGRID, ROTGRID, GETGRID, EQ2MOD and HPOINT.
  • What it calls: SLOPES (the derivatives $m_i$ at the data points) and MEVAL (the evaluation; EPS $=10^{-4}$ is a relative error tolerance passed on to MEVAL's internal routine CHOOSE).

The method. The spline is quadratic between the data points, matches the values and the slopes $m_i$ there, and preserves the data's monotonicity and convexity (hence "shape-preserving"); the details are in SLOPES and MEVAL.

Questions for the experts

  1. The error flag. MEVAL returns an error code ERR (1 if some XVAL lies outside the table, 2 if XVAL is not increasing), which OSPLIN ignores. Should a failure be reported?
