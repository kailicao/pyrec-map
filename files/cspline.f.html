Explanation

Purpose. The second derivatives of a cubic spline through tabulated points, from Numerical Recipes (SPLINE), in double precision "for opacities".

How it fits.

  • Inputs: X(N) (increasing), Y(N), and the end slopes YP1, YPN; a slope of $10^{30}$ or more asks for a natural spline (zero second derivative) at that end.
  • Who calls it: the opacity routines GTLAOL, GTLAOL2, GTPURZ, SULAOL and ZSULAOL.
  • Output: Y2(N), the second derivatives, for a spline evaluation routine.

The method. Continuity of the first derivative at interior points gives the tridiagonal system $$\frac{h_{i-1}}{6}y''_{i-1} + \frac{h_{i-1} + h_i}{3}y''_i + \frac{h_i}{6}y''_{i+1} = \frac{y_{i+1} - y_i}{h_i} - \frac{y_i - y_{i-1}}{h_{i-1}},$$ with $h_i = x_{i+1} - x_i$, solved by forward elimination and back substitution.

Questions for the experts

  1. Size. The work array U has the fixed size JSON = 5000; N larger than that would overflow. Fine for opacity tables.
  2. Duplicates. The code base has several spline routines (spline.f, splinj.f, splinnr.f, …). Could one serve all callers in the overhaul?

16      SUBROUTINE CSPLINE(X, Y, N, YP1, YPN, Y2)
17      IMPLICIT REAL*8 (A-H,O-Z)
18      PARAMETER(JSON=5000)
19      DIMENSION X(N), Y(N), Y2(N), U(JSON)
20      SAVE
21      IF (YP1 .GT. 0.99D30) THEN
22         Y2(1) = 0.0D0
23         U(1) = 0.0D0
24      ELSE
25         Y2(1) = -0.5D0
26         U(1) = (3.D0/(X(2)-X(1)))*((Y(2)-Y(1))/(X(2)-X(1))-YP1)
27      ENDIF
28      DO I=2, N-1
29         SIG = (X(I)-X(I-1))/(X(I+1)-X(I-1))
30         P = SIG*Y2(I-1)+2.0D0
31         Y2(I) = (SIG-1.0D0)/P
32         U(I) = (6.0D0*((Y(I+1)-Y(I))/(X(I+1)-X(I))-(Y(I)-Y(I-1))
33     1          /(X(I)-X(I-1)))/(X(I+1)-X(I-1))-SIG*U(I-1))/P
34      END DO
35      IF (YPN .GT. 0.99D30) THEN
36         QN = 0.0D0
37         UN = 0.0D0
38      ELSE
39         QN = 0.5D0
40         UN = (3.D0/(X(N)-X(N-1)))*(YPN-(Y(N)-Y(N-1))/(X(N)-X(N-1)))
41      END IF
42      Y2(N) = (UN-QN*U(N-1))/(QN*Y2(N-1)+1.0D0)
43      DO K=N-1, 1, -1
44         Y2(K) = Y2(K)*Y2(K+1)+U(K)
45      ENDDO
46      RETURN
47      END
