3.14 Input, output and analysis

Model files. ModelFile is the base; each format is a subclass with read(star, ierr) and write(star, cfg, ierr), so that STARIN and the writers no longer branch on the format.

type, abstract :: ModelFile
    character(len=:), allocatable :: path
contains
    procedure(read_if), deferred :: read      !! (star, ierr)
    procedure(write_if), deferred :: write    !! (star, cfg, ierr)
end type
type, extends(ModelFile) :: Model2File   !! GETMODEL2, PUTMODEL2, WRTLST
type, extends(ModelFile) :: Yrec7File    !! GETYREC7, PUTYREC7 (read only?)
type, extends(ModelFile) :: StoreFile    !! PUTSTORE; stitched: STITCH

Writers. Logger owns the .short file and the levels of its messages (Section 6.2), and ShortWriter writes each model's block in it; TrackWriter writes the track and the per-model summary (WRTHEAD, WRTOUT, PINDEX); PulsationWriter decides when and writes the pulsation models (PDIST, WRTMOD). Analyses read a model and never change it: AcousticAnal (CALCAD, acoustic depths $t = \int dr/c_s$), MilneAnal (WRTMIL, the homology invariants $U$, $V$), OverturnAnal (GETTAU, TAUINT, TAUINTNEW, TAUCAL, the convective overturn time $\tau_\mathrm{cz}$ that the wind and the output need).

Replaces: GETMODEL2, GETYREC7, PUTMODEL2, PUTYREC7 (never called), WRTLST, PUTSTORE, STITCH, and the writers and analyses named above. PUTSTORE, "mostly a clone of wrtlst.f and putmodel2.f", becomes StoreFile%write calling the shared Model2File code for the model part. The small helpers SORT_SHELL, CINTERP3, HUNT, SAFEDIVEXP, SAFEDIVIDE and AZBAR move to numerics or stay private to their type.
