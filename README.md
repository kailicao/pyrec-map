# PyREC scaffolding, from YREC's development branch

**This site is under development and contains unvetted AI-generated content. It is not part of YREC's official documentation; please refer to the [YREC documentation](https://yrec.readthedocs.io/en/latest/).**

A map of [YREC](https://github.com/yreclab/yrec), the Yale Rotating Evolution Code, read at its development branch's commit 09c3b9b (Oct 20, 2026), built as scaffolding for developing PyREC, a Python version of the code. It is Kaili Cao's working material, drafted with AI (Claude); YREC's developers have not vetted it.

- **`yrec-map/`, the code as it is.** One page per source file in `src/`: what each routine does, its calls and modules, questions for the code's experts, and each routine's Python translation beside its Fortran (from the [pyrec](https://github.com/kailicao/pyrec) repository, as the translation proceeds).
- **`pyrec-map/`, the new structure.** One page per component, with its modern-Fortran design and its Python stubs. These are drafts.
- **Reviews.** One round of review of every page, shown folded at the end of the pages it concerns.

Open `index.html` in a browser, or the site at its GitHub Pages address once it is set up. Each folder holds its sources (`notes/`, `reviews/`) beside the pages generated from them; nothing in YREC was run.
