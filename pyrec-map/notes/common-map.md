# The COMMON-block map

*In Python: `pyrec`, under Python below.*

## 6.4 What replaces the COMMON blocks

Each block's contents go to the type that owns them, grouped by physics. Settings go into `Config`'s parts, state into the objects of [Section 3](overview.md), and the work arrays of one method become private components of its type. Mutable settings change owner: a switch that a routine turns off in the middle of a run (`LDIFY`, `LPTIME`, `KTTAU`) becomes state of the object that turns it off, so `Config` stays as read.

**The map follows YREC's development branch (09c3b9b).** rp_1 had 243 COMMON blocks; the development branch has none: it made the remaining blocks into 87 modules (`…_MOD`), merged some of them on the way, and turned others into arguments or local variables. The blocks of the options it removed (the MHD, OPAL 1995 and OPAL 2001 equations of state; the OPAL 1992, LAOL 1989, Alexander 1995 and Kurucz 1990 opacity tables, apart from LAOL's pure-$Z$ table; the Monte Carlo loop) went with them, and so did their rows here. Most settings are now in two modules: [[nmlpar_mod.f#NMLPAR_MOD|`NMLPAR_MOD`]] holds the namelist members of 62 former blocks, and [[nmlbypass_mod.f#NMLBYPASS_MOD|`NMLBYPASS_MOD`]] the namelist variables that `PARMIN` only uses to derive others (from six blocks). Each row below names the modules of 09c3b9b and, in parentheses, the blocks of rp_1 they came from; every module of 09c3b9b appears once, apart from `NMLPAR_MOD`, `NMLBYPASS_MOD` and `IOUNITS_MOD`, which are split by topic. Where a block "became arguments" or "became local", the page of the routine that now owns the values says so in its "Changed since `rp_1`" line.

A module per block, as in the development branch (its `F90_CONVERSION_PLAN.md`; no `COMMON` statement is left since its issue 37, [Section 7.3](overview.md)), is the first half of this map: it makes the data explicit but still global. The second half, done type by type in [Section 7.2](overview.md), moves each module's variables into the derived type above and deletes the module.
