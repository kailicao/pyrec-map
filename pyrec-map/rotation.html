In Python: pyrec.rotation, under Python below.

3.10 Rotation: Distortion, RotationLaw, RotationTransport, WindLaw, RotationStep

The design follows YREC's development branch (09c3b9b). It removed no rotation option, but deleted the uncalled WCZ, whose method WCZIMP now carries, and turned the COMMON blocks named here into modules or arguments (Section 6.4).

RotationStep. Responsibility: evolve the internal rotation over one model step, as GETW does: without instabilities, $\Omega$ from $j$ and the wind; with them, $N$ diffusion substeps, each with the structure interpolated in time, the wind, mixing of convection zones, and transport of angular momentum and composition.

type :: RotationStep
    type(Distortion) :: dist
    type(RotationLaw) :: law
    type(RotationTransport) :: transport
    class(WindLaw), allocatable :: wind        !! Absent: no wind.
contains
    procedure :: run
        !! (star, start, zones, dt, ierr) GETW. Substeps
        !! N = min(ceil(DWMAX/DTDIF), ceil(DTWIND/DTDIF)).
    procedure, private :: midstep   !! (star, start, f) MIDMOD at fraction f.
    procedure, private :: check_j   !! CHECKJ: j > 0, convergence, Omega.
    procedure, private :: check_comp !! CHECKC: 0 <= X <= 1, cut substep.
end type

type :: Distortion
contains
    procedure :: factors   !! (star) FPFT with SHAPE, FUNC: f_P, f_T, <g>.
    procedure :: inertia   !! (star) MOMI, INTMOM: I and dI/dOmega.
    procedure :: quadrupole !! (star) GETQUA: the P2 potential (Zahn 1992).
end type

type :: RotationLaw
contains
    procedure :: omega_from_j  !! (star, lcz) GETROT; zones by WCZIMP.
    procedure :: solid_body    !! (star, jstart, jend) SOLID.
end type

type :: RotationTransport
    !! Diffusion coefficients and velocities on the interfaces (VCIRC);
    !! factors FW, FC, FES, FGSF, FMU, FSS (NMLPAR_MOD), Config%rot.
contains
    procedure :: secular
        !! (star, zones, dt, redo, ierr) SECULR: transport of j and of the
        !! composition by meridional circulation, GSF, secular and dynamical
        !! shear; redo : the substep must be shortened (LREDO).
end type

type, abstract :: WindLaw
contains
    procedure(dj_if), deferred :: domega
        !! (star, dt, dw) Change of the surface zone's Omega [rad s-1].
end type
type, extends(WindLaw) :: KawalerWind     !! WIND, COWIND
type, extends(WindLaw) :: MattWind        !! MWIND, MCOWIND, AMCALC

Replaces: GETW, MIDMOD, CHECKJ, CHECKC, ROTMIX, BURSMIX and BSROTMIX (never run: LBURS is false; kept only if KC wants them, Section 8); FPFT, SHAPE, FUNC, MOMI, INTMOM, GETQUA; GETROT, WCZIMP, SOLID (WCZIMP also does the work of WCZ, uncalled at rp_1 and since removed); SECULR, VCIRC, SETUPV, CODIFF, GETFC, DADCOEFT, DCOEFT, CCOEFT, ROTGRID, EQ2MOD, NDIFCOM; WIND, COWIND, MWIND, MCOWIND, AMCALC. Angular momentum and composition are transported by diffusion equations of the form $$\rho r^2\,\frac{\partial j}{\partial t} = \frac{1}{r^2}\frac{\partial}{\partial r}\Bigl(\rho r^4 D_J\,\frac{\partial\Omega}{\partial r}\Bigr),$$ with $D_J$ from the instabilities' velocities, solved on the ChiGrid. The many work modules that SETUPV and VCIRC share (INTVAR_MOD, VFACT_MOD, TAUKH_MOD, DIFAD2_MOD, DIFAD3_MOD; COMMON blocks at rp_1, where /DIFAD4/ was a third, now gone) become components of RotationTransport, private to it.

3.11 Mass loss: MassLossLaw, MassLoss

Responsibility: set the rate $\dot M$ by a law, and apply the change of mass to the model, its convection zone and its angular momentum.

type, abstract :: MassLossLaw
contains
    procedure(mdot_if), deferred :: rate
        !! (star) -> real(dp) dM/dt [Msun yr-1], < 0 for loss.
end type
type, extends(MassLossLaw) :: ConstantMassLoss   !! DMDT0
type, extends(MassLossLaw) :: ReimersMassLoss    !! CREIM, LREIMER

type :: MassLoss
    class(MassLossLaw), allocatable :: law
    real(dp) :: comp_acc(NSP)          !! Accreted composition (COMPACC).
contains
    procedure :: apply
        !! (star, dt, ierr) MASSLOSS, MDOT: limit the mass removed, rescale
        !! the mass coordinates, remove J, mix accreted matter in the CZ.
end type

Replaces: MASSLOSS, MDOT. The argument mismatch between them (MAIN question 2 at rp_1) cannot survive a checked interface; the development branch has already fixed it ("fix a CALL MDOT mismatch", Section 7.3). MASSLOSS's header calls it "experimental code and valid for Allard atmospheres only"; the design keeps it as it is and says so in the type's docstring.
