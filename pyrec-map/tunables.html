Tunable numbers

In Python: pyrec, under Python below.

The notes found these values written into the code. The table follows YREC's development branch (09c3b9b): the values of the Monte Carlo option (the base luminosity SUNL of its draws, its ages and its limit of 1000 parameter sets) and the KRA lists of the OPAL 1995 and 2001 equations of state went with those options, and are no longer here. Each becomes an UPPERCASE named constant in the module or type that uses it, with its unit and source in a comment, or a configuration entry where users already change it or should be able to. "Config" means a namelist entry with today's value as its default, so that results do not change.
