Purpose

KSPLINT evaluates at $x$ the 4-point cubic spline whose second derivatives KSPLINE computed (Numerical Recipes' SPLINT, with NM = 4 fixed).

How it fits

Called by the same routines as KSPLINE: KCSURFP, SURFP, EQSCVE, TAUINTNEW. No calls; it uses IOUNITS_MOD for the unit ISHORT of its error message.

The method

It finds the interval $[x_\mathrm{lo}, x_\mathrm{hi}]$ by bisection, then with $h = x_\mathrm{hi}-x_\mathrm{lo}$, $A = (x_\mathrm{hi}-x)/h$, $B = (x-x_\mathrm{lo})/h$:

$$y = A\,y_\mathrm{lo} + B\,y_\mathrm{hi} + \frac{h^2}{6}\left[(A^3-A)\,y''_\mathrm{lo} + (B^3-B)\,y''_\mathrm{hi}\right].$$

Outside the 4 points it extrapolates with the end interval's cubic. If two nodes coincide it stops the run (STOP 1), with a message giving the node and $x$, written to the terminal and to ISHORT.
