Purpose

"Model to equal" for the older settling routine GRSETT: it interpolates the diffusion coefficients and the abundances from the model points to an equally spaced grid in radius, at the grid points and at the midpoints. MICRODIFF_MTE is its newer counterpart, for MICRODIFF.

How it fits

  • Inputs: the coefficients COD1, COD2 and their derivatives with respect to $X$, QCOD1X, QCOD2X, at the model points (from SETUP_GRSETT); the metal coefficients COD1Z, COD2Z, QCOD1Z, QCOD2Z (arguments, formerly /GRAVSZ/: SETUP_GRSETT fills them in arrays GRSETT owns); HCOMP, the radii HRU and masses HS1 in Bahcall–Loeb units; IBEGIN, IEND, M.
  • Who calls it: only GRSETT.
  • What it calls: INTERP (four-point Lagrange weights).
  • Outputs: NPT, DR, the grid radii ER, and on the points and midpoints: masses (EM, EM_H), coefficients (ECOD1, ECOD1_H, ECOD2_H, EQCOD1X_H, EQCOD2X_H) and hydrogen (EX, EX_H). For metals (LDIFZ), the same in GRAVEZ_MOD, which LAX_WENDROF1, LAX_WENDROF2, GRSETT and EQUAL_TO_MODEL read.
  • Modules: NMLPAR_MOD (LDIFZ), GRAVEZ_MOD (written), DIMENSIONS_MOD (JSON).

The method

As in MICRODIFF_MTE: the number of points $N = \lceil (r_\mathrm{end}-r_\mathrm{begin})/\Delta r_\mathrm{min}\rceil$ (at least 4, at most JSON), here with $\Delta r_\mathrm{min}$ the smallest spacing over the whole region; the first midpoint by linear interpolation, the others by four-point Lagrange interpolation, $f(r) = \sum_{k=1}^4 w_k(r)\,f_{k_0+k-1}$; the end points take the model's values. The midpoint search for the first midpoint runs over the wrong range of indices (suspected bug 1).

The metals' abundances on the grid, EZ and EZ_H, are interpolated from HCOMP(8,·) (¹⁵N in MIX), not from $Z$ (HCOMP(3,·)); this does not change the result: LAX_WENDROF1 overwrites EZ_H(1..NPT-1), and GRSETT returns only the change EZ - EZ_ORIG, in which the starting values cancel, while the change itself comes from COD1Z, which SETUP_GRSETT computes from $Z$ (settled from the code, Nov 9, 2026: line 108↗, lines 189–190↗, line 209↗, lines 260–261↗, line 271↗; lax_wendrof1.f, lines 59–74↗; grsett.f, lines 149–153↗, grsett.f, lines 259–265↗; setup_grsett.f, line 209↗, setup_grsett.f, line 311↗).

ER holds the midpoints' radii while the midpoints are interpolated, and is then overwritten with the grid points' radii (lines 76–85↗; lines 195–198↗); the caller needs only the latter, for EQUAL_TO_MODEL (settled from the code, Nov 9, 2026: grsett.f, lines 269–270↗). The "center derivative" block computes FAC1, FAC2, and DELR (from DR1, DR2), which nothing reads (lines 110–125↗: unused?); the line IF(I-1 .EQ. 0) PRINT*, 'mte line 47' cannot fire, since I starts at 2, and names the other file (line 82↗: unused?); and the branch for NPT .EQ. 2 (lines 78–79↗) can no longer be taken, since NPT is at least 4 (unused?).

Suspected bugs, checked by running the code

Each bug is marked by what running the code showed: (changes results, large) or (small), the fix moving a run clearly beyond a null change; (stops the run); (wrong output), the fix changing only what is written; (harmless in the runs), within the noise; (never occurred), the code ran but the fault did not; (not reached); (cannot be reached), a guard prevents it; (withdrawn), the suspicion was wrong.

1. (not reached) The first midpoint's search runs over the wrong indices.

(lines 91–97↗) The search for the model point above the first midpoint ER(1) runs over IU = 2..NPT: model indices from 2, bounded by the number of equal-grid points, rather than IBEGIN+1..IEND. Since NPT is at least IEND - IBEGIN (every model spacing in the range is at least DRMIN), the search finds the right point whenever IBEGIN + 1 <= NPT; when IBEGIN is larger (a large convective or hydrogen-exhausted core under a radiative zone of few, evenly spaced shells), IU falls back to NPT, and the first midpoint's mass, coefficients, and $X$ are extrapolated from two points far below it. Whether models reach this case was not traced. Only with LDIFY (off by default) and LNEWDIF false (the default).

16# The Fortran's local arrays (SAVE).
17facinterp = np.zeros(5)
18facderiv = np.zeros(5)
19tabler = np.zeros(5)

22def _lagrange(f: np.ndarray, k0: int) -> float:
23    """FACINTERP(1)*F(K0) + ... + FACINTERP(4)*F(K0+3), in the Fortran's
24    order.
25
26    """
27
28    return (facinterp[1] * f[k0] + facinterp[2] * f[k0 + 1]
29            + facinterp[3] * f[k0 + 2] + facinterp[4] * f[k0 + 3])

32def _find_k0(r: float, jmin: int, iend: int, m: int, hru: np.ndarray) -> tuple[int, int]:
33    """Labels 20/30 (and 80/90): the first model point J >= JMIN at or
34    above radius r gives the four interpolation points K0..K0+3, kept
35    inside 1..M; returns (k0, jmin) (Fortran lines 133–146, 219–232).
36
37    """
38
39    for j in range(jmin, iend + 1):
40        if hru[j] >= r:
41            k0 = max(j - 2, 1)
42            k0 = min(k0, m - 3)
43            return k0, j
44    return m - 3, m

47def model_to_equal(cod1: np.ndarray, cod2: np.ndarray, hcomp: np.ndarray, hru: np.ndarray, hs1: np.ndarray, ibegin: int,
48                   iend: int, m: int, qcod1x: np.ndarray, qcod2x: np.ndarray, dr: float, ecod1: np.ndarray,
49                   ecod1_h: np.ndarray, ecod2_h: np.ndarray, em: np.ndarray, em_h: np.ndarray, eqcod1x_h: np.ndarray,
50                   eqcod2x_h: np.ndarray, er: np.ndarray, ex: np.ndarray, ex_h: np.ndarray, npt: int, cod1z: np.ndarray,
51                   cod2z: np.ndarray, qcod1z: np.ndarray, qcod2z: np.ndarray) -> tuple[float, int]:
52    """Interpolate the settling coefficients and abundances of GRSETT from
53    the model points (ibegin..iend) to an equally spaced grid in radius, at
54    the grid points and the midpoints (_h).
55
56    Translates: model_to_equal.f#MODEL_TO_EQUAL (7be4133)
57
58    Arguments: the coefficients cod1, cod2, their derivatives in X qcod1x,
59    qcod2x, and the metal ones cod1z, cod2z, qcod1z, qcod2z (from
60    SETUP_GRSETT); hcomp[k, j], the radii hru and masses hs1 (Bahcall-Loeb
61    units); m shells. dr and npt are passed in with any value. Arrays have
62    index 0 unused.
63
64    Sets in place: em, ex, ecod1 on the grid points; em_h, ecod1_h, ecod2_h,
65    eqcod1x_h, eqcod2x_h, ex_h on the midpoints; er (the grid radii, after
66    holding the midpoints' radii); with LDIFZ, the metal arrays of
67    gravez_mod.
68
69    Returns (dr, npt): the grid spacing and the number of grid points.
70
71    """
72
73    gz = gravez_mod
74    ldifz = nmlpar_mod.ldifz
75
76    # The minimum model point spacing in radius, over the whole region
77    # (Fortran lines 55–59).
78    drtot = hru[iend] - hru[ibegin]
79    drmin = drtot
80    for i in range(ibegin + 1, iend + 1):
81        drmin = min(drmin, hru[i] - hru[i - 1])
82
83    # The minimum number of equally spaced points such that DR <= DRMIN, at
84    # least 4 for the 4-point Lagrange stencils (Fortran lines 62–73).
85    npt = int(drtot / drmin)
86    if math.fmod(drtot, drmin) != 0.0:
87        npt = npt + 1
88    npt = max(npt, 4)
89    npt = min(npt, JSON)
90    dr = drtot / float(npt - 1)
91
92    # Equally spaced radii at the zone midpoints, held in ER for now
93    # (Fortran lines 76–85). The NPT == 2 branch cannot be taken.
94    er[1] = hru[ibegin] + 0.5 * dr
95    if npt == 2:
96        er[2] = er[1] + dr
97    else:
98        for i in range(2, npt):  # DO 10 (its debug PRINT can never fire)
99            er[i] = er[i - 1] + dr
100
101    # First midpoint: linear interpolation (Fortran lines 91–109).
102    # Suspected bug (see the page): the search runs over model indices
103    # 2..NPT.
104    iu = npt
105    for k in range(2, npt + 1):  # DO 15
106        if hru[k] >= er[1]:
107            iu = k
108            break
109    fx = (er[1] - hru[iu - 1]) / (hru[iu] - hru[iu - 1])
110
111    def lin(f):
112        return f[iu - 1] + fx * (f[iu] - f[iu - 1])
113
114    em_h[1] = lin(hs1)
115    ecod1_h[1] = lin(cod1)
116    ecod2_h[1] = lin(cod2)
117    eqcod1x_h[1] = lin(qcod1x)
118    eqcod2x_h[1] = lin(qcod2x)
119    ex_h[1] = hcomp[1, iu - 1] + fx * (hcomp[1, iu] - hcomp[1, iu - 1])
120    if ldifz:
121        gz.ecod1z_h[1] = lin(cod1z)
122        gz.ecod2z_h[1] = lin(cod2z)
123        gz.eqcod1z_h[1] = lin(qcod1z)
124        gz.eqcod2z_h[1] = lin(qcod2z)
125        # Row 8, not row 3 (Z); its values cancel in GRSETT's change.
126        gz.ez_h[1] = hcomp[8, iu - 1] + fx * (hcomp[8, iu] - hcomp[8, iu - 1])
127
128    # "Center derivative": FAC1, FAC2, DELR are never used (Fortran lines
129    # 111–125).
130    dr1 = er[1] - hru[iu - 1]
131    dr2 = hru[iu] - er[1]
132    if dr2 > dr1:
133        fac1, fac2, delr = 1.0, dr1 / dr2, 2.0 * dr1  # noqa: F841  (unused in the Fortran too)
134    elif dr1 > dr2:
135        fac1, fac2, delr = dr2 / dr1, 1.0, 2.0 * dr2  # noqa: F841  (unused in the Fortran too)
136    else:
137        fac1, fac2, delr = 1.0, 1.0, dr1 + dr2  # noqa: F841  (unused in the Fortran too)
138
139    # Other midpoints: 4-point Lagrange interpolation (Fortran lines
140    # 131–192).
141    jmin = ibegin + 1
142    for i in range(2, npt):  # DO 50
143        k0, jmin = _find_k0(er[i], jmin, iend, m, hru)
144        for k in range(1, 5):
145            tabler[k] = hru[k0 + k - 1]
146        interp(tabler, facinterp, facderiv, er[i])
147        em_h[i] = _lagrange(hs1, k0)
148        ecod1_h[i] = _lagrange(cod1, k0)
149        ecod2_h[i] = _lagrange(cod2, k0)
150        eqcod1x_h[i] = _lagrange(qcod1x, k0)
151        eqcod2x_h[i] = _lagrange(qcod2x, k0)
152        ex_h[i] = _lagrange(hcomp[1, :], k0)
153        if ldifz:
154            # Metal diffusion, treated as fully ionized iron.
155            gz.ecod1z_h[i] = _lagrange(cod1z, k0)
156            gz.ecod2z_h[i] = _lagrange(cod2z, k0)
157            gz.eqcod1z_h[i] = _lagrange(qcod1z, k0)
158            gz.eqcod2z_h[i] = _lagrange(qcod2z, k0)
159            gz.ez_h[i] = _lagrange(hcomp[8, :], k0)
160
161    # Equally spaced radii at the zone centers (Fortran lines 195–198).
162    er[1] = hru[ibegin]
163    for i in range(2, npt + 1):
164        er[i] = er[i - 1] + dr
165
166    # First point: by definition, at the starting point (Fortran lines
167    # 205–211).
168    em[1] = hs1[ibegin]
169    ex[1] = hcomp[1, ibegin]
170    ecod1[1] = cod1[ibegin]
171    if ldifz:
172        gz.ez[1] = hcomp[8, ibegin]
173        gz.ecod1z[1] = cod1z[ibegin]
174
175    # Other points: 4-point Lagrange interpolation (Fortran lines 217–263).
176    jmin = ibegin + 1
177    for i in range(2, npt):  # DO 70
178        k0, jmin = _find_k0(er[i], jmin, iend, m, hru)
179        for k in range(1, 5):
180            tabler[k] = hru[k0 + k - 1]
181        interp(tabler, facinterp, facderiv, er[i])
182        em[i] = _lagrange(hs1, k0)
183        ecod1[i] = _lagrange(cod1, k0)
184        ex[i] = _lagrange(hcomp[1, :], k0)
185        if ldifz:
186            gz.ecod1z[i] = _lagrange(cod1z, k0)
187            gz.ez[i] = _lagrange(hcomp[8, :], k0)
188
189    # Last point: by definition, at the ending point (Fortran lines
190    # 266–273).
191    em[npt] = hs1[iend]
192    ex[npt] = hcomp[1, iend]
193    ecod1[npt] = cod1[iend]
194    if ldifz:
195        gz.ez[npt] = hcomp[8, iend]
196        gz.ecod1z[npt] = cod1z[iend]
197
198    return dr, npt
