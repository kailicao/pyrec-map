Explanation

Purpose. "Model to equal" for the older settling routine GRSETT: it interpolates the diffusion coefficients and the abundances from the model points to an equally spaced grid in radius, at the grid points and at the midpoints. MICRODIFF_MTE is its newer counterpart, for MICRODIFF.

How it fits.

  • Inputs: the coefficients COD1, COD2 and their derivatives with respect to $X$, QCOD1X, QCOD2X, at the model points (from SETUP_GRSETT); the metal coefficients COD1Z, COD2Z, QCOD1Z, QCOD2Z (arguments, formerly /GRAVSZ/: SETUP_GRSETT fills them in arrays GRSETT owns); HCOMP, the radii HRU and masses HS1 in Bahcall–Loeb units; IBEGIN, IEND, M.
  • Who calls it: only GRSETT.
  • What it calls: INTERP (four-point Lagrange weights).
  • Outputs: NPT, DR, the grid radii ER, and on the points and midpoints: masses (EM, EM_H), coefficients (ECOD1, ECOD1_H, ECOD2_H, EQCOD1X_H, EQCOD2X_H) and hydrogen (EX, EX_H). For metals (LDIFZ), the same in GRAVEZ_MOD, which LAX_WENDROF1, LAX_WENDROF2, GRSETT and EQUAL_TO_MODEL read.
  • Modules: NMLPAR_MOD (LDIFZ), GRAVEZ_MOD (written), DIMENSIONS_MOD (JSON).

The method. As in MICRODIFF_MTE: the number of points $N = \lceil (r_\mathrm{end}-r_\mathrm{begin})/\Delta r_\mathrm{min}\rceil$ (at least 2, at most JSON), here with $\Delta r_\mathrm{min}$ the smallest spacing over the whole region; the first midpoint by linear interpolation, the others by four-point Lagrange interpolation, $f(r) = \sum_{k=1}^4 w_k(r)\,f_{k_0+k-1}$; the end points take the model's values.

KC's changes. 2025-05-31: the unused arguments HQPR and HTU removed.

Changed since rp_1. The metal coefficients COD1Z, COD2Z, QCOD1Z, QCOD2Z are four new last arguments (formerly /GRAVSZ/); COMMON blocks to modules, IMPLICIT NONE. No question is settled.

Questions for the experts

  1. The metals come from row 8. EZ and EZ_H are interpolated from HCOMP(8,·), while EQUAL_TO_MODEL applies the change to HCOMP(3,·) ($Z$), and MIX names row 8 ¹⁵N (XN15). Is row 8 a mistake for row 3? If so, the old routine's metal settling has been computed from the ¹⁵N profile.
  2. Unused derivative factors. The "center derivative" block computes FAC1, FAC2 and DELR, which are never used.
  3. The first midpoint's search. As in MICRODIFF_MTE, the search runs over model indices 2..NPT (bounded by the number of grid points) rather than IBEGIN+1..IEND.
  4. Midpoint radii lost. ER first holds the midpoint radii and is then overwritten with the grid points' radii, so the caller never sees the midpoints' radii. Intended?
  5. A debugging line. IF(I-1 .EQ. 0) PRINT*, 'mte line 47' cannot fire, and names the other file.

45    the model points (ibegin..iend) to an equally spaced grid in radius, at

51    qcod2x, and the metal ones cod1z, cod2z, qcod1z, qcod2z (from
52    SETUP_GRSETT); hcomp[k, j], the radii hru and masses hs1 (Bahcall-Loeb
53    units); m shells. dr and npt are passed in with any value. Arrays have
54    index 0 unused.

62    """
63    gz = gravez_mod
64    ldifz = nmlpar_mod.ldifz
65    # The minimum model point spacing in radius, over the whole region.
66    drtot = hru[iend] - hru[ibegin]
67    drmin = drtot
68    for i in range(ibegin + 1, iend + 1):
69        drmin = min(drmin, hru[i] - hru[i - 1])
70    # The minimum number of equally spaced points such that DR <= DRMIN.
71    npt = int(drtot / drmin)
72    if math.fmod(drtot, drmin) != 0.0:
73        npt = npt + 1
74    # JvS: trap for models with NPT = 1.
75    if npt == 1:
76        npt = npt + 1
77    npt = min(npt, JSON)
78    dr = drtot / float(npt - 1)
79
80    # Equally spaced radii at the zone midpoints (held in ER for now).
81    # Question (see the page): ER is overwritten below.
82    er[1] = hru[ibegin] + 0.5 * dr
83    if npt == 2:
84        er[2] = er[1] + dr
85    else:
86        for i in range(2, npt):  # DO 10 (its debug PRINT can never fire)
87            er[i] = er[i - 1] + dr
88
89    # First midpoint: linear interpolation.
90    # Question (see the page): the search runs over model indices 2..NPT.
91    iu = npt
92    for k in range(2, npt + 1):  # DO 15
93        if hru[k] >= er[1]:
94            iu = k
95            break
96    fx = (er[1] - hru[iu - 1]) / (hru[iu] - hru[iu - 1])
97
98    def lin(f):
99        return f[iu - 1] + fx * (f[iu] - f[iu - 1])
100
101    em_h[1] = lin(hs1)
102    ecod1_h[1] = lin(cod1)
103    ecod2_h[1] = lin(cod2)

28def _find_k0(r, jmin, iend, m, hru):
