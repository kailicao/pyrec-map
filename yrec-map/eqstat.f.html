Purpose

EQSTAT is the equation of state that the rest of YREC calls. Its header says it was added ("LLP 10-22-06") as a "new front end" so that the derivatives of the equation of state can be computed numerically, by calling the older routine, now EQSTAT2, at neighbouring points. All the physics is in EQSTAT2.

How it fits

  • Who calls it: ten routines across the code: COEFFT, ENVINT, HSUBP, MASSLOSS, PHYSIC, QATM, QENV, SCONVEC, STARIN and WRTOUT.
  • Inputs: TL, PL ($\log_{10}$ of $T$ in $\mathrm{K}$ and $P$ in $\mathrm{dyn\,cm^{-2}}$), X, Z, and the flags LDERIV (second derivatives wanted) and LATMO (atmosphere). DL serves as a starting guess.
  • What it calls: only EQSTAT2.
  • Outputs: those of EQSTAT2: T, P, D, DL, BETA, FXION, RMU, AMU, EMU, ETA, QDT $=\partial\ln\rho/\partial\ln T|_P$, QDP $=\partial\ln\rho/\partial\ln P|_T$, QCP ($c_P$), DELA ($\nabla_\mathrm{ad}$), and the derivatives QDTT, QDTP, QAT, QAP, QCPT, QCPP.
  • Modules: it reads only CLN ($\ln 10$, from CONSTANTS_MOD) and LNumDeriv (from NMLPAR_MOD, set in the PHYSICS namelist read by PARMIN).

The method

If LDERIV and LNumDeriv are both set, EQSTAT2 is called four times without derivatives, at $\log T \pm h_T$ and $\log P \pm h_P$, with $h_T = 3\times10^{-4}$ and $h_P = 1.5\times10^{-3}$ (the "approximate table intervals," 0.03 and 0.15, scaled down by 100: "empirically, scaling the intervals down by 100 seemed to work best"). Central differences give the second derivatives, for example $$\frac{\partial Q_{\rho T}}{\partial\ln T} = \frac{Q_{\rho T}^{+} - Q_{\rho T}^{-}}{2h_T\ln 10},\qquad \frac{\partial\log c_P}{\partial\log T} = \frac{\log c_P^{+} - \log c_P^{-}}{2h_T},\qquad \frac{\partial\log\nabla_\mathrm{ad}}{\partial\log T} = \frac{\log\nabla_\mathrm{ad}^{+} - \log\nabla_\mathrm{ad}^{-}}{2h_T},$$ and the same in $\log P$. A last call at the point itself, without derivatives, gives the values; its derivative outputs go to dummy variables so they cannot overwrite the numerical ones. Otherwise EQSTAT2 is called once, with analytic derivatives if LDERIV is set. The second derivatives are needed because the Henyey method linearizes the structure equations in $\ln P$ and $\ln T$: TPGRAD differentiates the temperature gradient (QAT, QAP $=\partial\ln\nabla_\mathrm{ad}/\partial\ln T, \partial\ln P$, and QCPT, QDTT, QDTP for the convective gradient), and COEFFT differentiates $\epsilon_\mathrm{grav}$, which contains $Q_{\rho T}$ and $\nabla_\mathrm{ad}$ (QDTT, QDTP, QAT, QAP). The symbols are in the overview's Notation: $Q_{\rho T}$ = QDT $= -\delta$ and $Q_{\rho P}$ = QDP $= \alpha$ in the notation of Kippenhahn, Weigert & Weiss.

Question 1 (lines 96–100↗; eqstat2.f, lines 192–202↗). The step size. The steps are 1/100 of an assumed table spacing of 0.15 in $\log P$ and 0.03 in $\log T$. EQSTAT2's own comment gives the SCV tables' spacing as 0.20 and 0.08. Was the step tested for each table EQSTAT2 can use?

From YREC's documentation

Microphysics in YREC: LNUMDERIV (default false) replaces YREC's semi-analytic EOS derivatives by numerical ones from the OPAL tables, at about three times the cost and with little effect on the solution.

1. (harmless in the runs) A misspelled counter.

(line 31↗; line 85↗; lines 111–113↗) The line KSSAHAx = KSAHA assigns a misspelled variable (declared as KSSAHAX, so IMPLICIT NONE does not flag it), and KSSAHAX is never read; the four derivative calls then pass KSAHAx, a saved local with no DATA, which is never set. KSAHA is only an iteration counter of EQSAHA (eqsaha.f, line 95↗), and KSAHAx is never copied back, so no result changes today: The caller's counter misses the derivative calls' iterations either way, and KSAHAx grows from an undefined start. Only with LNumDeriv (off by default, nmlpar_mod.f, line 123↗).

194# --- The dispatch as a kernel, for chains (the envelope's derivative kernels, qatm.py and qenv.py) ----------------
195#
196# _eqstat_k is eqstat's dispatch without numerical derivatives (the chain's callers check LNUMDERIV): one call of
197# eqstat2's kernel, LDERIV as passed. The module scalars a chain of calls carries are in an integer array (EIST):
198# scveos_mod's IDTSCV and IDP, eos06misc_mod's K3 and L2 (brought forward from esac06's st after each call, as the
199# next call reads them), esac06's flags st[13:16] OR'ed over the calls, and KSSAHAX. eos_in() fills it, eos_out()
200# writes it back (esac06.finish called once for the merged flags), as coefft.py's kernel does. A call with a message
201# or a status stops the chain (stop true): its 28 values are left for eos_tail(), the plain code's lines.
202
203EIST = 8      # idtscv, idp, k3, l2, f13, f14, f15, kssahax
204
205
206def eos_args() -> tuple:
207    """The scalars eqstat2's kernel reads that the envelope's chain does not change, and its two groups of module
208    arrays, as named tuples (esac06.eos_tuple, eqstat2.eq2_tuple: a structure inside this tuple would make Numba type
209    the chain's whole context in Python at each call)."""
210    c = constants_mod
211    nml = nmlpar_mod
212    cmp = comp_mod
213    dh = debhu_mod
214    return (c.cln, c.ca3, c.cgas, c.cmkh, c.clni, nml.tscut, nml.ldifz, nml.lscv, nml.lopale06, nml.ldh,
215            nml.etadh0, nml.etadh1, cmp.xenv, cmp.zenv, cmp.amuenv, dh.cdh, dh.xxdh, dh.yydh, dh.zzdh,
216            esac06_mod.eos_tuple(), eqstat2_mod.eq2_tuple())
217

219def eos_in(ist: np.ndarray) -> None:
220    """The chain's integer state from the modules (EIST)."""
221    m = eos06misc_mod
222    ist[0] = scveos_mod.idtscv
223    ist[1] = scveos_mod.idp
224    ist[2] = m.k3
225    ist[3] = m.l2
226    ist[4] = 0
227    ist[5] = 0
228    ist[6] = 0
229    ist[7] = -1
230
231
232def eos_out(ist: np.ndarray) -> None:
233    """The chain's integer state back to the modules: scveos_mod's stencil, eqstat's KSSAHAX (if a call was made),
234    and esac06's module scalars as the last call to set each left them (esac06.finish, no messages)."""
235    global kssahax
236    idtscv, idp, _, _, f13, f14, f15, kx = ist.tolist()
237    scveos_mod.idtscv, scveos_mod.idp = idtscv, idp
238    if kx >= 0:
239        kssahax = kx
240    if f13 or f14 or f15:
241        st = esac06_mod.st
242        st[12] = 0
243        st[13] = f13
244        st[14] = f14
245        st[15] = f15
246        esac06_mod.finish(0, 0.0, 0.0, 0.0)

249def eos_tail(r: np.ndarray, tl: float, pl: float, x: float, z: float, fxion: np.ndarray) -> None:
250    """What eqstat2's wrapper does after its kernel, for a call that stopped the chain: the messages, scveos_mod's
251    stencil, and esac06.finish, from the kernel's 28 values in r (eqstat2._eqstat2_fast's lines, in its order; the
252    earlier calls' esac06 flags were merged into st by the kernel and their module scalars written back by
253    eos_out)."""
254    scv = scveos_mod
255    flags = int(r[24])
256    status, rlast, t6 = int(r[25]), float(r[26]), float(r[27])
257    if flags & 1:
258        fo = eqstat2_mod.fo
259        iounits_mod.write(iounits_mod.ishort, f" EQSTAT2: BETA is negative: TL,PL,BETA,1-BETA "
260                                              f"{tl} {pl} {float(fo[0])} {1.0 - float(fo[0])}")
261    if flags & 2:
262        eqsaha_mod._failure(tl, pl)
263    if flags & 4:
264        eqrelv_mod._failure(tl, pl)
265    if flags & 16:
266        eqscve(tl, r[0], r[1], r[2], r[3], x, z, r[4], fxion, r[11], r[12], r[13], r[14], False)
267        raise RuntimeError("eqstat2's kernel: eqscve stopped, the plain code did not")
268    scv.idtscv, scv.idp = int(r[22]), int(r[23])
269    st = esac06_mod.st
270    if rlast != 0.0:
271        esac06_mod.finish(status, x, t6, rlast)
272    elif st[13] or st[14] or st[15]:
273        esac06_mod.finish(0, 0.0, 0.0, 0.0)
274    if flags & 8:
275        iounits_mod.write(iounits_mod.ishort, " WARNNING... OPAL TBL FAIL")

279def _eqstat_k(tl: float, pl: float, x: float, z: float, fxion: np.ndarray, lderiv: bool, latmo: bool, ksaha: int,
280              ea: tuple, ist: np.ndarray, r: np.ndarray) -> bool:
281    """eqstat's dispatch without numerical derivatives, through eqstat2's kernel, for a chain.
282
283    Parameters
284    ----------
285    tl, pl, x, z, lderiv, latmo, ksaha
286        As eqstat's; T, P, DL, D, and the derivatives passed in are zero, as qatm and qenv pass them.
287    fxion : np.ndarray, shape: `(4,)`, dtype: ``float``
288        Set: the ionization fractions (index 0 unused).
289    ea : tuple
290        OOP eos: (eos_args(), the EOS family's data, eqsaha's starting guess, a composition array of shape (16,))
291        (families.eos_chain_args()); the first is the chain's own (its Debye-Hueckel X, Y, Z and esac06's flags),
292        the others go to `eos_point`. The envelope's composition is X and Z only (qenv's and qatm's arguments), so
293        the composition array gets X, 1 - X - Z, Z in [1:4] and zeros after.
294    ist : np.ndarray, shape: `(EIST,)`, dtype: ``int64``
295        The chain's EOS state, read and updated.
296    r : np.ndarray, shape: `(28,)` or more, dtype: ``float``
297        Set: eqstat2's 22 values, then IDTSCV, IDP, the message flags, esac06's status, density, and T6. Without
298        LDERIV, eqstat passes zeros for QDTT ... QCPP and keeps them, so r[15:21] are zero.
299
300    Returns
301    -------
302    bool
303        True when the call has a message or a status for the plain code (eos_tail); the earlier calls' esac06
304        flags are then merged into st.
305
306    """
307    ec, data, ssv, comp = ea                        # OOP eos: the chain's context, the family's data, the guess
308    comp[1] = x                                     # OOP eos: the envelope's composition, as far as it is known
309    comp[2] = 1.0 - x - z
310    comp[3] = z
311    xxdh = ec[16]
312    yydh = ec[17]
313    zzdh = ec[18]
314    ist[7] = ksaha                                  # KSSAHAX = KSAHA (eqstat's misspelling)
315    # OOP eos: through `eos_point` (_eos_point, eqstat2's kernel; or the installed family's, families.py).
316    v = eos_point(tl, pl, 0.0, x, z, comp, fxion, 0.0, 0.0, lderiv, latmo, ksaha, xxdh, yydh, zzdh, ist[0], ist[1],
317                  ist[2], ist[3], ssv, data)
318    r[0] = v[0]
319    r[1] = v[1]
320    r[2] = v[2]
321    r[3] = v[3]
322    r[4] = v[4]
323    r[5] = v[5]
324    r[6] = v[6]
325    r[7] = v[7]
326    r[8] = v[8]
327    r[9] = v[9]
328    r[10] = v[10]
329    r[11] = v[11]
330    r[12] = v[12]
331    r[13] = v[13]
332    r[14] = v[14]
333    if lderiv:
334        r[15] = v[15]
335        r[16] = v[16]
336        r[17] = v[17]
337        r[18] = v[18]
338        r[19] = v[19]
339        r[20] = v[20]
340    else:
341        r[15] = 0.0
342        r[16] = 0.0
343        r[17] = 0.0
344        r[18] = 0.0
345        r[19] = 0.0
346        r[20] = 0.0
347    r[21] = v[21]
348    r[22] = v[22]
349    r[23] = v[23]
350    r[24] = v[24]
351    r[25] = v[25]
352    r[26] = v[26]
353    r[27] = v[27]
354    st = ec[19].sti
355    if v[24] != 0 or v[25] != 0 or st[12] != 0:
356        st[13] = st[13] | ist[4]
357        st[14] = st[14] | ist[5]
358        st[15] = st[15] | ist[6]
359        ist[4] = 0
360        ist[5] = 0
361        ist[6] = 0
362        return True
363    ist[0] = v[22]
364    ist[1] = v[23]
365    if st[13] != 0:
366        ist[4] = 1
367        ist[2] = st[8]
368        ist[3] = st[3]
369    if st[14] != 0:
370        ist[5] = 1
371    if st[15] != 0:
372        ist[6] = 1
373    return False
