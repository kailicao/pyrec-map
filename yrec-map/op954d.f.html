Explanation

Purpose. Gets the OPAL95 opacity from the full set of tables (MHP 7/98): a four-dimensional interpolation in $Z$, $X$, $\log T$ and $\log R$ ($R = \rho/T_6^3$). It is the general case, used when the point's composition matches neither pre-interpolated table.

How it fits.

  • Inputs: the full set in LLOT95A_MOD: the grids TGR, XXG, R0GR, ZZG, the opacities CAPPA2(126,70,19), and for each $Z$ the offset of its first table NZ and its number of $X$ tables NUMXM (loaded by LL95TBL); the indices, weights and extrapolation data from GETOPAL95 in OP95INTERP_MOD (formerly /OP95INDX/, /OP95FACT/ and /OP95EXT/; BZ, BX(K,·), and $\log R$ as RHO_T63L).
  • Who calls it: GETOPAL95, when the point's $Z$ differs from the table's ZTAB, and always when the acoustic depth is computed (LADON and LACOUT; GETOPAL95's comment, JVS 04/11).
  • Outputs: $\kappa$, $\log\kappa$, QOD, QOT, as in OP952D.

The method. For each of the four nearest $Z$ (table offset NZ(JZ+K-1)) and, within it, the four nearest $X$ (JX(K,J), which may differ between $Z$ values since high-$Z$ sets lack some $X$ tables), the $\log R$ and $\log T$ interpolation of OP952D; then four-point interpolation in $X$ (weights BX(K,·)) and in $Z$ (weights BZ), and the conversion of $\partial\log\kappa/\partial\log T$ to constant $\rho$.

Table layout. The header explains it: "tables are incremented in sets of NZ*NX", so the tables of the third metal abundance ($3\times10^{-4}$) are numbers 21–30; at high $Z$ some $X$ tables are missing ($X < 0.9$ for $Z = 0.1$). The offsets NZ (0, 10, …, 100, 109, 118, in LL95TBL) give $Z = 0.06$ and $0.08$ nine slots each and $Z = 0.1$ eight.

Changed since rp_1. Declarations only: COMMON blocks to modules (the three interpolation blocks merged into OP95INTERP_MOD), IMPLICIT NONE; the extrapolation's $\log R$ and its boundary value are renamed RHO_T63L and RHO_T63LL (formerly RL, RLL, names that clashed with the radius elsewhere). No question is settled.

Questions for the experts

  1. Tables stored over others? In LL95TBL each table goes to slot NZ(IZ)+IX. For $Z = 0.06$ and $0.08$, which lack table 9 ($X = 0.95$), table 10 ($X = 1 - Z$) then goes to NZ(IZ)+10, which is the first slot of the next $Z$: slot 110 ($Z = 0.08$, $X = 0$) and slot 119 ($Z = 0.1$, $X = 0$). The tables are read with $X$ in the outer loop, so these $X = 0$ tables are read first and overwritten later, while slots 109 and 118 stay empty. This routine reads CAPPA2(JX(K,J)+IZ,…) with the same indexing, so the interpolation is self-consistent for $X = 1 - Z$ but takes $X = 0$ at $Z = 0.08$ and $0.1$ from the wrong table. Is this so, and should table 10 at these $Z$ go to NZ(IZ)+9?

(MHP 7/98): the log R and log T interpolation of OP952D for each of the
4 x 4 nearest (Z, X) tables, then four-point interpolation in X and in
Z, with the indices and weights GETOPAL95 left in OP95INTERP_MOD.

Arguments: o, ol, qod, qot (set only; any value).

Returns (o, ol, qod, qot): the opacity kappa, log10 kappa, and
dlog kappa/dlog rho and dlog kappa/dlog T at constant rho.
20def op954d(o, ol, qod, qot):
21    """The OPAL95 opacity at the current point from the full set of tables
22    (MHP 7/98): the log R and log T interpolation of OP952D for each of the
23    4 x 4 nearest (Z, X) tables, then four-point interpolation in X and in
24    Z, with the indices and weights GETOPAL95 left in OP95INTERP_MOD.
25
26    Translates: op954d.f#OP954D (09c3b9b)
27
28    Arguments: o, ol, qod, qot (set only; any value).
29
30    Returns (o, ol, qod, qot): the opacity kappa, log10 kappa, and
31    dlog kappa/dlog rho and dlog kappa/dlog T at constant rho.
32    """
33    tab = llot95a_mod
34    ip = op95interp_mod
35    cappa2 = tab.cappa2
36    bd, bdd, bt, btt = ip.bd, ip.bdd, ip.bt, ip.btt
37    # Find the opacity at each of the 4 nearby values of Z.
38    for k in range(1, 5):
39        # Question (see the page): the slots NZ(IZ)+10 at Z = 0.06, 0.08.
40        iz = tab.nz[ip.jz + k - 1]
41        # Find the opacity at each of the 4 nearby values of X.
42        for j in range(1, 5):
43            ixz = ip.jx[k, j] + iz
44            # For each X, kappa at 4 values of T.
45            for i in range(1, 5):
46                it = ip.jt + i - 1
47                # For each T, kappa at 4 values of R.
48                id_ = ip.jd[i]
49                # log kappa at the desired rho for each of the 4 T.
50                c[i] = (bd[i, 1] * cappa2[ixz, it, id_]
51                        + bd[i, 2] * cappa2[ixz, it, id_ + 1]
52                        + bd[i, 3] * cappa2[ixz, it, id_ + 2]
53                        + bd[i, 4] * cappa2[ixz, it, id_ + 3])
54                # dlog kappa/dlog R for each of the 4 T.
55                qc[i] = (bdd[i, 1] * cappa2[ixz, it, id_]
56                         + bdd[i, 2] * cappa2[ixz, it, id_ + 1]
57                         + bdd[i, 3] * cappa2[ixz, it, id_ + 2]
58                         + bdd[i, 4] * cappa2[ixz, it, id_ + 3])
59            # Rho outside the table: extrapolate linearly with the
60            # derivative at the boundary.
61            if ip.lextl:
62                deltar = ip.rho_t63l - ip.rho_t63ll
63                for i in range(1, 5):
64                    c[i] = c[i] + deltar * qc[i]
65            elif ip.lexth:
66                for i in range(1, 5):
67                    if ip.lexh[i]:
68                        deltar = ip.rho_t63l - ip.rlh[i]
69                        c[i] = c[i] + deltar * qc[i]
70            # Interpolate in T: log kappa, dlog kappa/dlog T, and
71            # dlog kappa/dlog R.
72            cc[j] = bt[1] * c[1] + bt[2] * c[2] + bt[3] * c[3] + bt[4] * c[4]
73            cct[j] = (btt[1] * c[1] + btt[2] * c[2] + btt[3] * c[3]
74                      + btt[4] * c[4])
75            ccd[j] = (bt[1] * qc[1] + bt[2] * qc[2] + bt[3] * qc[3]
76                      + bt[4] * qc[4])
77        # Interpolate in X: log kappa, QOT and QOD.
78        bx = ip.bx
79        cz[k] = (bx[k, 1] * cc[1] + bx[k, 2] * cc[2] + bx[k, 3] * cc[3]
80                 + bx[k, 4] * cc[4])
81        czt[k] = (bx[k, 1] * cct[1] + bx[k, 2] * cct[2] + bx[k, 3] * cct[3]
82                  + bx[k, 4] * cct[4])
83        czd[k] = (bx[k, 1] * ccd[1] + bx[k, 2] * ccd[2] + bx[k, 3] * ccd[3]
84                  + bx[k, 4] * ccd[4])
85    # Interpolate in Z.
86    bz = ip.bz
87    ol = bz[1] * cz[1] + bz[2] * cz[2] + bz[3] * cz[3] + bz[4] * cz[4]
88    qot = bz[1] * czt[1] + bz[2] * czt[2] + bz[3] * czt[3] + bz[4] * czt[4]
89    qod = bz[1] * czd[1] + bz[2] * czd[2] + bz[3] * czd[3] + bz[4] * czd[4]
90    # From the derivative at fixed R to the derivative at fixed rho.
91    qot = qot - 3.0 * qod
92    o = 10.0**ol
93    return o, ol, qod, qot

OP954D reads with the same indexing, so $X = 0$ at $Z = 0.08$, $0.1$ is wrong in every 4D interpolation that reaches it. Fix: add a question; report to the LL95TBL page's group.
