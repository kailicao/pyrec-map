Explanation

Purpose. Polynomial interpolation through N points by Neville's algorithm (the routine POLINT of Numerical Recipes, by its name and form): it returns the value Y at X and an error estimate DY, the last correction added.

How it fits.

  • Who calls it: ALSURFP (the Allard model atmospheres' surface pressures) and FPFT (the rotational distortion factors).
  • Limits: at most 20 points (the arrays are fixed at 20, "for consistency with fpft", MHP 10/02).

The method. Starting from the nearest tabulated point, the tableau of differences $C_{i}$, $D_{i}$ is built column by column, $$D_i \leftarrow \frac{(x_{i+j}-x)\,(C_{i+1}-D_i)}{x_i - x_{i+j}},\qquad C_i \leftarrow \frac{(x_i-x)\,(C_{i+1}-D_i)}{x_i - x_{i+j}},$$ and the path through it that stays closest to the centre adds one correction per column to $y$.

Changed since rp_1. Declarations only: IMPLICIT NONE.

Questions for the experts

  1. A silent stop. Two equal abscissas stop the run (STOP) without a message, which is hard to trace in a long run. Add a message?

13    starting from the nearest tabulated point.

15    Translates: polint.f#POLINT (09c3b9b)

17    Arguments: xa[1..n], ya[1..n] (n <= 20); x; y, dy (set). Returns
18    (y, dy): the value at x and the last correction added, an error
19    estimate.
20    """
21    ns = 1
22    dif = abs(x - xa[1])
23    for i in range(1, n + 1):
24        dift = abs(x - xa[i])
25        if dift < dif:
26            ns = i
27            dif = dift
28        c[i] = ya[i]
29        d[i] = ya[i]
30    y = ya[ns]
31    ns = ns - 1
32    for j in range(1, n):
33        for i in range(1, n - j + 1):
34            ho = xa[i] - x
35            hp = xa[i + j] - x
36            w = c[i + 1] - d[i]
37            den = ho - hp
38            if abs(den) < 1.0e-20:
39                # Question (see the page): a stop without a message.
40                raise SystemExit()
41            den = w / den
42            d[i] = hp * den
43            c[i] = ho * den
44        if 2 * ns < n - j:
45            dy = c[ns + 1]
46        else:
47            dy = d[ns]
48            ns = ns - 1
49        y = y + dy
