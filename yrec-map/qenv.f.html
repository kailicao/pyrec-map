Purpose

The right-hand side of the envelope integration: with $\log P$ as the independent variable, it returns the derivatives of $\log m$ (relative to the total), $\log T$ and $\log r$, from hydrostatic equilibrium, mass conservation and the temperature gradient.

How it fits

  • Inputs: X0 $=\log P$; Y(1..3) $= \log(m/M_\ast)$, $\log T$, $\log r$; the luminosity B, the distortion factors FPL, FTL, TEFFL, $X$, $Z$; STOTAL ($\log M_\ast$) from COMP_MOD; the mixing length CMIXLQ from QENVMIX_MOD, set by ENVINT before every path that reaches QENV (the argument list must stay that of the EXTERNAL derivative routine, so CMIXL cannot be passed); LPUMOD from PULSE1_MOD.
  • Who calls it: ENVINT, directly and as the EXTERNAL derivative routine passed to BSSTEP and MMID.
  • What it calls: EQSTAT, GETOPAC, and TPGRAD (with CMIXLQ, and with IOVIM = -1 in DPMIX_MOD, so no overshoot point is flagged).
  • Outputs: DYDX(1..3); the counter KENV; the point's structure, gradients, $\beta$, convective velocity and ionization fractions in ENVPRT_MOD (always, since 07/02, 08/13 and 08/25), read by ENVINT, GETNEWENV and STARIN; and the quantities for pulsation output in PULSE2_MOD when saving. EFXION, QQDP, QQDT and QQCP are set always (lines 89–94↗) and again, to the same values, inside IF(LSAVE .OR. LPUMOD) (lines 107–109↗, line 120↗, line 125↗, line 127↗); the second assignments are redundant.

The method

With $f_P$ = FPL, $$\frac{d\log m}{d\log P} = -\frac{4\pi r^4 P}{G m^2 f_P},\qquad \frac{d\log T}{d\log P} = \nabla,\qquad \frac{d\log r}{d\log P} = -\frac{r P}{G m \rho}\,f_P,$$ with $\nabla$ from TPGRAD (lines 72–74↗; on $f_P$ in the last, suspected bug 1).

Suspected bugs, checked by running the code

Each bug is marked by what running the code showed: (changes results, large) or (small), the fix moving a run clearly beyond a null change; (stops the run); (wrong output), the fix changing only what is written; (harmless in the runs), within the noise; (never occurred), the code ran but the fault did not; (not reached); (cannot be reached), a guard prevents it; (withdrawn), the suspicion was wrong.

1. (harmless in the runs) The distortion factor in $d\log r/d\log P$.

(line 72↗; line 74↗) The interior equations in COEFFT have $d\log P/d\log m \propto f_P$ and $d\log r/d\log m$ without $f_P$ (coefft.f, lines 247–252↗); dividing gives $d\log r/d\log P \propto 1/f_P$. QENV divides by $f_P$ in $d\log m/d\log P$ (consistent) but multiplies by it in $d\log r/d\log P$. What follows: In a rotating model the slope $d\log r/d\log P$ is $f_P^2$ times the one COEFFT's form gives, so the fitting point's $\log r$ (RS) and the boundary plane of SURFBC are off; the effect is small where $f_P \approx 1$. Only with rotation (LROT, off by default; CRRECT passes $f_P$ of the outermost point, otherwise 1).

223# --- The Numba kernel, a link of the envelope's chain ----------------------------------------------------------------
224#
225# _qenv_k runs qenv's operations, calling eqstat's dispatch (_eqstat_k, over eqstat2's kernel), getopac's kernel, and
226# tpgrad's kernel directly; mmid.py's and bsstep.py's kernels call it on every derivative of the envelope's
227# integration (bsstep.Chain drives them from Python). The chain's context (ctx, built by bsstep.Chain) holds the
228# module state the kernels read; the scalars a call sets go to ctx's `out` (OUT names them, put() writes them back);
229# the counters and RL to ci and cf. At a call it does not cover, the kernel stops with a stage (as coefft.py's does:
230# 1 before the call, getopac's fast path not taken; 2 after the EOS, a message or a status; 3 after the EOS, getopac's
231# kernel stopped; 4 after the opacity, tpgrad's kernel sent the call back), the EOS's values in ctx's r, and
232# _qenv_plain does the rest.
233
234# For the tests: (n, stage) makes the n-th derivative call of a Chain stop at that stage as if a callee had sent it
235# to the plain code (bsstep.Chain passes it in ctx), so that the plain code's resumption is checked; (-1, 0)
236# otherwise. As coefft.test_stop.
237test_stop = np.array([-1, 0], dtype=np.int64)
238
239# ctx's out: the module scalars qenv sets, in order (the first 16 always, the rest when saving).
240OUT = ("ep", "et", "es", "er", "ed", "evel", "ebeta", "edel1", "edel2", "edel3", "efxion1", "efxion2", "efxion3",
241       "qqdp", "qqdt", "qqcp", "eo", "qtl", "qt", "qpl", "qp", "qdl", "qd", "qo", "qol", "qfs", "qqod", "qqot", "qdel",
242       "qdela", "qrmu", "qemu")

334@accel.njit(_nrt=False)
335def _opac_ok(tl: float, x: float, z: float, op: tuple) -> bool:
336    """getopac.fast_path (with getopal95's) on opac_args()'s values: whether getopac's kernel serves the point. It
337    does not depend on DL, so it is checked before the EOS."""
338    (tmolmin, tmolmax, lalex06, ze, xe, zenvo, optol, l2z, lopal95, tgr1, tgrn, ladonacout, ztab, nocond,
339     lcondopacp) = op
340    lgotatm = tl <= tmolmax
341    if lgotatm and (not lalex06 or abs(z - ze) > 1.0e-8 or abs(x - xe) > 1.0e-8):
342        return False
343    if not (tl < tmolmin and lgotatm):
344        if z > 0.1 and tl > 7.0:
345            return False
346        if z > 0.12 or (abs(z - zenvo) > optol and not l2z and not lopal95):
347            return False
348        if not lopal95:
349            return False
350        if tl < tgr1 or tl > tgrn or ladonacout or abs(z - ztab) / max(ztab, 1.0e-6) > 1.0e-4:
351            return False
352    if nocond:
353        return False
354    return True

366@accel.njit(_nrt=False)
367def _qenv_k(x0: float, y: np.ndarray, dydx: np.ndarray, b: float, fpl: float, ftl: float, latmo: bool,
368            lderiv: bool, lsave: bool, teffl: float, x: float, z: float, cf: np.ndarray, ci: np.ndarray,
369            ctx: tuple) -> int:
370    """qenv's kernel, a link of the envelope's chain.
371
372    Parameters
373    ----------
374    x0, y, b, fpl, ftl, latmo, lderiv, teffl, x, z
375        As qenv's (y: shape `(4,)`, index 0 unused).
376    dydx : np.ndarray, shape: `(4,)`, dtype: ``float``
377        Set: the three derivatives (index 0 unused).
378    lsave : bool
379        LSAVE or LPUMOD: whether the point is saved (the slots after the 16th).
380    cf : np.ndarray, shape: `(NCF,)`, dtype: ``float``
381        RL, set to y[3] (and qatm's TL, not used here).
382    ci : np.ndarray, shape: `(NCI,)`, dtype: ``int64``
383        KENV (incremented), KSAHA (set), the calls done since the last put (incremented), the calls begun
384        (incremented; test_stop).
385    ctx : tuple
386        The chain's context (bsstep.Chain.open): eqstat.eos_args(), the EOS state (EIST), opac_args(), gop_in(),
387        tpgrad's scalars, the constants, the work arrays fxion, r, and out, and test_stop.
388
389    Returns
390    -------
391    int
392        STAGE_DONE, or the stage it stopped at (STAGE_START: getopac's fast path not taken; STAGE_EOS: a message or
393        a status of the EOS; STAGE_OPAC: getopac's kernel stopped; STAGE_GRAD: tpgrad's kernel sent the call back),
394        the EOS's values then in ctx's r, for _qenv_plain.
395
396    """
397    ea, eist, op, go, tpg, cons, fxion, r, out, ts = ctx
398    ci[3] = ci[3] + 1
399    forced = ci[3] == ts[0]
400    cln, c4pil, cgl, clsunl, cdelrl, cmixl2, cmixl3, cc13, cc23, stotal, cmixlq, kttau, hras = cons
401    # OOP convection: tpg is the convection family's data (families.py), read by convection_point.
402    # The state; getopac's fast path checked first (Fortran lines 58–61).
403    pl = x0
404    sl = y[1] + stotal
405    tl = y[2]
406    rl = y[3]
407    if not _opac_ok(tl, x, z, op) or (forced and ts[1] == STAGE_START):
408        return STAGE_START
409    # The equation of state, opacity, and gradient (Fortran lines 62–71).
410    fxion[1] = 0.0
411    fxion[2] = 0.0
412    fxion[3] = 0.0
413    if _eqstat_k(tl, pl, x, z, fxion, lderiv, latmo, ci[1], ea, eist, r):
414        return STAGE_EOS
415    if forced and ts[1] == STAGE_EOS:
416        _eqstat_forced(ea, eist)
417        return STAGE_EOS
418    t = r[0]
419    p = r[1]
420    dl = r[2]
421    d = r[3]
422    beta = r[4]
423    rmu = r[7]
424    emu = r[9]
425    qdt = r[11]
426    qdp = r[12]
427    qcp = r[13]
428    dela = r[14]
429    o, ol, qod, qot, gstat = _getopac_c(dl, tl, x, z, fxion, op, go, cln)
430    if gstat != 0 or (forced and ts[1] == STAGE_OPAC):
431        return STAGE_OPAC
432    r[28] = o
433    r[29] = ol
434    r[30] = qod
435    r[31] = qot
436    # OOP convection: the installed convection family's point.
437    g = convection_point(tl, t, pl, p, d, rl, sl, b, o, qdt, qdp, qot, qod, qcp, dela, r[15], r[16], r[17], r[18],
438                         0.0, 0.0, 0.0, r[19], r[20], lderiv, fpl, ftl, cmixlq, -1, tpg)
439    if g[7] != 0 or (forced and ts[1] == STAGE_GRAD):
440        return STAGE_GRAD
441    dele = g[0]
442    delr = g[1]
443    vel = g[5]
444
445    # The derivatives and the counters (Fortran lines 72–75).
446    dydx[1] = -math.exp(cln * (c4pil + 4.0 * rl + pl - cgl - sl - sl)) / fpl
447    dydx[2] = dele
448    dydx[3] = -math.exp(cln * (pl + rl - cgl - sl - dl)) * fpl
449    ci[0] = ci[0] + 1
450    ci[1] = int(r[21])
451    ci[2] = ci[2] + 1
452    cf[0] = rl
453
454    # The module scalars, into the slots (Fortran lines 76–130).
455    out[0] = pl
456    out[1] = tl
457    out[2] = sl - stotal
458    out[3] = rl
459    out[4] = dl
460    out[5] = vel
461    out[6] = beta
462    out[7] = delr
463    out[8] = dela
464    out[9] = dele
465    out[10] = fxion[1]
466    out[11] = fxion[2]
467    out[12] = fxion[3]
468    out[13] = qdp
469    out[14] = qdt
470    out[15] = qcp
471    if lsave:
472        out[16] = o
473        out[17] = tl
474        out[18] = math.exp(cln * tl)
475        out[19] = pl
476        out[20] = math.exp(cln * pl)
477        out[21] = dl
478        out[22] = math.exp(cln * dl)
479        out[23] = o
480        out[24] = ol
481        out[25] = math.exp(cln * (sl - stotal))
482        out[26] = qod
483        out[27] = qot
484        out[28] = dele
485        out[29] = dela
486        out[30] = rmu
487        out[31] = emu
488    return STAGE_DONE
