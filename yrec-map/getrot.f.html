Purpose

GETROT turns a run of specific angular momentum $j(m)$ into a rotation curve $\Omega(m)$. Radiative shells are treated one at a time; each convection zone is given its rotation law as a whole. (Its comment calls it GETW, an older name.)

The comment names another routine. It begins "GETW TAKES THE ANGULAR MOMENTUM DISTRIBUTION…" (lines 21–23↗), but the routine is GETROT, and GETW is another routine, so the comment should name GETROT.

How it fits

  • Who calls it: CHECKJ, CRRECT, GETNEWENV, GETW, HPOINT and MIDMOD.
  • Inputs: HJM ($j$ per shell), LCZ (convective flags), the structure (HD, HR, HS, HS2), M.
  • What it calls: SOLID (for a single radiative shell) and WCZIMP (for a convection zone; "JNT 09/25 for 05/15 call WCZIMP instead of WCZ").
  • Outputs: OMEGA, HI (moments of inertia of the shells), ETA2, QIW, R0, filled by SOLID and WCZIMP; and HJM, which both rewrite as $j = I\Omega/\Delta m$, so that in a convection zone, where WCZIMP imposes the rotation law, $j$ is redistributed.

The method

Scanning outward: each radiative shell is passed to SOLID alone, which finds the $\Omega$ for which $\Omega\,I(\Omega) = j\,\Delta m$, iterating SHAPE and MOMI, since the shell's moment of inertia depends on $\Omega$ through its distortion; a run of convective shells is collected and passed to WCZIMP when the next radiative shell (or the surface) is reached (but see suspected bug 1).

Suspected bugs, checked by running the code

Each bug is marked by what running the code showed: (changes results, large) or (small), the fix moving a run clearly beyond a null change; (stops the run); (wrong output), the fix changing only what is written; (harmless in the runs), within the noise; (never occurred), the code ran but the fault did not; (not reached); (cannot be reached), a guard prevents it; (withdrawn), the suspicion was wrong.

1. (never occurred) A one-shell convective surface is never treated.

(lines 33–37↗; lines 51–58↗) If only the last shell is convective (LCZ(M) true, LCZ(M-1) false), the loop marks the start of a convection zone at I = M and ends without calling WCZIMP or SOLID for it; the case I.EQ.M is reached only when the zone began below M. What follows: OMEGA(M), HI(M), ETA2(M), R0(M) and QIW(M) keep the values they had before the call, and are not those of the current HJM(M) and structure. Only with rotation (LROT, off by default), and only for a model whose surface convection zone is a single shell.
