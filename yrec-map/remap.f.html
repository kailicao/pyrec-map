Purpose

Translates newer, "more intuitively named" namelist parameters (MHP 6/2014) into the arrays the rest of the code uses: the nuclear cross sections and their energy derivatives, and the tolerances for the mesh and the time step.

How it fits

  • Who calls it: PARMIN, after reading the namelists.
  • Inputs, through modules: NMLBYPASS_MOD (formerly /NEWPARAM/, /NEWCROSS/ and /XSECT/: the new cross-section parameters, such as S0_1_1 for p+p and S0P_1_12 for the first derivative of p+C12, the switch LNEWNUC, the new tolerance names, such as TOL_DM_MAX and TIME_DX_SHELL, and the switches LNEWVARS, LSTRUCT_TIME); shared only with PARMIN, which reads them, and STARIN, which uses none of them yet.
  • Outputs, through modules:
  • CROSS_MOD: QS0E(8), QQS0EE(8), FC12, FO16, and NMLPAR_MOD: SSTANDARD(17), all read by RATES and ENGEB;
  • NMLPAR_MOD: HPTTOL(12), the mesh tolerances, used by HPOINT and others;
  • NMLPAR_MOD: ATIME(14), the time-step limits, used by HTIMER and others;
  • NMLPAR_MOD: DTWIND, DTDIF, LPTIME.

The method

  1. Defaults. QS0E, QQS0EE, FC12, FO16 are set to 1.

  2. Cross sections, when LNEWNUC is true. SSTANDARD becomes the ratio of each new zero-energy S-factor to the reference value hard-coded here (…_REF, the values that RATES and ENGEB assume): $$\texttt{SSTANDARD}(j) = \frac{S_{0,j}}{S_{0,j}^{\mathrm{ref}}},\qquad f_{C12} = \frac{S_{0}^{\,15(p,\alpha)}}{6.75\times10^4},\qquad f_{O16} = \frac{S_0^{\,15(p,\gamma)}}{64}.$$ The resonant helium-burning reactions (8, 10, 11, 12) and the unused ones (9, 13) are left at 1. The derivative factors are ratios of $S'/S$ (and $S''/S$) to those of Solar Fusion I (Adelberger et al. 1998), whose values are hard-coded (QS0E_…_A98, QQS0EE_…_A98, in b): $$\texttt{QS0E}(j) = \frac{S'_j/S_{0,j}}{\bigl(S'/S_0\bigr)_j^{\mathrm{A98}}},\qquad \texttt{QQS0EE}(j) = \frac{S''_j/S_{0,j}}{\bigl(S''/S_0\bigr)_j^{\mathrm{A98}}},$$ set to 0 when $S_{0,j} \le 0$. RATES multiplies its $Q_2, Q_3$ terms by QS0E and its $Q_4, Q_5$ terms by QQS0EE (a comment, line 160↗, says the derivatives are used "in ENGEB AND NRATES"; the routine is RATES).

    The derivatives' units follow the references'. The inputs enter only as ratios to the reference values of Adelberger et al. (1998), (S0P_…/S0_…)/(QS0E_…_A98/S0_…_A98) (line 166↗) and likewise for the second derivatives (line 211↗), whose units the comments give as keV b for the S-factors and b for the first derivatives (line 81↗; lines 97–98↗; none for the second, line 103↗), so with S0_… in keV b, S0P_… is in b and S0PP_… in b keV$^{-1}$. The namelist documentation does not say so.

  3. Tolerances, when LNEWVARS is true. A one-to-one copy, with a comment on each: for example HPTTOL(1) = TOL_DM_MIN (minimum log mass spacing), HPTTOL(11) = TOL_DP_CORE_MAX, ATIME(7) = TIME_DX_SHELL (maximum fraction of X burned in a shell in a step), ATIME(13) = TIME_MAX_DT_FRAC.

    Question 1 (lines 128–131↗, lines 233–235↗). Both switches change other inputs silently. With LNEWNUC, any SSTANDARD given in the namelist is overwritten; with LNEWVARS, HPTTOL and ATIME are (the code's comments say so, but nothing is printed). Should a message warn a user who sets both?

Question 2 (line 235↗; nmlbypass_mod.f, line 63↗). LNEWVARS listed as legacy. The documentation presents the TOL_…, FLAG_… and TIME_… names as the mesh and time-step controls, but lists LNEWVARS ("use updated variable names for tolerances") and LNEWNUC under "Legacy options." Their default is false, so without LNEWVARS = .TRUE. in the namelist every one of these parameters is ignored and the old HPTTOL, ATIME values are used. Every namelist file in the repository that sets one of them (965) also sets LNEWVARS = .TRUE.. Should the default become true (or the old vectors go), or should the documentation say that LNEWVARS must be set?

Change log

The changes since rp_1

Changed since rp_1. The reference value S0_1_16_REF is now the double-precision 9.4D0 (it was 9.4E0, a single-precision constant, about $4\times10^{-8}$ smaller), which changes SSTANDARD(7) in the same proportion; otherwise COMMON blocks to modules (/NEWPARAM/ and /NEWCROSS/ merged into NMLBYPASS_MOD; the tolerances, time-step limits and SSTANDARD into NMLPAR_MOD), IMPLICIT NONE.

Changed since 09c3b9b. The derivative factors QS0E(2)–QS0E(7) and QQS0EE(4), QQS0EE(5), QQS0EE(7) are now normalized by each reaction's own A98 S-factor (S0_3_3_A98, S0_3_4_A98, S0_1_12_A98, S0_1_13_A98, S0_1_14_A98, S0_1_16_A98, whose DATA values, 5.4D3, 5.3D-1, 1.34D0, 7.6D0, 3.5D0 and 9.4D0 keV b, are restored) instead of p+p's S0_1_1_A98. Before, these factors came out of order $10^{-22}$, so with LNEWNUC the S′ and S″ terms of reactions 2–7 were dropped and the S0P_…, S0PP_… inputs had no effect; now they are of order 1, as intended. This settles former question 1; former questions 2–4 are now 1–3.

54def _ratio(s0, s0p, ref_deriv, ref_s0):
55    """(S'/S0) / (S'/S0)_A98, or 0 when S0 <= 0 (MHP 4/25)."""
56
57    if s0 > 0.0:
58        return (s0p / s0) / (ref_deriv / ref_s0)
59    return 0.0
