Purpose

This file computes the conductive opacity for a mixture of hydrogen, helium and metals from Potekhin's conductivity tables ("based on Chris Burke's conductive opacity code," LLP 5/31/04). GETOPAC then adds it to the radiative opacity in harmonic sum.

How it fits

  • Inputs: the arguments DL ($\log\rho$), TL ($\log T$), X, Z, and FXION, the ionization fractions (of H; of He singly and doubly).
  • Who calls it: GETOPAC, when the Potekhin option (LcondOpacP) is on.
  • What it calls: CONDOPACP, for $Z_\mathrm{ion}$ = 1, 2 and 8.
  • Outputs: OC and OCL (the conductive opacity and its log), QODC, QOTC (its derivatives in $\log\rho$ and $\log T$), and LCONDO (true if computed). If LCONDO is false, GETOPAC falls back to the Hubbard–Lampe formula or uses no conductive opacity.

The method

  1. Number fractions of H, He and metals (taken as oxygen, $A = 16$), $w_k = (X_k/A_k)/\sum_j(X_j/A_j)$, then weighted by ionization: $w_\mathrm{H} f_\mathrm{H^+}$, $w_\mathrm{He}(f_\mathrm{He^+} + 2f_\mathrm{He^{2+}})/2$; metals are taken as fully ionized.

    Question 1 (lines 30–40↗). Weights by number of ions. The comment says the weights count only charged atoms; for helium the weight $(f_1 + 2f_2)/2$ mixes ion number and charge. Is this what Chris Burke's code did?

  2. Inside $3 \le \log T \le 9$, $-6 \le \log\rho \le 9.75$: the conductivity $K_k$ of each pure composition from CONDOPACP, combined as $$\frac{1}{K} = \sum_k \frac{w_k}{K_k},$$ and the conductive opacity $$\kappa_\mathrm{cond} = \frac{16\,\sigma\,T^3}{3\,\rho\,K}, \qquad \log\kappa_\mathrm{cond} = -3.5194 + 3\log T - \log\rho - \log K,$$ with $\log(16\sigma/3) = -3.5194$ in cgs. Its derivatives are $\partial\log\kappa/\partial\log\rho = -1 - \partial\log K/\partial\log\rho$ and $\partial\log\kappa/\partial\log T = 3 - \partial\log K/\partial\log T$. These limits are the table's edges (see the suspected bug 1 of CONDOPACP, condopacp.f, lines 99–109↗, for the upper ones).

    Question 2 (line 21↗; line 41↗; line 58↗). The metals. All metals are represented by $Z_\mathrm{ion} = 8$ with $A = 16$ and full ionization; the comment justifies this by their low abundance. Fine for the Sun; for metal-rich or evolved cores (C/O), is it adequate?

  3. Below $\log\rho = -6$, where $\log R = \log\rho - 3(\log T - 6) \ge 0$ (so only for $\log T < 4$): evaluate at $\log\rho = -6$ and extrapolate linearly in $\log\rho$ with the hydrogen table's slope; $\partial\log\kappa/\partial\log T$ is hydrogen's alone, at $\log\rho = -6$.

  4. Elsewhere, LCONDO stays false, and OC is left at $10^{9.9998}$ with QODC = QOTC = OC; GETOPAC then either returns before using them ($\log T < 4.2$, or low density) or replaces them with the Hubbard–Lampe formula.

1. (changes results, small) Checked by KC (Nov 10, 2026) The mixture's derivatives are multiplied by $\log K$.

(line 68↗; line 72↗) QODC = CONDL * (WtH1*QODCX + …) multiplies the weighted derivatives by CONDL = $\log K$ itself. The derivative of the harmonic sum $1/K = \sum_k w_k/K_k$ is $\partial\log K/\partial\log\rho = \sum_k (w_k K/K_k)\,\partial\log K_k/\partial\log\rho$, with no factor $\log K$: For pure hydrogen ($w_\mathrm{H} = 1$) the code gives $\log K$ times the right value. The commented-out older lines (lines 69–70↗, lines 73–74↗) weight each derivative by its CONDX, as the fix below does, but also multiply by CONDL. What follows: QODC and QOTC are wrong wherever Potekhin's opacity is computed ($\log\rho \ge -6$), and GETOPAC folds them into the opacity's derivatives QOD and QOT with the weight $\kappa_\mathrm{rad}/(\kappa_\mathrm{rad} + \kappa_\mathrm{cond})$ (getopac.f, lines 219–222↗), so the error counts where conduction matters (degenerate cores). Only with LcondOpacP (off by default, set in all 51 decks of the test suite and recommended by the user guide).

How the code itself shows it. The routine's own lines fix what QODC must be. CondOpacP, which it calls, defines its outputs as $\log_{10}$ of the thermal conductivity $K$ and plain log derivatives (condopacp.f, lines 22–24↗: "DRK - d log kappa / d log rho," "DTK - d log kappa / d log T"). lines 76–77↗ build the opacity as OCL = -3.5194D0+3.0D0*TL-DL-CONDL, that is $\kappa_\mathrm{cond} = 16\sigma T^3/(3\rho K)$, and its density derivative as -1.0D0-QODC, so QODC must be $\partial$CONDL$/\partial\log\rho$: For pure, fully ionized hydrogen that is hydrogen's DRK itself, while line 68↗ gives CONDL times it. The same routine's branch below $\log\rho = -6$ uses DRK exactly so, with no factor CONDL, both as the derivative and as the slope it extrapolates along (line 84↗, lines 97–99↗). YREC's other conductive opacity, Hubbard and Lampe's in GETOPAC, returns QODC = 0.3901D0*TL - 0.2772D0*DL - 3.5853D0 (getopac.f, lines 206–211↗), exactly the density derivative of its own formula, and GETOPAC combines either option's QODC with the radiative one in the same way (getopac.f, lines 219–222↗); both options must therefore deliver the same quantity, and only this branch does not. 17    """The conductive opacity of a mixture: Potekhin's conductivities for
18    Z_ion = 1, 2 and 8, summed harmonically with weights by ionized number
19    fraction, then kappa = 16 sigma T^3 / (3 rho K); extrapolated linearly

44    wtox = wtoxbase
