Purpose

This file computes the conductive opacity for a mixture of hydrogen, helium and metals from Potekhin's conductivity tables ("based on Chris Burke's conductive opacity code," LLP 5/31/04). GETOPAC then adds it to the radiative opacity in harmonic sum.

How it fits

  • Inputs: the arguments DL ($\log\rho$), TL ($\log T$), X, Z, and FXION, the ionization fractions (of H; of He singly and doubly).
  • Who calls it: GETOPAC, when the Potekhin option (LcondOpacP) is on.
  • What it calls: CONDOPACP, for $Z_\mathrm{ion}$ = 1, 2 and 8.
  • Outputs: OC and OCL (the conductive opacity and its log), QODC, QOTC (its derivatives in $\log\rho$ and $\log T$), and LCONDO (true if computed). If LCONDO is false, GETOPAC falls back to the Hubbard–Lampe formula or uses no conductive opacity.

The method

  1. Number fractions of H, He and metals (taken as oxygen, $A = 16$), $w_k = (X_k/A_k)/\sum_j(X_j/A_j)$, then weighted by ionization: $w_\mathrm{H} f_\mathrm{H^+}$, $w_\mathrm{He}(f_\mathrm{He^+} + 2f_\mathrm{He^{2+}})/2$; metals are taken as fully ionized.

    Question 1 (lines 30–40↗). Weights by number of ions. The comment says the weights count only charged atoms; for helium the weight $(f_1 + 2f_2)/2$ mixes ion number and charge. Is this what Chris Burke's code did?

  2. Inside $3 \le \log T \le 9$, $-6 \le \log\rho \le 9.75$: the conductivity $K_k$ of each pure composition from CONDOPACP, combined as $$\frac{1}{K} = \sum_k \frac{w_k}{K_k},$$ and the conductive opacity $$\kappa_\mathrm{cond} = \frac{16\,\sigma\,T^3}{3\,\rho\,K}, \qquad \log\kappa_\mathrm{cond} = -3.5194 + 3\log T - \log\rho - \log K,$$ with $\log(16\sigma/3) = -3.5194$ in cgs. Its derivatives are $\partial\log\kappa/\partial\log\rho = -1 - \partial\log K/\partial\log\rho$ and $\partial\log\kappa/\partial\log T = 3 - \partial\log K/\partial\log T$. These limits are the table's edges (see the suspected bug 1 of CONDOPACP, condopacp.f, lines 99–109↗, for the upper ones).

    Question 2 (line 21↗; line 41↗; line 58↗). The metals. All metals are represented by $Z_\mathrm{ion} = 8$ with $A = 16$ and full ionization; the comment justifies this by their low abundance. Fine for the Sun; for metal-rich or evolved cores (C/O), is it adequate?

  3. Below $\log\rho = -6$, where $\log R = \log\rho - 3(\log T - 6) \ge 0$ (so only for $\log T < 4$): evaluate at $\log\rho = -6$ and extrapolate linearly in $\log\rho$ with the hydrogen table's slope; $\partial\log\kappa/\partial\log T$ is hydrogen's alone, at $\log\rho = -6$.

  4. Elsewhere, LCONDO stays false, and OC is left at $10^{9.9998}$ with QODC = QOTC = OC; GETOPAC then either returns before using them ($\log T < 4.2$, or low density) or replaces them with the Hubbard–Lampe formula.

1. (changes results, small) Checked by KC (Nov 10, 2026) The mixture's derivatives are multiplied by $\log K$.

(line 68↗; line 72↗) QODC = CONDL * (WtH1*QODCX + …) multiplies the weighted derivatives by CONDL = $\log K$ itself. The derivative of the harmonic sum $1/K = \sum_k w_k/K_k$ is $\partial\log K/\partial\log\rho = \sum_k (w_k K/K_k)\,\partial\log K_k/\partial\log\rho$, with no factor $\log K$: For pure hydrogen ($w_\mathrm{H} = 1$) the code gives $\log K$ times the right value. The commented-out older lines (lines 69–70↗, lines 73–74↗) weight each derivative by its CONDX, as the fix below does, but also multiply by CONDL. What follows: QODC and QOTC are wrong wherever Potekhin's opacity is computed ($\log\rho \ge -6$), and GETOPAC folds them into the opacity's derivatives QOD and QOT with the weight $\kappa_\mathrm{rad}/(\kappa_\mathrm{rad} + \kappa_\mathrm{cond})$ (getopac.f, lines 219–222↗), so the error counts where conduction matters (degenerate cores). Only with LcondOpacP (off by default, set in all 51 decks of the test suite and recommended by the user guide).

How the code itself shows it. The routine's own lines fix what QODC must be. CondOpacP, which it calls, defines its outputs as $\log_{10}$ of the thermal conductivity $K$ and plain log derivatives (condopacp.f, lines 22–24↗: "DRK - d log kappa / d log rho," "DTK - d log kappa / d log T"). lines 76–77↗ build the opacity as OCL = -3.5194D0+3.0D0*TL-DL-CONDL, that is $\kappa_\mathrm{cond} = 16\sigma T^3/(3\rho K)$, and its density derivative as -1.0D0-QODC, so QODC must be $\partial$CONDL$/\partial\log\rho$: For pure, fully ionized hydrogen that is hydrogen's DRK itself, while line 68↗ gives CONDL times it. The same routine's branch below $\log\rho = -6$ uses DRK exactly so, with no factor CONDL, both as the derivative and as the slope it extrapolates along (line 84↗, lines 97–99↗). YREC's other conductive opacity, Hubbard and Lampe's in GETOPAC, returns QODC = 0.3901D0*TL - 0.2772D0*DL - 3.5853D0 (getopac.f, lines 206–211↗), exactly the density derivative of its own formula, and GETOPAC combines either option's QODC with the radiative one in the same way (getopac.f, lines 219–222↗); both options must therefore deliver the same quantity, and only this branch does not. The factor is not small: CONDL, $\log_{10}K$, runs from about 1.1 to 19.3 in the table condall06.d. The combined derivatives reach the iteration's matrix (coefft.f, lines 263–264↗) and, in rotating runs, the meridional circulation through $\partial\ln\chi/\partial\ln T = 3 - \partial\ln\kappa/\partial\ln T$ (setupv.f, lines 431–433↗), each weighted by $\kappa_\mathrm{rad}/(\kappa_\mathrm{rad}+\kappa_\mathrm{cond})$, which goes to 1 where conduction dominates: The error counts most in degenerate cores, which no run with the fix reached. 33def condopacpint_weights(x: float, z: float, fxion: np.ndarray) -> tuple[float, float, float]:
34    """The number fractions of H1, He4, and the metals (as oxygen), weighted by their ionization (Fortran lines
35    24–41).
36
37    Parameters
38    ----------
39    x, z : float
40        The mass fractions of hydrogen and the metals.
41    fxion : np.ndarray, shape: `(4,)`, dtype: ``float64``
42        The ionization fractions H+, He+, He2+ in fxion[1..3] (index 0 unused).
43
44    Returns
45    -------
46    wth1, wthe4, wtox : float
47        The weights of Z_ion = 1, 2, and 8 in the harmonic sum.
48
49    """
50    y = 1.0 - x - z
51    wth1base = (x / AH1) / (x / AH1 + y / AHE4 + z / AOX)
52    wthe4base = (y / AHE4) / (x / AH1 + y / AHE4 + z / AOX)
53    wtoxbase = (z / AOX) / (x / AH1 + y / AHE4 + z / AOX)
54    # Question (see the page): (f1 + 2 f2)/2 for helium.
55    # Question (see the page): all metals as oxygen, fully ionized.
56    wth1 = wth1base * fxion[1]
57    wthe4 = wthe4base * (fxion[2] + 2.0 * fxion[3]) / 2.0
58    wtox = wtoxbase
59    return wth1, wthe4, wtox

65def condopacpint(dl: float, tl: float, x: float, z: float, oc: float, ocl: float, qodc: float, qotc: float,
66                 fxion: np.ndarray, lcondo: bool) -> tuple[float, float, float, float, bool]:
67    """The conductive opacity of a mixture: Potekhin's conductivities for
68    Z_ion = 1, 2 and 8, summed harmonically with weights by ionized number
69    fraction, then kappa = 16 sigma T^3 / (3 rho K); extrapolated linearly
70    below log rho = -6.
71
72    Translates: condopacpint.f#CONDOPACPINT (7be4133)
73
74    Parameters
75    ----------
76    dl, tl : float
77        log10 rho (g/cm^3) and log10 T (K).
78    x, z : float
79        The mass fractions of hydrogen and the metals.
80    oc, ocl, qodc, qotc : float
81        Output only (passed in with any value).
82    fxion : np.ndarray, shape: `(4,)`, dtype: ``float64``
83        The ionization fractions H+, He+, He2+ in fxion[1..3].
84    lcondo : bool
85        Output only.
86
87    Returns
88    -------
89    oc, ocl, qodc, qotc : float
90        The opacity, its log10, and its derivatives in log rho and log T
91        (without conduction: oc = 10**OCL_NONE, qodc = qotc = oc).
92    lcondo : bool
93        True if the conductive opacity was computed.
94
95    """
96    # The Numba kernel (accel.py), once condopacp's table is read; a stop in condopacp is left to the plain code.
97    if accel.USE_NUMBA and _cm.krun == _cm.KRUN_READ:
98        guess = _cm._guess
99        guess[0] = _cm.iz
100        guess[1] = _cm.it
101        guess[2] = _cm.ir
102        oc, ocl, qodc, qotc, lcondo, status = _condopacpint_nb(dl, tl, x, z, fxion, _cm.at, _cm.ar, _cm.az,
103                                                               _cm.akap, guess)
104        _cm.iz, _cm.it, _cm.ir = guess.tolist()
105        if status == 0:
106            return oc, ocl, qodc, qotc, lcondo
107
108    # The number fractions of H1, He4 and the metals, weighted by ionization; the metals taken as fully ionized
109    # (Fortran lines 24–41).
110    wth1, wthe4, wtox = condopacpint_weights(x, z, fxion)
111
112    # No significant conductive opacity, to begin with (Fortran lines 43–50).
113    lcondo = False
114    ocl = OCL_NONE
115    oc = 10.0 ** ocl
116    qodc = oc
117    qotc = oc
118
119    # Within the table's range (Fortran lines 52–54).
120    rl = dl - 3.0 * (tl - 6.0)
121    if tl >= TL_MIN and tl <= TL_MAX and dl <= DL_MAX:
122        if dl >= DL_MIN:
123            # The three pure compositions from the table (Fortran lines 55–58).
124            condxl, qodcx, qotcx = condopacp(1.0, tl, dl, 0.0, 0.0, 0.0)
125            condyl, qodcy, qotcy = condopacp(2.0, tl, dl, 0.0, 0.0, 0.0)
126            condzl, qodcz, qotcz = condopacp(8.0, tl, dl, 0.0, 0.0, 0.0)
127
128            # Their harmonic sum, log K (Fortran lines 60–66).
129            condx = 10.0 ** (-condxl)
130            condy = 10.0 ** (-condyl)
131            condz = 10.0 ** (-condzl)
132            condl = -math.log10(wth1 * condx + wthe4 * condy + wtox * condz)
133
134            # The mixture's derivatives (Fortran lines 68–74).
135            # Suspected bug (see the page): the factor condl (log K).
136            qodc = condl * (wth1 * qodcx + wthe4 * qodcy + wtox * qodcz)
137            # Suspected bug (see the page): the density derivatives again.
138            qotc = condl * (wth1 * qodcx + wthe4 * qodcy + wtox * qodcz)
139
140            # The conductive opacity (Fortran lines 76–80).
141            ocl = -3.5194 + 3.0 * tl - dl - condl
142            qodc = -1.0 - qodc
143            qotc = 3.0 - qotc
144            lcondo = True
145            oc = 10.0 ** ocl
146
147        if dl < DL_MIN and rl >= 0.0:
148            # Extrapolate from log rho = -6: the table there (Fortran lines 82–86).
149            condxl, qodc, qotc = condopacp(1.0, tl, -6.0, 0.0, 0.0, 0.0)
150            condyl, crap, crap2 = condopacp(2.0, tl, -6.0, 0.0, 0.0, 0.0)
151            condzl, crap, crap2 = condopacp(8.0, tl, -6.0, 0.0, 0.0, 0.0)
152
153            # Their harmonic sum (Fortran lines 88–92).
154            condx = 10.0 ** (-condxl)
155            condy = 10.0 ** (-condyl)
156            condz = 10.0 ** (-condzl)
157            # Suspected bug (see the page): no minus sign here, unlike above.
158            condl = math.log10(wth1 * condx + wthe4 * condy + wtox * condz)
159
160            # The opacity at log rho = -6, extrapolated to dl (Fortran lines 96–101).
161            ocl = -3.5194 + 3.0 * tl + 6.0 - condl
162            qodc = -1.0 - qodc
163            qotc = 3.0 - qotc
164            # Suspected bug (see the page): the step (-6 - dl) is reversed.
165            ocl = ocl + qodc * (-6.0 - dl)
166            oc = 10.0 ** ocl
167            lcondo = True
168
169    return oc, ocl, qodc, qotc, lcondo
