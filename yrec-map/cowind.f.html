Purpose

This file gives the change of the surface convection zone's angular velocity over a time step due to magnetized-wind angular-momentum loss, with the older "Kawaler-type" wind law and a saturation threshold. It is used when the newer Matt et al. law (LMWIND) is off.

How it fits

  • Inputs: the arguments BL ($\log L/L_\odot$), TEFFL, SMASS ($M/M_\odot$), DT (the time step), HICZ (the moment of inertia of the surface convection zone), OMEGAS (the surface $\Omega$ after the previous iteration), WOLD (at the start of the step), IT (the iteration); WMAX, EXMD, EXW, EXR, EXM, CONSTFACTOR in NMLPAR_MOD (set in PARMIN from the input index "ALFA", per the comment); TAUCZ (the convective overturn time) in OVRTRN_MOD; the solar constants in CONSTANTS_MOD.
  • Who calls it: MCOWIND, when LMWIND is false ("run old windlaw").
  • Outputs: WIND1, WIND2, the change of $\Omega$ over the step computed with $\Omega$ at its start and at its end. The comment says they enter the diffusion equations and are averaged: SECULR, which calls MCOWIND, passes them to DCOEFT or DADCOEFT, where the surface boundary takes $-\tfrac12(\mathtt{WIND1}+\mathtt{WIND2})$ times the moment of inertia.

The method

  1. Saturation. If WMAX $> 1$, it is read as $\Omega_\mathrm{sat,\odot}\,\tau_\odot$ and $\Omega_\mathrm{sat} = \mathtt{WMAX}/\tau_\mathrm{cz}$ (MHP 3/09; the run stops if $\tau_\mathrm{cz}$ is not defined, with exit code 1 and the message also in the .short file); otherwise $\Omega_\mathrm{sat} = \mathtt{WMAX}$. Unlike WIND, the reinterpretation does not depend on LINSTB.

    Question 1 (lines 80–96↗). The test WMAX > 1. A real $\Omega_\mathrm{sat}$ is far below 1 rad s$^{-1}$, so the test works as a switch; but the Physics namelist page describes WMAX only as an angular velocity in rad/s (and WMAX_SUN, which PARMIN converts for the new law only), not this second meaning. Should the documentation describe it, or a separate switch replace it?

  2. The radius from $L$ and $T_\mathrm{eff}$: $\log R = \tfrac12(\log(L/L_\odot) + \log L_\odot - \log 4\pi - \log\sigma - 4\log T_\mathrm{eff})$, in cm.

  3. The comment's law, $dJ/dt \propto K\,(\dot M/10^{-14})^{a}\,\Omega^{n}\,(M/M_\odot)^{c}(R/R_\odot)^{b}$, gives $$C = \frac{\Delta t}{I_\mathrm{CZ}}\,K\left(\frac{\dot M}{10^{-14}\,M_\odot\,\mathrm{yr}^{-1}}\right)^{a}\left(\frac{R}{R_\odot}\right)^{b}\left(\frac{M}{M_\odot}\right)^{c},$$ $$\Delta\Omega = C\,\min(\Omega, \Omega_\mathrm{sat})^{\,n-1}\,\Omega,$$ with $K$ = CONSTFACTOR, $a$ = EXMD, $b$ = EXR, $c$ = EXM, $n$ = EXW. So $\Delta\Omega \propto \Omega^n$ below saturation and $\propto \Omega\,\Omega_\mathrm{sat}^{n-1}$ above.

  4. WIND1 uses WOLD. WIND2 uses OMEGAS; from the second iteration on, it is the mean of its previous value and the new one, which damps the iteration.

    Question 2 (lines 111–115↗). The damping of WIND2. Averaging the previous WIND2 with the new value at each iteration means the converged WIND2 mixes values from several iterations, weighting the latest most. Is this only for stability, and does it converge to the value at the end of the step?

Design

The mass-loss rate is fixed: DMDOT = 2.0D-14 ($M_\odot$ yr$^{-1}$), so the factor $(\dot M/10^{-14})^a$ is the constant $2^a$.

Question 3 (lines 99–106↗). A fixed mass-loss rate. $\dot M$ is hard-coded to $2\times10^{-14}\,M_\odot$ yr$^{-1}$, not taken from the model's mass-loss rate (DMDT0, now in NMLPAR_MOD). Is it intended as a calibration constant, absorbed into CONSTFACTOR?

The changes since rp_1

Changed since rp_1. Declarations only: COMMON blocks to modules, IMPLICIT NONE; the unused /DEUTER/ is gone, and the wind parameters this file does not use (EXTAU, EXL, EXPR, EXCEN, C_2) are now namelist variables in NMLPAR_MOD, shared by all its users, which settles the former question 3 on unused inputs.

Changed since a8a5950. The error stop when $\tau_\mathrm{cz}$ is not defined now also writes its message to the .short file (ISHORT, through IOUNITS_MOD), and ends with STOP 1 instead of a bare STOP, so that a failed run no longer exits with status 0 (KNOWN_ISSUES.md, issue 38).

12def cowind(bl: float, dt: float, hicz: float, it: int, omegas: float, smass: float, teffl: float, wold: float,
13           wind1: float, wind2: float) -> tuple[float, float]:
14    """The change of the surface convection zone's Omega over the step by
15    magnetized-wind angular-momentum loss, with a saturation threshold:
16    delta Omega = (dt/I_cz) K (Mdot/1e-14)**a (R/R_sun)**b (M/M_sun)**c
17    min(Omega, Omega_sat)**(n-1) Omega, for Omega at the start of the
18    step (wind1) and at its end (wind2).
19
20    Translates: cowind.f#COWIND (7be4133)
21
22    Arguments: bl, log L/L_sun; dt, the time step; hicz, the moment of
23    inertia of the surface convection zone; it, the iteration; omegas,
24    the surface Omega after the previous iteration; smass, M/M_sun;
25    teffl, log Teff; wold, Omega at the start of the step; wind1, passed
26    in (with any value); wind2, its value from the previous iteration.
27
28    Returns (wind1, wind2).
29
30    """
31
32    c = constants_mod
33    n = nmlpar_mod
34    taucz = ovrtrn_mod.taucz
35
36    # WMAX > 1 is read as WMAX(sun)*TAUCZ(sun), and the saturation threshold is
37    # WMAX/TAUCZ(star) (MHP 3/09) (Fortran lines 82–96).
38    # Question (see the page): the test WMAX > 1 works as a switch.
39    if n.wmax > 1.0:
40        if taucz > 1.0:
41            wsat = n.wmax / taucz
42        else:
43            msg = (f"ERROR IN WIND - TAUCZ NOT DEFINED "
44                   f"{n.wmax:12.3E}{taucz:12.3E}STOPPED")
45            print(msg)
46            iounits_mod.write(iounits_mod.ishort, msg)
47            raise SystemExit(1)    # STOP 1, the run-time error code
48    else:
49        wsat = n.wmax
50
51    # The total radius of the star (cm) (Fortran lines 97–98).
52    rl = 0.5 * (bl + c.clsunl - c.c4pil - c.csigl - 4.0 * teffl)
53    rtot = math.exp(c.cln * rl)
54
55    # The mass-loss rate, in solar masses per year (Fortran line 100).
56    # Question (see the page): fixed, not the model's.
57    dmdot = 2.0e-14
58
59    # The changes at the start and end of the step; cc is the Fortran's C
60    # (c here names constants_mod) (Fortran lines 105–110).
61    cc = (dt / hicz * n.constfactor * (dmdot / 1.0e-14) ** n.exmd
62          * (rtot / c.crsun) ** n.exr * smass ** n.exm)
63    wp = min(wold, wsat)
64    wn = min(omegas, wsat)
65    wind1 = cc * wp ** (n.exw - 1.0) * wold
66    temp = cc * wn ** (n.exw - 1.0) * omegas
67
68    # WIND2 averaged with its previous value (Fortran lines 111–115).
69    # Question (see the page): the mean with the previous WIND2.
70    if it == 1:
71        wind2 = temp
72    else:
73        wind2 = 0.5 * (wind2 + temp)
74    return wind1, wind2
