Explanation

Purpose. IOUNITS_MOD holds the Fortran logical unit numbers of every input and output file, shared by 57 routines. It replaces COMMON/IOUNITS/ (MHP via Claude, 10/14/26), which had gathered, on 9/25/26, the unit numbers once scattered over COMMON/LUOUT/, /LUNUM/, /ALEX06/, /ACDPTH/, /NEWOPAC/, /LOPAL95/, /ATMOS2/, /ALATM03/, /OPALEOS/ and /SCV2/ (the dead IDYN, ILLDAT, ISCOMP, IKUR of /LUNUM/ removed). All members are INTEGER*4.

What its variables hold, who sets them, who reads them. PARMIN assigns every number (its comments name the files; they can be changed only in the code) and opens most of the files; the routines that read or write a file use its unit.

  • Run control: IOWR = 6 (the status output, the screen; the main program sets it to 9 before calling PARMIN, which overwrites it), ISTAND = 14 and IRUN = 13 (the CONTROL and PHYSICS namelists, read by PARMIN).
  • Models: IFIRST = 12 (the starting model), ILAST = 11 (the last model), ISTOR = 23 (saved models).
  • Outputs: ISHORT = 20 (all diagnostic information, the .short file), ITRACK = 19 (the track), IDEBUG = 18 (debugging), IMILNE = 21 (Milne's invariant variables, written by WRTMIL), IMODPT = 22 (shell-by-shell output), ISNU = 33 (neutrino fluxes), ISOUND = 500 (the sound-speed profile, written by WRTMOD with LSOUND), IOPMOD, IOPENV, IOPATM = 24, 25, 26 (interior, envelope and atmosphere for a pulsation code, also opened by PDIST), ICLCD = 91 (the acoustic-depth output, assigned only with LACOUT).
  • Input tables: IFERMI = 15 (Fermi–Dirac tables, read by SETUPS), IOATM = 38 (Kurucz atmospheres, SETUPS), IOATMA = 66 (Allard atmospheres, ALFILEIN), ILIV95 = 48 (OPAL95 opacities, LL95TBL), IALEX06 = 90 (Alexander 2006 opacities, READALEX06), IOPUREZ = 62 (the pure-CN opacities, RDZLAOL), IcondOpacP = 75 (Potekhin conductive opacities, CONDOPACP), IOPALE = 49 (OPAL 2006 equation of state, READCOEOS06), ISCVH, ISCVHE, ISCVZ = 72, 73, 74 (the SCV equation of state, SETUPS).
  • IJLAST: the unit to which WRTOUT writes the model with LJLAST (acoustic-depth output), but assigned nowhere; the branch never runs, since LACOUT cannot be turned on (see ACDPTH_MOD).

Design. A blanket USE IOUNITS_MOD. Unit numbers are fixed in PARMIN rather than allocated, so a new file must pick a free number by hand (ISOUND's 500 stands apart).

Changed since rp_1. New file: the unit numbers of ten COMMON blocks, and of /IOUNITS/ into which they were merged, as one module; the dead units IDYN, ILLDAT, ISCOMP, IKUR (and PARMIN's unshared ILSTBN, ISTOBN, IFSTBN) removed.

Questions for the experts

  1. A unit with no number. IJLAST is used by WRTOUT's acoustic-depth branch but assigned nowhere, so the branch would write to unit 0 if it ever ran. Assign it in PARMIN with ICLCD, or remove it with the branch?

57def open(unit, name, status='UNKNOWN', form='FORMATTED', access='SEQUENTIAL'):
58    """OPEN(unit, FILE=name, STATUS=status): connect a unit to a file.
59
60    status is Fortran's: 'OLD' (must exist), 'NEW' (must not exist),
61    'REPLACE', 'SCRATCH' or 'UNKNOWN' (kept if it exists, positioned at its
62    start). form and access are accepted and ignored (formatted, sequential).
63    """
64    close(unit)
65    name = str(name).strip()
66    status = status.upper()
67    if status == 'OLD':
68        mode = 'r+' if os.access(name, os.W_OK) else 'r'
69    elif status == 'NEW':
70        mode = 'x+'
71    elif status in ('REPLACE', 'SCRATCH'):
72        mode = 'w+'
73    else:   # UNKNOWN
74        mode = 'r+' if os.path.exists(name) else 'w+'
75    _units[unit] = builtins.open(name, mode)
76
77
78def _file(unit):
79    """The file of a unit, connecting an unopened unit to fort.<unit> as
80    Fortran does."""
81    if unit not in _units:
82        open(unit, f'fort.{unit}')
83    return _units[unit]

93def rewind(unit):

99def read(unit):
100    """READ(unit, ...): the next record as a string, without its newline,
101    or None at the end of the file (Fortran's END= branch). Unit 5 is
102    standard input."""
103    if unit == 5:
104        line = sys.stdin.readline()
105    else:
106        line = _file(unit).readline()
107    if line == '':
108        return None
109    return line.rstrip('\n')

112def write(unit, text):
113    """WRITE(unit, ...): write text as one or more records. Units 6 and '*'
114    are the screen. As in a sequential file, what follows the record just
115    written is cut off."""
116    if unit in (6, '*') and unit not in _units:
117        print(text)
118        return
119    f = _file(unit)
120    f.write(f'{text}\n')
121    f.truncate()
122    f.flush()
