Purpose

A diagnostic print of the Allard atmosphere table: its sizes, its limits, and the three tables ($\log P$ at $T_\mathrm{eff}$, $\log P$ and $\log T$ at $\tau = 100$), one row per $T_\mathrm{eff}$, with each row's valid range in $\log g$.

How it fits

  • Who calls it: only ALTABINIT, and only when it finds the table bad, just before the run stops.
  • Inputs: ALATM01_MOD (filled by ALFILEIN) and ALATM02_MOD (filled by ALTABINIT).
  • Output: text to unit ISHORT (from IOUNITS_MOD).

Design

Besides printing, it recomputes TEFFLmin and TEFFLmax in ALATM02_MOD, with the same formulas as ALTABINIT, so it has a (harmless) side effect.

Question 1 (lines 44–45↗). Side effect. ALPRINT writes TEFFLmin and TEFFLmax into ALATM02_MOD, with the formulas ALTABINIT has already applied (altabinit.f, lines 63–64↗). Is this left over from a time when ALTABINIT did not set them?
