Purpose

TPGRAD decides whether a point is convective and gives its temperature gradient $\nabla = d\ln T/d\ln P$. It computes the radiative gradient, compares it with the adiabatic one (the Schwarzschild criterion), and in convective regions solves the mixing-length theory's cubic for the actual gradient and the convective velocity; on request it also gives the gradient's derivatives for the Henyey solution. Its comments assume that the equation of state and the opacity have been computed already.

How it fits

  • Inputs: arguments: $\log T$, $T$, $\log P$, $P$, $\rho$ (D), $\log r$, $\log m$ (SL), $L/L_\odot$ (B), the opacity $\kappa$ (O) and its derivatives, the equation-of-state quantities ($\delta = -$QDT, $c_P$ = QCP, $\nabla_\mathrm{ad}$ = DELA, and derivatives), the rotation factors FPL, FTL, $\log T_\mathrm{eff}$, and the mixing length CMIXL (set for each run by the main program, CMIXL = CMIXLA(NK), and passed down by the callers). Through modules: the constants CDELRL, CMIXL2, CMIXL3, set by SETUPS, and CC13 (CONSTANTS_MOD); the temperature above which MLT is skipped, TGCUT, the overshoot switch LADOV and the spot parameters SPOTF, SPOTX, LSDEPTH (NMLPAR_MOD); the overshoot shells IOV1, IOV2, IOVIM (DPMIX_MOD); ISHORT (IOUNITS_MOD).
  • Who calls it: the routines that evaluate the physics at a point: PHYSIC, COEFFT, QENV, SCONVEC and STARIN.
  • Outputs: LCONV, DELR ($\nabla_\mathrm{rad}$), DEL ($\nabla$), VEL (the convective velocity, cm/s), and with LDERIV the logarithmic derivatives of $\nabla$ (QACT, QACP, QACR). It sets ALFMLT, PHMLT, CMXMLT in PUALPHA_MOD to zero (lines 77–79↗) and never computes them, so the pulsation output's mixing-length columns are zeros: ENVINT writes the three variables, and WRTMOD writes literal zeros in their place, "which were always zero" (settled from the code, Nov 9, 2026: wrtmod.f, lines 291–296↗, coefft.f, lines 500–502↗, envint.f, lines 590–592↗).

The method

  1. Radiative gradient. With CDELRL = $-\log(4\pi/3) - \log\sigma - \log 16$ (from SETUPS), $$\nabla_\mathrm{rad} = \frac{3\,\kappa\,L\,P}{64\pi\,\sigma\,G\,m\,T^4}\;\frac{f_T}{f_P},$$ with $L = $ B$\,L_\odot$, and $f_P$, $f_T$ the rotational distortion factors.

  2. Radiative if $\nabla_\mathrm{rad} - \nabla_\mathrm{ad} \le 10^{-6}$: $\nabla = \nabla_\mathrm{rad}$, $v = 0$; but inside an adiabatic overshoot region (LADOV, shell IOVIM between IOV1 and IOV2) $\nabla = \nabla_\mathrm{ad}$. This is the Schwarzschild criterion, without the composition term $\nabla_\mu$; the YREC paper (§2.3.3) says the code "considers the Schwarzschild criterion for instability, not the Ledoux criterion," and semiconvection (LSEMIC, SCONVEC) is the option for $\mu$-gradient regions (settled from the YREC paper, Nov 9, 2026: lines 80–93↗).

    Question 1 (line 83↗). The threshold $10^{-6}$. A point is radiative when $\nabla_\mathrm{rad} - \nabla_\mathrm{ad} \le 10^{-6}$, not $\le 0$. Is the margin meant to keep LC from flickering at a zone's edge from one iteration to the next, and does it shift the edges measurably? 3. Convective: above TGCUT (cores), $\nabla = \nabla_\mathrm{ad}$ and $v = 10^{-11}$, without MLT. The YREC paper (§2.3.3) gives the reason: "In convective cores the specific heat is quite high and there is an option to skip MLT calculations; in this case the adopted temperature gradient is the adiabatic one." The $v = 10^{-11}$ cm/s set there is not a convective velocity, so VEL in these regions should not be used for overturn times or mixing.

    Question 2 (lines 97–107↗). Skipping MLT in cores. Above TGCUT the gradient is set to $\nabla_\mathrm{ad}$ without solving the cubic. Deep in a convective core, $\nabla - \nabla_\mathrm{ad}$ would be tiny (of order $10^{-7}$ or less), so the skip should change the structure negligibly while saving time: Is that the reasoning, and has the effect been measured? 4. Spots (G. Somers 9/14): the radiative flux in convective regions is reduced, $\nabla_\mathrm{rad} \to \nabla_\mathrm{rad}/(f x^4 + 1 - f)$, with $f$ = SPOTF; the contrast $x$ is SPOTX, or with LSDEPTH varies with depth as the comment derives, $x(T) = 1 - (1 - x_\mathrm{surf})\,T_\mathrm{amb}/T$. The correction comes after the point is found convective (but see bug 1).

    The returned DELR stays uncorrected, while DEL and VEL use the corrected gradient; the derivatives of DELDEL do not follow the correction (suspected bug 2). 5. Mixing-length theory. With $g = Gm/r^2$, $H_p = P/(\rho g)$, the mixing length $\ell = \alpha H_p$, with $\alpha$ = CMIXL, $\phi = \alpha\,\kappa\rho H_p$ (the optical thickness of an element), CMIXL2 = 1/3 and CMIXL3 = $16\sqrt2\,\sigma$: $$A_1 = \frac{16\sqrt2\,\sigma\,T^3\kappa}{c_P\,(1 + \phi^2/3)\,\sqrt{(\nabla_\mathrm{rad} - \nabla_\mathrm{ad})\,g\,\delta/H_p}},\qquad A_3 = \frac{3\phi^2}{4\,(1 + \phi^2/3)\,A_1},$$ and the cubic $$A_3 V^3 + V^2 + A_1 V - 1 = 0$$ is solved for $V$ by a Newton iteration with a second-order correction (at most 25 steps, tolerance $10^{-10}$), starting from $V = 1/A_1$, or $V = A_3^{-1/3}$ when $A_3 > 10^3$. Then $$\nabla = \nabla_\mathrm{ad} + (\nabla_\mathrm{rad} - \nabla_\mathrm{ad})\,V(V + A_1),\qquad v = V\,\sqrt{\frac{g\,\delta\,\alpha^2 H_p\,(\nabla_\mathrm{rad} - \nabla_\mathrm{ad})}{8}} .$$ This is mixing-length theory (Böhm-Vitense 1958, as the YREC paper, §2.3.3, says). From the code's constants, for $\phi \gg 1$ the factor $1/(1 + \phi^2/3)$ drops out and $A_1 \to 2U/\sqrt{\nabla_\mathrm{rad} - \nabla_\mathrm{ad}}$, with $U = \dfrac{3acT^3}{c_P\rho^2\kappa\ell^2}\sqrt{\dfrac{8H_p}{g\delta}}$ (with $\ell = \alpha H_p$ in cm, $ac = 4\sigma$); $V$ is then the convective velocity in units of $\sqrt{g\delta\ell^2(\nabla_\mathrm{rad} - \nabla_\mathrm{ad})/(8H_p)}$. If the cubic does not converge, the point is taken as adiabatic, with a message. If $A_1$'s square root would be of a negative number, the run stops (STOP 912, "RUN ENDED"). The routine also computes DELPM and RRR, which nothing reads (unused?).

    Question 3 (lines 139–147↗; line 161↗). Which variant of the theory. The optically thin factor $1/(1 + \phi^2/3)$ and CMIXL3 $= 16\sqrt2\,\sigma$ fix the variant of mixing-length theory; the calibrated $\alpha$ depends on it. Which published formulation do these constants follow? The factor looks like the correction for optically thin elements of the kind Henyey, Vardya & Bodenheimer (1965) introduced, and $U$ above like the efficiency in Kippenhahn, Weigert & Weiss's textbook: Are they? 6. Derivatives (LDERIV): of $A_1$, $A_3$ and $V$ with respect to $\ln T$, $\ln P$, $\ln r$, combined into those of $\nabla$.

From YREC's documentation

Physics Options: above $\log T$ = TGCUT (default 6.9) convection is taken as adiabatic; LADOV (experimental) makes overshoot regions adiabatic. Starspots: SPOTF is the filling factor (default 0; 0.25 is the bound for active main-sequence stars), SPOTX the spots' temperature contrast (default 1; 0.85 is typical of sunspots; change it only if SPOTF > 0), and LSDEPTH lowers the contrast with depth, assuming a constant field, with no dramatic effect on the results.

1. (never occurred) Spots can stop the run on a point that is convective without them.

(lines 82–83↗; lines 127–135↗; lines 145–156↗) The Schwarzschild test uses $\nabla_\mathrm{rad}$ without the spot correction. For a point found convective, DELDEL is then recomputed with the spotted $\nabla_\mathrm{rad}/(f x^4 + 1 - f)$, which is smaller; if this makes DELDEL zero or negative (a point near a zone's edge, where $\nabla_\mathrm{rad} - \nabla_\mathrm{ad}$ is small), TEST is not positive and the run stops (STOP 912, "RUN ENDED"). Only with spots (SPOTF ≠ 0; the default is 0).

15def tpgrad(tl: float, t: float, pl: float, p: float, d: float, rl: float, sl: float, b: float, o: float, qdt: float,
16           qdp: float, qot: float, qod: float, qcp: float, dele: float, delr: float, dela: float, qdtt: float,
17           qdtp: float, qat: float, qap: float, qact: float, qacp: float, qacr: float, qcpt: float, qcpp: float,
18           vel: float, lderiv: bool, lconv: bool, fpl: float, ftl: float, teffl: float, cmixl: float) -> tuple[float,
19           float, float, float, float, float, bool]:
20    """Decide whether a point is convective and give its temperature
21    gradient: the radiative gradient, the Schwarzschild test against the
22    adiabatic one, and in convective regions the mixing-length cubic for
23    the actual gradient and the convective velocity; with lderiv, the
24    gradient's logarithmic derivatives for the Henyey solution.
25
26    Translates: tpgrad.f#TPGRAD (7be4133)
27
28    Arguments: log T, T, log P, P, rho (d), log r, log m (sl), L/Lsun (b),
29    the opacity o and the equation-of-state quantities (qdt = -delta, qdp,
30    qot, qod, qcp = c_P, dela = nabla_ad, and their derivatives qdtt, qdtp,
31    qat, qap, qcpt, qcpp), lderiv, the rotation factors fpl, ftl, log Teff
32    and cmixl (the mixing length in pressure scale heights). dele (the
33    Fortran's DEL), delr, qact, qacp, qacr, vel and lconv are outputs; the
34    derivatives keep their values where the Fortran does not set them.
35
36    Returns (dele, delr, qact, qacp, qacr, vel, lconv).
37
38    """
39
40    c = constants_mod
41    nml = nmlpar_mod
42
43    # The pulsation output's MLT values, always zero (Fortran lines 77–79).
44    pualpha_mod.alfmlt = 0.0
45    pualpha_mod.phmlt = 0.0
46    pualpha_mod.cmxmlt = 0.0
47
48    # The radiative gradient and the Schwarzschild test (Fortran lines
49    # 80–83).
50    # Question (see the page): the margin 1e-6.
51    delr = o * b * math.exp(c.cln * (pl - sl - 4.0 * tl + c.clsunl - c.cgl
52                                     + c.cdelrl)) * ftl / fpl
53    deldel = delr - dela
54    if deldel <= 1.0e-6:
55        # Radiative (adiabatic inside an adiabatic overshoot region)
56        # (Fortran lines 84–92).
57        lconv = False
58        dele = delr
59        vel = 0.0
60        if (nml.ladov and dpmix_mod.iovim >= dpmix_mod.iov1
61                and dpmix_mod.iovim <= dpmix_mod.iov2
62                and dpmix_mod.iovim != -1):
63            dele = dela
64        return dele, delr, qact, qacp, qacr, vel, lconv  # label 200
65
66    # Convective (Fortran lines 94–96).
67    lconv = True
68    dele = dela
69
70    # Cores: no mixing-length theory (Fortran lines 97–107).
71    # Question (see the page): skipping MLT in cores.
72    if tl > nml.tgcut:
73        vel = 1.0e-11
74        if lderiv:
75            qact = qat
76            qacp = qap
77            qacr = 0.0
78        return dele, delr, qact, qacp, qacr, vel, lconv
79
80    # Spots reduce the radiative flux in convective regions (G Somers 9/14)
81    # (Fortran lines 108–136).
82    # Question (see the page): delr itself and its derivatives are left
83    # uncorrected.
84    # Suspected bug (see the page): the radiative/convective test is made
85    # without the correction, and a deldel the correction makes negative
86    # stops the run below.
87    if nml.spotf != 0.00:
88        if nml.lsdepth:
89            ateffl = teffl - 0.25 * math.log10(
90                nml.spotf * nml.spotx**4.0 + 1.0 - nml.spotf)
91            deepx = 1.0 - (1.0 - nml.spotx) * (10.0**ateffl) / (10.0**tl)
92        else:
93            deepx = nml.spotx
94        deldel = delr / (nml.spotf * deepx**4.0 + 1.0 - nml.spotf) - dela
95
96    # Gravity, the scale height and the element's optical thickness (Fortran
97    # lines 137–141).
98    # Question (see the page): which variant of the theory.
99    g = math.exp(c.cln * (c.cgl + sl - rl - rl))
100    presht = p / (d * g)
101    phi = cmixl * d * o * presht
102    phi2 = phi * phi
103    phiphi = 1.0 / (1.0 + c.cmixl2 * phi2)
104
105    # Solve the cubic a3 v^3 + v^2 + a1 v - 1 = 0: a1, or a stop on a
106    # negative square root (Fortran lines 142–159).
107    test = deldel * g * (-qdt) / presht
108    if test > 0.0:
109        a1 = c.cmixl3 * phiphi * t**3 * o / (qcp * math.sqrt(test))
110    else:
111        print(f"***WARNING***\nTPGRAD TRIED TO TAKE SQUARE ROOT"
112              f" OF NEGATIVE NUMBER - RUN ENDED\n"
113              f" DELDEL {deldel:12.3E} QDT {qdt:12.3E} DISC. {test:12.3E}")
114        print("".join(f"{v:12.3E}" for v in
115                      (o, b, pl, sl, tl, ftl, fpl, delr, dela, rl)))
116        raise SystemExit(912)
117
118    # The Newton iteration (Fortran lines 160–171).
119    v = 1.0 / a1
120    a3 = 0.75 * phi2 * phiphi / a1
121    a3p = 3.0 * a3
122    if a3 > 1.0e+3:
123        v = a3**(-c.cc13)
124    converged = False
125    for it in range(1, 26):  # loop 10
126        v = min(v, 1.0)
127        vp = a1 + v * (2.0 + v * a3p)
128        vd = (-1.0 + v * (a1 + v * (1.0 + v * a3))) / vp
129        vd = vd * (1.0 + vd * (1.0 + v * a3p) / vp)
130        v = v - vd
131        if abs(vd) < VTOL:
132            converged = True
133            break  # to label 30
134
135    # No convergence: assume adiabatic convection (Fortran lines 172–184).
136    if not converged:
137        iounits_mod.write(iounits_mod.ishort,
138                          f" -----CUBIC NON-CONVERGENCE(PL,TL,CAPPA,CP,QDT)="
139                          f"{pl:10.6f}{tl:10.6f}\n"
140                          f"{o:12.6E}{qcp:12.6E}{qdt:12.6E}")  # format 20
141        # Assume adiabatic convection.
142        vel = 1.0e-11
143        if lderiv:
144            qact = qat
145            qacp = qap
146            qacr = 0.0
147        return dele, delr, qact, qacp, qacr, vel, lconv
148
149    # label 30: the gradient (Fortran lines 185–186).
150    ddel = deldel * v * (v + a1)
151    dele = dela + ddel
152
153    # The convective velocity; its radicand is positive, since a
154    # non-positive test above stopped (MHP 10/30/26) (Fortran lines
155    # 187–194).
156    vel = v * math.sqrt(g * (-qdt) * (cmixl**2) * presht * deldel / 8.0)
157    delpm = dele - v * v * deldel  # noqa: F841  (unused in the Fortran too)
158    rrr = 10.0**rl  # noqa: F841  (unused in the Fortran too)
159
160    # Derivatives of the convective gradient (Fortran lines 195–223).
161    if lderiv:
162        qdelat = qat * dela
163        qdelap = qap * dela
164        tempot = qod * qdt + qot
165        tempop = qod * qdp
166        qddelt = ((-4.0 + tempot) * delr - qdelat) / deldel
167        qddelp = ((+1.0 + tempop) * delr - qdelap) / deldel
168        temp1 = 2.0 * c.cmixl2 * phi2 * phiphi
169        qa1t = (tempot * (1.0 - temp1) - qcpt
170                - 0.5 * (qdt + qddelt + qdtt / qdt) + 3.0)
171        qa1p = (tempop * (1.0 - temp1) - temp1 - qcpp
172                - 0.5 * (qdp + qddelp + qdtp / qdt) + 0.5)
173        qa1r = -2.0 * temp1 + 2.0
174        qa3t = 2.0 * phiphi * tempot - qa1t
175        qa3p = 2.0 * phiphi * (1.0 + tempop) - qa1p
176        qa3r = 4.0 * phiphi - qa1r
177        temp1 = a1 * v
178        temp2 = a3 * v * v * v
179        temp3 = 1.0 / vp
180        qvt = -(temp1 * qa1t + temp2 * qa3t) * temp3
181        qvp = -(temp1 * qa1p + temp2 * qa3p) * temp3
182        qvr = -(temp1 * qa1r + temp2 * qa3r) * temp3
183        temp1 = deldel * (a1 + v + v)
184        temp2 = deldel * a1 * v
185        deli = 1.0 / dele
186        qact = (qdelat + qddelt * ddel + temp1 * qvt + temp2 * qa1t) * deli
187        qacp = (qdelap + qddelp * ddel + temp1 * qvp + temp2 * qa1p) * deli
188        qacr = (temp1 * qvr + temp2 * qa1r) * deli
189
190    return dele, delr, qact, qacp, qacr, vel, lconv  # label 200
