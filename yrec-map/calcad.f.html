Purpose

This file computes acoustic depths: the sound travel time from the surface to the center, $t_\mathrm{norm}$, and from the surface to the base of the convection zone, $t_\mathrm{CZ}$. It joins the interior model and a fresh envelope integration into one profile, computes the sound speed at each point from the equation of state, and integrates $dr/c_s$.

How it fits

  • Inputs: the arguments, the interior model HR, HD, HP, HT ($\log r$, $\log\rho$, $\log P$, $\log T$), HCOMP (composition), M (last interior point), JENV (the base of the convection zone), RCZL ($\log r_\mathrm{CZ}/R_\odot$), BL, TEFFL, FP, FT, HSTOT, DAGE (the age), CMIXL (the mixing length, passed on to ENVINT).
  • Who calls it: WRTOUT, when the options LACOUT and LADON are on and the model has a convective envelope (JENV > 1) (lines 696–700↗). LACOUT is in no namelist and set nowhere, so it keeps its initial value, false (line 55↗), and CALCAD never runs today (settled from the code, Nov 9, 2026; see ACDPTH_MOD).
  • What it calls: ENVINT (the envelope, which fills /ENVSTRUCT/); for the sound speed, ESAC06 (OPAL 2006 EOS) or EQSTAT2; SPLINJ and SPLINT to interpolate at $r_\mathrm{CZ}$; BOOLE to integrate.
  • Outputs: in /ACDPTH/, TNORM, TCZ, TAUCZN $= t_\mathrm{CZ}/t_\mathrm{norm}$, TATMOS (always 0, see below) and DELADJ ($\nabla_\mathrm{ad}$ at each point). WRTOUT prints them in its output columns (its comment: columns 68–70). A line to ISHORT at every call; with LCLCD, the full profile to unit ICLCD.
  • Modules: ACDPTH_MOD (with ENVINT, GETOPAL95, the main program, PARMIN, WRTOUT; it also holds the output switches LCLCD, LADON, LACOUT); ENVSTRUCT_MOD (the envelope profile, filled by ENVINT); NMLPAR_MOD (the integration step sizes ATMBEG … ENVMAX and ATMSTP, ENVSTP, the spot parameters SPOTF, SPOTX, and the switch LOPALE06); EOS06MISC_MOD (ESAC06's output EOS); COMP_MOD, CONSTANTS_MOD, IOUNITS_MOD (the units ISHORT, ICLCD) and DIMENSIONS_MOD.

The method

  1. The envelope. Set the atmosphere and envelope step sizes to the fixed values ATMSTP, ENVSTP, then integrate the envelope with ENVINT (with the model's mixing length CMIXL), from the surface to the interior's outer point, with $$\log R = \tfrac12(\log L - \log 4\pi - \log\sigma - 4\log T_\mathrm{eff}), \qquad \log g = \log G + \log M - 2\log R.$$ For a spotted star (SPOTF $\ne 0$, SPOTX $\ne 1$) and only when JENV = M, the envelope uses the ambient temperature $$\log T_\mathrm{amb} = \log T_\mathrm{eff} - \tfrac14\log_{10}\!\left(f_s x_s^4 + 1 - f_s\right),$$ with $f_s$ = SPOTF (the spot filling factor) and $x_s$ = SPOTX (probably the spot-to-ambient temperature ratio).

    Question 1 (lines 228–232↗; line 328↗). Spots only at JENV = M. The ambient temperature is used only when JENV = M, which is also exactly the case in which no convection zone is found (TCZ needs JENV < M), so the spot correction applies only to stars for which TCZ = 0. WRTMOD has the same condition (line 228↗). Why that condition?

  2. One profile. The interior points $1..M$, then envelope points $2..N_\mathrm{env}$, in linear units, $T$ in $10^6$ K.

  3. Sound speed. With the OPAL 2006 EOS, $\Gamma_1$ = EOS(8) and $\nabla_\mathrm{ad} = 1/$EOS(9) (EOS(9) is $\Gamma_2/(\Gamma_2-1)$). Otherwise, from EQSTAT2's derivatives (QDPJ, QDTJ, probably $(\partial\ln\rho/\partial\ln P)_T$ and $(\partial\ln\rho/\partial\ln T)_P$) and $c_P$, by Cox and Giuli's chapter 9: $$\chi_\rho = \frac{1}{\mathtt{QDP}}, \quad \chi_T = -\chi_\rho\,\mathtt{QDT}, \quad c_V = c_P - \frac{P}{\rho T}\frac{\chi_T^2}{\chi_\rho}, \quad \Gamma_1 = \frac{\chi_\rho\,c_P}{c_V}.$$ The code stores the inverse sound speed $1/c_s$, with $c_s = \sqrt{\Gamma_1 P/\rho}$.

  4. Integrate with Boole's rule: $$t_\mathrm{norm} = \int_0^{R} \frac{dr}{c_s}, \qquad t_\mathrm{CZ} = \int_{r_\mathrm{CZ}}^{R} \frac{dr}{c_s},$$ in seconds. For $t_\mathrm{CZ}$, the point just below $r_\mathrm{CZ}$ is replaced by $r_\mathrm{CZ}$ itself, with $1/c_s$ from a cubic spline through 7 neighboring points.

    Question 2 (line 310↗; line 322↗; lines 249–256↗). The last point. K = M + NUMENV - 2 is passed to BOOLE as the number of points, but the profile has $M + N_\mathrm{env} - 1$ points, so the outermost point is left out of both integrals. Is this intended (the surface point having $c_s$ ill-defined)?

  5. $\tau_\mathrm{CZ,n} = t_\mathrm{CZ}/t_\mathrm{norm}$.

The atmosphere's acoustic depth (TATMOS) was computed by a section now commented out (lines 387–437↗), so it is always 0.

Question 3 (line 186↗; lines 444–446↗). The atmosphere's acoustic depth. TATMOS is always 0, yet it is written to ISHORT at every call. Should the atmosphere part be restored or removed?

Design

The header lists IACAT, IJLAST and other output switches, some marked "obsolete?" (IACAT and the other unused unit numbers are no longer in the module). Many local variables and arrays remain from the commented-out sections.

Suspected bugs, by priority

(a) may give wrong results; (b) may crash; (c) misbehaves silently (a wrong message, an ignored setting); (d) fragile: correct today, but breaks on a change or an unusual input.

Later envelope integrations in the same run (the surface boundary condition at every step) then use the fixed steps. 220        for i in range(1, k + 1):
221            if starr[i] <= rcz and starr[i + 1] >= rcz:
222                icz = i
223            # Suspected bug (see the page): ICZ may be stale, from an
224            # earlier call, and then can match I before the bracket is
225            # found.
226            if i == icz and flg == 0 and icz > 3:
227                flg = 1
228                for p in range(1, 8):
229                    hood1[p] = starr[icz - 4 + p]
230                    hood2[p] = starc[icz - 4 + p]
231                splinj(hood1, hood2, d, 7)
232                ans, klo, khi = splint(hood1, hood2, 7, d, rcz, ans, klo, khi)
233                starr[icz] = rcz
234                starc[icz] = ans
235            if i == icz and flg == 0 and icz <= 3:
236                flg = 1
237                if icz == 1:
238                    rcz = starr[icz]
239                    ans = starc[icz]
240                else:
241                    for p in range(1, 8):
242                        hood1[p] = starr[icz - 2 + p]
243                        hood2[p] = starc[icz - 2 + p]
244                    splinj(hood1, hood2, d, 7)
245                    ans, klo, khi = splint(hood1, hood2, 7, d, rcz, ans,
246                                           klo, khi)
247                    starr[icz] = rcz
248                    starc[icz] = ans
249
250        # The profile from r_CZ outward (loop 27; Fortran lines 370–373).
251        for i in range(1, k - icz + 2):  # label 27
252            starrz[i] = starr[icz - 1 + i]
253            starcz[i] = starc[icz - 1 + i]
254
255        # Boole's rule from r_CZ to the surface (Fortran lines 375–382).
256        u = (k - icz + 1) % 4
257        v = k - icz + 1
258        if u != 0:
259            nn = k - icz + 1 + 4 - u + 1
260        else:
261            nn = k - icz + 1 + 1
262        acd.tcz = boole(starrz, starcz, v, nn, acd.tcz)
263    else:
264        acd.tcz = 0.0
265
266    # The normalized acoustic depth (Fortran lines 440–441). Suspected bug
267    # (see the page): TNORM = 0 for a short profile; Python raises
268    # ZeroDivisionError where the Fortran gives Inf or NaN.
269    acd.tauczn = 0.0
270    acd.tauczn = acd.tcz / acd.tnorm
271

274    iounits_mod.write(

276        f" Acoustic depth to CZ:{acd.tcz:14.8f}  Acoustic depth to center"

278        f"Acoustic depth of atmopshere:{acd.tatmos:16.8f}  ")
279

282        iounits_mod.write(

284            f" Number of points in envelope:{numenv:5d}  "
285            f"Number of points in interior:{m:5d}  Index near Rcz:{icz:5d}  ")
286        for i in range(1, m + numenv):  # label 1505

291            else:
292                row = (dage, starr[i], starc[i], 0.0, 0.0, acd.deladj[i],
293                       gm1[i], starp[i], start[i], stard[i], starx[i])
