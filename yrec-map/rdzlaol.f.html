Purpose

Reads a LAOL89 opacity table for pure metals (no hydrogen or helium), the "pure Z" table.

How it fits

  • Who calls it: SETUPOPAC, when LPUREZ is true, before ZSULAOL sets up its interpolation.
  • Input: the formatted file FPUREZ, on unit IOPUREZ (from IOUNITS_MOD).
  • Output, through a module: ZLAOL_MOD (ZOLAOL(rho, T), the grids ZORHO, ZOT, sizes NUMRHOZ, NUMTZ), read by ZSULAOL and GTPURZ.
  • Other module: IOUNITS_MOD (IOPUREZ, ISHORT).

The method

The file has the same layout as the LAOL89 tables of RDLAOL (removed since rp_1), with one composition: the header with the mix and the hydrogen fraction is read into a dummy array and skipped, then the density and temperature grids and, for each density, a heading line and its NUMTZ opacities, six to a record (lines 65–70↗). The run stops with "Z OPACITY INPUT ERROR." if the file has more than one composition or the grids are too large (104 × 52).

The changes since rp_1

Changed since rp_1. Declarations only: COMMON blocks to modules (/ZLAOL/ to ZLAOL_MOD; the unit IOPUREZ of /NWLAOL/ and /LUOUT/ to IOUNITS_MOD), IMPLICIT NONE; the unused /NEWOPAC/ and REAL*8 list are gone, which settles the former question 1 (removed).

Changed since a8a5950. The stop on a bad file ("Z OPACITY INPUT ERROR.") now exits with status 3, the code for input errors, instead of a bare STOP (KNOWN_ISSUES.md, issue 38).

8def _e_records(unit, n, per=6, w=12):
9    """Read n reals as FORMAT (1P6E12.5) does: per to a record, so
10    ceil(n/per) records. (1P would scale a field without an exponent by
11    1/10; the tables' fields have exponents, and it is not applied.)"""
12
13    out = []
14    while len(out) < n:
15        line = iounits_mod.read(unit)
16        for k in range(min(per, n - len(out))):
17            text = line[k * w:(k + 1) * w].replace(' ', '')
18            out.append(float(text.replace('D', 'E')) if text else 0.0)
19    return out
