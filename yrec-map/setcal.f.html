Purpose

Prepares the list of runs ("kind cards") for the automatic calibration of a solar model: it fills 48 runs, 16 repetitions of a three-run pattern, from the first three runs given by the user. The calibration itself (adjusting $X$ and the mixing length between repetitions; with $Z$ or $Z/X$ held fixed, setting $X$ sets the initial helium $Y = 1 - X - Z$, which is why the documentation speaks of calibrating the helium) is done elsewhere, by CHKCAL.

How it fits

  • Who calls it: the main program (main.f), when LCALS is true, before the loop over runs. It passes FACAGE, an age factor, now always 1 (main.f sets FACAGE = 1.0D0, main.f, line 369↗; it was drawn per model in the Monte Carlo option, removed since rp_1), and LSOL, a local of the main program that this routine sets to false (the flag CHKCAL sets when the calibration has converged).

    Question 1 (line 2↗; lines 77–82↗; main.f, line 369↗). FACAGE still an argument. With the Monte Carlo option removed, main.f sets FACAGE = 1.0D0 and nothing changes it, so the factor on the end ages and SETDT of runs 2 and 3 is always 1. Can the argument go, or is it kept for a planned use?

  • Inputs and outputs, through modules (besides LSOL): NMLPAR_MOD, the namelist's per-run arrays (NUMRUN, NMODLS, LFIRST, ENDAGE, SETDT, XENV0A, ZENV0A, CMIXLA, LSENV0A, SENV0A, RSCLZC, RSCLZM1, RSCLZM2, and CALSOLAGE, the solar age), and RUNLOOP_MOD (RESCAL, IRESCA, LENDAG, LSETDT). These are shared with PARMIN (which reads them), CHKCAL, RSCALE, STARIN and the main program.

The method

  • NUMRUN = 48; the composition and mixing length of run 1 are copied to runs 2–48.

    Question 2 (lines 52–55↗). A stale comment. Can the comment be brought up to date, to say that the first three runs are copied to the next 15 series of three (runs 4–48)?

  • Runs 4, 7, …, 46 repeat run 1 (a new starting model with its rescaling; LFIRST true).

  • Run 2 ends at $10^8$ yr × FACAGE, and run 3 at CALSOLAGE × FACAGE; both time steps SETDT are scaled by FACAGE too. Runs 5, 8, …, 47 repeat run 2, and runs 6, 9, …, 48 repeat run 3, each continuing from the previous model (IRESCA = 1, LFIRST false).

    Question 3 (lines 76–77↗). The hard-wired $10^8$ yr. Run 2's end age is fixed at $10^8$ yr regardless of the input ENDAGE(2) (the older line, line 78↗, is commented out). What is this run for (probably reaching the zero-age main sequence)? Would a namelist value be clearer?

    The stop criteria END_DCEN, END_XCEN, and END_YCEN are not copied (suspected bug 1).

From YREC's documentation

Control Options (Calibration): LCALS calibrates the solar helium abundance and mixing length automatically, to match the Sun's radius and luminosity at its age CALSOLAGE (default 4.57D9 yr; the documentation calls it a "tolerance"), within TOLL and TOLR (1.0D-5, 1.0D-4); with LCALSOLZX, $Z/X$ is held at CALSOLZX (0.02292, GS98), otherwise $Z$ is held fixed.
