Explanation

Purpose. A helper for shape-preserving quadratic splines (D. F. McAllister and J. A. Roulier; coded by S. L. Dodd and M. Roulier). For one interval, it chooses which of four constructions ("cases") the spline needs, from the slopes at the two ends compared with the slope of the chord.

How it fits.

  • Inputs: the end points $(p_1,p_2)$, $(q_1,q_2)$, the end slopes $m_1$, $m_2$, and a tolerance EPS.
  • Who calls it: MEVAL (itself called by OSPLIN), which then calls CASES with the result.
  • Output: NCASE, 1 to 4.

The method. With the chord's slope $s = (q_2 - p_2)/(q_1 - p_1)$:

  • Case 1: the tangent lines at the ends meet between $p_1$ and $q_1$ (or one slope has the wrong sign and the other exceeds $(1+\epsilon)|s|$, or $s = 0$ with $m_1m_2 < 0$). When an end slope is within $\epsilon|s|$ of $s$, this test is skipped and the case is 2 or 3.
  • Case 2: a knot at the midpoint $(p_1 + q_1)/2$: both tangents cross the midline, or both slopes have the sign opposite to $s$, or $s = 0$ with $m_1 m_2 \ge 0$.
  • Cases 3 and 4: all three slopes have the same sign and one or both end slopes exceed about $2|s|$; case 4 puts two knots in the interval.

Design. "Modification by Marc Pinsonneault": if $m_1 = 0$ or $m_2 = 0$, case 2 is taken at once, to avoid a division by zero in CASES.

Changed since rp_1. Declarations only: IMPLICIT NONE.

Questions for the experts

  1. The modification. Forcing case 2 when an end slope is zero changes the original algorithm. Does it keep the spline monotone in that case?
  2. Equal abscissas. $s$ divides by $q_1 - p_1$ with no check.

5def choose(p1, p2, m1, m2, q1, q2, eps, ncase):
6    """Choose which of the four cases of McAllister and Roulier's
7    quadratic spline the interval needs, from the end slopes and the
8    slope of the chord.
9
10    Translates: choose.f#CHOOSE (09c3b9b)
11
12    Arguments: (p1, p2), (q1, q2), the points of interpolation; m1, m2,
13    the slopes there; eps, the tolerance for slopes close to the chord's
14    slope or twice it; ncase, passed in (with any value).
15
16    Returns ncase, 1 to 4.
17    """
18    # The slope of the chord.
19    # Question (see the page): no check that q1 != p1.
20    spq = (q2 - p2) / (q1 - p1)
21    # Modification by Marc Pinsonneault, to avoid a division by zero in
22    # CASES: a zero end slope gives case 2 at once.
23    if m1 == 0.0 or m2 == 0.0:
24        return 2  # labels 9, 10
25    if spq == 0.0:
26        if m1 * m2 >= 0.0:
27            return 2  # label 10
28        return 1
29    # label 20
30    prod1 = spq * m1
31    prod2 = spq * m2
32    mref = abs(spq)
33    mref1 = abs(m1)
34    mref2 = abs(m2)
35    if abs(spq - m1) <= eps * mref or abs(spq - m2) <= eps * mref:
36        # label 30: an end slope close to the chord's: case 2 or 3.
37        if prod1 < 0.0 or prod2 < 0.0:
38            return _opposite_signs(prod1, prod2, mref, mref1, mref2, eps)
39    else:
40        if prod1 < 0.0 or prod2 < 0.0:
41            return _opposite_signs(prod1, prod2, mref, mref1, mref2, eps)
42        prod = (mref - mref1) * (mref - mref2)
43        if prod < 0.0:
44            # The two tangent lines meet between p1 and q1.
45            return 1
46    # label 40: all three slopes have the same sign.
47    if mref1 > 2.0 * mref:
48        # label 50
49        if mref2 > (2.0 - eps) * mref:
50            return 4  # label 70
51        return 3
52    if mref2 > 2.0 * mref:
53        # label 60
54        if mref1 > (2.0 - eps) * mref:
55            return 4  # label 70
56        return 3
57    # Both tangents cross the midline: a knot at (p1 + q1)/2.
58    return 2
