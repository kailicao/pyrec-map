Purpose

A helper for shape-preserving quadratic splines (D. F. McAllister and J. A. Roulier; coded by S. L. Dodd and M. Roulier). For one interval, it chooses which of four constructions ("cases") the spline needs, from the slopes at the two ends compared with the slope of the chord.

How it fits

  • Inputs: the end points $(p_1,p_2)$, $(q_1,q_2)$, the end slopes $m_1$, $m_2$, and a tolerance EPS.
  • Who calls it: MEVAL (itself called by OSPLIN), which then calls CASES with the result.
  • Output: NCASE, 1 to 4.

The method

With the chord's slope $s = (q_2 - p_2)/(q_1 - p_1)$ (line 52↗):

  • Case 1: the tangent lines at the ends meet between $p_1$ and $q_1$ (or one slope has the wrong sign and the other exceeds $(1+\epsilon)|s|$, or $s = 0$ with $m_1m_2 < 0$). When an end slope is within $\epsilon|s|$ of $s$, this test is skipped and the case is 2 or 3.
  • Case 2: a knot at the midpoint $(p_1 + q_1)/2$: both tangents cross the midline, or both slopes have the sign opposite to $s$, or $s = 0$ with $m_1 m_2 \ge 0$.
  • Cases 3 and 4: all three slopes have the same sign and one or both end slopes exceed about $2|s|$; case 4 puts two knots in the interval.

Design

"Modification by Marc Pinsonneault": if $m_1 = 0$ or $m_2 = 0$, case 2 is taken at once, to avoid a division by zero in CASES. Without it, a zero end slope would give case 1 or 2, never case 3 or 4 (the cases that divide by $m_1$, $m_2$): The modification changes only case 1 to case 2, when the other slope has the chord's sign and exceeds $|s|$ (lines 77–89↗). Case 2 then stays monotone as long as the other slope is at most $4|s|$ (the middle control value $w_2 = q_2 - m_2(q_1-p_1)/4$ must not pass $p_2$), and the slopes from SLOPES, which OSPLIN always uses, are at most $2|s|$ (inside, the harmonic mean $2m_1m_2/(m_1+m_2)$ of the two chords; at the ends, at most twice the end chord's slope). So the modification keeps the spline monotone in every call YREC makes (settled from the code, Nov 9, 2026).

Question 1 (line 52↗). Equal abscissas. $s$ divides by $q_1 - p_1$ with no check. MEVAL's comment requires XTAB to be increasing (lines 37–38↗), and SLOPES would meet the same zero difference first (question 1). Can a caller pass a table with two equal abscissas?

5def choose(p1: float, p2: float, m1: float, m2: float, q1: float, q2: float, eps: float, ncase: int) -> int:
6    """Choose which of the four cases of McAllister and Roulier's
7    quadratic spline the interval needs, from the end slopes and the
8    slope of the chord.
9
10    Translates: choose.f#CHOOSE (7be4133)
11
12    Arguments: (p1, p2), (q1, q2), the points of interpolation; m1, m2,
13    the slopes there; eps, the tolerance for slopes close to the chord's
14    slope or twice it; ncase, passed in (with any value).
15
16    Returns ncase, 1 to 4.
17
18    """
19
20    # The slope of the chord (Fortran line 52).
21    # Question (see the page): no check that q1 != p1.
22    spq = (q2 - p2) / (q1 - p1)
23
24    # Modification by Marc Pinsonneault, to avoid a division by zero in
25    # CASES: a zero end slope gives case 2 at once (Fortran line 57).
26    if m1 == 0.0 or m2 == 0.0:
27        return 2  # labels 9, 10
28
29    # A flat chord (Fortran lines 59–65).
30    if spq == 0.0:
31        if m1 * m2 >= 0.0:
32            return 2  # label 10
33        return 1
34
35    # Label 20: the end slopes against the chord's (Fortran lines 67–91).
36    prod1 = spq * m1
37    prod2 = spq * m2
38    mref = abs(spq)
39    mref1 = abs(m1)
40    mref2 = abs(m2)
41    if abs(spq - m1) <= eps * mref or abs(spq - m2) <= eps * mref:
42        # label 30: an end slope close to the chord's: case 2 or 3.
43        if prod1 < 0.0 or prod2 < 0.0:
44            return _opposite_signs(prod1, prod2, mref, mref1, mref2, eps)
45    else:
46        if prod1 < 0.0 or prod2 < 0.0:
47            return _opposite_signs(prod1, prod2, mref, mref1, mref2, eps)
48        prod = (mref - mref1) * (mref - mref2)
49        if prod < 0.0:
50            # The two tangent lines meet between p1 and q1.
51            return 1
52
53    # Label 40: all three slopes have the same sign (Fortran lines
54    # 92–122).
55    if mref1 > 2.0 * mref:
56        # label 50
57        if mref2 > (2.0 - eps) * mref:
58            return 4  # label 70
59        return 3
60    if mref2 > 2.0 * mref:
61        # label 60
62        if mref1 > (2.0 - eps) * mref:
63            return 4  # label 70
64        return 3
65    # Both tangents cross the midline: a knot at (p1 + q1)/2.
66    return 2
