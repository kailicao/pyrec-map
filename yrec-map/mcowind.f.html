Purpose

MCOWIND returns the change in the angular velocity of the surface convection zone caused by magnetized-wind angular-momentum loss over a (diffusion) time step. It implements the newer wind law (G. Somers 3/17, "PMM-style", by its comment after van Saders and Pinsonneault, probably) with saturation, an optional Rossby scaling and the centrifugal correction of Matt et al. (2012, ApJ 754, L26). When the new law is off (LMWIND false) it hands over to the older COWIND.

How it fits

  • Who calls it: only SECULR, in the angular-momentum transport, once per iteration IT of the diffusion solution.
  • Inputs: BL ($\log L/L_\odot$), DT (the diffusion step, s), HICZ (moment of inertia of the surface convection zone), IT, OMEGAS (surface $\Omega$ at the end of the previous iteration), WOLD (surface $\Omega$ at the start of the step), SMASS ($M/M_\odot$), TEFFL.
  • Outputs: WIND1 and WIND2, the changes in $\Omega$ over the step computed with $\Omega$ at the start and at the end of the step; the caller averages them (its comment).
  • Calls: COWIND (old law) or AMCALC, which returns STRUCTFACTOR (an output argument, formerly in CWIND) from $M$, $L$ and $T_\mathrm{eff}$.
  • Modules: NMLPAR_MOD (the run's parameters, from PARMIN: the wind law's WMAX, EXW, CONSTFACTOR, EXCEN, formerly in CWIND, and LMWIND, LROSSBY, LBSCALE, the solar values PMMSOLW, PMMSOLTAU, formerly in PMMWIND), OVRTRN_MOD (TAUCZ, TAUCZ0, FRACSTEP: the convective turnover time at the start and end of the step and the fraction of the step reached), and CONSTANTS_MOD (the constants, with C_2, set once in PARMIN).

The method

  1. Saturation. With Rossby scaling, the turnover time is interpolated in the step, $\tau = \tau_0 + f\,(\tau_1 - \tau_0)$, and the saturation rate is $\Omega_\mathrm{sat} = \Omega_\mathrm{max}\,\tau_\odot/\tau$. With the extra field scaling as well (LBSCALE, which acts only with Rossby scaling) the rates $\Omega$ and $\Omega_\mathrm{sat}$ are multiplied by $\tau/\tau_\odot$. Otherwise $\Omega_\mathrm{sat}$ = WMAX.

    Question 1 (lines 105–108↗). $\tau_\mathrm{cz}$ = 0. With LROSSBY, WSAT = WMAX*PMMSOLTAU/TCZ divides by the interpolated turnover time, which is 0 when TAUCZ and TAUCZ0 are both 0, as for a star with no surface convection zone; MWIND has the same division (question 1). Is a model without a surface convection zone kept from reaching here, or should the saturation be skipped when TCZ = 0?

    Question 2 (lines 110–114↗; lines 159–162↗). Rates scaled for LBSCALE. With LBSCALE, WFIRST and WNOW are scaled by $\tau/\tau_\odot$, but the final formula multiplies by the unscaled WOLD and OMEGAS, so the torque goes as $(\Omega\tau)^{a-1}\Omega$ (MWIND does the same). Is that the intended law?

  2. Coefficient. $C = (\Delta t/I_\mathrm{cz})\,K_\mathrm{const}\,K_\mathrm{struct}$.

  3. Centrifugal term. With $f = \Omega^2R^3/(2GM)$, for the star (at the start and end values of $\Omega$) and for the Sun ($f_\odot$), $$F_\mathrm{cen} = \left(\frac{c_2^2 + f_\odot}{c_2^2 + f}\right)^{n},$$ $c_2$ = C_2, $n$ = EXCEN; $R$ from $L = 4\pi R^2\sigma T_\mathrm{eff}^4$. The literals 0.5 and 3.0 in these lines are single precision but exact in binary, so the results are those of double precision (lines 150–154↗; settled from the code, Nov 9, 2026).

  4. Torque. With $\Omega_p = \min(\Omega,\Omega_\mathrm{sat})$ and the exponent $a$ = EXW, $$\Delta\Omega_1 = C\,\Omega_{p,\mathrm{start}}^{\,a-1}\,\Omega_\mathrm{start}\,F_{\mathrm{cen},1},\qquad \Delta\Omega_2 = C\,\Omega_{p,\mathrm{now}}^{\,a-1}\,\Omega_\mathrm{now}\,F_{\mathrm{cen},2},$$ and WIND2 is the running mean of $\Delta\Omega_2$ over the iterations (set at IT = 1, then averaged with the previous value).

    Question 3 (lines 165–169↗). WIND2 averaging. For IT > 1, WIND2 is $\tfrac12$(previous WIND2 + new value), which weights the latest iterations most, not an average over iterations. Is it intended, as a damping?

Change log

The changes since rp_1

Changed since rp_1. Declarations only: COMMON blocks to modules, IMPLICIT NONE; CWIND and PMMWIND retired (C_2 to CONSTANTS_MOD, the rest to NMLPAR_MOD), so STRUCTFACTOR is now returned by AMCALC as an argument; the unused DEUTER dropped. No question settled: GL is still a local that is never set.

Changed since a8a5950. The Sun's centrifugal term FSUN now divides by $G$ (CGL, as the star's terms do) instead of EXP(CLN*GL) with GL an unset local, and GL is no longer declared; the code's comment puts the old $f_\odot$ about $1.5\times10^7$ too small. This settles former question 1; former questions 2–4 are now 1–3.

15    """Return the change in the surface convection zone's angular velocity
16    over a diffusion step from magnetized-wind loss: a saturated power law
17    in Omega, with optional Rossby scaling of the saturation and the
18    centrifugal correction of Matt et al. (2012). With LMWIND false it
19    hands over to the older law, COWIND.
20
21    Translates: mcowind.f#MCOWIND (7be4133)
22
23    Arguments: bl (log L/Lsun), dt (the diffusion step, s), hicz (moment of
24    inertia of the convection zone), it (the iteration), omegas (surface
25    Omega now), smass (M/Msun), teffl (log Teff), wold (surface Omega at
26    the start of the step); wind1 is output only; wind2 is the running
27    mean from the previous iteration (used for it > 1).
28
29    Returns (wind1, wind2): the changes in Omega computed with Omega at the
30    start and at the end of the step.
31
32    """
33
34    c = constants_mod
35    n = nmlpar_mod
36
37    # The old law, if LMWIND is off (Fortran lines 94–98).
38    if not n.lmwind:
39        wind1, wind2 = cowind(bl, dt, hicz, it, omegas, smass,
40                              teffl, wold, wind1, wind2)
41        return wind1, wind2  # label 9999
42
43    # The saturation, with Rossby scaling if desired (Fortran lines
44    # 101–117).
45    wfirst = wold
46    wnow = omegas
47    if n.lrossby:
48        # Turnover time interpolated within the step; saturation scaled.
49        tcz = (ovrtrn_mod.taucz0
50               + ovrtrn_mod.fracstep * (ovrtrn_mod.taucz - ovrtrn_mod.taucz0))
51        wsat = n.wmax * n.pmmsoltau / tcz
52        if n.lbscale:
53            # Question (see the page): only the rates in the min() are
54            # scaled.
55            wfirst = wfirst * tcz / n.pmmsoltau
56            wnow = wnow * tcz / n.pmmsoltau
57            wsat = wsat * tcz / n.pmmsoltau
58    else:
59        wsat = n.wmax
60
61    # New calculation: AMCALC sets the structure factor (Fortran line 139).
62    structfactor = amcalc(smass, bl, teffl, 0.0)
63
64    # The new wind coefficient (Fortran line 143).
65    cc = (dt / hicz) * n.constfactor * structfactor
66
67    # Centrifugal correction (Matt et al. 2012) (Fortran lines 150–156).
68    fsun = 0.5 * n.pmmsolw**2 * c.crsun**3 / math.exp(c.cln * c.cgl) / c.cmsun
69    rl = 0.5 * (bl + c.clsunl - c.c4pil - c.csigl - 4.0 * teffl)
70    fcorr1 = 0.5 * wold**2 * math.exp(c.cln * (3.0 * rl - c.cgl)) / smass / c.cmsun
71    fcorr2 = 0.5 * omegas**2 * math.exp(c.cln * (3.0 * rl - c.cgl)) / smass / c.cmsun
72    fcen1 = ((c.c_2**2 + fsun) / (c.c_2**2 + fcorr1))**n.excen
73    fcen2 = ((c.c_2**2 + fsun) / (c.c_2**2 + fcorr2))**n.excen
74
75    # The changes at the start and end of the step; WIND2 averaged with
76    # its previous value (Fortran lines 159–169).
77    wp = min(wfirst, wsat)
78    wn = min(wnow, wsat)
79    wind1 = cc * wp**(n.exw - 1.0) * wold * fcen1
80    temp = cc * wn**(n.exw - 1.0) * omegas * fcen2
81    if it == 1:
82        wind2 = temp
83    else:
84        # Question (see the page): a running half-and-half mean.
85        wind2 = 0.5 * (wind2 + temp)
86    return wind1, wind2
