icondopacp

Purpose

This file interpolates the electron thermal conductivity in the table of A. Y. Potekhin (condall.d; Potekhin, Baiko, Haensel and Yakovlev 1999, A&A 346, 345, and Potekhin 1999, A&A 351, 787, per its header), for one ion charge $Z_\mathrm{ion}$, temperature and density. It is Potekhin's published routine (version 23.05.99), with small changes for YREC.

How it fits

  • Inputs: the arguments Zion, TLG ($\log T$), RLG ($\log\rho$); the table, read from unit IcondOpacP (IOUNITS_MOD) at the first call. PARMIN sets the unit (75) and opens the file ("MHP 8/25: file opening moved to parmin").
  • Who calls it: CONDOPACPINT, three times per point (for H, He and a metal of charge 8).
  • What it calls: HUNT and CINTERP3, both in this file.
  • Outputs: CK = $\log_{10} K$ (the conductivity, cgs), DRK = $\partial\log K/\partial\log\rho$, DTK = $\partial\log K/\partial\log T$.

The method

The table has 15 values of $\log Z_\mathrm{ion}$, 19 of $\log T$ and 64 of $\log\rho$; in the files of input/opacity/conductive/potekhin/ (condall.d, condall06.d) they span $Z_\mathrm{ion}$ = 1 to 60, $3 \le \log T \le 9$ (steps of 1/3) and $-6 \le \log\rho \le 9.75$ (steps of 0.25).

  1. Locate the point in each grid with HUNT; outside the table the run stops (CONINTER: … out of range).
  2. Cubic interpolation in $\log\rho$ at 4 temperatures and 2 charges (8 calls to CINTERP3), giving $\log K$ and its derivative in $\log\rho$.
  3. Linear interpolation in $\log Z_\mathrm{ion}$.
  4. Cubic interpolation in $\log T$, of $\log K$ (giving also $\partial\log K/\partial\log T$) and of $\partial\log K/\partial\log\rho$.

Design

The table is kept in local SAVEd arrays, read once (KRUN = 12345 marks it read). The array sizes must match the file. The error branch for $T$ prints the $Z$ grid before stopping, a debugging leftover.

Physics Options: LCONDOPACP uses the updated conductive opacity tables, whose path is FcondOpacP (Control Options).

1. (never occurred) A point on the table's last temperature or density stops the run.

(lines 99–109↗) HUNT returns N for a value equal to the last grid value (lines 269–276↗), and the tests after it treat N as out of range, so the run stops ("CONINTER: T out of range," "CONINTER: rho out of range"). CONDOPACPINT guards its calls with limits that include the table's upper edges, $\log T \le 9$ and $\log\rho \le 9.75$ (condopacpint.f, line 54↗), so a point at exactly $\log T = 9$ or $\log\rho = 9.75$ passes the guard and stops the run. Only with LcondOpacP (off by default, set in all 51 decks of the test suite and recommended by the user guide), and only at exactly these values, so rare.

Interpolation on the interval $[z_0, z_1]$ from 4 tabulated points: a cubic Hermite polynomial whose end slopes are weighted means of the neighboring secant slopes, $$v'_0 = \frac{(v_1 - v_0)/h^2 + (v_0 - v_-)/h_-^2}{1/h + 1/h_-},$$ and likewise $v'_1$; quadratic at the table's first and last intervals. Returns the value, the first and the second derivative.

233*   Numerical Receipes(Cambridge Univ., 1986)
234*     Given an array XX of length N, and given a value X,
235*     returns a value JLO such that X is between XX(JLO) and XX(JLO+1).
236*     XX must be monotonic, either increasing or decreasing.

41def _read_values(unit: int, n: int) -> list:

67def condopacp(zion: float, tlg: float, rlg: float, ck: float, drk: float, dtk: float) -> tuple[float, float, float]:
68    """Interpolate log10 of the electron thermal conductivity, and its
69    derivatives in log rho and log T, in Potekhin's table: cubic in
70    log rho and log T, linear in log Z_ion. Reads the table at the first
71    call.
72
73    Translates: condopacp.f#CONDOPACP (7be4133)
74
75    Parameters
76    ----------
77    zion : float
78        The ion charge.
79    tlg, rlg : float
80        log10 T (K) and log10 rho (g/cm^3).
81    ck, drk, dtk : float
82        Output only (passed in with any value).
83
84    Returns
85    -------
86    ck, drk, dtk : float
87        log10 K (cgs), d log K / d log rho, and d log K / d log T.
88
89    """
90
91    global krun, iz, it, ir
92
93    # Read the table at the first call; the file is opened by PARMIN (Fortran lines 72–86).
94    if krun != KRUN_READ:
95        ip = iounits_mod.icondopacp
96        iounits_mod.read(ip)  # skip the first line
97        for iz in range(1, MAXZ + 1):
98            vals = _read_values(ip, 1 + MAXT)
99            z = vals[0]
100            for it in range(1, MAXT + 1):
101                at[it] = vals[it]
102            az[iz] = math.log10(z)
103            for ir in range(1, MAXR + 1):
104                vals = _read_values(ip, 1 + MAXT)
105                ar[ir] = vals[0]
106                for it in range(1, MAXT + 1):
107                    akap[it, ir, iz] = vals[it]
108        iounits_mod.close(ip)
109        krun = KRUN_READ
110
111        # The middle of the table, HUNT's first guesses: INT(MAXZ/2.)+1, the same as
112        # MAXZ/2+1, KC 2025-05-30 (Fortran lines 87–93).
113        iz = int(MAXZ / 2.0) + 1
114        it = int(MAXT / 2.0) + 1
115        ir = int(MAXR / 2.0) + 1
116
117    # The Numba kernel (accel.py), with the table and HUNT's guesses passed in; a stop is left to the plain code.
118    if accel.USE_NUMBA:
119        guess = _guess
120        guess[0] = iz
121        guess[1] = it
122        guess[2] = ir
123        ck, drk, dtk, status = _condopacp_nb(zion, tlg, rlg, at, ar, az, akap, guess)
124        if status == 0:
125            iz, it, ir = guess.tolist()
126            return ck, drk, dtk
127
128    # The charge in its grid (Fortran lines 96–98).
129    zlg = math.log10(zion)
130    iz = hunt(az, MAXZ, zlg, iz)
131    if iz == 0 or iz == MAXZ:
132        raise SystemExit('CONINTER: Z out of range')
133
134    # The temperature in its grid (Fortran lines 99–106).
135    it = hunt(at, MAXT, tlg, it)
136    # Suspected bug (see the page): a point exactly at the last grid value
137    # (log T = 9) also stops here.
138    if it == 0 or it == MAXT:
139        # A debugging leftover: the Z grid is printed before stopping.
140        print(*az[1:])
141        print(MAXZ, tlg, iz)
142        raise SystemExit('CONINTER: T out of range')
143
144    # The density in its grid (Fortran lines 108–109).
145    ir = hunt(ar, MAXR, rlg, ir)
146    # Suspected bug (see the page): a point exactly at the last grid value
147    # (log rho = 9.75) also stops here.
148    if ir == 0 or ir == MAXR:
149        raise SystemExit('CONINTER: rho out of range')
150
151    # The neighbors used for the cubics (Fortran lines 110–113).
152    itm = max(1, it - 1)
153    itp = min(MAXT, it + 2)
154    irm = max(1, ir - 1)
155    irp = min(MAXR, ir + 2)
156
157    # Cubic interpolation in log rho, at the 4 temperatures ITM, IT,
158    # IT+1, ITP and the 2 charges IZ, IZ+1 (Fortran lines 114–148).
159    cktmz0, drktmz0, dr2ktmz0 = condopacp_in_rho(ar, akap, irm, ir, irp, rlg, itm, iz)
160    ckt0z0, drkt0z0, dr2kt0z0 = condopacp_in_rho(ar, akap, irm, ir, irp, rlg, it, iz)
161    ckt1z0, drkt1z0, dr2kt1z0 = condopacp_in_rho(ar, akap, irm, ir, irp, rlg, it + 1, iz)
162    cktpz0, drktpz0, dr2ktpz0 = condopacp_in_rho(ar, akap, irm, ir, irp, rlg, itp, iz)
163    cktmz1, drktmz1, dr2ktmz1 = condopacp_in_rho(ar, akap, irm, ir, irp, rlg, itm, iz + 1)
164    ckt0z1, drkt0z1, dr2kt0z1 = condopacp_in_rho(ar, akap, irm, ir, irp, rlg, it, iz + 1)
165    ckt1z1, drkt1z1, dr2kt1z1 = condopacp_in_rho(ar, akap, irm, ir, irp, rlg, it + 1, iz + 1)
166    cktpz1, drktpz1, dr2ktpz1 = condopacp_in_rho(ar, akap, irm, ir, irp, rlg, itp, iz + 1)
167
168    # Linear interpolation in log Z (Fortran lines 149–163).
169    xz1 = (zlg - az[iz]) / (az[iz + 1] - az[iz])
170    xz0 = 1.0 - xz1
171    cktm = xz0 * cktmz0 + xz1 * cktmz1
172    drktm = xz0 * drktmz0 + xz1 * drktmz1
173    dr2ktm = xz0 * dr2ktmz0 + xz1 * dr2ktmz1  # noqa: F841  (unused in the Fortran too)
174    ckt0 = xz0 * ckt0z0 + xz1 * ckt0z1
175    drkt0 = xz0 * drkt0z0 + xz1 * drkt0z1
176    dr2kt0 = xz0 * dr2kt0z0 + xz1 * dr2kt0z1  # noqa: F841  (unused in the Fortran too)
177    ckt1 = xz0 * ckt1z0 + xz1 * ckt1z1
178    drkt1 = xz0 * drkt1z0 + xz1 * drkt1z1
179    dr2kt1 = xz0 * dr2kt1z0 + xz1 * dr2kt1z1  # noqa: F841  (unused in the Fortran too)
180    cktp = xz0 * cktpz0 + xz1 * cktpz1
181    drktp = xz0 * drktpz0 + xz1 * drktpz1
182    dr2ktp = xz0 * dr2ktpz0 + xz1 * dr2ktpz1  # noqa: F841  (unused in the Fortran too)
183
184    # Cubic interpolation in log T: of log K (giving d log K / d log T),
185    # and of d log K / d log rho (Fortran lines 164–170).
186    ck, dtk, dt2k, xt = cinterp3(at[itm], at[it], at[it + 1], at[itp], tlg,
187                                 it, MAXT, cktm, ckt0, ckt1, cktp,
188                                 0.0, 0.0, 0.0, 0.0)
189    drk, drtk, drt2k, xt = cinterp3(at[itm], at[it], at[it + 1], at[itp],
190                                    tlg, it, MAXT, drktm, drkt0, drkt1,
191                                    drktp, 0.0, 0.0, 0.0, 0.0)
192    return ck, drk, dtk

224def cinterp3(zm: float, z0: float, z1: float, zp: float, z: float, n0: int, mxnv: int, vm: float, v0: float, v1: float,
225             vp: float, vf: float, df: float, d2: float, xh: float) -> tuple[float, float, float, float]:
226    """Interpolate at z on [z0, z1] from 4 tabulated points: a cubic
227    Hermite polynomial with end slopes from the neighboring secants, and
228    quadratic on the table's first and last intervals.
229
230    Translates: condopacp.f#CINTERP3 (7be4133)
231
232    Parameters
233    ----------
234    zm, z0, z1, zp : float
235        The four abscissae (z0 and z1 bracket z).
236    z : float
237        The point of interpolation.
238    n0 : int
239        The index of z0 in the table.
240    mxnv : int
241        The table's length.
242    vm, v0, v1, vp : float
243        The values at the four abscissae.
244    vf, df, d2, xh : float
245        Output only (passed in with any value).
246
247    Returns
248    -------
249    vf, df, d2, xh : float
250        The value, the first and the second derivative, and the fraction
251        of the way from z0 to z1.
252
253    """
254    # The interval checked (Fortran line 189).
255    if n0 <= 0 or n0 >= mxnv:
256        raise SystemExit('CINTERP: N0 out of range')
257    if accel.USE_NUMBA:
258        return _cinterp3_nb(zm, z0, z1, zp, z, n0, mxnv, vm, v0, v1, vp)
259
260    # The position in the interval (Fortran lines 190–192).
261    x = z - z0
262    h = z1 - z0  # the basic interval
263    xh = x / h
264
265    # The slopes at the two ends, where there is a neighbor (Fortran lines 193–202).
266    if n0 > 1:
267        hm = z0 - zm  # the left adjoining interval
268        v01 = (((v1 - v0) / (h * h) + (v0 - vm) / (hm * hm))
269               / (1.0 / h + 1.0 / hm))  # the left derivative
270    if n0 < mxnv - 1:
271        hp = zp - z1  # the right adjoining interval
272        v11 = (((v1 - v0) / (h * h) + (vp - v1) / (hp * hp))
273               / (1.0 / h + 1.0 / hp))  # the right derivative
274
275    if n0 > 1 and n0 < mxnv - 1:
276        # Cubic interpolation (Fortran lines 203–210).
277        c2 = 3.0 * (v1 - v0) - h * (v11 + 2.0 * v01)
278        c3 = h * (v01 + v11) - 2.0 * (v1 - v0)
279        vf = v0 + v01 * x + c2 * (xh * xh) + c3 * (xh * xh * xh)
280        df = v01 + (2.0 * c2 * xh + 3.0 * c3 * (xh * xh)) / h
281        d2 = (2.0 * c2 + 6.0 * c3 * xh) / (h * h)
282        return vf, df, d2, xh  # GOTO 10
283
284    if n0 == 1:
285        # Quadratic interpolation, first interval (Fortran lines 211–215).
286        c2 = v0 - v1 + v11 * h
287        vf = v1 - v11 * (h - x) + c2 * ((1.0 - xh) * (1.0 - xh))
288        df = v11 - 2.0 * c2 * (1.0 - xh) / h
289        d2 = 2.0 * c2 / (h * h)
290    else:
291        # Quadratic interpolation, last interval, N0 = MXNV-1 (Fortran lines 216–221).
292        c2 = v1 - v0 - v01 * h
293        vf = v0 + v01 * x + c2 * (xh * xh)
294        df = v01 + 2.0 * c2 * xh / h
295        d2 = 2.0 * c2 / (h * h)
296    return vf, df, d2, xh

299def hunt(xx: np.ndarray, n: int, x: float, jlo: int) -> int:
300    """Numerical Recipes' HUNT: find jlo with x between xx[jlo] and
301    xx[jlo+1] in a monotonic table, starting from the guess jlo and
302    doubling the step before bisecting.
303
304    Translates: condopacp.f#HUNT (7be4133)
305
306    Parameters
307    ----------
308    xx : np.ndarray, shape: `(n + 1,)` at least, dtype: ``float64``
309        The table xx[1..n], monotonic (index 0 unused).
310    n : int
311        The table's length.
312    x : float
313        The value to bracket.
314    jlo : int
315        The first guess.
316
317    Returns
318    -------
319    int
320        jlo: 0 or n outside the table (n also for x equal to xx[n]).
321
322    """
323    if accel.USE_NUMBA:
324        return _hunt_nb(xx, n, x, jlo)
325
326    # The table's order (Fortran line 241).
327    ascnd = xx[n] > xx[1]  # True if ascending
328
329    if jlo <= 0 or jlo > n:
330        # The guess is not useful: go to bisection (Fortran lines 242–246).
331        jlo = 0
332        jhi = n + 1
333    else:
334        inc = 1
335        if (x >= xx[jlo]) == ascnd:
336            # Hunt up, label 1 (Fortran lines 247–256).
337            while True:
338                jhi = jlo + inc
339                if jhi > n:
340                    jhi = n + 1  # off the end of the table
341                    break
342                elif (x >= xx[jhi]) == ascnd:
343                    jlo = jhi
344                    inc = inc + inc
345                    continue
346                break
347        else:
348            # Hunt down, label 2 (Fortran lines 257–267).
349            jhi = jlo
350            while True:
351                jlo = jhi - inc
352                if jlo < 1:
353                    jlo = 0  # off the end of the table
354                    break
355                elif (x < xx[jlo]) == ascnd:
356                    jhi = jlo
357                    inc = inc + inc
358                    continue
359                break
360
361    # Bisection, label 3 (Fortran lines 268–276).
362    while jhi - jlo != 1:
363        jm = (jhi + jlo) // 2
364        if (x >= xx[jm]) == ascnd:
365            jlo = jm
366        else:
367            jhi = jm
368    return jlo

371# --- The Numba kernels (accel.py) -----------------------------------------------------------------------------------
372#
373# The plain code above is the reference; the kernels repeat its statements, in its order, for Numba. condopacp's
374# kernel takes the table (at, ar, az, akap: locals the Fortran SAVEs, module-level here) and HUNT's three guesses
375# (guess: iz, it, ir, changed in place) as arguments, and returns a status: 0, or 1-3 for the stops (Z, T, rho out of
376# range), left to the plain code, which prints and stops as the Fortran does. getopac's kernel calls it directly.
377
378@accel.njit(_nrt=False, inline='always')
379def _cinterp3_nb(zm: float, z0: float, z1: float, zp: float, z: float, n0: int, mxnv: int, vm: float, v0: float,
380                 v1: float, vp: float) -> tuple[float, float, float, float]:
381    """cinterp3 for 1 <= n0 < mxnv (the caller checks): (vf, df, d2, xh) (Fortran lines 190–221)."""
382    x = z - z0
383    h = z1 - z0
384    xh = x / h
385    v01 = 0.0
386    v11 = 0.0
387    if n0 > 1:
388        hm = z0 - zm
389        v01 = (((v1 - v0) / (h * h) + (v0 - vm) / (hm * hm))
390               / (1.0 / h + 1.0 / hm))
391    if n0 < mxnv - 1:
392        hp = zp - z1
393        v11 = (((v1 - v0) / (h * h) + (vp - v1) / (hp * hp))
394               / (1.0 / h + 1.0 / hp))
395    if n0 > 1 and n0 < mxnv - 1:
396        c2 = 3.0 * (v1 - v0) - h * (v11 + 2.0 * v01)
397        c3 = h * (v01 + v11) - 2.0 * (v1 - v0)
398        vf = v0 + v01 * x + c2 * (xh * xh) + c3 * (xh * xh * xh)
399        df = v01 + (2.0 * c2 * xh + 3.0 * c3 * (xh * xh)) / h
400        d2 = (2.0 * c2 + 6.0 * c3 * xh) / (h * h)
401        return vf, df, d2, xh
402    if n0 == 1:
403        c2 = v0 - v1 + v11 * h
404        vf = v1 - v11 * (h - x) + c2 * ((1.0 - xh) * (1.0 - xh))
405        df = v11 - 2.0 * c2 * (1.0 - xh) / h
406        d2 = 2.0 * c2 / (h * h)
407    else:
408        c2 = v1 - v0 - v01 * h
409        vf = v0 + v01 * x + c2 * (xh * xh)
410        df = v01 + 2.0 * c2 * xh / h
411        d2 = 2.0 * c2 / (h * h)
412    return vf, df, d2, xh
