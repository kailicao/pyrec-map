icondopacp

Purpose

This file interpolates the electron thermal conductivity in the table of A. Y. Potekhin (condall.d; Potekhin, Baiko, Haensel and Yakovlev 1999, A&A 346, 345, and Potekhin 1999, A&A 351, 787, per its header), for one ion charge $Z_\mathrm{ion}$, temperature and density. It is Potekhin's published routine (version 23.05.99), with small changes for YREC.

How it fits

  • Inputs: the arguments Zion, TLG ($\log T$), RLG ($\log\rho$); the table, read from unit IcondOpacP (IOUNITS_MOD) at the first call. PARMIN sets the unit (75) and opens the file ("MHP 8/25: file opening moved to parmin").
  • Who calls it: CONDOPACPINT, three times per point (for H, He and a metal of charge 8).
  • What it calls: HUNT and CINTERP3, both in this file.
  • Outputs: CK = $\log_{10} K$ (the conductivity, cgs), DRK = $\partial\log K/\partial\log\rho$, DTK = $\partial\log K/\partial\log T$.

The method

The table has 15 values of $\log Z_\mathrm{ion}$, 19 of $\log T$ and 64 of $\log\rho$; in the files of input/opacity/conductive/potekhin/ (condall.d, condall06.d) they span $Z_\mathrm{ion}$ = 1 to 60, $3 \le \log T \le 9$ (steps of 1/3) and $-6 \le \log\rho \le 9.75$ (steps of 0.25).

  1. Locate the point in each grid with HUNT; outside the table the run stops (CONINTER: … out of range).
  2. Cubic interpolation in $\log\rho$ at 4 temperatures and 2 charges (8 calls to CINTERP3), giving $\log K$ and its derivative in $\log\rho$.
  3. Linear interpolation in $\log Z_\mathrm{ion}$.
  4. Cubic interpolation in $\log T$, of $\log K$ (giving also $\partial\log K/\partial\log T$) and of $\partial\log K/\partial\log\rho$.

Design

The table is kept in local SAVEd arrays, read once (KRUN = 12345 marks it read). The array sizes must match the file. The error branch for $T$ prints the $Z$ grid before stopping, a debugging leftover.

From YREC's documentation

Physics Options: LCONDOPACP uses the updated conductive opacity tables, whose path is FcondOpacP (Control Options).

225            subroutine HUNT(XX,N,X,JLO)
226C 10/20/26 MHP via Claude
227C code changed to replace implicit typing with IMPLICIT NONE and
228C explicit declarations.
229            implicit none
230            real*8 x,xx
231            integer inc,jhi,jlo,jm,n
232*   W.H.Press, B.P.Flannery, S.A.Teukolsky, W.T.Vetterling
233*   Numerical Receipes(Cambridge Univ., 1986)
234*     Given an array XX of length N, and given a value X,
235*     returns a value JLO such that X is between XX(JLO) and XX(JLO+1).
236*     XX must be monotonic, either increasing or decreasing.
237*     JLO=0 or JLO=N is returned to indicate that X is out of range.
238*     JLO on input is taken as the initial guess for JLO on output.

155def cinterp3(zm: float, z0: float, z1: float, zp: float, z: float, n0: int, mxnv: int, vm: float, v0: float, v1: float,
156             vp: float, vf: float, df: float, d2: float, xh: float) -> tuple[float, float, float, float]:
157    """Interpolate at z on [z0, z1] from 4 tabulated points: a cubic
158    Hermite polynomial with end slopes from the neighboring secants, and
159    quadratic on the table's first and last intervals.
160
161    Translates: condopacp.f#CINTERP3 (7be4133)
162
163    Arguments: zm, z0, z1, zp and vm, v0, v1, vp, the 4 points; z; n0, the
164    index of z0 in the table; mxnv, the table's length; vf, df, d2, xh,
165    passed in (with any value).
166
167    Returns (vf, df, d2, xh): the value, the first and the second
168    derivative, and the fraction of the way from z0 to z1.
169
170    """
171    # The interval checked (Fortran line 189).
172    if n0 <= 0 or n0 >= mxnv:
173        raise SystemExit('CINTERP: N0 out of range')
174
175    # The position in the interval (Fortran lines 190–192).
176    x = z - z0
177    h = z1 - z0  # the basic interval
178    xh = x / h
179
180    # The slopes at the two ends, where there is a neighbor (Fortran lines 193–202).
181    if n0 > 1:
182        hm = z0 - zm  # the left adjoining interval
183        v01 = (((v1 - v0) / h ** 2 + (v0 - vm) / hm ** 2)
184               / (1.0 / h + 1.0 / hm))  # the left derivative
185    if n0 < mxnv - 1:
186        hp = zp - z1  # the right adjoining interval
187        v11 = (((v1 - v0) / h ** 2 + (vp - v1) / hp ** 2)
188               / (1.0 / h + 1.0 / hp))  # the right derivative
189
190    if n0 > 1 and n0 < mxnv - 1:
191        # Cubic interpolation (Fortran lines 203–210).
192        c2 = 3.0 * (v1 - v0) - h * (v11 + 2.0 * v01)
193        c3 = h * (v01 + v11) - 2.0 * (v1 - v0)
194        vf = v0 + v01 * x + c2 * xh ** 2 + c3 * xh ** 3
195        df = v01 + (2.0 * c2 * xh + 3.0 * c3 * xh ** 2) / h
196        d2 = (2.0 * c2 + 6.0 * c3 * xh) / h ** 2
197        return vf, df, d2, xh  # GOTO 10
198
199    if n0 == 1:
200        # Quadratic interpolation, first interval (Fortran lines 211–215).
201        c2 = v0 - v1 + v11 * h
202        vf = v1 - v11 * (h - x) + c2 * (1.0 - xh) ** 2
203        df = v11 - 2.0 * c2 * (1.0 - xh) / h
204        d2 = 2.0 * c2 / h ** 2
205    else:
206        # Quadratic interpolation, last interval, N0 = MXNV-1 (Fortran lines 216–221).
207        c2 = v1 - v0 - v01 * h
208        vf = v0 + v01 * x + c2 * xh ** 2
209        df = v01 + 2.0 * c2 * xh / h
210        d2 = 2.0 * c2 / h ** 2
211    return vf, df, d2, xh

214def hunt(xx: np.ndarray, n: int, x: float, jlo: int) -> int:
215    """Numerical Recipes' HUNT: find jlo with x between xx[jlo] and

226    # The table's order (Fortran line 241).
227    ascnd = xx[n] > xx[1]  # True if ascending

231        jlo = 0

262    while jhi - jlo != 1:
