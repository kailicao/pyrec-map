Purpose

Tests the edges of the first convection zone (every zone at rp_1) for semiconvection and, where the region next to it is unstable, extends the zone, following Castellani et al. (1971, Ap&SS 10, 340), as the header comment says. It then merges zones that have come to overlap.

How it fits

  • Who calls it: MIX, before the composition is mixed in the convection zones, when semiconvection is on (LSEMIC) and from the second iteration (ITLVL > 1).
  • Inputs: the step DELTS (s), the model's $\log\rho$ (HD), $L$ (HL, in solar units, by the factor CLSUN), $\log P$, $\log r$, $\log m$, $\log T$ (HP, HR, HS, HT), the composition HCOMP, TEFFL, the mixing length CMIXL (passed on to TPGRAD), and the zones MXZONE(12,2) (bottom and top shell of each), NZONE.
  • What it calls: for each test point, EQSTAT (equation of state: $\nabla_\mathrm{ad}$, the mean molecular weights), GETOPAC (opacity) and TPGRAD (the radiative gradient $\nabla_\mathrm{rad}$).
  • Outputs: MXZONE and NZONE, changed; a line in the short output (ISHORT) for each edge it moves and each merger. Also, HD at the shells it tests is overwritten with the density returned by EQSTAT.
  • Modules: DEBHU_MOD (it loads XXDH, YYDH, ZZDH, ZDH(1..3) with each test point's composition for the Debye–Hückel correction in EQSTAT, when LDH is set), CONSTANTS_MOD, NMLPAR_MOD, IOUNITS_MOD (ISHORT), DIMENSIONS_MOD.

Question 1 (lines 186–194↗; lines 243–252↗). Overwriting the model's density. EQSTAT lists DL among its outputs (the density for the given $P$, $T$ and composition), and HD(JMR) = DL and HD(II) = DL write it back into the model. At JMR, the value kept is the one from the second call, with the shell's own composition; but in the walk it is computed for the shell as it is, before any mixing. Is this write-back needed, and is it safe for the next steps of MIX?

The method

For the first zone only (a local switch, L_ONLY_CORE, set to true; with it false, every zone) and each edge that is not the center or the surface (LFLAGD, LFLAGU); a fully convective star is skipped:

Question 2 (line 63↗; lines 90–98↗). Only the first zone. A local switch, L_ONLY_CORE = .TRUE., set just before the loop over zones (no dated comment), limits the test to MXZONE(1,·), the innermost zone, whether it is a convective core or, in a star without one, an intermediate or the surface zone (whose bottom edge is then still tested). The name suggests that only a convective core was meant, and the header comment still says all convective regions are tested. Is this restriction meant to stay, and should it test MXZONE(1,1) = 1 (a core) rather than the first zone, or be a namelist parameter?

  1. At the first radiative shell outside the edge (JMR), compute $\nabla_\mathrm{rad}$ with the zone's composition. If $\nabla_\mathrm{rad} < \nabla_\mathrm{ad}$, the edge is stable. Otherwise keep $\nabla_\mathrm{rad,1}$, the mean molecular weight $\mu_\mathrm{CZ}$ (XINTMU = AMU + EMU), and $1 - \nabla_\mathrm{ad}/\nabla_\mathrm{rad}$.
  2. Recompute at the same shell with its own composition: $\nabla_\mathrm{rad,0}$, and the ratio $f = \nabla_\mathrm{rad,1}/\nabla_\mathrm{rad,0}$ (FDEL).

  3. The farthest the instability can reach in one step is the propagation speed (eq. 5′, p. 347 of the paper) times the step: $$R_\mathrm{max} = \Bigl(1 - \frac{\nabla_\mathrm{ad}}{\nabla_\mathrm{rad,1}}\Bigr)\,\frac{L}{10\cdot4\pi P\,r^2}\,\Delta t,$$ with $L$, $P$, $r$ at the zone's edge shell.

    Question 3 (lines 198–202↗). The factor 10. $R_\mathrm{max}$ has $L/(10\cdot4\pi P r^2)$. Is the 10 from the paper's equation 5′, or a tuning factor? 4. Walk outward from the edge (down for the bottom edge, up for the top), shell by shell, accumulating $$R_\Sigma = \sum \Bigl(1 - \frac{\mu_\mathrm{CZ}}{\mu}\Bigr)\,\Delta r .$$ Stop when $R_\Sigma > R_\mathrm{max}$ (the limit, LMAX true) or when the shell is stable against the rescaled gradient, $f\,\nabla_\mathrm{rad} < \nabla_\mathrm{ad}$. The edge moves to the last unstable shell. In the walk, every quantity passed to TPGRAD is reset for the shell except RL (but see bug 2).

    "Overshoot" in the comments means semiconvection. The comments at line 198↗, line 205↗, and line 219↗ speak of "OVERSHOOT," but the routine is the semiconvection of Castellani et al. (1971) (lines 63–65↗), and its own merger message says "MERGED DUE TO SEMICONVECTION" (line 282↗), so the word is a leftover. 5. Mergers. If the top of zone $j$ is now above the bottom of zone $j+1$, they become one zone, and the list is shifted down (but see bug 1).

    Question 4 (line 278↗). Touching zones. Zones are merged only when they overlap (MXZONE(J,2) .GT. MXZONE(J+1,1)), not when they become adjacent (top of one = bottom of the next − 1), which leaves no radiative shell between them. Should adjacency also merge?

1. (not reached) A merger keeps the upper zone's top.

(lines 278–291↗) When zones $j$ and $j+1$ overlap, the merged zone takes the bottom of zone $j$ and the top of zone $j+1$ (MXZONE(J+1,1) = MXZONE(J,1), then the list is shifted). The walk upward from zone 1's top (step 4) passes through any zone above it and can end beyond that zone's top; the merged zone then ends at the upper zone's top, below the edge just found, and the semiconvective region above it is not mixed. Only with LSEMIC (off by default) and a second zone within $R_\mathrm{max}$ of the first.

252                              HD(II) = DL
253C EXIT IF ZONE IS RADIATIVELY STABLE.
254                              IF(FDEL*DELR.LT.DELA) GO TO 34
255   32          32       CONTINUE
256                        IF(K.EQ.1) II = 0
257                        IF(K.EQ.2) II = M + 1
258   33          33       LMAX = .TRUE.
259   34          34       CONTINUE
260C ASSIGN THE NEW EDGE LOCATION TO MXZONE.
261                        IF(K.EQ.1)THEN
262                              MXZONE(I,K) = II + 1
263                              JMC2 = II + 1
264                        ELSE IF(K.EQ.2)THEN
265                              MXZONE(I,K) = II - 1
266                              JMC2 = II - 1
267                        ENDIF
268                        WRITE(ISHORT,601) JMC,JMC2,LMAX,DELR1,DELR0
269  601         601       FORMAT(1X,'CZ OLD EDGE ',I3,' EXTENDED TO-',
270     *              *             I3,' LIMIT=',L1,' RAD.GRADS-IN/OUT',2F8.4)
271  200      200    CONTINUE
272  210   210 CONTINUE
273C  CHECK FOR MERGERS OF NEARBY CONVECTION ZONES CAUSED BY SEMI-CONVECTION.
274            IF(NZONE.LE.1) RETURN
275            J = 1
276   85    85 CONTINUE
277C  CHECK IF 'TOP' OF ONE REGION IS ABOVE 'BOTTOM' OF THE NEXT ONE.
278            IF(MXZONE(J,2).GT.MXZONE(J+1,1))THEN
279C  IF THIS OCCURS, TWO CONVECTION ZONES HAVE MERGED.
280                  WRITE(ISHORT,93)((MXZONE(K,K1),K1=1,2),K=J,J+1),MXZONE(J,1),
281     *           *              MXZONE(J+1,2)
282   93       93    FORMAT(2X,'MIXED ZONES MERGED DUE TO SEMICONVECTION'
283     *           *          /2X,'OLD',2('[',I3,'-',I3,']'),
284     *           *          ' NEW','[',I3,'-',I3,']')
285                  MXZONE(J+1,1) = MXZONE(J,1)
286                  DO 90 K = J,NZONE-1
287                        DO 95 J2 = 1,2
288                              MXZONE(K,J2) = MXZONE(K+1,J2)
289   95          95       CONTINUE
290   90       90    CONTINUE
291                  NZONE = NZONE - 1
292                  IF(J.LE.NZONE-1)THEN
293                        GOTO 85
294                  ELSE
295                        RETURN
296                  ENDIF
297            ENDIF
298            J = J + 1
299            IF (J.LE.NZONE-1)GOTO 85
300
301            RETURN
302            END

53def sconvec(delts: float, hcomp: np.ndarray, hd: np.ndarray, hl: np.ndarray, hp: np.ndarray, hr: np.ndarray,
54            hs: np.ndarray, ht: np.ndarray, m: int, mxzone: np.ndarray, nzone: int, teffl: float, cmixl: float) -> int:
55    """Test the edges of the first convection zone (L_ONLY_CORE) for
56    semiconvection and extend the zone where the region next to it is
57    unstable, as far as the propagation speed allows in one step; then
58    merge zones that overlap.
59
60    Translates: sconvec.f#SCONVEC (7be4133)
61
62    Arguments: the step delts (s); hcomp[species, shell]; the model's hd
63    (log rho; overwritten at the shells tested), hl (L/Lsun), hp, hr, hs,
64    ht (logs); m shells; the zones mxzone[k, 1..2] (changed in place) and
65    their count nzone; teffl; cmixl, the mixing length (for tpgrad).
66
67    Returns nzone (reduced by mergers).
68
69    """
70
71    c = constants_mod
72
73    # Only the first zone (Fortran lines 89–98).
74    # Question (see the page): only the first zone is tested.
75    l_only_core = True
76    if l_only_core:
77        iloop = 1
78    else:
79        iloop = nzone
80    for i in range(1, iloop + 1):                   # loop 210
81        # Core, surface or intermediate zone: LFLAGU (test above),
82        # LFLAGD (test below) (Fortran lines 101–119).
83        if mxzone[i, 1] == 1:
84            # Convective core; skip a fully convective star.
85            if mxzone[i, 2] == m:
86                return nzone
87            lflagu = True
88            lflagd = False
89        elif mxzone[i, 2] == m:
90            lflagu = False
91            lflagd = True
92        else:
93            lflagu = True
94            lflagd = True
95
96        for k in (1, 2):                            # loop 200
97            # Fortran lines 120–134.
98            if k == 1 and not lflagd:
99                continue
100            if k == 2 and not lflagu:
101                continue
102            # The edge of the zone (JMC) and the first radiative shell
103            # outside it (JMR).
104            jmc = mxzone[i, k]
105            if k == 1:
106                jmr = jmc - 1
107            if k == 2:
108                jmr = jmc + 1
109            lderiv = False
110            locond = True  # noqa: F841  (unused in the Fortran too)
111            latmo = True
112            ksaha = 0
113
114            # The structure of JMR with the zone's composition (Fortran
115            # lines 135–168).
116            b = hl[jmr]
117            sl = hs[jmr]
118            pl = hp[jmr]
119            tl = ht[jmr]
120            dl = hd[jmr]
121            rl = hr[jmr]
122            x = hcomp[1, jmc]
123            z = hcomp[3, jmc]
124            fpl = 1.0
125            ftl = 1.0
126            iu = jmc
127            _load_debhu(hcomp, jmc)
128            dl, amu, emu, dela, delr = _gradients(
129                tl, pl, dl, rl, sl, b, x, z, lderiv, latmo, ksaha,
130                fpl, ftl, teffl, cmixl)
131            # Skip if stable with the zone's composition.
132            if delr < dela:
133                continue
134
135            # Fortran lines 169–173.
136            xintmu = amu + emu
137            delr1 = delr
138            rmax = 1.0 - dela / delr
139
140            # Repeat with the local composition (Fortran lines 174–194).
141            # Question (see the page): hd overwritten.
142            x = hcomp[1, jmr]
143            z = hcomp[3, jmr]
144            iu = jmr
145            _load_debhu(hcomp, jmr)
146            dl, amu, emu, dela, delr = _gradients(
147                tl, pl, dl, rl, sl, b, x, z, lderiv, latmo, ksaha,
148                fpl, ftl, teffl, cmixl)
149            hd[jmr] = dl
150
151            # Ratio of the gradients with the zone's and the local
152            # composition (Fortran lines 195–197).
153            fdel = delr1 / delr
154            delr0 = delr
155
156            # RMAX: the step times the propagation speed (eq. 5') (Fortran
157            # lines 198–202).
158            # Question (see the page): the factor 10.
159            rmax = (rmax * (hl[jmc] * c.clsun
160                            / (10.0 * c.c4pi * math.exp(c.cln * hp[jmc])))
161                    * (delts / math.exp(c.cln * (hr[jmc] + hr[jmc]))))
162
163            # The walk's start (Fortran lines 203–217).
164            rsum = 0.0
165            lmax = False
166            if k == 1:
167                rval1 = math.exp(c.cln * hr[jmr + 1])
168                jbeg = jmr - 1
169                jend = 1
170                jstep = -1
171            elif k == 2:
172                rval1 = math.exp(c.cln * hr[jmr - 1])
173                jbeg = jmr + 1
174                jend = m
175                jstep = 1
176
177            # The walk, shell by shell (Fortran lines 218–259).
178            stable = False
179            for ii in range(jbeg, jend + jstep, jstep):     # loop 32
180                # The limit in radius (Fortran lines 219–225).
181                if k == 1:
182                    rval2 = math.exp(c.cln * hr[ii + 1])
183                if k == 2:
184                    rval2 = math.exp(c.cln * hr[ii - 1])
185                rdiff = rval2 - rval1
186                rsum = rsum + (1.0 - xintmu / (amu + emu)) * rdiff
187                rval1 = rval2
188                if rsum > rmax:
189                    break                                   # go to 33
190
191                # The rescaled radiative gradient (Fortran lines 226–254).
192                # Suspected bug (see the page): RL is not updated here.
193                b = hl[ii]
194                sl = hs[ii]
195                pl = hp[ii]
196                tl = ht[ii]
197                dl = hd[ii]
198                x = hcomp[1, ii]
199                z = hcomp[3, ii]
200                iu = ii  # noqa: F841  (unused in the Fortran too)
201                _load_debhu(hcomp, ii)
202                dl, amu, emu, dela, delr = _gradients(
203                    tl, pl, dl, rl, sl, b, x, z, lderiv, latmo, ksaha,
204                    fpl, ftl, teffl, cmixl)
205                hd[ii] = dl
206                if fdel * delr < dela:
207                    stable = True
208                    break                                   # go to 34
209            else:
210                # The loop ran out: the edge of the star.
211                if k == 1:
212                    ii = 0
213                if k == 2:
214                    ii = m + 1
215            if not stable:
216                lmax = True                                 # label 33
217
218            # label 34: the new edge (Fortran lines 260–270).
219            if k == 1:
220                mxzone[i, k] = ii + 1
221                jmc2 = ii + 1
222            elif k == 2:
223                mxzone[i, k] = ii - 1
224                jmc2 = ii - 1
225            iounits_mod.write(
226                iounits_mod.ishort,
227                f" CZ OLD EDGE {jmc:3d} EXTENDED TO-{jmc2:3d} LIMIT="
228                f"{'T' if lmax else 'F'} RAD.GRADS-IN/OUT"
229                f"{delr1:8.4f}{delr0:8.4f}")                # format 601
230
231    # Mergers of zones that overlap after semiconvection (Fortran lines
232    # 273–301).
233    if nzone <= 1:
234        return nzone
235    j = 1
236    while True:                                             # label 85
237        # Question (see the page): overlap only, not adjacency.
238        if mxzone[j, 2] > mxzone[j + 1, 1]:
239            iounits_mod.write(
240                iounits_mod.ishort,
241                "  MIXED ZONES MERGED DUE TO SEMICONVECTION\n"
242                f"  OLD[{mxzone[j, 1]:3d}-{mxzone[j, 2]:3d}]"
243                f"[{mxzone[j + 1, 1]:3d}-{mxzone[j + 1, 2]:3d}]"
244                f" NEW[{mxzone[j, 1]:3d}-{mxzone[j + 1, 2]:3d}]")  # 93
245            # Suspected bug (see the page): the merged zone keeps zone j+1's
246            # top.
247            mxzone[j + 1, 1] = mxzone[j, 1]
248            for kk in range(j, nzone):
249                for j2 in (1, 2):
250                    mxzone[kk, j2] = mxzone[kk + 1, j2]
251            nzone = nzone - 1
252            if j <= nzone - 1:
253                continue
254            return nzone
255        j = j + 1
256        if j > nzone - 1:
257            return nzone
