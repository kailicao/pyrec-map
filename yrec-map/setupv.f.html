Purpose

Prepares, once per call of the rotational-mixing step, the structural factors that the stability criteria and circulation velocities need at each interface between shells. Its comment explains the scheme: stability is computed for the interface $i/i-1$ and stored in element $i$; each criterion is "a combination of variables stored at each shell multiplied by a gradient between the shells," which must stay below a critical number. SETUPV computes the parts that "do not change during a diffusion timestep"; VCIRC multiplies them by the current $\Omega$ gradients.

How it fits

  • Who calls it: SECULR, once per time step, before the iterations.
  • Inputs: the model's $\log\rho$, $g$ (HG), $L$ (solar units), $\log P$, $\log r$, enclosed mass (g), $\log T$, and the range IMIN–IMAX; from MDPHY_MOD the shell values of $\mu$ (AMUM), $c_P$ (CPM), $\nabla$, $\nabla_\mathrm{ad}$, $\nabla_\mathrm{rad}$ (DELM, DELAM, DELRM), $\epsilon$ (ESUMM), $\kappa$ (OM), $\partial\ln\rho/\partial\ln T$ (QDTM); from ROTDER_MOD the derivatives of $\kappa$ and $\epsilon$ (SQOT, SQET) and the nuclear fraction FRACNUC, set in COEFFT; the namelist switch LDIFAD from NMLPAR_MOD.
  • Outputs: HRU (radii), QWRMAX (the largest stable $d\Omega/d\ln r$ for the dynamical shear), the interpolation weights FACI (an argument owned by SECULR, which passes it on to VCIRC), and, through modules, read by VCIRC, CODIFF, GETFC and DADCOEFT: the interface values in INTVAR_MOD (RM, PM, TM, DM, DELMI, DELAMI, QDTMI, HS3, EPSILM, ALM, HGM), the velocity factors FACT1…FACT5, FACT7, FACT8 (VFACT_MOD), FACT6, FES1–FES3, FGSFJ, FGSFK (TAUKH_MOD), DDELM, FESTIME, THM (OLDROT2_MOD), and with LDIFAD the higher-order terms in DIFAD3_MOD and EGRIDDER_MOD.

The method

  1. Interface values. At the midpoint $r_{m,i} = \tfrac12(r_i + r_{i-1})$, each quantity is found by 4-point Lagrange interpolation in $r$ over shells $i-2 \dots i+1$ (the first and last interfaces use the first or last four shells); $P$, $T$, $\rho$ are interpolated in the log. The actual gradient is $\nabla = \min(\nabla_\mathrm{rad}, \nabla_\mathrm{ad})$.

  2. Scales. With $G$, $m$ the mass inside the interface, $H_p = P r^2/(\rho G m)$, $H_T = H_p/\nabla$, $\eta = \tfrac43\,r^3/(G m)$, and $\Delta\nabla = \max(\nabla_\mathrm{ad} - \nabla,\ \nabla_\mathrm{min})$ with a floor of $10^{-3}$ (larger at the ends of the range, including a $\mu$-gradient term).

    Question 2 (lines 320–335↗; lines 358–361↗; line 392↗). Two floors for $\nabla_\mathrm{ad} - \nabla$. FACT1 and QWRMAX use a floor of $10^{-3}$; FESTIME and FGSFK use DDEL with the end-dependent floor DMIN; DDELM adds the $\mu$ gradient. The comment says 1/(∇ad − ∇) "is set to a maximum of 10^6," but the floor $10^{-3}$ gives a maximum of $10^3$. Which is intended?

  3. Eddington–Sweet circulation (Endal and Sofia, paper II, as cited): $v_\mathrm{ES} = $ FACT1·FACT2·$\Omega^2$, with $$\texttt{FACT1} = \frac{1}{(\partial\ln\rho/\partial\ln T)\,\max(\nabla_\mathrm{ad}-\nabla,\,10^{-3})},\qquad \texttt{FACT2} = \frac{\nabla_\mathrm{ad}}{g}\,\eta\,\Bigl(\epsilon - \frac{L}{m}\Bigr).$$

  4. GSF and $\mu$ currents. FACT3 $= |H_T r|$ for the Goldreich–Schubert–Fricke velocity; FACT4 $= \frac{r^2}{G m\rho}\,(P - aT^4/3)/\sqrt g$ for the "fictitious $\mu$ currents" (Kippenhahn, IAU 66).
  5. Dynamical shear. Stable when the Richardson number $\frac{\rho}{P}(\nabla_\mathrm{ad}-\nabla)\,g^2/(d\Omega/d\ln r)^2 > \tfrac14$, that is when $$\left|\frac{d\Omega}{d\ln r}\right| < \texttt{QWRMAX} = 2g\sqrt{\frac{\rho}{P}\max(\nabla_\mathrm{ad}-\nabla,\,10^{-3})}.$$
  6. Secular shear with $\mu$ gradients: FACT5 $= \frac{\rho g^2}{P\,\Delta\ln P}\cdot\frac{p_r - 1}{1 + 3p_r}$, where $p_r = aT^4/(3P)$ is the radiation-pressure fraction ($1 - p_r$ is the comment's "BETA") and the last factor is the comment's $-d\ln T/d\ln\mu$.
  7. Zahn-type terms (FES1, FES2, FES3, FV*, and, with LDIFAD, FACT7, FACD2, FACD3, following Zahn and Maeder 1998 as the comments say), built from $F = P/(g\,\Delta\nabla\,c_P\,\rho\,T)$, $L/m$ and $\epsilon$; and THM $= r_i^2 r_{i-1}^2/(G\sqrt{m_i m_{i-1}}) \approx r^2/g$ for the $d\theta/dt$ term (lines 304–309↗). With LDIFAD, the block starts at shell IMIN-1 (lines 408–410↗); IMIN is at least 2 (midmod.f, lines 375–383↗), so no index 0 is read (settled from the code, Nov 9, 2026). In that block V0, QC1R, QQC1RR, QQCHITR, HTP2 and QHTR are computed but used only in the commented-out forms of FACT7 and FACT8, and FACT8 is always 0 (lines 418–450↗): unused?; so are QQQCOD (stored at line 410↗ and line 435↗, read by no routine) and FV1A, FV1B, FV2A, FV2B, FGSFJ and FACT3 (lines 350–355↗, line 374↗: read by no other routine). 27def _lagrange(hru: np.ndarray, rm: np.ndarray, i: int, j: int, faci: np.ndarray) -> None:
28    """Fill faci[1..4, i], the 4-point Lagrange weights at rm[i] over the
29    shells j .. j+3 (the Fortran repeats this block three times: lines
30    122–139, 172–189 and 222–239)."""
31
32    a43 = hru[j + 3] - hru[j + 2]
33    a42 = hru[j + 3] - hru[j + 1]
34    a41 = hru[j + 3] - hru[j]
35    a32 = hru[j + 2] - hru[j + 1]
36    a31 = hru[j + 2] - hru[j]
37    a21 = hru[j + 1] - hru[j]
38    d1 = -a21*a31*a41
39    d2 = a21*a32*a42
40    d3 = -a31*a32*a43
41    d4 = a41*a42*a43
42    xa1 = rm[i] - hru[j]
43    xa2 = rm[i] - hru[j + 1]
44    xa3 = rm[i] - hru[j + 2]
45    xa4 = rm[i] - hru[j + 3]
46    faci[1, i] = (xa2*xa3*xa4)/d1
47    faci[2, i] = (xa1*xa3*xa4)/d2
48    faci[3, i] = (xa1*xa2*xa4)/d3
49    faci[4, i] = (xa1*xa2*xa3)/d4

52def _interp(y: np.ndarray, faci: np.ndarray, i: int, j: int) -> float:
53    """y interpolated to interface i from shells j .. j+3, summed in the
54    Fortran's order."""
55
56    return (y[j]*faci[1, i] + y[j + 1]*faci[2, i]
57            + y[j + 2]*faci[3, i] + y[j + 3]*faci[4, i])

60def _interface_values(i: int, j: int, hd: np.ndarray, hg: np.ndarray, hl: np.ndarray, hp: np.ndarray,
61                      hs1: np.ndarray, ht: np.ndarray, faci: np.ndarray) -> None:
62    """The physical variables at interface i, from shells j .. j+3 (the
63    Fortran repeats this block three times: first, last and inner
64    interfaces, lines 141–166, 191–216 and 247–282). P, T and rho are
65    interpolated in the log."""
66
67    c = constants_mod

69    md = mdphy_mod

71    iv.tm[i] = math.exp(c.cln*_interp(ht, faci, i, j))
72    iv.dm[i] = math.exp(c.cln*_interp(hd, faci, i, j))

75    iv.delami[i] = _interp(md.delam, faci, i, j)
76    iv.qdtmi[i] = _interp(md.qdtm, faci, i, j)       # d ln rho / d ln T

79    iv.alm[i] = c.clsun*_interp(hl, faci, i, j)      # luminosity (erg/s)

85def setupv(hd: np.ndarray, hg: np.ndarray, hl: np.ndarray, hp: np.ndarray, hr: np.ndarray, hs1: np.ndarray,

87    """Prepare, for the interfaces imin..imax (interface i lies between
88    shells i-1 and i), the factors of the stability criteria and
89    circulation velocities that do not change during a diffusion time
90    step; VCIRC multiplies them by the current Omega gradients.
91
92    Translates: setupv.f#SETUPV (7be4133)
93
94    Arguments: the model's log rho (hd), gravity (hg), L in solar units
95    (hl), log P (hp), log r (hr), enclosed mass in g (hs1), log T (ht),

97    number of shells. Set in place: hru (unlogged radii), qwrmax (the

179    for i in range(2, m + 1):
180        fac = (2.0*(hr[i] + hr[i - 1])
181               - 0.5*(math.log10(hs1[i]) + math.log10(hs1[i - 1])) - c.cgl)
182        o2.thm[i] = math.exp(c.cln*fac)
183
184    # Structural quantities for the velocities at all interfaces (label 40)
185    # (Fortran lines 312–405).
186    cpigi = 4.0/c.c4pi/cg
187    for i in range(imin, imax + 1):
188        # The mu gradient and the floors of del_ad - del (Fortran lines
189        # 314–335).
190        if not nmlpar_mod.ldifad:
191            delmu = ((math.log10(md.amum[i]) - math.log10(md.amum[i - 1]))
192                     / (hp[i] - hp[i - 1]))
193        else:
194            delmu = 0.0
195        if i == imin:
196            dmin = max(1.0e-3, 0.5*(md.delam[imin + 1] - md.delm[imin + 1])
197                       + delmu)
198        elif i == imax:
199            dmin = max(1.0e-3, 0.5*(md.delam[imax - 1] - md.delm[imax - 1])
200                       + delmu)
201        else:
202            dmin = 1.0e-3
203        ddel = max(iv.delami[i] - iv.delmi[i], dmin)
204        o2.ddelm[i] = max(iv.delami[i] - iv.delmi[i] + delmu, dmin)
205
206        # Scale heights and the Zahn-type factors (Fortran lines 337–355).
207        o2.festime[i] = iv.pm[i]/(iv.hgm[i]*ddel*iv.dm[i])
208        hpsc = iv.pm[i]*iv.rm[i]**2/iv.dm[i]/iv.hs3[i]/cg
209        htsc = hpsc/iv.delmi[i]
210        # Question (see the page): the factor 2 in eta.
211        eta = 2.0*c.cc23*iv.rm[i]**3/cg/iv.hs3[i]
212        tk.fgsfk[i] = 8.0*hpsc*eta/ddel
213        ff = iv.pm[i]/(iv.hgm[i]*ddel*cpmi[i]*iv.dm[i]*iv.tm[i])
214        fac = 2.0*eta*ff
215        em = iv.alm[i]/iv.hs3[i]
216        tk.fes1[i] = fac*(em - iv.epsilm[i])
217        tk.fes2[i] = -0.5*fac*em*cpigi/iv.dm[i]
218        tk.fes3[i] = em*ff*c.cc13*cpigi*iv.rm[i]/iv.dm[i]
219        da.fv0[i] = ff
220        da.fv1a[i] = tk.fes1[i]/ff
221        da.fv1b[i] = tk.fes2[i]/ff
222        da.fv2a[i] = em*cpigi*3.0*htsc/iv.dm[i]
223        da.fv2b[i] = -em*cpigi*iv.rm[i]/iv.dm[i]
224        tk.fgsfj[i] = abs(fac*em*htsc)*iv.rm[i]
225
226        # Eddington circulation: v_ES = fact1*fact2*Omega**2 (Endal and
227        # Sofia, paper II) (Fortran lines 361–367).
228        # Question (see the page): the floor 1e-3 caps 1/(del_ad - del)
229        # at 1e3, not the comment's 1e6.
230        vf.fact1[i] = 1.0/iv.qdtmi[i]/max(iv.delami[i] - iv.delmi[i], 1.0e-3)
231        fac = iv.delami[i]/iv.hgm[i]
232        vf.fact2[i] = fac*eta*(iv.epsilm[i] - em)
233        tk.fact6[i] = -fac*em/c.c4pi/cg/iv.dm[i]/iv.rm[i]
234
235        # GSF: fact3 is the temperature scale height times the radius
236        # (Fortran line 374).
237        vf.fact3[i] = abs(htsc*iv.rm[i])
238
239        # Fictitious mu currents (Kippenhahn, IAU 66) (Fortran lines
240        # 387–388).
241        vf.fact4[i] = (iv.rm[i]**2/iv.hs3[i]/cg/iv.dm[i]
242                       * (iv.pm[i] - c.ca3*iv.tm[i]**4)/math.sqrt(iv.hgm[i]))
243
244        # Dynamical shear: stable when the Richardson number exceeds 1/4
245        # (Fortran lines 392–393).
246        qwrmax[i] = (math.sqrt(iv.dm[i]/iv.pm[i]
247                               * max(iv.delami[i] - iv.delmi[i], 1.0e-3))
248                     * 2.0*iv.hgm[i])
249
250        # Secular shear inhibited by mu gradients (Fortran lines 401–402).
251        vf.fact5[i] = (iv.dm[i]*iv.hgm[i]**2/iv.pm[i]/c.cln
252                       / (hp[i] - hp[i - 1])
253                       * (c.ca3*iv.tm[i]**4/iv.pm[i] - 1.0)
254                       / (1.0 + 3.0*c.ca3*iv.tm[i]**4/iv.pm[i]))
255
256    # Terms of order d Omega/dr from Zahn and Maeder 1998; imin >= 2, so
257    # shell imin-1 exists (Fortran lines 407–465). qqqcod is read by no
258    # routine: unused? (see the page).
259    if nmlpar_mod.ldifad:
260        htm = (math.exp(c.cln*(hp[imin - 1] + 2.0*hr[imin - 1]
261                               - hd[imin - 1]))
262               / hs1[imin - 1]/cg/md.delrm[imin - 1])
263        eg.qqqcod[imin - 1] = htm
264        for i in range(imin, imax + 1):
265            hpsc = iv.pm[i]*iv.rm[i]**2/iv.dm[i]/iv.hs3[i]/cg
266            htsc = hpsc/iv.delmi[i]
267            f1 = iv.pm[i]/(iv.hgm[i]*o2.ddelm[i]*cpmi[i]*iv.dm[i]*iv.tm[i])
268            f2 = iv.alm[i]*iv.rm[i]/iv.hs3[i]/3.0
269            f3 = 0.75*iv.hs3[i]/(c.cpi*iv.dm[i]*iv.rm[i]**3)
270            # v0, qc1r, qqc1rr, qqchitr, htp2 and qhtr feed only
271            # commented-out formulas: unused? (see the page).
272            v0 = -f1*f2*f3  # noqa: F841  (unused in the Fortran too)
273            ff = iv.rm[i]**3/iv.hs3[i]
274            c1 = c.cc23*iv.rm[i]**4/cg/iv.hs3[i]
275            eg.qqcod[i] = c1
276            qc1r = 4.0*c.cc23*ff/cg*(1.0 - c.cpi*iv.dm[i]*ff)  # noqa: F841  (unused in the Fortran too)
277            dr = 10.0**hr[i] - 10.0**hr[i - 1]
278            qdr = (10.0**hd[i] - 10.0**hd[i - 1])/dr
279            qqc1rr = (8.0*ff/cg/iv.rm[i]  # noqa: F841  (unused in the Fortran too)
280                      * (1.0 - c.cc13*c.cpi*ff*(1.0e1*iv.dm[i] - iv.rm[i]*qdr)
281                         + c.cc13*8.0*(c.cpi*iv.dm[i]*ff)**2))
282            # d ln chi / d ln T = 3 - d ln kappa / d ln T
283            qchit = 3.0 - 0.5*(rd.sqot[i] + rd.sqot[i - 1])
284            qqchitr = (rd.sqot[i - 1] - rd.sqot[i])/dr  # noqa: F841  (unused in the Fortran too)
285            htp = (math.exp(c.cln*(hp[i] + 2.0*hr[i] - hd[i]))
286                   / hs1[i]/cg/md.delm[i])
287            eg.qqqcod[i] = htp
288            htp2 = dr/c.cln/(ht[i - 1] - ht[i])  # noqa: F841  (unused in the Fortran too)
289            qhtr = (abs(htp) - abs(htm))/dr  # noqa: F841  (unused in the Fortran too)
290            htm = htp
291            qetm = 0.5*(rd.sqet[i] + rd.sqet[i - 1])
292            fnu = 0.5*(rd.fracnuc[i] + rd.fracnuc[i - 1])
293            vf.fact7[i] = (-f1*c1*(fnu*qetm
294                                   + iv.epsilm[i]*(1.0 - fnu - qchit)))
295            da.fv2b[i] = da.fv2b[i] + vf.fact7[i]/f1
296            vf.fact8[i] = 0.0
297            fl = iv.alm[i]/c.c4pi/iv.dm[i]/iv.rm[i]**2
298            da.facd2[i] = f1*(fl*qchit - iv.epsilm[i]*htsc)
299            da.facd3[i] = -f1*fl
