Explanation

Purpose. FINDSH locates, in a model, the outer edge of a central convection zone, the inner edge of a surface convection zone, and, once the core's hydrogen falls below a threshold, the beginning, middle and end of the hydrogen-burning shell. Its comment lists a planned addition ("TO BE ADDED"): finding the exact edges of the convection zones and adding points there.

How it fits.

  • Who calls it: the main program (main.f) and RSCALE.
  • Inputs: HCOMP (abundances; row 1 is $X$), HL (luminosity in solar units), LC (convective flags), M (number of points).
  • Outputs: JCORE (outermost point of the convective core; 1 if none), JENV (innermost point of the surface convection zone; M if none), LSHELL (a hydrogen shell exists), and JXBEG, JXMID, JXEND (the shell's start, middle and end).
  • Modules: NMLPAR_MOD, for ATIME(1) (formerly in /CTLIM/), the central $X$ below which the star has a shell rather than a core (set in PARMIN).

The method.

  1. Shell (if $X_\mathrm{c} \le$ ATIME(1)): going outward, JXBEG counts the points with $X \le$ ATIME(1), JXMID also those with $X \le X_\mathrm{surf}/2$; the shell ends (JXEND) at the first point where $L_i - L_{i-1} < 10^{-5}L_\mathrm{surf}$ or $X_\mathrm{surf} - X_i < 10^{-5}$.
  2. Core: JCORE is the last point of the run of convective points from the centre.
  3. Envelope: JENV is the first point of the run of convective points from the surface.
  4. For a fully convective star (JENV = 1), JCORE is set to 1, "because JCORE is used in computing the nuclear timestep, and putting it at the surface does strange things".

Changed since rp_1. Declarations only: COMMON blocks to modules, IMPLICIT NONE.

Questions for the experts

  1. The shell's middle and end. JXMID counts points rather than recording an index; it equals the first point with $X > X_\mathrm{surf}/2$ only if the composition increases monotonically outward. Is that guaranteed?
  2. HL(I-1) at the centre. If HCOMP(1,1) exceeds both ATIME(1) and XMID, which cannot happen when LSHELL is set, the loop would read HL(0). Safe as written, but fragile.
  3. A comment's variable. The comments speak of ENDSHL; the code uses DLMIN and XLEND.

13    """Find the outermost point of the convective core, the innermost
14    point of the surface convection zone and, once the central X is at
15    most nmlpar_mod.atime[1], the start, middle and end of the hydrogen
16    shell.
17
18    Translates: findsh.f#FINDSH (09c3b9b)
19
20    Arguments: hcomp (abundances, row 1 is X), hl (luminosities), lc
21    (convective flags), m (number of points); jcore, jenv, jxbeg, jxend,
22    jxmid, lshell are only set.
23
24    Returns (jcore, jenv, jxbeg, jxend, jxmid, lshell).
25    """
26    jxbeg = 1
27    jxmid = 1
28    jxend = 1
29    lshell = False
30
31    if hcomp[1, 1] <= nmlpar_mod.atime[1]:
32        lshell = True
33        xmid = 0.50 * hcomp[1, m]
34        xlend = dlmin * hl[m]
35        # Question (see the page): jxmid counts points rather than
36        # recording an index.
37        i = m  # if no end is found
38        for ii in range(1, m + 1):  # label 10
39            if hcomp[1, ii] <= nmlpar_mod.atime[1]:
40                jxbeg = jxbeg + 1
41                jxmid = jxmid + 1
42            elif hcomp[1, ii] <= xmid:
43                jxmid = jxmid + 1
44            elif hl[ii] - hl[ii - 1] < xlend:
45                i = ii
46                break  # GOTO 20
47            elif hcomp[1, m] - hcomp[1, ii] < dxmin:
48                i = ii
49                break  # GOTO 20
50        jxend = i  # label 20
51
52    # The core: the last point of the convective run from the centre.
53    i = m + 1  # Fortran's index after a loop that runs out
54    for ii in range(1, m + 1):  # label 30
55        if not lc[ii]:
56            i = ii
57            break  # GOTO 40
58    if i > 1:  # label 40
59        jcore = i - 1
60    else:
61        jcore = 1
62
63    # The envelope: the first point of the convective run from the surface.
64    i = 0
65    for ii in range(m, 0, -1):  # label 50
66        if not lc[ii]:
67            i = ii
68            break  # GOTO 60
69    if i < m:  # label 60
70        jenv = i + 1
71    else:
72        jenv = m
73
74    # Fully convective: JCORE is used in the nuclear time step, and
75    # putting it at the surface does strange things.
76    if jenv == 1:
77        jcore = 1
78    return jcore, jenv, jxbeg, jxend, jxmid, lshell
