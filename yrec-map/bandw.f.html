bandw.f

186 lines · 1 definitions · on GitHub (7be4133)

Python version: bandw.py, 79 lines, on the right (switch to Python above the code).

Purpose

This file solves a banded linear system $A\,\mathbf{x} = \mathbf{b}$ by Gaussian elimination without pivoting. It is the solver for the implicit angular-momentum transport in DADCOEFT (its comments speak of $\Omega$ and its radial derivatives).

How it fits

  • Inputs: the arguments A(NMAX,10) (the band), NM (the number of unknowns) and B (the right-hand side).
  • Who calls it: only DADCOEFT.
  • Output: the solution, returned in B; A is overwritten.
  • No COMMON blocks.

Storage. Row $i$ of the matrix is stored in A(i,1:10), with the diagonal in column 5: A(i,5+k) is the coefficient of unknown $x_{i+k}$, for $k = -4, \dots, 5$. The band thus has 4 subdiagonals and 5 superdiagonals. A is declared A(NMAX,10) with NMAX = 8000 (line 9↗; line 12↗), and DADCOEFT declares the same (line 39↗; line 92↗); the two must agree, since the first dimension sets where each column starts. KNOWN_ISSUES.md (lines 1845–1848) keeps NMAX per routine on purpose.

The method

  1. Forward elimination, row by row: divide row $i$ and $b_i$ by the pivot $a_{ii}$, then remove $x_i$ from the next 4 rows, $$a_{jk} \leftarrow a_{jk} - a_{ji}\,a_{ik}, \qquad b_j \leftarrow b_j - a_{ji}\,b_i, \qquad j = i+1, \dots, i+4.$$ The last 4 rows are handled separately, since their bands are cut off by the end of the matrix. A pivot smaller than $10^{-20}$ in absolute value stops the run (STOP 999), after printing the row (for the last row it stops without printing).

  2. Back substitution: with unit diagonal, for $i = N, \dots, 2$, $$b_{i-l} \leftarrow b_{i-l} - b_i\,a_{i-l,\,i}, \qquad l = 1, \dots, \min(5, i-1).$$

Design

No pivoting: the method relies on the matrix being diagonally dominant enough.

Question 1 (lines 29–32↗; lines 52–55↗; line 75↗). No pivoting. Is the system from DADCOEFT always diagonally dominant? A small pivot stops the whole run rather than trying a pivoted solve.

About 100 lines of an earlier version (blocks of 4 rows per shell, "DIAGONALIZE OMEGA(II) TERM") remain as comments.

Question 2 (lines 16–27↗; lines 81–152↗). Dead code. The commented-out block solver: can it go in the overhaul?

19def bandw(a: np.ndarray, nm: int, b: np.ndarray) -> None:
20    """Solve A x = b by Gaussian elimination without pivoting, for a band
21    matrix with 4 subdiagonals and 5 superdiagonals: a[i, 5 + k] is the
22    coefficient of x[i + k], k = -4..5 (diagonal in column 5).
23
24    Translates: bandw.f#BANDW (7be4133)
25
26    Arguments: a (NMAX+1 by 11, index 0 unused), overwritten; nm, the
27    number of unknowns; b (NMAX+1), the right-hand side, replaced in place
28    by the solution. A pivot below TINY stops the run (STOP 999).
29
30    Returns nothing.
31
32    """
33
34    # Forward elimination, full band: rows 1..nm-5 (Fortran lines 28–49).
35    # Question (see the page): no pivoting.
36    for i in range(1, nm - 5 + 1):
37        if abs(a[i, 5]) < TINY:
38            _print_row(a, i)
39            sys.exit(999)
40        b[i] = b[i] / a[i, 5]
41        for j in range(6, 11):
42            a[i, j] = a[i, j] / a[i, 5]
43        for j in range(i + 1, i + 4 + 1):
44            imj = i - j
45            imj5 = 5 + imj          # column of x_i in row j
46            b[j] = b[j] - a[j, imj5] * b[i]
47            for k in range(imj5 + 1, 10 + imj + 1):
48                a[j, k] = a[j, k] - a[j, imj5] * a[i, k + j - i]
49
50    # The last rows, whose band is cut off by the end of the matrix
51    # (Fortran lines 50–74).
52    for i in range(nm - 4, nm):
53        ii = nm - i
54        if abs(a[i, 5]) < TINY:
55            _print_row(a, i)
56            sys.exit(999)
57        b[i] = b[i] / a[i, 5]
58        for j in range(6, 5 + ii + 1):
59            a[i, j] = a[i, j] / a[i, 5]
60        for j in range(i + 1, nm + 1):
61            imj = i - j
62            imj5 = 5 + imj
63            b[j] = b[j] - a[j, imj5] * b[i]
