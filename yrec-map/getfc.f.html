Purpose

GETFC computes, shell by shell, the factor $f_c$ that relates the diffusion coefficient for chemical mixing to that for angular momentum transport by meridional circulation, "using the prescription of Zahn (1992)" (its comment).

How it fits

  • Who calls it: only SECULR, when LVFC is set, for the shells IMIN..IMAX.
  • Inputs: HD ($\log\rho$ at zone centres), HRU (radii at zone centres), HV (circulation velocities $U$ at zone edges), OMEGA; and from INTVAR_MOD, RM (radii at zone edges, the means of neighbouring centre radii) and DM (density at zone edges, interpolated in $\log\rho$), both set by SETUPV.
  • Output: the argument VFC, an array that SECULR owns (it clears it, and passes it on to CODIFF, which reads it).
  • Modules: NMLPAR_MOD gives FC and LVFC (namelist parameters, read in PARMIN); INTVAR_MOD (the edge quantities), shared with CODIFF, SECULR, SETUPV, VCIRC; CONSTANTS_MOD (CLN, CC13); DIMENSIONS_MOD (JSON).

The method

The comment gives $$f_c = \min\left(1,\ \frac{C}{30}\,\frac{U}{2V - \alpha U}\right),\qquad \alpha = \frac12\frac{d\ln(r^2\Omega)}{d\ln r},\qquad V = \frac{1}{6\rho r}\frac{d}{dr}(\rho r^2 U).$$ The code computes:

  1. ALPHA $= \dfrac{1}{\Omega_m r_m}\dfrac{\Delta(\Omega r^2)}{\Delta r}$ between neighbouring zone centres, with $\Omega_m$ the mean of the two and $r_m$ = RM the edge between them, which is $d\ln(r^2\Omega)/d\ln r$, without the factor ½ (Bugs, by priority, 1). It uses shell IMIN-1, which exists: MIDMOD sets IMIN ≥ 2.
  2. V $= \dfrac{1}{3\rho r}\dfrac{d}{dr}(\rho r^2 U)$, which is $2V$; at the first and last shells, by the product rule with $dU/dr$ from the neighbour.

  3. VFC $= \dfrac{f_c^{\mathrm{in}}}{\max\left(|{\tt V} - {\tt ALPHA}\,U|/U,\ f_c^{\mathrm{in}}\right)} = \min\left(1,\ \dfrac{f_c^{\mathrm{in}}\,U}{|2V - {\tt ALPHA}\,U|}\right)$, with $f_c^{\mathrm{in}}$ = FC; zero where $U \le 0$, and everywhere if FC ≤ 0. The absolute value is the code's; the comment's formula has none.

    Question 1 (line 63↗, lines 112–113↗). FC and $C/30$. The input FC plays the part of $C/30$ in the comment's formula, while without LVFC it is the constant ratio of the two coefficients (CODIFF). Is that the intended meaning of the parameter with LVFC?

    Question 2 (lines 109–110↗). Negative velocities. Where $U \le 0$, $f_c = 0$: no chemical mixing where the circulation flows inward. Intended, or should $|U|$ be used?

Suspected bugs, by priority

(a) may give wrong results; (b) may crash; (c) misbehaves silently (a wrong message, an ignored setting); (d) fragile: correct today, but breaks on a change or an unusual input.

  1. (a) The factor ½ in $\alpha$. (line 63↗; lines 75–79↗; line 112↗) The comment defines $\alpha = \tfrac12\,d\ln(J/M)/d\ln r$, as in Zahn (1992), and uses $2V - \alpha U$. The code computes ALPHA $= d\ln(r^2\Omega)/d\ln r$, with no ½, and then V - ALPHA*HV, where V is already $2V$. So the code's denominator is $2V - 2\alpha U$, and the $\alpha$ term is twice what the comment gives, which changes $f_c$ wherever that term matters. Only with LVFC (off by default; "experimental" in the Physics namelist page). Read from the code, not run. A possible fix (unless the comment is the slip):

21    """Compute, for the shells imin..imax, Zahn's (1992) ratio f_c of the
22    chemical to the angular-momentum diffusion coefficient, capped at 1
23    (equations on the page); zero where the circulation velocity is <= 0,
24    and everywhere if FC <= 0.
25

27
28    Arguments: hd (log rho at zone centres), hru (radii at zone centres),
29    hv (circulation velocities U at zone edges), imin, imax, omega. Array
30    changed in place: vfc (owned by seculr, read by codiff). Nothing is
31    returned.
32
33    """

35    c = constants_mod
36    iv = intvar_mod
37    fc = nmlpar_mod.fc
38
39    # No mixing if FC <= 0 (Fortran lines 66–73).
40    if fc <= 0.0:
41        for i in range(imin, imax + 1):
42            vfc[i] = 0.0
43        return                                     # go to 9999

45    # alpha = d ln(r^2 Omega) / d ln r between neighbouring centres.
46    # Suspected bug (see the page): no factor 1/2 (Fortran lines 74–79).
47    for i in range(imin, imax + 1):
48        wm = 0.5 * (omega[i] + omega[i - 1])
49        alpha[i] = ((omega[i] * hru[i]**2 - omega[i - 1] * hru[i - 1]**2)
50                    / (hru[i] - hru[i - 1]) / (wm * iv.rm[i]))

52    # v = (1/(3 rho r)) d(rho r^2 U)/dr, i.e. 2V; U interpolated to the
53    # zone centres (Fortran lines 80–91).
54    fx = (hru[imin] - iv.rm[imin]) / (iv.rm[imin + 1] - iv.rm[imin])
55    vm = hv[imin] + fx * (hv[imin + 1] - hv[imin])

57    for i in range(imin + 1, imax):
58        fx = (hru[i] - iv.rm[i]) / (iv.rm[i + 1] - iv.rm[i])
59        vp = hv[i] + fx * (hv[i + 1] - hv[i])
60        dr2vp = math.exp(c.cln * hd[i]) * hru[i]**2 * vp

66    # 92–105).

69               - math.exp(c.cln * hd[imin - 1]) * hru[imin - 1]**2)
70              / (hru[imin] - hru[imin - 1]))

84            vfc[i] = 0.0
