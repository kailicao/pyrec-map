Purpose

Solves a tridiagonal linear system by the Thomas algorithm (Numerical Recipes' TRIDAG, per its comment), for the new abundance of a species after rotational mixing.

How it fits

  • Inputs: N, and the coefficients A, B, C and right-hand side D in TRIDI_MOD, set by CCOEFT.
  • Who calls it: MIXCOM.
  • Output: the solution U in TRIDI_MOD (GAMA is a work array there). The same module serves the angular-momentum problem: DCOEFT fills it for TRIDIA, and GETQUA also uses it.

The method

For $a_j u_{j-1} + b_j u_j + c_j u_{j+1} = d_j$: forward elimination with $\beta_1 = b_1$, $\gamma_j = c_{j-1}/\beta_{j-1}$, $\beta_j = b_j - a_j\gamma_j$, $u_j = (d_j - a_j u_{j-1})/\beta_j$; then back substitution $u_j \leftarrow u_j - \gamma_{j+1}u_{j+1}$. No pivoting; a zero $\beta$ stops the run (with the message "TRIDIA: singular matrix").

Question 1 (lines 19–24↗). Exact zero test. Only $\beta = 0$ exactly is caught, and only from $j = 2$ ($\beta_1 = b_1$ is not tested); a tiny $\beta$ passes. The diffusion matrices from CCOEFT are diagonally dominant, so this should not arise. Should the test compare $|\beta|$ with a small threshold, as BANDW does, and include $j = 1$?

Design

TRIDIA is the same solver with extra bookkeeping of the change in angular momentum; this copy is for composition.
