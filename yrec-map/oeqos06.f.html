Explanation

Purpose. The interface to the 2006 OPAL equation of state ("LLP, October 17, 2006"), with the same arguments and outputs as OEQOS and OEQOS01 (removed since rp_1); it is now the only OPAL equation of state. Its inline comments document the entries of EOS it uses: EOS(5) is $c_V = dE/dT_6$ at constant volume, EOS(6) is $\partial\log P/\partial\log\rho$ at constant $T_6$, EOS(7) is $\partial\log P/\partial\log T_6$ at constant $\rho$, EOS(8) is $\Gamma_1$, and EOS(9) is $\Gamma_2/(\Gamma_2-1)$.

How it fits.

  • Inputs: T10 $=\log T$, P10 $=\log P$, XC, Z; the tables read by READCOEOS06.
  • Who calls it: EQSTAT2.
  • What it calls: RHOOFP06, ESAC06 (IORDER = 9) and MU.
  • Outputs: $T$, $P$, $\log\rho$ and $\rho$, BETA, BETAI, BETA14, RMU, AMU, EMU, QDT, QDP, QCP, DELA, and the alternate return.
  • Modules: EOS06MISC_MOD (the result EOS(10), formerly /EEOS06/; shared with ESAC06, RADSUB06, READCOEOS06, RHOOFP06, T6RINTEOS06 and CALCAD), CONSTANTS_MOD (CGAS), IOUNITS_MOD (ISHORT). The unused /COMP/, /CTLIM/, /CONST1/ and /CCOUT2/ of rp_1 are no longer declared.

The method.

  1. Density. From $T$ and $P$ (given as logs T10, P10), with $T_6 = T/10^6$ K and $P_{12} = P/10^{12}$ dyn cm⁻², the table routine finds $\rho(P, T, X)$ (RHOOFP…), with radiation included (IRAD = 1). A value $\le -998$ means failure.

  2. Thermodynamics. The table routine ESAC… fills the array EOS at $(X, T_6, \rho)$. From it: $$\texttt{QDP} = \left(\frac{\partial\ln\rho}{\partial\ln P}\right)_T = \frac{1}{\chi_\rho},\qquad \texttt{QDT} = \left(\frac{\partial\ln\rho}{\partial\ln T}\right)_P = -\frac{\chi_T}{\chi_\rho},$$ $$c_P = 10^{6}\,\frac{c_V\,\Gamma_1}{\chi_\rho}\ \ (\texttt{QCP};\ c_V\ \text{per}\ 10^6\ \mathrm{K}\ \text{in the table}),\qquad \nabla_\mathrm{ad} = \frac{\Gamma_2 - 1}{\Gamma_2}\ \ (\texttt{DELA}),$$ where $\chi_\rho = (\partial\ln P/\partial\ln\rho)_T$, $\chi_T = (\partial\ln P/\partial\ln T)_\rho$.

  3. Radiation. $1-\beta = aT^4/(3P)$, coded as BETA14 $= 2.521971383\times10^{-3}\,T_6^4/P_{12}$; BETA $=\beta$, BETAI $= 1/\beta$.

  4. Mean molecular weight. RMU $= \beta P/(\rho T)$; MU gives the ion and electron terms AMU and EMU; if EMU $\le 0$, it is set to zero and AMU $=$ RMU$/\mathcal{R}$.

The alternate return (RETURN 1) tells the caller to fall back on another equation of state when the point is outside the table or the table fails.

Range. $0.00187 \le T_6 \le 200$.

KC's changes. 2025-05-31: the unused argument ZTAB removed from the calls to RHOOFP06 and ESAC06.

Changed since rp_1. Declarations only: COMMON blocks to modules, IMPLICIT NONE; the unused parameters IVARX, CNVS and ZERO removed (question 2 updated).

Questions for the experts

  1. The pressure check. The check that the table reproduces the input pressure is commented out (as it was in OEQOS01, while OEQOS stopped on it; both removed since rp_1).
  2. Unused parameters. MX, MV, NR, NT (the table's dimensions; NT = 197 here, 191 in OEQOS01 at rp_1; MV sized /EEOS06/'s EOS, now in EOS06MISC_MOD) are declared but not used in this routine, and ZTAB is set but, since KC's change, no longer passed on.

Python version: oeqos06
From log T and log P, find the density in the 2006 OPAL tables
(RHOOFP06, radiation included), the thermodynamic derivatives (ESAC06),
the radiation pressure fraction and the mean-molecular-weight terms
(MU). Fails (alt1) outside 0.00187 <= T6 <= 200 or where the table
fails, so that the caller falls back on another equation of state.

Translates: oeqos06.f#OEQOS06 (09c3b9b)

Arguments: t10 = log T, p10 = log P, the composition xc (X) and z; the
others are passed in with any value.

Returns (t, p, d10, d, beta, betai, beta14, rmu, amu, emu, qdt, qdp,
qcp, dela, alt1): T and P unlogged, log rho and rho, beta = 1 - aT^4/3P,
1/beta and 1 - beta, the mean-molecular-weight terms, dln rho/dln T at
constant P, dln rho/dln P at constant T, c_P, nabla_ad, and alt1, True
when the Fortran takes its alternate return (RETURN 1).
