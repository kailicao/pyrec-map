Explanation

Purpose. Chooses which shells of a model are printed (ID(1..IDM)): every NPRTPT-th shell, plus every shell of the hydrogen-burning shell when LSHELL is true. The first and last shells are always included.

How it fits.

  • Inputs: the edges of the burning shell JXBEG, JXEND, the flag LSHELL, the number of shells M; NPRTPT from NMLPAR_MOD (formerly /CCOUT1/; set in PARMIN).
  • Who calls it: only PUTSTORE.
  • Outputs: the list ID and its length IDM.

The method. Without a shell: $1, k, 2k, \dots, M$ with $k$ = NPRTPT. With a shell: the multiples of $k$ below JXBEG, every shell from JXBEG to JXEND, the multiples of $k$ above, and $M$.

Changed since rp_1. Declarations only: COMMON blocks to modules (/CCOUT1/, now gone, to NMLPAR_MOD; the unused /CCOUT/ dropped), JSON from DIMENSIONS_MOD, IMPLICIT NONE.

Questions for the experts

  1. IEND undefined. In the LSHELL branch, if NPRTPT $\ge$ JXBEG, the first block is skipped and IF(IEND .EQ. JXBEG) reads IEND from an earlier call (SAVE), or undefined on the first. The result decides whether JXBEG is listed twice or not at all. Set IEND = 0 first?
  2. M listed twice. In the LSHELL branch, if M is a multiple of NPRTPT, the loop adds M and so does the final ID(IDM) = M; the general branch guards against this (IF (IEND .EQ. M) IEND = IEND - NPRTPT), the shell branch does not.

10def pindex(jxbeg, jxend, lshell, m, id_, idm):
11    """List the shells to print in id_[1..idm]: 1, every NPRTPT-th shell
12    and m; with lshell, also every shell of the hydrogen-burning shell
13    jxbeg..jxend.
14
15    Translates: pindex.f#PINDEX (09c3b9b)
16
17    Arguments: jxbeg, jxend, the burning shell's edges; lshell; m, the
18    number of shells; id_, set in place (ID in the Fortran); idm (set).
19    Returns idm, the length of the list.
20    """
21    global iend
22    nprtpt = nmlpar_mod.nprtpt
23    id_[1] = 1
24    idm = 2
25    if lshell:
26        if nprtpt < jxbeg:
27            ibeg = max(2, nprtpt)
28            iend = (jxbeg // nprtpt) * nprtpt
29            for j in range(ibeg, iend + 1, nprtpt):
30                id_[idm] = j
31                idm = idm + 1
32        # Question (see the page): IEND may be left from an earlier call.
33        if iend == jxbeg:
34            ixbeg = jxbeg + 1
35        else:
36            ixbeg = jxbeg
37        for j in range(ixbeg, jxend + 1):
38            id_[idm] = j
39            idm = idm + 1
40        if nprtpt < m:
41            ibeg = (jxend // nprtpt + 1) * nprtpt
42            iend = (m // nprtpt) * nprtpt
43            # Question (see the page): m may be listed twice here.
44            for j in range(ibeg, iend + 1, nprtpt):
45                id_[idm] = j
46                idm = idm + 1
47    elif nprtpt < m:
48        ibeg = max(2, nprtpt)
49        iend = (m // nprtpt) * nprtpt
50        if iend == m:
51            iend = iend - nprtpt
52        for j in range(ibeg, iend + 1, nprtpt):
53            id_[idm] = j
54            idm = idm + 1
55    id_[idm] = m
56    return idm
