Purpose

Chooses which shells of a model are printed (ID(1..IDM)): every NPRTPT-th shell, plus every shell of the hydrogen-burning shell when LSHELL is true. The first and last shells are always included.

How it fits

  • Inputs: the edges of the burning shell JXBEG, JXEND, the flag LSHELL, the number of shells M; NPRTPT from NMLPAR_MOD (formerly /CCOUT1/; set in PARMIN).
  • Who calls it: only PUTSTORE, which passes LSHELL, JXBEG and JXEND as locals it never sets (putstore.f, line 262↗), so the LSHELL branch is not taken wherever the compiler zero-fills SAVEd locals (settled from the code, Nov 9, 2026).
  • Outputs: the list ID and its length IDM.

The method

Without a shell: $1, k, 2k, \dots, M$ with $k$ = NPRTPT. With a shell: the multiples of $k$ below JXBEG, every shell from JXBEG to JXEND, the multiples of $k$ above, and $M$.

1. (cannot be reached) IEND undefined.

(lines 48–56↗) In the LSHELL branch, if NPRTPT $\ge$ JXBEG, the first block is skipped and IF(IEND .EQ. JXBEG) reads IEND from an earlier call (SAVE), or undefined on the first. The result decides whether JXBEG is listed twice or not at all. Only if the LSHELL branch is taken (above).

2. (cannot be reached) M listed twice.

(lines 65–72↗; line 83↗) In the LSHELL branch, if M is a multiple of NPRTPT (always, with the default NPRTPT = 1), the loop adds M and so does the final ID(IDM) = M; the general branch guards against this (line 77↗), the shell branch does not.
