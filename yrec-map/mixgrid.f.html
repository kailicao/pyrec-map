Explanation

Purpose. Sets up the equally spaced grid for mixing one unstable region (in the coordinate $\chi$ of GETGRID) and puts the mass of each grid zone and the diffusion coefficient on it, for MIXCOM.

How it fits.

  • Inputs: the mixing coefficients COD2 at the model interfaces (from CODIFF); the model (HD, HL, HP, HR, HS, HS1, HS2, HSTOT); the region IBEG..IEND; LCZ; the energy generation EPSM at the intermediate time (MDPHY_MOD, from MIDMOD); and the weights HPTTOL of the rezoning, a namelist variable in NMLPAR_MOD.
  • Who calls it: only NDIFCOM.
  • What it calls: GETGRID (the grid, in EGRID_MOD) and OSPLIN.
  • Outputs: the zone masses EM, the coefficients ECOD2, and LDUM2 (true if the region spans only one unstable interface, in which case nothing else is done).
  • Modules: EGRID_MOD, SPLIN_MOD, MDPHY_MOD, NMLPAR_MOD (HPTTOL), CONSTANTS_MOD (CLSUN, CLN, C4PI, CGL) and DIMENSIONS_MOD. ROTGRID does the same for angular momentum.

The method.

  1. The coordinate. GETGRID defines, at each model point, $\chi = \log m/\Delta_m + L/\Delta_L - \log P/\Delta_P$, with $\Delta_m$, $\Delta_L$, $\Delta_P$ from HPTTOL, and an equal grid in $\chi$ (ECHI, step DCHI).
  2. Zone masses. Interior zones: $\Delta M_i = \tfrac12 (m_{i+1} - m_{i-1})$ (ES1 are the grid points' masses). The first and last zones reach to the midpoint with the neighbouring model point (or to the centre, or the surface), and add any adjoining convection zone's mass.
  3. The coefficient. COD2 is interpolated to the zone edges (taken as constant beyond the end interfaces). It is multiplied by $\rho r^2\, d\chi/dr$, where, as the comment derives with $\mathrm{FAC} = 4\pi\rho r^2$, $$\frac{d\chi}{dr} = \frac{4\pi\rho r^2}{\ln 10\,\Delta_m\, m} + \frac{4\pi\rho r^2\,\varepsilon}{\Delta_L} + \frac{G m \rho}{\ln 10\,\Delta_P\, P\, r^2},$$ interpolated in $\log$ to the grid with OSPLIN. Here $\Delta_m$ = HPTTOL(2), $\Delta_L$ = HPTTOL(9)$\times L_\ast$ (HL(M)*CLSUN, in erg s⁻¹; GETGRID uses the same scale, HPTTOL(9)*HL(M), in the solar units of HL), $\Delta_P$ = HPTTOL(11), and $\varepsilon$ = EPSM. The coefficient ECOD2(I) lies at the edge between grid points I-1 and I (XVAL(I) = ECHI(I) - DCHI/2), where CCOEFT uses it.

Changed since rp_1. Declarations only: COMMON blocks to modules, IMPLICIT NONE.

Questions for the experts

  1. A wrong loop variable. When looking for the edges of the adjoining convection zones, I0 = I + 1 and I1 = I - 1 use I (left over from an earlier loop) instead of the loop variable II. I0 and I1 are not used afterwards in this routine, so the result is unaffected; should the lines be fixed or removed?
  2. A comment that omits $P$. The comment writes the last term as RHO*GM/(LN10*DP*R**2); the code divides by $P$ as well (-HP(II) in the exponent), which is the correct $-d\log P/dr$.

Set up the equal grid in chi over the region ibeg..iend (GETGRID),
the mass em of each grid zone (the end zones with any adjoining
convection zone), and the coefficient ecod2: cod2 interpolated to the
zone edges times rho r^2 dchi/dr. Does nothing but set ldum2 = True
when the region spans a single unstable interface.

Translates: mixgrid.f#MIXGRID (09c3b9b)

Arguments: the mixing coefficients cod2 at the model interfaces; the
model hd, hl, hp, hr, hs (logs), hs1 (mass, g), hs2 (shell masses),
hstot (log total mass); the region ibeg..iend; the flags lcz; m shells.
ldum2 is passed in with any value. Arrays have index 0 unused.

Sets in place: ecod2 and em on the egrid_mod.ntot grid points.

Returns ldum2.
