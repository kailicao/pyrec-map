Purpose

DWMAX_MOD holds the critical rotation gradient for the shear instability at each shell, and its value at the start of the step, shared by PHYSIC and HPOINT. It replaces COMMON/DWMAX/ (MHP via Claude, 10/14/26); JSON comes from DIMENSIONS_MOD.

What its variables hold, who sets them, who reads them.

  • QWRMAX(JSON): the critical $d\Omega/d\ln r$ (Endal and Sofia 1978, as PHYSIC's comments cite), set by PHYSIC for the interface between shells IM-1 and IM: 0 where both shells are convective or the root is not real (lines 155–186↗). Read only by HPOINT, to copy it (line 855↗), so PHYSIC's computation reaches nothing (so also at rp_1): unused?
  • QWRMX0(JSON): the start-of-step copy, made by HPOINT when it saves the old model; read nowhere: unused?

Design

A blanket USE DWMAX_MOD. SECULR has a local array of the same name, QWRMAX, which SETUPV fills for the angular momentum transport; it is not this module's. At rp_1, MIDMOD also declared the block without using it.
