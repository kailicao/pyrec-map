Purpose

WRTLST writes a converged model to a model file, in the MODEL2 format, which a later run can read back as its starting model (STARIN through GETMODEL2). Its comment: it writes the last converged model, and the stored models every NPUNCH models. Before writing, it turns the run's physics switches into the four header labels.

How it fits

  • Inputs: the model and its envelope triangle (arguments), the unit IWRITE, the mixing length CMIXL and COMPMIX (the initial composition's code, carried from input to output), both now arguments; and the physics switches in NMLPAR_MOD: KTTAU, LDH, LSCV, LOPALE06, LOPAL95 for the labels, and LEXCOM, LROT, LDIFY, LDIFZ, LDISK, LINSTB, LJDOT0, LOVSTC, LOVSTE, LOVSTM, LPUREZ, LSEMIC, PDISK, TDISK, WMAX, whose values are written as they are. The units ILAST, IOWR, ISHORT come from IOUNITS_MOD.
  • Who calls it: the main program main.f (unit ILAST) and WRTOUT (ILAST, and IJLAST).
  • What it calls: PUTMODEL2, which writes the file.
  • Outputs: the model file on IWRITE; a line on IOWR and one on ISHORT, which omits the age when IWRITE is 11, the unit number PARMIN gives ILAST (line 658↗) (settled from the code, Nov 9, 2026: lines 150–156↗). The unit ILAST is rewound, so it holds only the latest model.

The labels.

  • Atmosphere: KTTAU 0–5 → EDD (Eddington), KS, HRA, KUR (Kurucz), ALL (Allard), K/C (Kurucz–Castelli); any other value leaves ATM unset (bug 2).
  • Equation of state: SAHA, plus DH (Debye–Hückel), SCV, and the OPAL 2006 tables (O6) in six-character combinations: SAHA, SAH+DH, SCV, SCV+DH, SCDHO6, OPAL06, OP6+DH; the seventh, SCV+O6, is never written (bug 1).
  • Low-temperature opacity ALOK: always NONE now; high-temperature HIK: OP95 or NONE.

For users (from YREC's Quick Start). Through the unit ILAST, this is the .last file (FLAST in the control namelist): the last converged model, in the same format as a starting model, so that a later job can start from it (FFIRST).

Suspected bugs, by priority

(a) may give wrong results; (b) may crash; (c) misbehaves silently (a wrong message, an ignored setting); (d) fragile: correct today, but breaks on a change or an unusual input.

  1. (c) A lost label. (lines 110–118↗) In the SCV branch, IF (LOPALE06) EOS='SCV+O6' sits inside IF (LDH) and is overwritten on the next line by 'SCV+DH', so SCV with OPAL 2006 and without Debye–Hückel is labelled SCV. What follows: a wrong equation-of-state label in the model file's flags line; GETMODEL2 reads the label back, but nothing acts on it. Only with LSCV and LOPALE06 on and LDH off. PUTSTORE has the same lines (suspected bug 1). Read from the code, not run. A possible fix:
