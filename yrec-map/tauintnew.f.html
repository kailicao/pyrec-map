Purpose

TAUINTNEW computes the convective overturn time scale $\tau_\mathrm{cz}$ (TAUCZ) and the radius of the base of the convection zone (RBCZ), by the method G. Somers introduced in 3/17. Its comment: search from the centre up for the base of the surface convection zone, and from the surface down; if both agree the zone is unique and the "old top-down sinkline method" is used; if not, several convective cells exist, and the crossing time of the lowest cell in the envelope is taken.

How it fits

  • Inputs: the full profile from GETTAU (interior and envelope; M points, of which MINT are interior shells): HS1, LCZ, HR, HP, HD, HG, SVEL, and DEL1, DEL2: for interior shells GETTAU passes SDEL(1,·) and SDEL(3,·), the radiative and adiabatic gradients, but for the stitched envelope points EDELS(1,·) and EDELS(2,·), the radiative and actual gradients.
  • Who calls it: only GETTAU, when LNEWTCZ is set; otherwise GETTAU calls TAUINT.
  • What it calls: KSPLINE and KSPLINT, a natural cubic spline through four points.
  • Outputs: TAUCZ in OVRTRN_MOD (read by the mass-loss and rotation routines, by their names), and the argument RBCZ in solar radii.
  • Modules: OVRTRN_MOD (TAUCZ), CONSTANTS_MOD (CLN, CMSUN, CRSUN), JSON from DIMENSIONS_MOD.

The method

  1. Find the zone. From shell IBEG (first 1) upward: pass the convective core, if any (its top JCORE, 0 at the start of each call), then the first convective shell above a radiative region is IMAX. From the surface downward, the base of the outermost zone is JMAX: the first point J below a convective point J+1 that is radiative, plus one, so that radiative points at the surface are passed over (JvS 02/2026; if no such point exists, JMAX = 1). A star with no such zone is radiative ($\tau_\mathrm{cz} = 0$); one convective throughout is fully convective.

    Question 1 (lines 73–82↗; lines 115–119↗). JCORE may be stale. JCORE is set only when the upward search leaves a convective region that started at IBEG. It is 0 at the start of each call, but not reset at label 50, so when a restart begins in a radiative shell, JCORE keeps its value from the earlier pass. KC's check avoids an index of 0, but not a stale index. Should JCORE be reset at label 50?

    Question 2 (line 74↗; lines 85–98↗). A fully convective star. The code reaches "fully convective" only when every point from IBEG to M is convective, and then sets IMAX = 1, JCORE = 1. A star convective throughout its interior is not stitched (GETTAU stitches the envelope only when its CHKPRS = HP(IMAX)-HP(M) < 1, and here IMAX = 1: gettau.f, lines 88–103↗), so M = MINT and the near-core test is skipped; but after a restart that begins inside a zone reaching M, with the envelope stitched (M ≠ MINT), the near-core test HP(1) - HP(1) < 1 holds, IBEG = 2, and the search starts again, possibly in the same state. And if the outermost points are radiative (point M, which GETTAU's own search skips), the whole convective interior is taken as a convective core, and $\tau_\mathrm{cz} = 0$. How should a fully convective star be handled?

  2. Reject false zones and search again from above: a zone less than one decade in pressure above the core, $\log P(\mathrm{JCORE}) - \log P(\mathrm{IMAX}) < 1$ (unless the profile is the interior only); a zone fewer than 3 shells thick; in the interior-only case with two zones (IJMAX ≠ 0, M = MINT), IMAX is set to JMAX; and, at the end, a result $\tau_\mathrm{cz} > 10^{20}$. For a zone, HSTOP > HSBOT, so LCZSUR is always true (lines 137–150↗); HSTOP and HSBOT serve only that test.

    Nothing bounds the restarts or keeps their tests inside the profile (suspected bug 2).

  3. The base: $r_b$ where $\nabla_1 - \nabla_2$ changes sign, by linear interpolation in $\log r$ (for a fully convective star, $\log r_b = 1$: The comment's "very small number" is RBCZ = 1., then EXP(CLN*RBCZ), that is 10 cm, harmless next to a star's radius; settled from the code, Nov 9, 2026: lines 157–168↗).

    Question 3 (lines 163–166↗; gettau.f, lines 155–157↗; gettau.f, lines 177–179↗). Two kinds of gradient. DEL2 is the adiabatic gradient for interior shells but the actual gradient for the stitched envelope points, so the sign change of $\nabla_1 - \nabla_2$ means different things on the two sides of the fitting point. Intended?

  4. One zone (IMAX = JMAX): go up from the base to where $r - r_b = H_p$, with $H_p = P/(\rho g)$. Around that point, four shells give $\delta_k = (r_k - r_b) - H_{p,k}$, and natural cubic splines in $\delta$ evaluated at $\delta = 0$ give $v$ and $H_p$ (the four shells KK-2 to KK+1, with KK kept between 3 and M-1, so that they lie inside the profile); then $$\tau_\mathrm{cz} = \frac{H_p}{v}\bigg|_{\,r - r_b = H_p} .$$ If already at IMAX $r - r_b > H_p$, $\tau_\mathrm{cz} = H_p/v$ there; but the code then goes on to step 5, which replaces it (bug 1). A third spline gives the radius at that point, ENVRCL, which nothing reads (unused?, lines 218–223↗).

  5. Several cells, or $r_b + H_p$ outside the star: the lowest zone's top $r_t$ (again where $\nabla_1 - \nabla_2$ changes sign), its width $\Delta r = r_t - r_b$, and $v$ at its middle, $r_b + \Delta r/2$, from a four-point spline in $r$ (the same limits on KK): $$\tau_\mathrm{cz} = \frac{\Delta r}{v(r_b + \Delta r/2)} .$$

Change log

The changes since rp_1

Changed since rp_1. COMMON blocks to modules, IMPLICIT NONE (the unused blocks dropped); the downward search for the base of the outermost zone now requires a convective point above the radiative one (JvS 02/2026), so a radiative layer at the surface no longer makes JMAX = M. No question is settled: question 6 (now the question on a fully convective star) concerns the upward search.

Changed since a8a5950. JCORE starts at 0 in each call, so a model with a radiative centre no longer reads a value left from an earlier call (narrows question 1); the four-point stencils keep KK between 3 and M-1, so they no longer read point M+1 (settles former question 3).

17def _psca(hp: np.ndarray, hd: np.ndarray, hg: np.ndarray, k: int) -> float:
18    # The pressure scale height P/(rho g) at shell k.
19    cln = constants_mod.cln
20    return math.exp(cln * (hp[k] - hd[k])) / hg[k]

25    """Compute the convective overturn time TAUCZ (in ovrtrn_mod) and the
26    radius of the base of the convection zone: find the zone from the

29    over the velocity at its middle.
