Explanation

Purpose. MDOT applies a mass change (loss or accretion) to the model over a step: it limits the step so that not too much mass changes, removes mass from the surface convection zone or adds it at the surface, rescales the mass coordinates, the total mass and the shell masses, removes angular momentum with lost mass, and for accretion mixes the accreted composition into the convection zone. Sign convention: DMDT > 0 is a mass gain.

How it fits.

  • Who calls it: only MASSLOSS, when LMDOT is true.
  • Inputs and outputs (arguments): DELTS (s, may be shortened), the model (HCOMP, HD, HJM, HP, HR, HS, HS1, HS2, HT, OMEGA, M, JENV), HSTOT and SMASS (updated), DMDT ($M_\odot$/yr), RTOT, SUMDM (the convection zone's mass, from MASSLOSS); EACC, ETHAV and RMU have no effect (see step 4); outputs LNEW (= true: recompute the surface boundary condition) and SENVOLD (the old HS(M) − HSTOT, for GETNEWENV).
  • Modules: NMLPAR_MOD, the namelist variables (FCZDMDT, FTOTDMDT, COMPACC, LMDOT, TDISK, LDISK, LROT, WALPCZ, LSOLWIND); MASSCHG2_MOD (SCEN, SMASS0, DLOGP, DLOGT; with MASSLOSS and COEFFT, which adds DLOGT, DLOGP to $\log T$, $\log P$ at and above JENV in its entropy terms when LMDOT and DMDT0 > 0); DISK_MOD (the age SAGE, for the disk lifetime); COMP_MOD (STOTAL, SENV); DEUTER_MOD (FMASSACC, read by LIBURN, DBURN and DBURNM); CONSTANTS_MOD; JSON from DIMENSIONS_MOD. The solar-wind parameters DMSUN, DMWSUN, DMWMAX (formerly COMMON MASSCHG3) are now locals set to zero by DATA.

The method. Two masses of the convection zone appear: $M_\mathrm{cz}$ = DMCZ = HS1(M) − HS1(JENV) (or HS1(M) if JENV = 1), and $M'_\mathrm{cz}$ = DMCZT = SUMDM.

  1. Optionally (LSOLWIND with rotation, and only if DMWSUN > 0) $\dot M = \dot M_\odot\,\min\big((\Omega/\Omega_\odot)^2, (\Omega_\mathrm{max}/\Omega_\odot)^2\big)$, with $\dot M_\odot$ = DMSUN, $\Omega_\odot$ = DMWSUN, $\Omega_\mathrm{max}$ = DMWMAX. Since these three are zero, the branch is inert; the guard on DMWSUN keeps it from dividing by zero now that LSOLWIND reaches this routine from the namelist.
  2. Rate in g/s: $|\dot M|\,M_\odot/\mathrm{yr}$. Step limits: $\Delta t \le f_\mathrm{tot}M/|\dot M|$, $\Delta t \le f_\mathrm{cz}\,M_\mathrm{cz}/|\dot M|$ ($f_\mathrm{tot}$ = FTOTDMDT, $f_\mathrm{cz}$ = FCZDMDT), and at most half the mass outside the fitting point, $\tfrac12(10^{\texttt{HSTOT}} - 10^{\texttt{HS(M)}})/|\dot M|$. The comment speaks of adding mass, but this limit applies to loss as well. With a disk (LDISK) and accretion, the step ends at the disk's lifetime TDISK (Gyr), and LMDOT is then turned off.
  3. $\Delta M = \dot M\,\Delta t$ (g).
  4. Accretion ($\Delta M > 0$):
  5. the new mean thermal energy $\bar e = (e_\mathrm{acc}\Delta M + \bar e_\mathrm{th}M'_\mathrm{cz})/(\Delta M + M'_\mathrm{cz})$ and FAC = $\log_{10}(\bar e/\bar e_\mathrm{th})$ are computed but not used (their use is commented out);
  6. RMU = $P\beta/(\rho T)$ (the gas constant over $\mu$) is recomputed at JENV, and a scale factor $\Delta\ln E = (\Delta M/M_\mathrm{cz})\,s_\mathrm{cen}/(\mathcal{R}/\mu)$, with $s_\mathrm{cen}$ = SCEN, gives $\Delta\log r = \tfrac23\Delta\ln E/\ln 10$, $\Delta\log T = -\Delta\log r$, $\Delta\log P = -4\Delta\log r$ (the mass term DLNM is set to zero);
  7. if JENV = 1 (fully convective), $\log r$, $\log P$, $\log T$ of every point change by these amounts; otherwise only $P$ and $T$ at JENV, and the radii above it are stretched about $r_\mathrm{b} = r_\mathrm{JENV}$: $r \leftarrow r_\mathrm{b} + 10^{\Delta\log r}(r - r_\mathrm{b})$.

MASSLOSS sets SCEN = 0, so these changes are zero in practice. 5. Angular momentum (rotation, loss): the lost matter carries the surface's specific angular momentum, $\Delta J = \tfrac23 R^2\,\Omega_s\,\Delta M$ (solid-body zone, WALPCZ ≥ 0), or $j_s\Delta M$ (WALPCZ ≤ −2), or the same with $\Omega_s = \Omega_M (r_M/R)^{\texttt{WALPCZ}}$; the zone's specific angular momentum HJM is scaled by $(J_\mathrm{cz}+\Delta J)/J_\mathrm{cz}$, with $J_\mathrm{cz} = \sum$ HJM·HS2 from JENV to M. 6. Mass coordinates (loss): points in the zone are compressed toward its base, $m_i \leftarrow m_\mathrm{b} + \frac{M_\mathrm{cz}+\Delta M}{M_\mathrm{cz}}(m_i - m_\mathrm{b})$. For accretion HS1 is not changed: the gain goes to the outermost shell. 7. New total mass (SMASS, SMASS0, HSTOT, STOTAL), shell masses HS2 from JENV to M − 1 as half the distance between neighbours, HS2(M) = $10^{\texttt{HSTOT}}$ − (HS1(M) + HS1(M−1))/2, and SENV. 8. Accretion: elements 1–11 of the zone are mixed with the accreted composition COMPACC, $\bar x = (x_\mathrm{JENV}\,M'_\mathrm{cz} + x_\mathrm{acc}\Delta M)/(M'_\mathrm{cz}+\Delta M)$; FMASSACC = $\Delta M$.

Design. Several unconditional WRITE(*,…) lines report the step reduction, the angular momentum and the mass change.

KC's changes. 2025-05-30: the variables of COMMON MASSCHG3 reordered (the logical LSOLWIND moved to the end). The block is gone since.

Changed since rp_1. COMMON blocks to modules, IMPLICIT NONE; MASSCHG3 dropped (its three reals now zeroed locals, LSOLWIND from the namelist); the solar-wind branch guarded by DMWSUN > 0 (a bug fix: it would have given $\dot M$ = NaN). The call from MASSLOSS now matches the interface (fixed in massloss.f), which settles former question 1; former question 2 (MASSCHG3 set nowhere) is settled by the authors' fix, which confirms it and keeps the option inert until the three parameters are given a source.

Questions for the experts

  1. Inert code. With SCEN = 0 and DLNM = 0, the structure changes of step 4 vanish, and ETHNEW and FAC are not used; so EACC, ETHAV and the RMU argument have no effect. Is the code kept for later work?
  2. Hard stop. IF(JENV.EQ.M) STOP911 (that is, STOP 911) ends the run with only the stop code 911 when there is no surface convection zone.
  3. Angular momentum of accreted matter. For accretion HJM is not changed while HS2(M) grows, so the accreted matter implicitly takes the outer point's specific angular momentum. Intended?
  4. Out-of-bounds read (apparent bug). The loop DO I = JENV,M-1: HS2(I) = 0.5D0*(HS1(I+1)-HS1(I-1)) (lines 249–250) reads HS1(0) when JENV = 1, a case the routine handles elsewhere (lines 118 and 174). Should it start at MAX(JENV,2), with the central shell treated apart?
  5. The sign of WALPCZ. Line 209 sets $\Omega_\mathrm{surf} \propto r^{-\alpha}$ with $\alpha$ = WALPCZ, the opposite sign to WCZ's $\Omega = C\,r^{\alpha}$ (wcz.f line 58 at rp_1; WCZ has since been removed as unreachable); see GETNEWENV, question 7. Which sign is meant?

40    the old hs[m] - hstot.
41    """

52    dmczt = sumdm
53    # Mass of the surface convection zone below the fitting point.
54    # Question (see the page): hard stop with code 911 only.
55    if jenv == m:
56        raise SystemExit(911)

58        dmcz = hs1[m] - hs1[jenv]
59    else:

64    dtcz = nmlpar_mod.fczdmdt * dmcz / rate

79            ldone = True
80        else:
81            ldone = False
82    else:

86

94        d = 10.0**hd[jenv]

96        rmu = p * beta / (d * t)
97        # Question (see the page): SCEN = 0, so these changes vanish.
98        dlogen = (delm / dmcz) * masschg2_mod.scen / rmu
99        dlnm = 0.0
100        dlogr = (c.cc23 * dlogen - c.cc13 * dlnm) / c.cln
101        masschg2_mod.dlogt = dlnm / c.cln - dlogr

108        else:

112            facr = 10.0**dlogr
113            for j in range(jenv + 1, m + 1):
114                rinit = 10.0**hr[j]
115                rnew = rb + facr * (rinit - rb)
116                hr[j] = math.log10(rnew)
117
118    # Rotation and mass loss: the lost matter carries its local specific
119    # angular momentum (a thermal wind).
120    if nmlpar_mod.lrot and delm < 0.0:
121        surfi = 2.0 / 3.0 * rtot**2
122        walpcz = nmlpar_mod.walpcz
123        if walpcz >= 0.0:
124            # Solid-body zone.
125            delj = omega[m] * surfi * delm
126        elif walpcz <= -2.0:

128            delj = hjm[m] * delm
129        else:
130            # Question (see the page): the sign of WALPCZ.
131            wsurf = omega[m] * 10.0**(hr[m] * walpcz) / rtot**walpcz
132            delj = wsurf * surfi * delm

134        cjtot = hjm[jenv] * hs2[jenv]
135        for j in range(jenv + 1, m + 1):
136            cjtot = cjtot + hjm[j] * hs2[j]
137        cjnew = cjtot + delj
138        ratio = cjnew / cjtot
139        print(f"{delm:13.4E}{delj:13.4E}{omega[m]:13.4E}{cjnew:13.4E}"
140              f"{cjtot:13.4E}{dmczt:13.4E}")  # format 22
141        for j in range(jenv, m + 1):
142            hjm[j] = hjm[j] * ratio
143
144    # Remove mass in the convection zone: compress toward its base
145    # (hs1: shell centres in g; hs: log10 of hs1).
146    if delm < 0.0:
147        fx = (dmcz + delm) / dmcz
148        for i in range(jenv + 1, m + 1):
149            hs1[i] = hs1[jenv] + fx * (hs1[i] - hs1[jenv])
150            hs[i] = math.log10(hs1[i])
151
152    # New total mass in solar units (smass) and log g (hstot, stotal).
153    smass = smass + delm / c.cmsun
154    masschg2_mod.smass0 = smass
155    dmsun0 = delm / c.cmsun
156    print(f"MASS LOSS APPLIED - NEW M,DEL M{smass:19.10E}{dmsun0:19.10E}")
157    hstot1 = 10.0**hstot
158    hstot2 = hstot1 + delm
159    hstot = math.log10(hstot2)
160    comp_mod.stotal = hstot
161    # Shell masses hs2 (g).
162    # Question (see the page): reads hs1[0] when jenv = 1.
163    for i in range(jenv, m):
164        hs2[i] = 0.5 * (hs1[i + 1] - hs1[i - 1])
165    hs2[m] = hstot2 - 0.5 * (hs1[m] + hs1[m - 1])
166    comp_mod.senv = hs[m] - hstot
167    lnew = True
168    # Accretion: remix the zone with the accreted composition.
169    if delm > 0.0:
170        for i in range(1, 12):
171            abund = ((hcomp[i, jenv] * dmczt + nmlpar_mod.compacc[i] * delm)
172                     / (delm + dmczt))
173            for j in range(jenv, m + 1):
174                hcomp[i, j] = abund
175        deuter_mod.fmassacc = delm
176    if ldone:
177        nmlpar_mod.lmdot = False
178    return delts, hstot, lnew, rmu, smass, dmdt, senvold
