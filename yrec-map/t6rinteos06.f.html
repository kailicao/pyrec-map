Purpose

T6RINTEOS06 interpolates one equation-of-state quantity in temperature T6 and density for the OPAL 2006 EOS (its comment's words). At rp_1 it had two twins, line for line apart from table sizes and COMMON names: t6rinteos01.f for the 2001 tables and t6rinterp.f for the original OPAL tables (both removed since rp_1); this version has NT = 197 temperatures.

How it fits

  • Who calls it: only ESAC06.
  • What it calls: QUADEOS06.
  • Inputs: SLR and SLT, the density and temperature; from AEOS06_MOD the grids RHO, T6A, the inverse spacings DFS, DFSR and ESK, the values already interpolated in $X$; from EOS06MISC_MOD the grid indices K1–K4, L1–L4 and the switches IP, IQ, set by ESAC06, and the work arrays H, Q.
  • Output: ESACT in EOS06MISC_MOD, read by ESAC06; the module is also used by OEQOS06, RADSUB06, READCOEOS06, RHOOFP06, EQBOUND06 and CALCAD.

The method

QUADEOS06 gives the quadratic through three points, evaluated at $x$. For each of the temperatures $T_{k_1}, \dots$, a quadratic in density through the rows $l_1$–$l_3$ gives $h_k$, and, if IQ = 3, another through $l_2$–$l_4$ gives $q_k$. Quadratics in temperature through $h_{k_1..k_3}$ and $h_{k_2..k_4}$ (if IP = 3) are then blended linearly: $$f = w\,f_{123} + (1 - w)\,f_{234},\qquad w = (T_{k_3} - T)\,/\,(T_{k_3} - T_{k_2}),$$ the weight from DFS(K3), the inverse grid spacing. The same is done for the $q$'s, and, when IP = 3, the two results are blended in density with $w_\rho = (\rho_{l_3} - \rho)\,/\,(\rho_{l_3} - \rho_{l_2})$ (DFSR(L3)). A result above $10^{15}$ stops the run ("interpolation indices out of range").
