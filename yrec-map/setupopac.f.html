Variables on this page (6)

Purpose

Reads the opacity tables chosen for the run and sets up their interpolation. Its comment: "THIS SUBROUTINE READS IN SPECIFIED OPACITY TABLES AND SET UP SPLINES FOR THE TABLES. WHEN LZRAMP=T OR LDIFZ=T THEN READ IN SECOND SET OF OPACITY TABLES AT DIFFERENT Z."

How it fits

  • Who calls it: SETUPS, once per run; the file names are passed through (MHP 8/25).
  • What it calls, by the namelist switches in NMLPAR_MOD:
  • interior tables: OPAL95, LL95TBL then OP95XTAB (LOPAL95); the pure-Z table, RDZLAOL then ZSULAOL (LPUREZ);
  • low-temperature tables: Ferguson et al. 2005, READALEX06 (LALEX06).
  • Inputs: XENV (the envelope's $X$, for the tables built at fixed composition) and the file names FALEX06, FLIV95, FPUREZ. Sets L2Z = LZRAMP or LDIFZ (both namelist parameters) in NEWOPAC_MOD (line 64↗); despite the header's comment, no reader reads it, and only GETOPAC does, in its single-table test (lines 140–141↗; settled from the code, Nov 9, 2026).
  • Output: the tables, in the modules of the routines called. They are used at run time by GETOPAC.

From YREC's documentation

Control Options (Input files): FALEX06 is the molecular opacity table (Ferguson et al. 2005, with LALEX06, recommended), FLIV95 the atomic one (OP/OPAL format, with LOPAL95, recommended), and FPUREZ the pure Y/Z table (with LPUREZ).
