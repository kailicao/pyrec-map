Purpose

The one-time setup of a run's physics: it sets the physical constants used everywhere, then reads (or has read) every table the run needs: opacities, the Fermi–Dirac tables for the degenerate equation of state, the model-atmosphere pressure tables for the surface boundary condition, the OPAL 2006 equation-of-state tables, and the SCV equation-of-state tables.

How it fits

  • Who calls it: the main program (main.f), once, after PARMIN has read the namelists. Since "MHP 8/25," the file names are passed as arguments rather than through COMMON.
  • What it calls: HRA (a fit to the Harvard Reference Atmosphere's $T(\tau)$; here $\log_{10} T$ at $\tau = 2/3$, stored as HRAS), SETUPOPAC (all opacity tables), ALFILEIN (Allard atmospheres, when KTTAU = 4), and SETEOS06 (the OPAL 2006 EOS table, when LOPALE06; it was read on the first call to ESAC06 before).
  • Inputs, through modules: the switches KTTAU, LSCV, LOPALE06 from NMLPAR_MOD; the unit numbers (IFERMI, IOATM, ISCVH, ISCVHE, ISCVZ, ISHORT) from IOUNITS_MOD; XENV from COMP_MOD, passed on to SETUPOPAC.
  • Outputs, through modules: the constants in CONSTANTS_MOD (read by nearly every physics routine); the Debye–Hückel constant CDH and charges DHNUE (DEBHU_MOD, used by EQSTAT and others); the Fermi tables DVAL, ETAT8, DTABLE, IDEN (CCR_MOD, used by EQRELV); HRAS (ATMOS_MOD); the atmosphere tables ATMPL, ATMTL, ATMGL, ATMZ (ATMOS2_MOD) or ATMPLC… (ATMOS2C_MOD) and their usable ranges IMIN, IMINMAX, IMIN2, IMINMAX2 (FAC_MOD), used by SURFP and KCSURFP; and the SCV tables TLOGX, NPTSX, TABLEX, TABLEY, TABLEZ (SCVEOS_MOD), which SETSCV later combines.

The method

  1. Constants (cgs): $\ln 10$, $M_\odot = 1.9891\times10^{33}$ g, $M_\mathrm{bol,\odot} = 4.79$, a year of $3.1558\times10^7$ s, $c$, $\sigma$, $a/3 = 4\sigma/(3c)$ (CA3), $R = 8.31451\times10^7$ (CGAS), $\log G = -7.17571$, $m_e$, $k$, $h$, and the combinations $$\texttt{CMKH} = \log_{10}\frac{(2\pi m_e k)^{3/2}}{h^3},\qquad \texttt{CDELRL} = -\log_{10}\Bigl(\tfrac{4\pi}{3}\cdot 16\,\sigma\Bigr),\qquad \texttt{CDH} = -\frac{e^3}{3}\sqrt{\frac{\pi}{k\,m_H^3}},$$ with $m_H = 1/N_A$ g; CMIXL3 $= 16\sqrt2\,\sigma$, the constant in the coefficient $A_1$ of the mixing-length cubic $A_3V^3 + V^2 + A_1V - 1 = 0$ that TPGRAD solves for the convective efficiency. $M_\mathrm{bol,\odot}$ (CMBOL) gives the model's bolometric magnitude, $M_\mathrm{bol} = 4.79 - 2.5\log(L/L_\odot)$, in WRTOUT. $L_\odot$ and $R_\odot$ are taken from CONSTANTS_MOD as already set (initialized there, and in the PHYSICS namelist).

    Question 1 (line 141↗, line 148↗, lines 156–172↗). Constants of different vintages. $G$, $\sigma$, $k$, $h$, $m_e$ are 1986 CODATA values, $M_\odot$ is set here, but $L_\odot$ and $R_\odot$ come from elsewhere (initialized in CONSTANTS_MOD, and in the namelist). CSECYR is $3.1558\times10^7$ s, while RATES says it uses the sidereal year (rates.f, line 657↗). Should the constants be updated together?

    Question 2 (line 146↗). $M_\mathrm{bol,\odot} = 4.79$. With $L_\odot$ = CLSUN = $3.8515\times10^{33}$ erg s⁻¹, the IAU 2015 zero point ($M_\mathrm{bol} = 0$ at $3.0128\times10^{35}$ erg s⁻¹) gives $M_\mathrm{bol,\odot} = 4.73$, and the IAU nominal value is 4.74; CMBOL = 4.79 is fixed here, apart from CLSUN, which the namelist can change. Which zero point do the bolometric magnitudes written by WRTOUT follow, and should CMBOL be derived from CLSUN?

  2. Opacity tables through SETUPOPAC.

  3. Fermi–Dirac tables: 43 values of the density variable DVAL and of ETAT8, then 860 records of DTABLE(1..5, I, J); the index IDEN(1..261) maps a density bin in steps of 0.05 to the table row. A non-increasing DVAL stops the run (exit status 3, an input error).

    The Fermi table's indices are safe in the shipped file. READ(IFERMI,160) (I,J,(DTABLE(K,I,J),K=1,5),NCARDS=1,860) (line 221↗) reads I and J from each record and uses them as subscripts at once, so a bad record would write anywhere in DTABLE(5,43,20) (ccr_mod.f, line 26↗); but the 860 records of input/eos/yale/FERMI.TAB have 860 distinct pairs, with I from 1 to 43 and J from 1 to 20 (checked from the file, Nov 10, 2026), so a check of the indices would guard only a user's own table.

    The real-valued monotonicity test is the right one. A comment (MHP 10/02) says the test should compare INT values, but the line that does is commented out (lines 227–229↗). The active test is right for the shipped table. In FERMI.TAB, DVAL is strictly increasing but not spaced by whole numbers ($-16$, $-15$, …, $-12$, $-11.5$, …), so an INT test would stop the run at 29 of its 41 checks (checked from the file, Nov 10, 2026), and the comment can go.

  4. Atmosphere pressure tables (KTTAU = 3, 4: 57 $\log T_\mathrm{eff}$ × 11 $\log g$; KTTAU = 5: Kurucz/Castelli 2004, 76 × 11, "JNT 6/14"). Missing entries are $-999$; for each temperature, the code records the range of gravities with valid pressures ("G Somers 5/15"; for KTTAU = 5, bug 1).

  5. OPAL 2006 EOS tables (LOPALE06): SETEOS06. Independent of the SCV tables; a run may use both.
  6. SCV tables (LSCV): for each of 63 temperatures, NPTSX(I) rows of 11 quantities for hydrogen and helium, and 13 for metals (the metal table is stored in reverse order of pressure; "computed using the Prather equation of state in the old Yale code").

From YREC's documentation

Control Options (Input files) and Microphysics in YREC: FFERMI is the table of Fermi integrals for partial (and relativistic) degeneracy, required for every run; FSCVH, FSCVHE, FSCVZ the SCV EOS tables for H, He and metals (the last generated with YREC's own EOS, for consistency); FATM the Kurucz or Kurucz/Castelli atmosphere table; FALLARD the Allard atmospheres (solar $Z$ only). Physics Options (Constants): the code works in cgs but writes solar units, with CLSUN and CRSUN as $L_\odot$ and $R_\odot$.

27def _fields(line, widths):
28    """Split a fixed-format record into floats (a blank field reads as 0,
29    as in Fortran)."""
30
31    out, pos = [], 0
32    for w in widths:
33        text = line[pos:pos + w].strip()
34        out.append(float(text.replace('D', 'E')) if text else 0.0)
35        pos += w
36    return out

39def _read_e16(f, n, rows):
40    """Read n values in E16.8 fields, as many per record as `rows` says
41    (formats 201, 202, 203, 206, 208)."""
42
43    values = []
44    for count in rows:
45        values += _fields(f.readline(), [16] * count)
46    return values[:n]

208def _set_imin(atmpl, nt, ng, imin, iminmax, ng_empty):
209    """G Somers 5/15: for each temperature j, the range of gravities with a
210    valid pressure: iminmax[j], the highest, and imin[j], the lowest of the
211    contiguous valid run below it (or ng_empty if there is none). Written
212    out twice in the Fortran, for each grid (Fortran lines 270–299 and
213    327–356)."""
214
215    for j in range(1, nt + 1):
216        lcatch = False
217        for k in range(ng, 0, -1):
218            if atmpl[j, k] <= 0.0:
219                if lcatch:
220                    imin[j] = k + 1
221                    break  # to label 5 (6)
222            else:
223                if not lcatch:
224                    iminmax[j] = k
225                lcatch = True
226        else:
227            imin[j] = 1
228        if not lcatch:
229            imin[j] = ng_empty
