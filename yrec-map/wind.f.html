Purpose

WIND removes angular momentum from the surface convection zone by a magnetized wind, "a Weber–Davis magnetic wind model" (its comment), over one time step. It is the older loss law; MWIND calls it when LMWIND is off, and otherwise uses its own law.

How it fits

  • Inputs: $\log L$ (BL), the time step DELTS (s), the convection zone's mass range (HSBOT, HSTOP) and shells (JSTART, JEND), the switch LJDOT, the surface rate OMEGAS, the mass SMASS (in solar masses, probably), $\log T_\mathrm{eff}$, the zone's moment of inertia HICZ. Through modules: the law's constant and exponents (NMLPAR_MOD, formerly COMMON/CWIND/: CONSTFACTOR, EXMD, EXW, EXR, EXM, the saturation WMAX, set by PARMIN); the overturn time TAUCZ (OVRTRN_MOD, from GETTAU); LINSTB (NMLPAR_MOD, formerly COMMON/ROT/).
  • Who calls it: only MWIND.
  • Output: HJM, each shell's specific angular momentum in the zone, reduced.
  • Modules: NMLPAR_MOD, OVRTRN_MOD, CONSTANTS_MOD, DIMENSIONS_MOD, IOUNITS_MOD (for ISHORT).

The method

  1. Saturation. $\Omega_\mathrm{sat}$ = WMAX; but with angular momentum transport (LINSTB) and WMAX > 1, WMAX is read as $\Omega_\mathrm{sat}\tau_\mathrm{cz}$ for the Sun, and $\Omega_\mathrm{sat} = $ WMAX$/\tau_\mathrm{cz}$ (MHP 3/09); the run stops if $\tau_\mathrm{cz} \le 1$, with exit code 1 and the message also in the .short file.

    Question 1 (lines 64–80↗). The saturation's units. WMAX > 1 switches the meaning of WMAX (rad/s, or rad/s × s). A rate above 1 rad/s is unphysical, so the test works as a switch, but the Physics namelist page describes WMAX only in rad/s. Would a separate switch, or a sentence in the documentation, be clearer?

  2. The loss law. With $R = \sqrt{L/(4\pi\sigma T_\mathrm{eff}^4)}$ and the fixed mass-loss rate $\dot M = 2\times10^{-14}\,M_\odot$/yr, $$I\,\frac{d\Omega}{dt} = -K\left(\frac{\dot M}{10^{-14}}\right)^{a}\left(\frac{R}{R_\odot}\right)^{c} M^{d}\;\Omega\,\min(\Omega, \Omega_\mathrm{sat})^{\,b-1},$$ with $K$ = CONSTFACTOR, $a$ = EXMD, $b$ = EXW, $c$ = EXR, $d$ = EXM.

    Question 2 (line 87↗; lines 97–99↗). A fixed mass-loss rate. DMDOT = 2.0D-14 is hard-coded, so the factor $(\dot M/10^{-14})^{a}$ is the constant $2^{a}$, whatever the model's own rate (DMDT0). Is this meant, as a part of the calibration through CONSTFACTOR?

  3. Integration. If one explicit step would remove more than $\Omega$, the step is split into NSTEP substeps. In each, $\Omega_\mathrm{new}$ is found by iteration: the loss is evaluated at the mean of the start and the previous estimate, until the relative change is below $10^{-6}$ (at most 21 evaluations). The new rate is stored in WNEW, which is also a namelist variable (bug 1).

    Question 3 (lines 117–134↗). No convergence check. After 21 evaluations without convergence, the last estimate is used without a message. Should the routine warn, or cut the substep?

  4. Removal. $\Delta j = (\Omega_\mathrm{s} - \Omega_\mathrm{new})\,I_\mathrm{cz}/\Delta M_\mathrm{cz}$, with $\Delta M_\mathrm{cz}$ = HSTOP - HSBOT, is subtracted from every shell of the zone.

Suspected bugs, by priority

(a) may give wrong results; (b) may crash; (c) misbehaves silently (a wrong message, an ignored setting); (d) fragile: correct today, but breaks on a change or an unusual input.

  1. (a) WNEW overwrites the namelist's solid-body rate. (line 122↗; line 133↗; line 142↗) The iterated new rate is assigned to WNEW, which USE NMLPAR_MOD makes the namelist variable WNEW (line 129↗): the rate at which STARIN starts a model in solid-body rotation when LWNEW is set (lines 365–371↗). Each call of WIND therefore replaces the input with the last wind rate. The main program calls STARIN again for each run of its DO 200 NK = 1, NUMRUN loop (line 397↗), so a later run of the same job with LWNEW would start from the previous run's last surface rate, not from the input. Only with LROT, LWNEW (off by default), the old wind law (LMWIND off, the default), and more than one run (NUMRUN > 1); suspected bug 1 is the same for the new law. Read from the code, not run. A possible fix: a local name for the iterate, here and in MWIND:

The older wind braking law: $I\,d\Omega/dt \propto \Omega\,\min(\Omega,\Omega_\mathrm{sat})^{b-1}$ with fixed exponents, integrated over the step and taken from the surface convection zone's specific angular momentum.
