Purpose

Computes the settling coefficients of one species at each point of the equally spaced grid, "in the method of the Thoul routine," for MICRODIFF_RUN. Its header (G. Somers, 5/15) says it was written for light-element diffusion; it now serves hydrogen and metals too.

How it fits

  • Inputs: NPT points with radius ER (units of $R_\odot$), density EDEN (g cm⁻³), temperature ETEM (K), $d\ln P/dr$ (EHQPR), $\nabla$ (EDELR), the three abundances ESPEC(3,·), and the species' weight THEA, charge THEZ and column J.
  • Who calls it: only MICRODIFF_RUN, once on the grid points and once on the midpoints.
  • What it calls: THDIFF, which solves for the diffusion coefficients of the four-species mixture (H, He, the species, electrons).
  • Outputs: ECOD1 and ECOD2, and the hydrogen concentration gradient EDXDR, written on the hydrogen call ($J = 1$) and read on later calls.
  • Modules: CONSTANTS_MOD (CC13 $=1/3$), NMLPAR_MOD (the namelist factors FGRY and FGRZ, set by PARMIN) and DIMENSIONS_MOD (JSON).

The method

At each point, with mass fractions $X_k$ (floored at $10^{-24}$), weights $A_k$ (1.008, 4.004, THEA, $5.486\times10^{-4}$) and charges $Z_k$ (1, 2, THEZ, −1):

  1. Concentrations relative to electrons: $c_k = \dfrac{X_k/A_k}{\sum_l Z_l X_l/A_l}$ for the three ions, $c_e = 1$.
  2. Electron and ion densities: $n_e = \rho / (m_p \sum_k A_k c_k)$ with $m_p = 1.6726\times10^{-24}$ g, $n_i = \sum_\mathrm{ions} c_k\, n_e$.
  3. Lengths: the inter-ionic distance $a_0 = (3/(4\pi n_i))^{1/3}$ (0.23873 $= 3/4\pi$), the Debye length $\lambda_D = 6.9010\,\sqrt{T/(n_e \sum_k c_k Z_k^2)}$ cm, and $\lambda = \max(\lambda_D, a_0)$.

  4. Coulomb logarithms for each pair: $$x_{kl} = \frac{2.3939\times10^{3}\, T\, \lambda}{|Z_k Z_l|},\qquad \ln\Lambda_{kl} = 0.81245\,\ln\!\left(1 + 0.18769\, x_{kl}^{1.2}\right).$$

  5. THDIFF returns the coefficients $A_P$ (TAP), $A_T$ (TAT) and $A_{kl}$ (TAC).

  6. The coefficients. With $f = F\, r'^2\, T'^{5/2} / 2.2$ ($r'$ in $R_\odot$, $T'$ in $10^7$ K, 2.2 the fixed LN_LAMBDA; $F$ is FGRY on the hydrogen call, $J = 1$, FGRZ on the third column, $J = 3$, and 1 otherwise, the same factors as in SETUP_GRSETT; ER is already in $R_\odot$, so the local CON_RAD, line 75↗, is set and never read: unused?): $$C_1 = -f\left[(A_P + A_T\nabla)\,\frac{d\ln P}{dr} + A_{j1}\,\frac{d\ln c_H}{dr}\right] X_j ,\qquad C_2 = -f\,A_{jj}.$$ The comment writes the velocity as $A_P\, d\ln P/dr + A_T\, d\ln T/dr + A_X\, d\ln X/dr + A_D\, d\ln D/dr$; here $d\ln T/dr = \nabla\, d\ln P/dr$. The hydrogen term is dropped on the hydrogen call (it is the same as the last term) and is zero at the first and last points; $d\ln c_H/dr$ is a centred difference.

    The two Coulomb logarithms cancel. Pairwise Coulomb logarithms go into THDIFF, but the coefficient is also divided by a fixed $\ln\Lambda$ = LN_LAMBDA = 2.2 (line 74↗; lines 148–154↗), and the time unit in MICRODIFF_SETUP, CON_TIME = $2.7 \times 10^{13}$ yr, "INCLUDES FACTOR OF 2.2 FROM LN LAMBDA" (microdiff_setup.f, lines 147–148↗), so the two factors of 2.2 cancel exactly, and the net unit, $5.94 \times 10^{13}$ yr, is within 1% of Thoul et al.'s $6 \times 10^{13}$ yr; whether that unit itself assumes $\ln\Lambda = 2.2$ the code does not show. (THDIFF's page raises the same point from its side.)

    Question 1 (lines 152–154↗; microdiff.f, lines 187–188↗; microdiff.f, lines 213–215↗). FGRZ for light elements. FGRZ scales every call with $J = 3$, which MICRODIFF uses both for the metals (LDIFZ) and for each light element (LDIFLI), so a factor named for metals also scales lithium, beryllium, and boron settling; in SETUP_GRSETT it scales the metals only. Is this intended? The documentation's "metal-settling" (docs/source/namelist_physics.md, line 32) does not settle it, since in astronomical usage the metals include lithium and beryllium, and SETUP_GRSETT diffuses no light elements to compare with; the intent of the change that added FGRY and FGRZ (JvS 01/26, lines 145–146↗) would settle it, and with the default FGRZ = 1 (nmlpar_mod.f, line 80↗) no run is affected.

1. (cannot be reached) Without hydrogen settling, the hydrogen gradient is never computed.

(line 96↗; lines 191–212↗) The gradient $d\ln c_H/dr$ (EDXDR, and EDXDR_H on the midpoint call) is computed and stored only on the hydrogen call ($J = 1$); later calls read it back. When LDIFY is false, MICRODIFF makes no hydrogen call (microdiff.f, line 157↗), so its SAVEd arrays EDXDR and EDXDR_H are never set (zero in practice, though the standard does not promise it), and the term $A_{j1}\,d\ln c_H/dr$ silently drops out of the settling of metals and light elements. What follows: where $X$ varies (the burned core, the base of the convective envelope), metals and light elements settle without the hydrogen-gradient term of Thoul et al. (1994). Only with LNEWDIF and LDIFZ or LDIFLI but not LDIFY (all off by default; the test suite's settling decks set all three, so they do not take this path).

47    fractions of H (k = 1), He (2) and the species (3); its weight thea and
48    charge thez; j, the column diffused (1 for hydrogen, 3 otherwise).
49    Arrays have index 0 unused.
50
51    Sets in place: ecod1, ecod2 (the coefficients) and, on the hydrogen call
52    (j = 1), edxdr, the hydrogen concentration gradient read by later calls.
53    Returns nothing.
54
55    """
56
57    nml = nmlpar_mod
58
59    # Set up the atomic weight and charge matrices (Fortran lines 64–72).
60    atomwt[1] = 1.008
61    atomwt[2] = 4.004
62    atomwt[3] = thea
63    atomwt[4] = 5.486e-4
64    zspec[1] = 1.0
65    zspec[2] = 2.0
66    zspec[3] = thez
67    zspec[4] = -1.0
68
69    # Set LN_LAMBDA, CON_RAD and CON_TEMP (Fortran lines 73–76).
70    ln_lambda = 2.2
71    con_rad = 1.0 / 6.9598e10  # noqa: F841  (unused in the Fortran too)
72    con_temp = 1.0e-7
73
74    # Calculate diffusion coefficients for each layer (Fortran lines 77–168).
75    for i in range(1, npt + 1):  # DO 5
76        # Make sure XFRAC = 0.0 isn't used for diffusion coefficients
77        # (Fortran lines 79–85).
78        xfrac[1] = espec[1, i]
79        xfrac[2] = espec[2, i]
80        xfrac[3] = espec[3, i]
81        for k in (1, 2, 3):
82            if xfrac[k] < 1.0e-24:
83                xfrac[k] = 1.0e-24
84
85        # Concentrations from mass fractions; the hydrogen concentration is
86        # saved when X is diffused (Fortran lines 86–96).
87        zxa = 0.0
88        for ii in range(1, NSPEC):
89            zxa = zxa + zspec[ii] * xfrac[ii] / atomwt[ii]
90        for ii in range(1, NSPEC):
91            concen[ii] = xfrac[ii] / (atomwt[ii] * zxa)
92        concen[NSPEC] = 1.0
93        # Suspected bug (see the page): with LDIFY off, the hydrogen
94        # gradient is never computed.
95        if j == 1:
96            hydcon[i] = concen[1]
97
98        # Skip the Thoul routine where the species is absent here and at the
99        # next point; the first depleted shell is kept, so that AD is right
100        # (Fortran lines 97–105).
101        # Suspected bug (see the page): only ADS is reset; FACS ... AHS keep
102        # old values.
103        if espec[j, i] == 0.0 and i != npt:
104            if espec[j, i + 1] == 0.0:
105                ads[i] = 0.0
106                continue  # GOTO 5
107
108        # Electron density NE from the mass density (Fortran lines 106–114).
109        rho = eden[i]
110        t = etem[i]
111        ac = 0.0
112        for ii in range(1, NSPEC + 1):
113            ac = ac + atomwt[ii] * concen[ii]
114        ne = rho / (1.6726e-24 * ac)
115
116        # Inter-ionic distance AO (Fortran lines 115–120).
117        ni = 0.0
118        for ii in range(1, NSPEC):
119            ni = ni + concen[ii] * ne
120        ao = (0.23873 / ni)**constants_mod.cc13
121
122        # Debye length LAMBDAD, and LAMBDA for the Coulomb logarithm
123        # (Fortran lines 121–128).
124        cz = 0.0
125        for ii in range(1, NSPEC + 1):
126            cz = cz + concen[ii] * zspec[ii]**2
127        lambdad = 6.9010 * math.sqrt(t / (ne * cz))
128        lam = max(lambdad, ao)  # LAMBDA
129
130        # Coulomb logarithms (Fortran lines 129–136).
131        for ii in range(1, NSPEC + 1):
132            for jj in range(1, NSPEC + 1):
133                xij = 2.3939e3 * t * lam / abs(zspec[ii] * zspec[jj])
134                tcl[ii, jj] = 0.81245 * math.log(1.0 + 0.18769 * xij**1.2)
135
136        # The diffusion coefficients (Fortran lines 137–140).
137        thdiff(NSPEC, atomwt, zspec, xfrac, tcl, tap, tat, tac)
138
139        # The factor FAC, scaled by FGRY and FGRZ, JvS 01/26 (Fortran lines
140        # 141–154).
141        # Question (see the page): FGRZ also scales the light elements (j = 3).
142        hru_i = er[i]
143        htu_i = t * con_temp
144        fac = hru_i**2 * htu_i**2.5 / ln_lambda
145        if j == 1:
146            fac = nml.fgry * hru_i**2 * htu_i**2.5 / ln_lambda
147        if j == 3:
148            fac = nml.fgrz * hru_i**2 * htu_i**2.5 / ln_lambda
149
150        # The first diffusion terms for hydrogen, the third for the others;
151        # stored so that the hydrogen gradient can be finished first
152        # (Fortran lines 155–167).
153        facs[i] = fac
154        aps[i] = -tap[j]
155        ats[i] = -tat[j] * edelr[i]
156        ahs[i] = -tac[j, 1]
157        ads[i] = -tac[j, j]
158
159    # The velocity is Ap dlnP/dR + At dlnT/dR + Ax dlnX/dR + Ad dlnD/dR
160    # (Thoul et al. 1994); for hydrogen the third term is the fourth
161    # (Fortran lines 169–215).
162    for i in range(1, npt + 1):  # DO 10
163        fac = facs[i]
164        ap = aps[i]
165        at = ats[i]
166        ah = ahs[i]
167        ad = ads[i]
168
169        # The hydrogen gradient: computed on the hydrogen call, zero at the
170        # ends, then zeroed locally to remove the second self-diffusion
171        # term; read back on the other calls (Fortran lines 175–212).
172        if j == 1:
173            if i == 1:
174                dlncdr = 0.0
175            elif i == npt:
176                dlncdr = 0.0
177            else:
178                coni = math.log(hydcon[i])
179                conip1 = math.log(hydcon[i + 1])
180                conim1 = math.log(hydcon[i - 1])
181                dradi = er[i + 1] - er[i]
182                t1 = (coni - conim1) / dradi
183                t2 = (conip1 - coni) / dradi
184                dlncdr = 0.5 * (t1 + t2)
185            edxdr[i] = dlncdr
186            dlncdr = 0.0
187        else:
188            # Suspected bug (see the page): EDXDR is never set if hydrogen is
189            # not diffused.
190            dlncdr = edxdr[i]
191
192        # The coefficients (Fortran lines 213–214).
193        ecod1[i] = fac * (ehqpr[i] * (ap + at) + dlncdr * ah) * espec[j, i]
194        ecod2[i] = fac * ad
