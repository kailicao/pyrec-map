Explanation

Purpose. SPLINC computes the second derivatives of a natural cubic spline through the points $(x_i, y_i)$, $i = 1, \dots, N$, for interpolation with SPLINTD2. It is the tridiagonal algorithm of Numerical Recipes' spline, with the end conditions fixed to a natural spline.

How it fits.

  • Who calls it: only HPOINT, which then calls SPLINTD2 with the result.
  • Outputs: Y2, the second derivatives at the points.
  • COMMON blocks: none.

The method. A natural spline has $y''_1 = y''_N = 0$. For the interior points the second derivatives solve

$$\frac{x_i - x_{i-1}}{6}\,y''_{i-1} + \frac{x_{i+1} - x_{i-1}}{3}\,y''_i + \frac{x_{i+1} - x_i}{6}\,y''_{i+1} = \frac{y_{i+1} - y_i}{x_{i+1} - x_i} - \frac{y_i - y_{i-1}}{x_i - x_{i-1}},$$

which the code solves by forward elimination (SIG, P, U) and back substitution.

Design. The arrays have the fixed size JSON (5000, from DIMENSIONS_MOD). splinj.f is the same routine with arrays sized N.

Changed since rp_1. Declarations only: the array size JSON from DIMENSIONS_MOD, IMPLICIT NONE.

15    """The second derivatives y2 of the natural cubic spline through
16    (x, y) (y2 = 0 at both ends), for interpolation with SPLINTD2.
17
18    Translates: splinc.f#SPLINC (09c3b9b)
19
20    Arguments: x[1..n] (increasing), y[1..n]; y2[1..n], filled in place;
21    n (at most JSON). None is returned.
22    """
23    y2[1] = 0.0
24    u[1] = 0.0
25    # Forward elimination.
26    for i in range(2, n):
27        sig = (x[i] - x[i - 1]) / (x[i + 1] - x[i - 1])
28        p = sig * y2[i - 1] + 2.0
29        y2[i] = (sig - 1.0) / p
30        u[i] = (6.0 * ((y[i + 1] - y[i]) / (x[i + 1] - x[i])
31                       - (y[i] - y[i - 1]) / (x[i] - x[i - 1]))
32                / (x[i + 1] - x[i - 1]) - sig * u[i - 1]) / p
33    qn = 0.0
34    un = 0.0
35    y2[n] = (un - qn * u[n - 1]) / (qn * y2[n - 1] + 1.0)
36    # Back substitution.
37    for k in range(n - 1, 0, -1):
38        y2[k] = y2[k] * y2[k + 1] + u[k]
