Purpose

EGRIDDER_MOD holds the coefficients of the higher-derivative terms of the diffusion-plus-advection treatment of angular momentum (LDIFAD), shared by SETUPV, VCIRC and DADCOEFT. It replaces COMMON/EGRIDDER/ (MHP via Claude, 10/14/26); JSON comes from DIMENSIONS_MOD.

What its variables hold, who sets them, who reads them.

  • QQCOD(JSON): $\tfrac23\,r^4/(G\,m)$-type factors at each shell (CC23*RM**4/CG/HS3), set by SETUPV; VCIRC multiplies them by $\Omega$ (WM) into EQQCOD.
  • EQQCOD(JSON): read by DADCOEFT as the coefficients of its $d^2\Omega/dr^2$ rows.
  • QQQCOD(JSON): factors set by SETUPV (HTM, HTP, line 410↗, line 435↗); read nowhere: unused?

  • EQQQCOD(JSON): read by DADCOEFT as the coefficients of its $d^3\Omega/dr^3$ rows (lines 371–373↗), but set by no routine (so at rp_1 too), so those coefficients are zero.

    Question 1 (lines 371–373↗; line 435↗). A coefficient never set. EQQQCOD, read by DADCOEFT, is set nowhere, while QQQCOD, set by SETUPV, is read nowhere. Was VCIRC meant to form EQQQCOD from QQQCOD, as it forms EQQCOD from QQCOD? (Only with LDIFAD, off by default; what follows is DADCOEFT's suspected bug 1.)

Design

A blanket USE EGRIDDER_MOD. The pairs mirror each other: VCIRC turns QQCOD into EQQCOD, but nothing turns QQQCOD into EQQQCOD, the same gap as in DIFAD3_MOD.
