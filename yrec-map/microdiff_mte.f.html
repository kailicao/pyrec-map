Purpose

"Model to equal": interpolates the model's variables onto an equally spaced grid in radius, at the grid points and at the midpoints between them, for MICRODIFF.

How it fits

  • Inputs: from MICRODIFF_SETUP: the radii HRU (units of $R_\odot$), IBEGIN, IEND, and the density ODEN and temperature OTEM; and the composition HCOMP, HQPR, HS1 and $\nabla$ (SDEL(2,·) in SCRTCH_MOD).
  • Who calls it: only MICRODIFF.
  • What it calls: INTERP, for the four-point Lagrange weights.
  • Outputs: NPT, DR, and on the grid points (E…) and midpoints (E…_H): the mass $m$, $\rho$, $T$, $d\ln P/dr$, $\nabla$, $X$, $Y$, $Z$ and the light elements; these go to MICRODIFF_RUN. The radius, mass and $d\ln P/dr$ are in the Bahcall–Loeb units of MICRODIFF_SETUP; $\rho$ and $T$ are in cgs units (g cm⁻³, K).
  • Modules: SCRTCH_MOD (read: SDEL), NMLPAR_MOD (LDIFLI), DIMENSIONS_MOD (JSON).

The method

  1. Spacing. $\Delta r_\mathrm{min}$ is the smallest model spacing among the 20 points below IEND (the base of the surface convection zone). The number of points is $$N = \left\lceil \frac{r_\mathrm{end} - r_\mathrm{begin}}{\Delta r_\mathrm{min}} \right\rceil,\quad N \ge 4,\quad N \le 5000\ (\mathrm{JSON}),\qquad \Delta r = \frac{r_\mathrm{end} - r_\mathrm{begin}}{N-1}.$$

    Question 1 (lines 56–60↗). Where the spacing is measured. $\Delta r_\mathrm{min}$ is measured only over the 20 points below the surface convection zone ("ID THE MINIMUM SPACING IN THE 20 LAYERS BELOW THE SURFACE CZ"). Deeper regions with finer model spacing are then under-resolved. Is this intended?

    Question 2 (lines 61–64↗; line 83↗). The grid is coarser than the comment says. The comment asks for "the minimum number of equally spaced grid points such that DR <= DRMIN", but NPT $=\lceil \Delta r_\mathrm{tot}/\Delta r_\mathrm{min}\rceil$ points make NPT-1 intervals, so DR $= \Delta r_\mathrm{tot}/(N-1)$ is larger than $\Delta r_\mathrm{min}$ (up to 4/3 as large, when $N = 4$). Should NPT be one more?

  2. Midpoints. $r_{i+1/2} = r_\mathrm{begin} + (i - \tfrac12)\Delta r$ for $i = 1,\dots,N-1$. The first is found by linear interpolation; the others by four-point Lagrange interpolation over the four model points around them, $f(r) = \sum_{k=1}^{4} w_k(r)\, f_{k_0+k-1}$. Two pieces of code here cannot run: the branch for NPT = 2 (lines 87–88↗), since NPT is at least 4, and the debugging line IF(I-1 .EQ. 0) PRINT*, 'mte line 47' (line 91↗) inside DO 10 I = 2,NPT-1 (unused?).

  3. Grid points. $r_i = r_\mathrm{begin} + (i-1)\Delta r$. The first and last take the model's values at IBEGIN and IEND; the others use the same four-point interpolation.

    Question 3 (lines 164–177↗; lines 256–267↗). Interpolated composition. Four-point Lagrange interpolation of $X$, $Y$, $Z$ near steep gradients can overshoot (negative or above one). MICRODIFF_COD floors the mass fractions at $10^{-24}$ for its coefficients (lines 83–85↗), and MICRODIFF_ETM maps back only the changes, which limits the harm. Is an overshoot guarded anywhere else, or does it need to be?

Suspected bugs, by priority

(a) may give wrong results; (b) may crash; (c) misbehaves silently (a wrong message, an ignored setting); (d) fragile: correct today, but breaks on a change or an unusual input.

  1. (a) The first midpoint can be interpolated from the wrong model points. (lines 100–113↗) The search for the model point above the first midpoint runs over IU = 2..NPT: model indices from 2, bounded by the number of equal-grid points, rather than IBEGIN+1..IEND. The model point needed lies above IBEGIN; when NPT is smaller than its index (a large IBEGIN, such as a convective core with many points, and a coarse equal grid), the loop ends, IU falls back to NPT, and the "interpolation" extrapolates from points NPT-1 and NPT, far inside the core. What follows: wrong values at the first midpoint (EM_H(1), EDEN_H(1), ETEM_H(1), EHQPR_H(1), EDELR_H(1) and the abundances), which MICRODIFF_RUN uses in its first cell (line 146↗). The older settling path has the same search (suspected bug 1). Only with LNEWDIF and LDIFY, LDIFZ or LDIFLI (all off by default; the test suite's settling decks set them), and only when NPT is that small; how often a run reaches it was not traced. Read from the code, not run. A possible fix:

Change log

The changes since rp_1

Changed since rp_1. The cap on NPT is now JSON itself (the same 5000) rather than a repeated literal; the authors' comment says the name HALFJSON is presumably left from an earlier cap of JSON/2, which settles the former question 3; COMMON blocks to modules (the unused /GRAVS3/ is gone), IMPLICIT NONE.

Changed since a8a5950. The grid has at least 4 points, not 2, since the 4-point Lagrange stencils here and in MICRODIFF_ETM read ER(K0..K0+3), and a 2- or 3-point grid read points never set, or ER(-1) and ER(0).

21def _lagrange(f, k0):
22    # FACINTERP(1)*F(K0) + ... + FACINTERP(4)*F(K0+3), in the Fortran's
23    # order (Fortran lines 152–187, 246–275).
24    return (facinterp[1] * f[k0] + facinterp[2] * f[k0 + 1]
25            + facinterp[3] * f[k0 + 2] + facinterp[4] * f[k0 + 3])

28def _find_k0(r, jmin, iend, m, hru):
29    # Labels 20/30 (and 80/90): the first model point J >= JMIN at or above
30    # radius r gives the four interpolation points K0..K0+3, kept inside
31    # 1..M; returns (k0, jmin) (Fortran lines 128–141, 222–235).
32    for j in range(jmin, iend + 1):
33        if hru[j] >= r:
34            k0 = max(j - 2, 1)
35            k0 = min(k0, m - 3)
36            return k0, j
37    return m - 3, m

40def microdiff_mte(nlight: int, cslight: np.ndarray, hcomp: np.ndarray, hqpr: np.ndarray, hru: np.ndarray,
41                  hs1: np.ndarray, ibegin: int, iend: int, m: int, dr: float, npt: int, oden: np.ndarray,
42                  otem: np.ndarray, em: np.ndarray, er: np.ndarray, eden: np.ndarray, etem: np.ndarray,
43                  ehqpr: np.ndarray, edelr: np.ndarray, ex: np.ndarray, ey: np.ndarray, ez: np.ndarray, eli: np.ndarray,
44                  em_h: np.ndarray, er_h: np.ndarray, eden_h: np.ndarray, etem_h: np.ndarray, ehqpr_h: np.ndarray,
45                  edelr_h: np.ndarray, ex_h: np.ndarray, ey_h: np.ndarray, ez_h: np.ndarray,
46                  eli_h: np.ndarray) -> tuple[float, int]:
47    """Interpolate the model between shells ibegin and iend onto an equally
48    spaced grid in radius, at the grid points (e...) and the midpoints
49    between them (e..._h), for MICRODIFF.
50
51    Translates: microdiff_mte.f#MICRODIFF_MTE (7be4133)
52
53    Arguments: nlight light elements, at the hcomp rows cslight[1..nlight];
54    the model's hcomp[k, j], hqpr, radius hru (Rsun), mass hs1, density
55    oden and temperature otem, with m shells; the gradient comes from
56    scrtch_mod.sdel[2, j]. dr and npt are passed in with any value.
57    Arrays have index 0 unused.
58
59    Sets in place: em, er, eden, etem, ehqpr, edelr, ex, ey, ez, eli[kk, i]
60    on the npt grid points, and the same with _h on the npt - 1 midpoints.
61
62    Returns (dr, npt): the grid spacing and the number of grid points.
63
64    """
65
66    sdel = scrtch_mod.sdel
67    ldifli = nmlpar_mod.ldifli
68
69    # Find the minimum model point spacing in radius, in the 20 layers below
70    # the surface convection zone (Fortran lines 53–60).
71    # Question (see the page): only these 20 layers.
72    drtot = hru[iend] - hru[ibegin]
73    drmin = drtot
74    istart = max(iend - 20, ibegin + 1)
75    for i in range(istart, iend + 1):
76        drmin = min(drmin, hru[i] - hru[i - 1])
77
78    # The minimum number of equally spaced points such that DR <= DRMIN
79    # (Fortran lines 61–64).
80    # Question (see the page): NPT points make NPT - 1 intervals.
81    npt = int(drtot / drmin)
82    if math.fmod(drtot, drmin) != 0.0:
83        npt = npt + 1
84
85    # At least 4 points, as the 4-point Lagrangian stencils read
86    # ER(K0..K0+3), and at most JSON; the spacing (Fortran lines 65–83).
87    npt = max(npt, 4)
88    halfjson = JSON
89    npt = min(npt, halfjson)
90    dr = drtot / float(npt - 1)
91
92    # Equally spaced radii at the zone midpoints (Fortran lines 84–94); the
93    # NPT = 2 branch and the debug PRINT cannot run.
94    er_h[1] = hru[ibegin] + 0.5 * dr
95    if npt == 2:
96        er_h[2] = er_h[1] + dr
97    else:
98        for i in range(2, npt):  # DO 10
99            er_h[i] = er_h[i - 1] + dr
100
101    # First midpoint: linear interpolation (Fortran lines 96–119).
102    # Suspected bug (see the page): the search runs over model indices
103    # 2..NPT, not IBEGIN+1..IEND.
104    iu = npt
105    for k in range(2, npt + 1):  # DO 15
106        if hru[k] >= er_h[1]:
107            iu = k
108            break
109    fx = (er_h[1] - hru[iu - 1]) / (hru[iu] - hru[iu - 1])
110
111    def lin(f):
112        return f[iu - 1] + fx * (f[iu] - f[iu - 1])
113
114    em_h[1] = lin(hs1)
115    eden_h[1] = lin(oden)
116    etem_h[1] = lin(otem)
117    ehqpr_h[1] = lin(hqpr)
118    edelr_h[1] = sdel[2, iu - 1] + fx * (sdel[2, iu] - sdel[2, iu - 1])
119    ex_h[1] = hcomp[1, iu - 1] + fx * (hcomp[1, iu] - hcomp[1, iu - 1])
120    ey_h[1] = hcomp[2, iu - 1] + fx * (hcomp[2, iu] - hcomp[2, iu - 1])
121    ez_h[1] = hcomp[3, iu - 1] + fx * (hcomp[3, iu] - hcomp[3, iu - 1])
122    if ldifli:
123        for kk in range(1, nlight + 1):
124            ii = cslight[kk]
125            eli_h[kk, 1] = (hcomp[ii, iu - 1]
126                            + fx * (hcomp[ii, iu] - hcomp[ii, iu - 1]))
127
128    # Other midpoints: 4-point Lagrange interpolation. JMIN is the uppermost
129    # model point above the previous grid point (Fortran lines 121–188).
130    # Question (see the page): the interpolated composition can overshoot.
131    jmin = ibegin + 1
132    for i in range(2, npt):  # DO 50
133        k0, jmin = _find_k0(er_h[i], jmin, iend, m, hru)
134        for k in range(1, 5):
135            tabler[k] = hru[k0 + k - 1]
136        interp(tabler, facinterp, facderiv, er_h[i])
137        em_h[i] = _lagrange(hs1, k0)
138        eden_h[i] = _lagrange(oden, k0)
139        etem_h[i] = _lagrange(otem, k0)
140        ehqpr_h[i] = _lagrange(hqpr, k0)
141        edelr_h[i] = _lagrange(sdel[2, :], k0)
142        ex_h[i] = _lagrange(hcomp[1, :], k0)
143        ey_h[i] = _lagrange(hcomp[2, :], k0)
144        ez_h[i] = _lagrange(hcomp[3, :], k0)
145        if ldifli:
146            for kk in range(1, nlight + 1):
147                eli_h[kk, i] = _lagrange(hcomp[cslight[kk], :], k0)
148
149    # Equally spaced radii at the zone centers (Fortran lines 190–194).
150    er[1] = hru[ibegin]
151    for i in range(2, npt + 1):
152        er[i] = er[i - 1] + dr
153
154    # First point: by definition, at the starting point (Fortran lines
155    # 199–214).
156    em[1] = hs1[ibegin]
157    eden[1] = oden[ibegin]
158    etem[1] = otem[ibegin]
159    ehqpr[1] = hqpr[ibegin]
160    edelr[1] = sdel[2, ibegin]
161    ex[1] = hcomp[1, ibegin]
162    ey[1] = hcomp[2, ibegin]
163    ez[1] = hcomp[3, ibegin]
164    if ldifli:
165        for kk in range(1, nlight + 1):
166            eli[kk, 1] = hcomp[cslight[kk], ibegin]
167
168    # Other points: 4-point Lagrange interpolation (Fortran lines 215–277).
169    jmin = ibegin + 1
170    for i in range(2, npt):  # DO 70
171        k0, jmin = _find_k0(er[i], jmin, iend, m, hru)
172        for k in range(1, 5):
173            tabler[k] = hru[k0 + k - 1]
174        interp(tabler, facinterp, facderiv, er[i])
175        em[i] = _lagrange(hs1, k0)
176        eden[i] = _lagrange(oden, k0)
177        etem[i] = _lagrange(otem, k0)
178        ehqpr[i] = _lagrange(hqpr, k0)
179        edelr[i] = _lagrange(sdel[2, :], k0)
180        ex[i] = _lagrange(hcomp[1, :], k0)
181        ey[i] = _lagrange(hcomp[2, :], k0)
182        ez[i] = _lagrange(hcomp[3, :], k0)
183        if ldifli:
184            for kk in range(1, nlight + 1):
185                eli[kk, i] = _lagrange(hcomp[cslight[kk], :], k0)
186
187    # Last point: by definition, at the ending point (Fortran lines
188    # 278–292).
189    em[npt] = hs1[iend]
190    eden[npt] = oden[iend]
191    etem[npt] = otem[iend]
192    ehqpr[npt] = hqpr[iend]
193    edelr[npt] = sdel[2, iend]
194    ex[npt] = hcomp[1, iend]
195    ey[npt] = hcomp[2, iend]
196    ez[npt] = hcomp[3, iend]
197    if ldifli:
198        for kk in range(1, nlight + 1):
199            eli[kk, npt] = hcomp[cslight[kk], iend]
200
201    return dr, npt
