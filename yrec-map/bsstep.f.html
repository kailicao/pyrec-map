Purpose

This file takes one adaptive step of the Bulirsch–Stoer method for the envelope and atmosphere integration: the modified midpoint method for an increasing number of substeps, extrapolated to zero substep size. It is the Numerical Recipes routine BSSTEP (first edition, with rational extrapolation), extended with the physical arguments that the derivative routine needs.

How it fits

  • Inputs: Y(3), DYDX(3) at X0 (the independent variable), the trial step HTRY, the tolerance EPS, the scales YSCAL, the derivative routine DERIV (passed as an argument by ENVINT: QATM for the atmosphere, QENV for the envelope) and the stellar quantities it needs (B, FPL, FTL, GL, RL, TEFFL, X, Z, …); IMAX and NUSE from the module INTPAR_MOD (initialized there to 11 and 7; both are also in the PHYSICS namelist, read by PARMIN, so a run can change them).
  • Who calls it: ENVINT.
  • What it calls: MMID (modified midpoint) and RATEXT (rational extrapolation).
  • Outputs: Y and X0 advanced, HDID (the step taken), HNEXT (the suggested next step), ERR (the scaled error of each variable); on a step-size underflow, a message on the screen and on ISHORT (from IOUNITS_MOD).

The method

For $i = 1, \dots, I_\mathrm{max}$, integrate across $H$ with $n_i$ = 2, 4, 6, 8, 12, 16, … midpoint substeps, and extrapolate the results in $(H/n_i)^2$ to zero. Accept the step when $$\max_j \frac{|\epsilon_j|}{y_{\mathrm{scal},j}} < \mathrm{EPS}.$$ The next step is $0.95H$ if it took NUSE sequences, $1.2H$ if one fewer, otherwise $H\,n_{\mathrm{NUSE}-1}/n_i$. If all $I_\mathrm{max}$ sequences fail, retry with $$H \leftarrow \frac{H/4}{2^{\lfloor (I_\mathrm{max} - N_\mathrm{use})/2 \rfloor}}.$$ If the new step no longer changes X (the hydrogen abundance, not the position: suspected bug 1), the run stops with exit status 1, printing X and $H$ (lines 62–71↗).

From YREC's documentation

Physics Options describes IMAX and NUSE (defaults 11 and 7) together: the integrators of the envelope and the atmosphere start with a large step, divide it into smaller ones and extrapolate to zero step size; IMAX is the largest number of such divisions, NUSE the number of earlier steps used in the extrapolation.

1. (never occurred) The step-size underflow test uses the hydrogen abundance.

(line 64↗) IF(X+H.EQ.X) tests X, which here is the hydrogen abundance passed through to DERIV, not the independent variable X0 ($\log\tau$ in the atmosphere, $\log P$ in the envelope: envint.f, lines 395–397↗, envint.f, lines 693–695↗); Numerical Recipes tests the independent variable. What follows: The test fires when $H$ is negligible next to $X \approx 0.7$, not next to the position, so a failing step goes on shrinking $H$ (by a factor 16 per round of IMAX sequences, with the defaults) somewhat longer before the run stops with "ERROR IN BSSTEP"; with $X = 0$ it fires only once $H$ underflows to zero. The stop and its message come late, the result is not changed. On every run's path, but only when the integration fails.

251    -------
252    stage, where : int, int
253        (STAGE_DONE, 0) when done; (STATUS_UNDERFLOW, 0) at an underflow; (stage, WHERE_MMID) when mmid's
254        derivative call stopped, (stage, WHERE_END) when the one at the step's end did.
255
256    """
257    stage = _bsstep_k(resume, y, dydx, nv, x0, htry, eps, yscal, err, which, b, fpl, ftl, gl, latmo, lderiv, lsave,
258                      teffl, x, z, cf, ci, ctx, bf, bi, ysav, dysav, yseq, yerr, ym, yn, sx, rx, rd, rfx, imax, nuse)
259    if stage == STATUS_UNDERFLOW:
260        return STATUS_UNDERFLOW, 0
261    if stage != STAGE_DONE:
262        return stage, WHERE_MMID
263    stage = _deriv_k(which, bf[2], y, dydx, b, fpl, ftl, gl, latmo, lderiv, lsave, teffl, x, z, cf, ci, ctx)
264    if stage != STAGE_DONE:
265        return stage, WHERE_END
266    return STAGE_DONE, 0

269class Chain:
270    """The envelope chain's driver, for qatm's (which = 0) or qenv's (1) integration.
271
272    Between open() and close(), the module state of the EOS and the opacity is in the chain's arrays: nothing else
273    may call them. A derivative call the kernels stop at is done by the plain code between close() and open().
274    Run-time settings (the namelist's, the modules') are read by open() and passed to the kernels as arguments.
275
276    Attributes
277    ----------
278    which : int
279        0 for qatm, 1 for qenv.
280    cf : np.ndarray, shape: `(NCF,)`, dtype: ``float``
281        RL; qatm's SAVE'd TL.
282    ci : np.ndarray, shape: `(NCI,)`, dtype: ``int64``
283        KOUNT (KATM or KENV), KSAHA, the calls done since the last put, the calls begun (qenv.test_stop).
284    bf, bi : np.ndarray, shapes: `(NBF,)`, `(NBI,)`, dtypes: ``float``, ``int64``
285        bsstep's kernel's state (_bsstep_k).
286    sx : np.ndarray, shape: `(2,)`, dtype: ``float``
287        mmid's kernel's state (_mmid_k).
288    r, out, fxion : np.ndarray, shapes: `(qenv.NR,)`, `(qenv.NOUT,)`, `(4,)`, dtype: ``float``
289        The EOS's values, the slots of module scalars, the ionization fractions.
290    eist : np.ndarray, shape: `(eqstat.EIST,)`, dtype: ``int64``
291        The chain's EOS state.
292    gop, ctx : tuple
293        getopac's kernel's arguments (qenv.gop_in), and the context the kernels take.
294
295    Methods
296    -------
297    open : Read the modules into the context.
298    close : Write the chain's EOS and opacity state back to the modules.
299    deriv : One derivative call (for qatm and qenv).
300    step : One step of envint's integration (bsstep and the derivative after it).
301
302    """
303
304    def __init__(self, which: int):
305        self.which = which
306        self.cf = np.zeros(NCF)
307        self.ci = np.zeros(NCI, dtype=np.int64)
308        self.bf = np.zeros(NBF)
309        self.bi = np.zeros(NBI, dtype=np.int64)
310        self.sx = np.zeros(2)                          # mmid's X0; the call stopped at
311        self.r = np.zeros(qenv_mod.NR)
312        self.out = np.zeros(qenv_mod.NOUT)
313        self.fxion = np.zeros(4)
314        self.eist = np.zeros(eqstat_mod.EIST, dtype=np.int64)
315        self.open()
316
317    def open(self) -> None:
318        """Read the modules into the context (the EOS state, getopac's state, the constants and settings, the
319        slots)."""
320        eqstat_mod.eos_in(self.eist)
321        self.gop = qenv_mod.gop_in()
322        cons = families.atmosphere().kernel_args()    # OOP atmosphere: the integrands' settings (qatm.cons_in)
323        tpg = families.convection().kernel_args()     # OOP convection: the installed convection family's data
324        # OOP eos: the EOS context is (eqstat.eos_args(), the EOS family's data, eqsaha's guess) (families.py).
325        self.ctx = (families.eos_chain_args(), self.eist, qenv_mod.opac_args(), self.gop, tpg, cons, self.fxion,
326                    self.r, self.out, qenv_mod.test_stop)
327        self.cf[1] = qatm_mod.tl
328        self.ci[2] = 0
329        (qatm_mod if self.which == 0 else qenv_mod).get(self.out)
330
331    def close(self) -> None:
332        """Write the chain's EOS and opacity state back to the modules."""
333        eqstat_mod.eos_out(self.eist)
334        qenv_mod.gop_out(self.gop)
335
336    def _put(self, lsave: bool) -> None:
337        """Write the slots of the kernels' last derivative call to the modules, if a call was done since the
338        last put."""
339        if self.ci[2] > 0:
340            if self.which == 0:
341                qatm_mod.put(self.out, lsave, float(self.cf[1]))
342            else:
343                qenv_mod.put(self.out, lsave)
344            self.ci[2] = 0
345
346    def _finish(self, stage: int, x0: float, y: np.ndarray, dydx: np.ndarray, b: float, fpl: float, ftl: float,
347                gl: float, latmo: bool, lderiv: bool, lsave: bool, teffl: float, x: float, z: float) -> None:
348        """The derivative call the kernel stopped at, by the plain code from its stage."""
349        self._put(lsave or pulse1_mod.lpumod)
350        self.close()
351        args = (x0, y, dydx, b, fpl, ftl, gl, latmo, lderiv, False, lsave, float(self.cf[0]), teffl, x, z,
352                int(self.ci[0]), int(self.ci[1]), stage, self.r.copy(), self.fxion.copy())
353        if self.which == 0:
354            self.ci[0], self.ci[1] = qatm_mod._qatm_plain(*args)
355        else:
356            self.cf[0], self.ci[0], self.ci[1] = qenv_mod._qenv_plain(*args)
357        self.open()
358
359    def deriv(self, x0: float, y: np.ndarray, dydx: np.ndarray, b: float, fpl: float, ftl: float, gl: float,
360              latmo: bool, lderiv: bool, lsave: bool, rl: float, teffl: float, x: float, z: float, kount: int,
361              ksaha: int) -> tuple[float, int, int]:
362        """DERIV(X0, Y, DYDX, ...) through the kernel: (rl, kount, ksaha)."""
363        lsv = bool(lsave or pulse1_mod.lpumod)
364        cf, ci = self.cf, self.ci
365        cf[0] = rl
366        ci[0] = kount
367        ci[1] = ksaha
368        # OOP pilot: the chain for the installed families (families.py).
369        stage = families.chains()._deriv_k(self.which, x0, y, dydx, b, fpl, ftl, gl, latmo, lderiv, lsv, teffl, x, z,
370                                           cf, ci, self.ctx)
371        if stage != STAGE_DONE:
372            self._finish(stage, x0, y, dydx, b, fpl, ftl, gl, latmo, lderiv, lsave, teffl, x, z)
373        self._put(lsv)
374        return float(cf[0]), int(ci[0]), int(ci[1])
375
376    def step(self, y: np.ndarray, dydx: np.ndarray, nv: int, x0: float, htry: float, eps: float, yscal: np.ndarray,
377             err: np.ndarray, b: float, fpl: float, ftl: float, gl: float, latmo: bool, lderiv: bool, lsave: bool,
378             rl: float, teffl: float, x: float, z: float, kount: int, ksaha: int) -> tuple:
379        """BSSTEP's call and the derivative at the step's end, as envint makes them: (x0, hdid, hnext, rl, kount,
380        ksaha), y advanced and dydx its derivative."""
381        lsv = bool(lsave or pulse1_mod.lpumod)
382        cf, ci, bf = self.cf, self.ci, self.bf
383        cf[0] = rl
384        ci[0] = kount
385        ci[1] = ksaha
386        resume = 0
387        step_k = families.chains()._step_k     # OOP pilot: the chain for the installed families (families.py)
388        while True:
389            stage, where = step_k(resume, y, dydx, nv, x0, htry, eps, yscal, err, self.which, b, fpl, ftl, gl, latmo,
390                                   lderiv, lsv, teffl, x, z, cf, ci, self.ctx, bf, self.bi, _ysav, _dysav, _yseq,
391                                   _yerr, mmid_mod.ym, mmid_mod.yn, self.sx, ratext_mod.x, ratext_mod.d,
392                                   ratext_mod.fx, intpar_mod.imax, intpar_mod.nuse)
393            if stage == STAGE_DONE:
394                break
395            if stage == STATUS_UNDERFLOW:
396                self._put(lsv)
397                self.close()
398                _underflow(x, float(bf[0]))
399            if where == WHERE_MMID:
400                self._finish(stage, float(self.sx[0]), mmid_mod.yn, _yseq, b, fpl, ftl, gl, latmo, lderiv, lsave,
401                             teffl, x, z)
402                resume = 1
403            else:
404                self._finish(stage, float(bf[2]), y, dydx, b, fpl, ftl, gl, latmo, lderiv, lsave, teffl, x, z)
405                break
406        self._put(lsv)
407        return float(bf[2]), float(bf[3]), float(bf[4]), float(cf[0]), int(ci[0]), int(ci[1])
