Purpose

This file takes one adaptive step of the Bulirsch–Stoer method for the envelope and atmosphere integration: the modified midpoint method for an increasing number of substeps, extrapolated to zero substep size. It is the Numerical Recipes routine BSSTEP (first edition, with rational extrapolation), extended with the physical arguments that the derivative routine needs.

How it fits

  • Inputs: Y(3), DYDX(3) at X0 (the independent variable), the trial step HTRY, the tolerance EPS, the scales YSCAL, the derivative routine DERIV (passed as an argument by ENVINT: QATM for the atmosphere, QENV for the envelope) and the stellar quantities it needs (B, FPL, FTL, GL, RL, TEFFL, X, Z, …); IMAX and NUSE from the module INTPAR_MOD (initialized there to 11 and 7; both are also in the PHYSICS namelist, read by PARMIN, so a run can change them).
  • Who calls it: ENVINT.
  • What it calls: MMID (modified midpoint) and RATEXT (rational extrapolation).
  • Outputs: Y and X0 advanced, HDID (the step taken), HNEXT (the suggested next step), ERR (the scaled error of each variable); on a step-size underflow, a message on the screen and on ISHORT (from IOUNITS_MOD).

The method

For $i = 1, \dots, I_\mathrm{max}$, integrate across $H$ with $n_i$ = 2, 4, 6, 8, 12, 16, … midpoint substeps, and extrapolate the results in $(H/n_i)^2$ to zero. Accept the step when $$\max_j \frac{|\epsilon_j|}{y_{\mathrm{scal},j}} < \mathrm{EPS}.$$ The next step is $0.95H$ if it took NUSE sequences, $1.2H$ if one fewer, otherwise $H\,n_{\mathrm{NUSE}-1}/n_i$. If all $I_\mathrm{max}$ sequences fail, retry with $$H \leftarrow \frac{H/4}{2^{\lfloor (I_\mathrm{max} - N_\mathrm{use})/2 \rfloor}}.$$ If the new step no longer changes X (the hydrogen abundance, not the position: suspected bug 1), the run stops with exit status 1, printing X and $H$ (lines 62–71↗).

From YREC's documentation

Physics Options describes IMAX and NUSE (defaults 11 and 7) together: the integrators of the envelope and the atmosphere start with a large step, divide it into smaller ones and extrapolate to zero step size; IMAX is the largest number of such divisions, NUSE the number of earlier steps used in the extrapolation.

1. (never occurred) The step-size underflow test uses the hydrogen abundance.

(line 64↗) IF(X+H.EQ.X) tests X, which here is the hydrogen abundance passed through to DERIV, not the independent variable X0 ($\log\tau$ in the atmosphere, $\log P$ in the envelope: envint.f, lines 395–397↗, envint.f, lines 693–695↗); Numerical Recipes tests the independent variable. What follows: The test fires when $H$ is negligible next to $X \approx 0.7$, not next to the position, so a failing step goes on shrinking $H$ (by a factor 16 per round of IMAX sequences, with the defaults) somewhat longer before the run stops with "ERROR IN BSSTEP"; with $X = 0$ it fires only once $H$ underflows to zero. The stop and its message come late, the result is not changed. On every run's path, but only when the integration fails.
