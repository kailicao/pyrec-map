Explanation

Purpose. The second derivatives of a cubic spline through tabulated points, from Numerical Recipes (SPLINE), in double precision "for opacities".

How it fits.

  • Inputs: X(N) (increasing), Y(N), and the end slopes YP1, YPN; a slope of $10^{30}$ or more asks for a natural spline (zero second derivative) at that end.
  • Who calls it: the opacity routines GTPURZ and ZSULAOL; at rp_1 also GTLAOL, GTLAOL2 and SULAOL (removed since rp_1).
  • Output: Y2(N), the second derivatives, for a spline evaluation routine.

The method. Continuity of the first derivative at interior points gives the tridiagonal system $$\frac{h_{i-1}}{6}y''_{i-1} + \frac{h_{i-1} + h_i}{3}y''_i + \frac{h_i}{6}y''_{i+1} = \frac{y_{i+1} - y_i}{h_i} - \frac{y_i - y_{i-1}}{h_{i-1}},$$ with $h_i = x_{i+1} - x_i$, solved by forward elimination and back substitution.

Changed since rp_1. Declarations only: JSON from DIMENSIONS_MOD, IMPLICIT NONE; three of its callers removed with their files.

Questions for the experts

  1. Size. The work array U has the fixed size JSON (5000, from DIMENSIONS_MOD); N larger than that would overflow. Fine for opacity tables.
  2. Duplicates. The code base has several spline routines (spline.f, splinj.f, splinnr.f (removed since rp_1), …). Could one serve all callers in the overhaul?

15def cspline(x, y, n, yp1, ypn, y2):
16    """The second derivatives y2 of the cubic spline through (x, y), with
17    end slopes yp1, ypn; a slope of 0.99e30 or more gives a natural
18    spline (zero second derivative) at that end.
19
20    Translates: cspline.f#CSPLINE (09c3b9b)
21
22    Arguments: x[1..n] (increasing), y[1..n]; n; yp1, ypn; y2[1..n],
23    filled in place. None is returned.
24    """
25    if yp1 > 0.99e30:
26        y2[1] = 0.0
27        u[1] = 0.0
28    else:
29        y2[1] = -0.5
30        u[1] = (3.0 / (x[2] - x[1])) * ((y[2] - y[1]) / (x[2] - x[1]) - yp1)
31    # Forward elimination.
32    for i in range(2, n):
33        sig = (x[i] - x[i - 1]) / (x[i + 1] - x[i - 1])
34        p = sig * y2[i - 1] + 2.0
35        y2[i] = (sig - 1.0) / p
36        u[i] = (6.0 * ((y[i + 1] - y[i]) / (x[i + 1] - x[i])
37                       - (y[i] - y[i - 1]) / (x[i] - x[i - 1]))
38                / (x[i + 1] - x[i - 1]) - sig * u[i - 1]) / p
39    if ypn > 0.99e30:
40        qn = 0.0
41        un = 0.0
42    else:
43        qn = 0.5
44        un = (3.0 / (x[n] - x[n - 1])) * (ypn - (y[n] - y[n - 1])
45                                          / (x[n] - x[n - 1]))
46    y2[n] = (un - qn * u[n - 1]) / (qn * y2[n - 1] + 1.0)
47    # Back substitution.
48    for k in range(n - 1, 0, -1):
49        y2[k] = y2[k] * y2[k + 1] + u[k]
