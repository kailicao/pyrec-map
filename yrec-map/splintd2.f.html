Explanation

Purpose. SPLINTD2 evaluates a cubic spline at one point; it is splint.f's algorithm and equation, with arrays of the fixed size JSON (5000, from DIMENSIONS_MOD), for the second derivatives made by SPLINC. Its header comment still names it "SUBROUTINE SPLINTD".

How it fits.

  • Who calls it: only HPOINT, after SPLINC.
  • Modules: IOUNITS_MOD, for the unit ISHORT of its error message ("ERROR IN SPLINT ROUTINE", then STOP).

Changed since rp_1. Declarations only: /LUOUT/ to IOUNITS_MOD, the array size JSON from DIMENSIONS_MOD, IMPLICIT NONE.

Questions for the experts

7def splintd2(xa, ya, n, y2a, x, y, klo, khi):
8    """The cubic-spline value y at x, from the table (xa, ya) and its second
9    derivatives y2a (from SPLINC). Stops the run if two abscissas coincide;
10    outside the table it extrapolates the end interval.
11
12    Translates: splintd2.f#SPLINTD2 (09c3b9b)
13
14    Arguments: xa[1..n] (increasing), ya[1..n]; n (at most JSON);
15    y2a[1..n]; x; y, klo and khi, set only (klo and khi are reset on
16    entry). Returns (y, klo, khi), with klo, khi the bracketing indices.
17    """
18    klo = 1
19    khi = n
20    while khi - klo > 1:  # label 1
21        k = (khi + klo) // 2
22        if xa[k] > x:
23            khi = k
24        else:
25            klo = k
26    h = xa[khi] - xa[klo]
27    if h == 0.0:
28        iounits_mod.write(iounits_mod.ishort, " ERROR IN SPLINT ROUTINE.")
29        raise SystemExit()
30    a = (xa[khi] - x) / h
31    b = (x - xa[klo]) / h
32    y = (a * ya[klo] + b * ya[khi]
33         + ((a ** 3 - a) * y2a[klo] + (b ** 3 - b) * y2a[khi]) * (h ** 2) / 6.0)
34    return y, klo, khi
