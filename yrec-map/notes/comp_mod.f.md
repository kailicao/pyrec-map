## Explanation

**Purpose.** `COMP_MOD` holds the composition of the envelope and the star's total and envelope masses, shared by 23 routines. It replaces `COMMON/COMP/` (MHP via Claude, 10/14/26), with the same names and types (`REAL*8` throughout) and an explicit `SAVE`.

**What its variables hold, who sets them, who reads them.**
- `XENV`, `ZENV`: the envelope's $`X`$ and $`Z`$. [`STARIN`](starin.f.md#starin) sets them from `XNEW`, `ZNEW`; [`RSCALE`](https://github.com/yreclab/yrec/blob/7be4133/src/rscale.f#L5-L432) and [`PARMIN`](https://github.com/yreclab/yrec/blob/7be4133/src/parmin.f#L16-L1489) may reset `ZENV`. Read by the equation of state ([`EQSTAT2`](eqstat2.f.md#eqstat2), [`EQSCVE`](eqscve.f.md#eqscve), [`SETSCV`](https://github.com/yreclab/yrec/blob/7be4133/src/setscv.f#L4-L255)), [`MU`](https://github.com/yreclab/yrec/blob/7be4133/src/mu.f#L6-L50), [`PHYSIC`](https://github.com/yreclab/yrec/blob/7be4133/src/physic.f#L3-L191), [`GETOPAC`](getopac.f.md#getopac) (`ZENV`), [`CHECKC`](checkc.f.md#checkc), [`WRTMIL`](wrtmil.f.md#wrtmil), and [`SETUPS`](https://github.com/yreclab/yrec/blob/7be4133/src/setups.f#L16-L396) (`XENV`, passed to `SETUPOPAC`).
- `ZENVM`: "Z other than CNO cycle elements" (STARIN's comment): `ZENV` times the share of the metals' relative mass fractions left after removing `V(6)`, `V(8)`, `V(9)`; set in `STARIN`, read by [`MIXCZ`](https://github.com/yreclab/yrec/blob/7be4133/src/mixcz.f#L3-L248).
- `AMUENV`, `FXENV(12)`: set in `STARIN` from the envelope's mass fractions $`X_i`$ and atomic weights $`A_i`$ of the twelve species: $`\mathtt{AMUENV} = \sum_i X_i/A_i`$, the inverse mean molecular weight per ion (as PHYSIC's comment says), and `FXENV(I)` $`= (X_i/A_i)/\mathtt{AMUENV}`$, the number fractions. `AMUENV` is read by `MU`, `EQSTAT2`, `PHYSIC`, and `CHECKC`, which correct it for the local composition; `FXENV` by `EQSTAT2` alone, which passes it on to the Saha solver.

    **STARIN's comment on `AMUENV` is stale.** It calls `AMUENV` the "mean atomic weight of surface Z" ([starin.f, line 920](https://github.com/yreclab/yrec/blob/7be4133/src/starin.f#L920)), but loop 610 sums $`X_i/A_i`$ over all twelve species, hydrogen (`V(7)`) and helium (`V(12)`) included ([starin.f, lines 926–937](https://github.com/yreclab/yrec/blob/7be4133/src/starin.f#L926-L937)), so `AMUENV` is the inverse mean molecular weight per ion, as PHYSIC's comment says ([physic.f, line 121](https://github.com/yreclab/yrec/blob/7be4133/src/physic.f#L121)).
- `XNEW`, `ZNEW`: the surface $`X`$ and $`Z`$ for which the surface opacity table was last made. Set in `STARIN`, `RSCALE`, and [`HPOINT`](hpoint.f.md#hpoint) (which calls [`SURFOPAC`](surfopac.f.md#surfopac) when the surface $`X`$ has changed by more than $`10^{-8}`$); read by [`CRRECT`](crrect.f.md#crrect) and [`WRTOUT`](wrtout.f.md#wrtout).
- `STOTAL`: $`\log M_*`$, set from `HSTOT` in `STARIN`, `RSCALE`, and [`MDOT`](mdot.f.md#mdot); read by the envelope and surface routines ([`QENV`](https://github.com/yreclab/yrec/blob/7be4133/src/qenv.f#L6-L136), [`SURFBC`](surfbc.f.md#surfbc), [`GETNEWENV`](getnewenv.f.md#getnewenv)), [`CALCAD`](calcad.f.md#calcad), and the output routines (`MIXCZ` names it only in a commented-out line).
- `SENV`: $`\log(m/M_*)`$ at the fitting point between the interior model and the envelope. Set in `STARIN`, `HPOINT` (when outer points are added or removed), `MDOT`, `GETNEWENV`, and `CRRECT`; read by [`ENVINT`](envint.f.md#envint), which integrates the envelope down to it.

**Design.** A blanket `USE COMP_MOD` in each routine, the convention of the conversion: All 23 files declared the block identically, so the module brings in exactly the names the block made global. The header says `SAVE` is explicit because module variables are saved implicitly only from Fortran 2008, which the Intel compiler it names predates.

**Changed since `rp_1`.** New file: `COMMON/COMP/` as a module.
