## Explanation

**Purpose.** `main.f` is YREC's main program (it has no `PROGRAM` statement; the site lists it as `(file level)`). It reads the run's settings, sets up the physics tables, and then, for each "kind card" (one run of a job: a starting model and what to do with it), loads the starting model and evolves it model by model. Each evolutionary step does, in order: mass loss, mixing and nuclear burning, rezoning, the iterative solution of the structure equations, rotation, light-element burning, the next time step, and output. Around this loop sit optional drivers: automatic calibration of a solar model or of a star of given $L$ and $T_\mathrm{eff}$. This is the reader's starting point.

**How it fits.**
- **Inputs:** everything comes through [[parmin.f#PARMIN|`PARMIN`]] (the run's parameters, per kind card; it also opens files, returns the names of the table files and prints the banner with the version and git hash that [[version.f#SETVERSION|`SETVERSION`]] sets) and [[setups.f#SETUPS|`SETUPS`]] (constants, and the opacity, EOS and atmosphere tables). The starting model is read by [[starin.f#STARIN|`STARIN`]] from the unit `IFIRST`.
- **Who calls it:** nobody; it is the program.
- **Outputs:** written by the routines it calls: headers by [[wrthead.f#WRTHEAD|`WRTHEAD`]], each model by [[wrtout.f#WRTOUT|`WRTOUT`]] (the output driver: short output `ISHORT`, track `ITRACK`, model printouts and so on), the last model of a run by [[putstore.f#PUTSTORE|`PUTSTORE`]] (unit `ISTOR`, for continuing a sequence), the model before a step by [[wrtlst.f#WRTLST|`WRTLST`]] (unit `ILAST`, for He-flash runs), pulsation output by [[pdist.f#PDIST|`PDIST`]], and the solar calibration's summary to `ISNU`. main.f now owns some values the output routines used to read from COMMON, and passes them on: the mixing length `CMIXL` (set from `CMIXLA(NK)` for each kind card), the mass `XMSOL` (the starting mass, kept for the output), the mixture's name `COMPMIX` (from `STARIN`), and `NK`.
- **Modules:** main.f uses 20 modules (the COMMON blocks it shared before), mostly to set flags or keep state across the loop: `NMLPAR_MOD` (the run's parameters, among them per kind card `NUMRUN`, `NMODLS`, `XENV0A`, `ZENV0A`, `CMIXLA`, the stop conditions `ENDAGE`, `END_DCEN`, `END_XCEN`, `END_YCEN`, the iteration limits `NITER1`–`NITER4`, `ITDIF1`, and the switches `LCALS`, `LCALST`, `LSNU`, `LNEWS`, `LEXCOM`, `LROT`, `LINSTB`, `LKUTHE`, `LOVSTE`, `ALPHAE`, `LPTIME`, `KTTAU`), `RUNLOOP_MOD` (`IRESCA`, `RESCAL`, `LENDAG`, per kind card), `ENTROP_MOD` (the rates of change of $\log T$, $\log P$, $\ln L$, $\log r$ from the previous model; shared only with `HPOINT`, which moves them to the new grid), `OLDMOD_MOD` (the model at the start of the step, and `HCOMPP`), `PREVCZ_MOD`, `LIOV_MOD` (light-element burning with overshoot), `CTOL_MOD` (`FCORR`), `DISK_MOD` (`SAGE`), `ACDPTH_MOD` (outputs at chosen ages), `CENT_MOD` and `FLUXES_MOD` (the central values, the convection zone's base and the neutrino fluxes, for the calibration summary), `IOUNITS_MOD` (the unit numbers), `CONSTANTS_MOD`, and `DIMENSIONS_MOD`, `LABEL_MOD`, `CENV_MOD`, `SOUND_MOD`, `OVRTRN_MOD`, `DEUTER_MOD`, `OP95INTERP_MOD`. Former blocks that are now locals or arguments: `ORIGSTART` (start-of-step $j$ and composition when iterating between structure and rotation; local arrays `HJM0`, `HCOMPP0`), `CALSUN` (`DLDX`, `DRDX`, `DLDA`, `DRDA`, `LSOL`, now arguments of `SETCAL` and `CHKCAL`), `CALSTAR` (`ALRI`, `LSTAR`, `LPASSR`, now arguments of `SETSCAL` and `CHKSCAL`), `ROTPRT` (`LPRT0`, an argument of `GETW`), `BE7` (an output of `ENGEB`), `VERSION`, `I2O`, `PULSE` (`YRECVER`, `GITHASH`, `COMPMIX`, `XMSOL`).

**The order of the run.**
1. **Settings and tables.** [[version.f#SETVERSION|`SETVERSION`]]; `IOWR` = 9; [[parmin.f#PARMIN|`PARMIN`]], then [[setups.f#SETUPS|`SETUPS`]] (MHP 8/25: the table file names are now passed as arguments instead of through COMMON).
2. **Calibration set-up:** [[setcal.f#SETCAL|`SETCAL`]] for a solar calibration (`LCALS`; it changes the kind cards and sets `LSOL` false, and `LPTIME`, `KTTAU` are saved to be restored at each cycle; `DLDX`, `DRDX`, `DLDA`, `DRDA`, `LSOL` start at zero and false, so that the final test of `LSOL` is defined without a calibration), [[setscal.f#SETSCAL|`SETSCAL`]] for a star of given $L$, $T_\mathrm{eff}$ (`LCALST`).
3. **Kind-card loop** (`DO 200 NK = 1, NUMRUN`): set the run's $X$, $Z$, mixing length and envelope options; [[starin.f#STARIN|`STARIN`]] reads (or keeps) the starting model and rescales it if asked; stop if `LROT` is set but $\Omega = 0$; disable stop conditions already met by the starting model; [[wrthead.f#WRTHEAD|`WRTHEAD`]]; for He-flash runs (`LKUTHE`) store the model with `WRTLST`; [[findsh.f#FINDSH|`FINDSH`]] (the H-burning shell and convection-zone edges); [[htimer.f#HTIMER|`HTIMER`]] (the first step); zero the entropy terms and the light-element rates of the surface zone.
4. **Model loop** (`DO 100 MODELN = 1, NMODLS(NK)`), the evolution step, below.
5. **End of a kind card** (label 110): `PUTSTORE` the last model if asked; for a solar calibration, every third kind card [[chkcal.f#CHKCAL|`CHKCAL`]] compares $L$, $R$ (and the surface $Z/X$) with the targets and either ends (`LSOL`) or starts another cycle; the counter `ICONV` starts at 1 and the calibration gives up, silently, when it reaches 15 (the comment still says 10). The radius comes from $L = 4\pi R^2\sigma T_\mathrm{eff}^4$ (`RLL`, with `BL` = $\log(L/L_\odot)$):
$$\log\frac{R}{R_\odot} = \tfrac12\Bigl[\log\frac{L}{L_\odot} + \log L_\odot - \log 4\pi - \log\sigma - 4\log T_\mathrm{eff}\Bigr] - \log R_\odot;$$ for `LCALST`, end when the star is matched (`LSTAR`, on an even kind card).
6. **After the runs** (label 250): for a converged solar calibration with `LSNU`, its summary to `ISNU` (the iterations and derivatives, the neutrino fluxes, the central values, the initial composition, the convection zone's base `CZsurf_R`, `CZsurf_M` and the surface composition, the energy-generation fractions), then `STOP`.

**The evolution step** (one pass of the model loop).
1. Output switches: rewind `ISHORT` if `LRWSH`; turn on pulsation output on the last model, at chosen ages (`AGEOUT`, JVS 02/11) or at the final age; [[pdist.f#PDIST|`PDIST`]] if `LPOUT`.
2. **After a failed model** (label 15). If the previous attempt diverged or did not converge (`LARGE`), call `STARIN` again. Despite the comment "STARIN called here for timestep cutting", STARIN does not cut the step: with `LARGE` set it prints "RUN STOPPED" and stops (`starin.f`, lines 225–232). So a failed model ends the run.
3. **Ageing?** `LAGE` is true when `MODEL` ≥ 0, unless the kind card only relaxes a rescaled model (`IRESCA` = 2, except for pre-main-sequence models with $\log T_c$ < 6.6).
4. **Mass loss and mixing** (if `LAGE`): [[massloss.f#MASSLOSS|`MASSLOSS`]]; save the composition in `HCOMPP`; [[mix.f#MIX|`MIX`]] (convective mixing, nuclear burning through [[kemcom.f#KEMCOM|`KEMCOM`]], settling through [[grsett.f#GRSETT|`GRSETT`]]); advance the age: `DDAGE` = $\Delta t$/`CSECYR`, `DAGE` += $10^{-9}$`DDAGE` (Gyr).
5. **Rezoning:** [[hpoint.f#HPOINT|`HPOINT`]] (not in He-flash runs, which only save the old model for `PTIME`).
6. **Light elements at the start** (if `LEXCOM`): the convection zone's base `JENV0`, the overshoot distance $\alpha_e H_P$ with $H_P = P r^2/(\rho G m)$ (`PSCAL0`), and [[lirate88.f#LIRATE88|`LIRATE88`]] (rates, `J` = 1).
7. **First guess of the structure.** If `LNEWS` and the step is positive, extrapolate each point from the previous model's rates of change:
$$\log T \mathrel{+}= \dot{(\log T)}_0\,\Delta t,\quad \log P \mathrel{+}= \dot{(\log P)}_0\,\Delta t,\quad L \mathrel{+}= L\,\dot{(\ln L)}_0\,\Delta t,\quad \log r \mathrel{+}= \dot{(\log r)}_0\,\Delta t;$$
otherwise zero these terms. A non-ageing step is made negative (a relaxation).
8. **Structure: four levels of [[crrect.f#CRRECT|`CRRECT`]]** (the Henyey iteration), each with its own iteration limit: level 1 (`NITER1`) with the previous envelope triangle; level 2 (`NITER2`) checking the surface boundary condition (`LSBC`); level 3 (`NITER3`); then, after storing the new rates of change
$$\dot{(\log T)}_0 = \frac{\Delta\log T}{\Delta t},\quad \dot{(\ln L)}_0 = \frac{2(L - L_\mathrm{old})}{(L + L_\mathrm{old})\,\Delta t},\ \dots$$
for the next step's guess, level 4 (`NITER4`), which repeats the iteration between mixing and structure (its comment: not for models where semiconvection matters; for high-precision work such as solar models). Any divergence (`LARGE`), or no convergence after level 4, goes back to step 2, which stops the run. With rotation, the block from level 4 through step 9 (level 4, the convergence test, `MIXCZ`, `GETW`, `FPFT`) can be iterated `ITDIF1` times, restoring the start-of-step composition `HCOMPP` and $j$ each time.
9. **After convergence:** [[mixcz.f#MIXCZ|`MIXCZ`]] (fully mix the convection zones; G. Somers 6/14 also computes the turnover time there); `SAGE` = age; for rotating models [[getw.f#GETW|`GETW`]] (the new $\Omega$: angular-momentum transport and wind loss) and [[fpft.f#FPFT|`FPFT`]] (the distortion terms).
10. [[findsh.f#FINDSH|`FINDSH`]] again.
11. **Light-element burning** (if `LEXCOM`, `MODEL` ≥ 0 and the step is positive, and not rotating with rotational mixing; in that case [[getw.f#GETW|`GETW`]] calls `LIRATE88`, `LIBURN` and `LIBURN2` itself): [[convec.f#CONVEC|`CONVEC`]] for the zone's base at the end, `PSCAL1`, `LIRATE88` (`J` = 2), [[liburn.f#LIBURN|`LIBURN`]].
12. **After accretion** (`LNEWFIT`): [[getnewenv.f#GETNEWENV|`GETNEWENV`]] restores the envelope fitting point, then `FPFT`.
13. **Next step:** [[htimer.f#HTIMER|`HTIMER`]]. When the final age is reached, the step written with the model is the step just taken, `DELTS = MAX(DELTS0, 1.0D-3*DAGE*CSECYR)`, instead of a zero one, so that the sequence can be continued (see question 3 on the floor).
14. `MODEL` += 1 (unless relaxing); [[wrtout.f#WRTOUT|`WRTOUT`]].
15. **Stop conditions** (MHP 10/24): end the kind card when the final age is reached, or the central D, $X$ or $Y$ falls below its threshold; for `LCALST`, [[chkscal.f#CHKSCAL|`CHKSCAL`]] on even kind cards from the second model on (on success, `LPASSR`, it jumps to label 200, which skips `PUTSTORE`).

**Which routines do what, in brief.** Settings: `SETVERSION`, `PARMIN`, `SETUPS`. Starting model: `STARIN` (with `RSCALE`). Time step: `HTIMER`. Mass change: `MASSLOSS`, `MDOT`. Mixing, burning, settling: `MIX`, `KEMCOM`, `GRSETT`, `MIXCZ`, `CONVEC`. Rezoning: `HPOINT`. Structure: `CRRECT` (with `COEFFT`, `ENVINT`, `HSOLVE` and the physics: EOS, opacities, energy generation `ENGEB`). Rotation: `GETW`, `FPFT`, `MOMI`. Light elements: `LIRATE88`, `LIBURN`. Output: `WRTHEAD`, `WRTOUT`, `PUTSTORE`, `WRTLST`, `PDIST`. Calibration: `SETCAL`, `CHKCAL`, `SETSCAL`, `CHKSCAL`.

**Design.** The program is one long routine with `GOTO`s across loop levels (back to label 15 after a failed model, which stops the run, forward to 110, 200 and 250). The state of the evolution lives in local arrays passed to every routine, and in modules. Some variables are passed before main.f gives them a value and are set by the callees: `GL` by `WRTOUT`, `LMIX`, `LOCOND`, `LATMO`, `LDERIV` by `COEFFT` through `CRRECT`, `QDT`, `QDP` by `STARIN`. `TEFFI` is set and never used. A neutrino-flux table block (`LNUTAB`) is switched off by a hard-coded `.FALSE.`. The comment at the top still says to change the array size by a global change of "JSON=2000"; `JSON` = 5000 is now set once, in `DIMENSIONS_MOD`.

## Questions for the experts

1. **Disabling the stop conditions.** When the starting central $X$ is already below `END_XCEN`, the code sets `END_DCEN(NK) = -END_XCEN(NK)` (not `END_XCEN`), so the $X$ stop stays active and the deuterium stop is altered. The messages for $X$ and $Y$ also print the central deuterium `HCOMP(12,1)` and `END_DCEN`. Copy-paste slips?
2. **The neutrino table block.** It is off (`LNUTAB = .FALSE.`); it writes to unit 76, which nothing opens, and after KC's 2025-05-31 change it passes `IU`, which is undefined in main.f, to `ENGEB` (it used to pass the loop index `I`). Remove the block, or repair it?
3. **The floor on the final step.** At the final age, `DELTS = MAX(DELTS0, 1.0D-3*DAGE*CSECYR)`: with `DAGE` in Gyr this is $10^{-3}$ times the age in Gyr, in years, i.e. $10^{-12}$ of the age, so the floor never acts. Was `1.0D-3*DAGE*1.0D9*CSECYR` ($10^{-3}$ of the age) meant?
4. **The He-flash copy to `ILAST`.** The comment says time-step cutting "requires a model stored in logical unit ILAST or it will crash", but the copy runs only if `LPUNCH`, which is false on the first kind card (and again after `PUTSTORE`); it also passes `JCORE` before `FINDSH` has set it for this kind card. Should the copy be unconditional, after `FINDSH`?
5. **Hard-coded values.** `IOWR` = 9; $\log T_c$ < 6.6 for pre-main-sequence relaxation.
