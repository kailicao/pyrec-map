## Explanation

**Purpose.** `IOUNITS_MOD` holds the Fortran logical unit numbers of every input and output file, shared by 57 routines. It replaces `COMMON/IOUNITS/` (MHP via Claude, 10/14/26), which had gathered, on 9/25/26, the unit numbers once scattered over `COMMON/LUOUT/`, `/LUNUM/`, `/ALEX06/`, `/ACDPTH/`, `/NEWOPAC/`, `/LOPAL95/`, `/ATMOS2/`, `/ALATM03/`, `/OPALEOS/` and `/SCV2/` (the dead `IDYN`, `ILLDAT`, `ISCOMP`, `IKUR` of `/LUNUM/` removed). All members are `INTEGER*4`.

**What its variables hold, who sets them, who reads them.** [[parmin.f#PARMIN|`PARMIN`]] assigns every number (its comments name the files; they can be changed only in the code) and opens most of the files; the routines that read or write a file use its unit.
- Run control: `IOWR` = 6 (the status output, the screen; the [[main.f#(file level)|main program]] sets it to 9 before calling PARMIN, which overwrites it), `ISTAND` = 14 and `IRUN` = 13 (the `CONTROL` and `PHYSICS` namelists, read by PARMIN).
- Models: `IFIRST` = 12 (the starting model), `ILAST` = 11 (the last model), `ISTOR` = 23 (saved models).
- Outputs: `ISHORT` = 20 (all diagnostic information, the `.short` file), `ITRACK` = 19 (the track), `IDEBUG` = 18 (debugging), `IMILNE` = 21 (Milne's invariant variables, written by [[wrtmil.f#WRTMIL|`WRTMIL`]]), `IMODPT` = 22 (shell-by-shell output), `ISNU` = 33 (neutrino fluxes), `ISOUND` = 500 (the sound-speed profile, written by [[wrtmod.f#WRTMOD|`WRTMOD`]] with `LSOUND`), `IOPMOD`, `IOPENV`, `IOPATM` = 24, 25, 26 (interior, envelope and atmosphere for a pulsation code, also opened by [[pdist.f#PDIST|`PDIST`]]), `ICLCD` = 91 (the acoustic-depth output, assigned only with `LACOUT`).
- Input tables: `IFERMI` = 15 (Fermi–Dirac tables, read by [[setups.f#SETUPS|`SETUPS`]]), `IOATM` = 38 (Kurucz atmospheres, SETUPS), `IOATMA` = 66 (Allard atmospheres, [[alfilein.f#ALFILEIN|`ALFILEIN`]]), `ILIV95` = 48 (OPAL95 opacities, [[ll95tbl.f#LL95TBL|`LL95TBL`]]), `IALEX06` = 90 (the low-temperature opacities of Ferguson et al. 2005, called ALEX06 in the code, [[readalex06.f#READALEX06|`READALEX06`]]), `IOPUREZ` = 62 (the pure-metal, "pure Z," LAOL89 table, $Z = 1$; PARMIN's comment calls it "pure CN"; [[rdzlaol.f#RDZLAOL|`RDZLAOL`]]), `IcondOpacP` = 75 (Potekhin conductive opacities, [[condopacp.f#CONDOPACP|`CONDOPACP`]]), `IOPALE` = 49 (OPAL 2006 equation of state, [[readcoeos06.f#READCOEOS06|`READCOEOS06`]]), `ISCVH`, `ISCVHE`, `ISCVZ` = 72, 73, 74 (the SCV equation of state, SETUPS).
- `IJLAST`: the unit to which [[wrtout.f#WRTOUT|`WRTOUT`]] writes the model with `LJLAST` (acoustic-depth output, [[wrtout.f#L710-L715]]), but assigned nowhere (PARMIN's assignment is commented out, [[parmin.f#L847-L849]]; bug 1); the branch never runs, since `LACOUT` cannot be turned on (see [[acdpth_mod.f#ACDPTH_MOD|`ACDPTH_MOD`]]).

**Design.** A blanket `USE IOUNITS_MOD`. Unit numbers are fixed in PARMIN rather than allocated, so a new file must pick a free number by hand (ISOUND's 500 stands apart).

**Changed since `rp_1`.** New file: the unit numbers of ten COMMON blocks, and of `/IOUNITS/` into which they were merged, as one module; the dead units `IDYN`, `ILLDAT`, `ISCOMP`, `IKUR` (and PARMIN's unshared `ILSTBN`, `ISTOBN`, `IFSTBN`) removed.

## Bugs, by priority

1. **(cannot be reached)** **`IJLAST` is never assigned.** ([[#L42]]; [[wrtout.f#L710-L715]], [[parmin.f#L847-L849]]) WRTOUT writes the last model to unit `IJLAST` when `LJLAST` is true, but no routine gives `IJLAST` a number or opens its file: PARMIN's three lines that did (`IJLAST = 93`, the file name, the `OPEN`) are commented out. If the branch ran, the model would go to unit 0 (with gfortran, standard error). It does not run today: `LJLAST` is set true only in the main program's acoustic-depth branch ([[main.f#L651]]), and `LACOUT` cannot be turned on (see [[acdpth_mod.f#ACDPTH_MOD|`ACDPTH_MOD`]]).

    **A possible fix,** a choice for the developers: restore PARMIN's three lines beside `ICLCD`, or remove `IJLAST` together with WRTOUT's `LJLAST` branch.

    **Checked by running YREC** (Nov 9, 2026; a line added at each suspected path counted how often it was taken, the outputs otherwise unchanged): Not reached in 33 runs, and it cannot be reached at 7be4133: `LJLAST` is set only in the main program's `LACOUT` branch, and `LACOUT` is in no namelist group and set nowhere in `src/` ([[acdpth_mod.f#L55]]). The fix (PARMIN's three lines restored) was not run. Intent: The three lines are commented out beside PARMIN's comment of 9/25/26 that removed other unit reservations as "declared but never opened anywhere" ([[parmin.f#L844-L849]]), so the unit may have been dropped with them.
