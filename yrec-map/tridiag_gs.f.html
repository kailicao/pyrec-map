Purpose

TRIDIAG_GS solves a tridiagonal system $a_j x_{j-1} + b_j x_j + c_j x_{j+1} = e'_j$, $j = 1, \dots, n$ (the Thomas algorithm), with the matrix and right-hand side as arguments. A zero pivot stops the run, with the message "#TRIDIA:SINGULAR MATRIX."

How it fits

  • Who calls it: GRSETT (the new run of $X$ in gravitational settling, by its comment) and MICRODIFF_RUN (the new run of Li).
  • Output: the solution EX.
  • Modules: DIMENSIONS_MOD (the array size JSON) only.
