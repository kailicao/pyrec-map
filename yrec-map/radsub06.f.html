Purpose

Adds radiation, optionally, to the gas equation of state interpolated in the OPAL 2006 tables. The older versions were RADSUB and RADSUB01 (both removed since rp_1).

How it fits

  • Who calls it: ESAC06, only when its argument irad is 1, and it passes irad on (esac06.f, lines 481–485↗); so irad is always 1 here, and the branch for irad $= 0$ never runs (unused?).
  • Modules: EOS06MISC_MOD, which merges the former /EEOS06/ (ESACT, EOS(MV)) and /BEOS06/ (ZZ, IRI, INDEX, NTA, NRA) with two other blocks; shared with ESAC06, OEQOS06, READCOEOS06, RHOOFP06, T6RINTEOS06, CALCAD and EQBOUND06. This routine uses EOS and IRI only.
  • Output: EOS(IRI(1..9)) overwritten.

The method

As in RADSUB01 (equations in RADSUB; both removed since rp_1), with the 2006 order of quantities: IRI(4) is $\partial E/\partial\rho$, IRI(5) is $c_V$, IRI(6) is $\chi_\rho$, IRI(7) is $\chi_T$, IRI(8..10) the $\Gamma$s. With irad $\ne 0$, the radiation terms are added, $\partial E/\partial\rho$ becomes $\partial E_g/\partial\rho - E_r/\rho$, and the differences (with minus without radiation) are added to $\Gamma_1$ and to GAM2PT. The line that would add the difference to eos(iri(10)) ($\Gamma_3$, line 102↗) is commented out, while RADSUB01 corrected all three $\Gamma$s; it has nothing to correct, since EOS(10) is never interpolated (the tables hold nine quantities, readcoeos06.f, lines 124–126↗) and nothing reads it (settled from the code, Nov 9, 2026). With irad $= 0$, the routine only rewrites the gas values, with $c_V$ multiplied by $Nk/M$ (molenak/tmass).

29def radsub06_prad(t6: float) -> float:
30    """The radiation pressure in Mb (Fortran lines 56 and 76: RAT = SIGMACC; PR = 4/3 RAT T6**4).
31
32    T6**4 is computed as gfortran computes an integer power, (x*x)*(x*x), not by pow() as Python's ** does (they

38        The temperature in 10^6 K.
39
40    Returns
41    -------
42    float
43        The radiation pressure, Mb.

46    t62 = t6 * t6
47    return 4.0 / 3.0 * SIGMACC * (t62 * t62)

53def radsub06(irad: int, t6: float, density: float, moles: float, tmass: float) -> None:
54    """Rewrite EOS(IRI(1..7)) in eos06misc_mod with radiation added (when irad != 0).
55
56    Pressure, energy, entropy, dE/drho, c_V, chi_rho, and chi_T are rewritten, and the radiation's differences are
57    added to Gamma_1 and Gamma_2/(Gamma_2-1). With irad = 0 only the gas values are rewritten (c_V times Nk/M).
58
59    Translates: radsub06.f#RADSUB06 (7be4133)

70        The particles per nucleus (gmass06's amoles).

73

76    Changes eos06misc_mod.eos in place, at the indices eos06misc_mod.iri(1..9). Returns nothing.
77
78    """

86    molenak = moles * APROP     # Mb-cc/unit T6
87
88    # The equation of state without radiation (Fortran lines 60–72).
89    pt = eos[iri[1]]
90    et = eos[iri[2]]
91    st = eos[iri[3]]
92    dedrho = eos[iri[4]]

94    chitt = (eos[iri[1]] * eos[iri[7]]) / pt
95    cvtt = (eos[iri[5]] * molenak / tmass)

105        pt = eos[iri[1]] + pr
106        et = eos[iri[2]] + er
107        st = eos[iri[3]] + sr
108        dedrho = eos[iri[4]] - er / density
109        chir = eos[iri[6]] * eos[iri[1]] / pt
110        chitt = (eos[iri[1]] * eos[iri[7]] + 4.0 * pr) / pt
111        cvtt = (eos[iri[5]] * molenak / tmass + 4.0 * er / t6)
