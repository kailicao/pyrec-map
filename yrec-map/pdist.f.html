Explanation

Purpose. Decides when to write a model for pulsation calculations: it "calculates the distance the star has travelled in the HR diagram; if far enough, output pulsation model". When the accumulated distance passes a threshold, it opens three new output files named after the run and the model number, and sets LPULSE so that the output routines write the model to them.

How it fits.

  • Inputs: the previous point (POL1 $=\log L$, POT1 $=\log T_\mathrm{eff}$, POA1 = age) and the running total POLEN; the current BL ($\log L/L_\odot$), TEFFL, MODELN, the run index NK and the age DAGE (arguments); the weights POA, POB, POC and the threshold POMAX in NMLPAR_MOD (namelist CONTROL, read by PARMIN); the base file names FPMOD, FPENV, FPATM (arguments, since MHP 8/25).
  • Who calls it: the main program in main.f, after each model when LPOUT is set.
  • Outputs: POLEN and the previous point updated; LPULSE in NMLPAR_MOD; the units IOPMOD, IOPENV, IOPATM (from IOUNITS_MOD) opened as <FPMOD>NN_MMMM and so on, with NN = NK (the main program's loop over runs, DO 200 NK = 1, NUMRUN) and MMMM the model number; a line to IOWR and ISHORT. While LPULSE is true, WRTMOD writes the model to IOPMOD and passes LPULPT on to ENVINT, which writes the atmosphere and envelope to IOPATM and IOPENV from the points QATM and QENV store.

The method. The squared step in the HR diagram and in age, with weights $a, b, c$, is accumulated: $$\ell^2 \mathrel{+}= (a\,\Delta\log L)^2 + (b\,\Delta\log T_\mathrm{eff})^2 + (c\,\Delta t)^2 .$$ When $\ell^2 \ge$ POMAX, the files are opened and $\ell^2$ is reset to zero; otherwise the three units are closed and LPULSE is set false.

Changed since rp_1. NK and DAGE are now arguments (from /ZRAMP/ and /THEAGE/ before; main.f is the only caller); the other COMMON blocks to modules, IMPLICIT NONE; the unused /PULSE/ members and dead /LUNUM/ units dropped.

Questions for the experts

  1. POMAX is a squared distance. The sum is of squares (printed as "LEN SQ"), so POMAX = 0.1 means a distance of about 0.32. Is the namelist documentation clear about this?
  2. Two different lines. The same format writes the step's differences (TM1–TM3) to IOWR but their weighted squares (TMP1–TMP3) to ISHORT, under the same labels "D L", "D Te", "D AGE".
  3. STATUS='NEW'. The files are opened as new, so rerunning a model sequence in the same directory stops at the first existing pulsation file.

three new pulsation output files and set LPULSE, otherwise close them

31    and in age since the last pulsation model; when it reaches POMAX, open
32    three new pulsation output files and set LPULSE, otherwise close them
33    and clear LPULSE.
34
35    Translates: pdist.f#PDIST (09c3b9b)
36
37    Arguments: pol1, pot1, poa1 (log L, log Teff and age at the previous
38    model), polen (the accumulated squared distance); bl, teffl, the
39    model number modeln, the run index nk and the age dage now; the base
40    file names fpatm, fpenv, fpmod.
41
42    Returns (pol1, pot1, poa1, polen), updated. Sets nmlpar_mod.lpulse.
43    """
44    tm1 = bl - pol1
45    tm2 = teffl - pot1
46    tm3 = dage - poa1
47    tmp1 = nmlpar_mod.poa * tm1 * nmlpar_mod.poa * tm1
48    tmp2 = nmlpar_mod.pob * tm2 * nmlpar_mod.pob * tm2
49    tmp3 = nmlpar_mod.poc * tm3 * nmlpar_mod.poc * tm3
50    # Question (see the page): POMAX is compared with a squared distance.
51    polen = polen + tmp1 + tmp2 + tmp3
52    pol1 = bl
53    pot1 = teffl
54    poa1 = dage
55    if polen >= nmlpar_mod.pomax:
56        nmlpar_mod.lpulse = True
57        polen = 0.0
58        # Question (see the page): STATUS='NEW' stops if the file exists.
59        iounits_mod.open(iounits_mod.iopmod, _pulse_name(fpmod, nk, modeln),
60                         status="new")
61        iounits_mod.open(iounits_mod.iopenv, _pulse_name(fpenv, nk, modeln),
62                         status="new")
63        iounits_mod.open(iounits_mod.iopatm, _pulse_name(fpatm, nk, modeln),
64                         status="new")
65    else:
66        iounits_mod.close(iounits_mod.iopmod)
67        iounits_mod.close(iounits_mod.iopenv)
68        iounits_mod.close(iounits_mod.iopatm)
69        nmlpar_mod.lpulse = False
70    # Question (see the page): the differences go to IOWR, their weighted
71    # squares to ISHORT, under the same labels.
72    iounits_mod.write(iounits_mod.iowr, _fmt276(polen, tm1, tm2, tm3))
73    iounits_mod.write(iounits_mod.ishort, _fmt276(polen, tmp1, tmp2, tmp3))

Python version: _pulse_name
The file name <base>NN_MMMM (or NN_MMMMM from model 10000 on).

base is a CHARACTER*256 in Fortran, padded with blanks: the name ends
at its first blank, INDEX(base, ' ') - 1. A Python string has no
padding, so a name without blanks is taken whole.
14def _pulse_name(base, nk, modeln):
15    """The file name <base>NN_MMMM (or NN_MMMMM from model 10000 on).
16
17    base is a CHARACTER*256 in Fortran, padded with blanks: the name ends
18    at its first blank, INDEX(base, ' ') - 1. A Python string has no
19    padding, so a name without blanks is taken whole."""
20    ioccol = base.find(" ") if " " in base else len(base)
21    if modeln < 10000:
22        ctemp = f"{nk:02d}_{modeln:04d}"
23    else:
24        ctemp = f"{nk:02d}_{modeln:05d}"
25    return base[:ioccol] + ctemp
