Purpose

MEVAL evaluates a shape-preserving (osculatory) quadratic spline at a set of points: McAllister and Roulier's algorithm, "coded by S. L. Dodd and M. Roulier, N.C. State University" (its header). The spline passes through the data with given slopes and keeps the data's monotonicity and convexity.

How it fits

Called only by OSPLIN, which computes the slopes and passes EPS = $10^{-4}$; OSPLIN is the interpolator that HPOINT uses to move every model variable to the new mass points, and is also called by EQ2MOD and GETGRID. It calls SEARCH (the interval of a point), CHOOSE (which of the spline's cases applies in an interval), CASES (the spline's parameters for that case) and the function SPLINE (its value). No COMMON blocks; it takes the array size JSON from DIMENSIONS_MOD.

The method

Its arguments: the points XVAL(1..NUME) (nondecreasing), the data XTAB, YTAB and slopes MTAB (NUM points), the tolerance EPS; the output YVAL and the error code ERR (0 normal; 1 extrapolation; 2 XVAL not sorted, in which case nothing is computed). It walks through the evaluation points and the data intervals together: points equal to a data abscissa get the data value; for each interval containing points it calls CHOOSE and CASES once and evaluates SPLINE at each point; points beyond the ends are extrapolated with the end intervals' splines. OSPLIN does not check ERR (suspected bug 1). The dummy arrays are declared with the fixed size JSON (lines 21–22↗), not with NUM and NUME.

XTAB(1), then XVAL(I)=YTAB(1)" (and the same at the top end): the code extrapolates with the end spline instead, and writes YVAL, not XVAL.
