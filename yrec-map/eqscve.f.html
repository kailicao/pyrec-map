Purpose

EQSCVE interpolates the Saumon–Chabrier–Van Horn (SCV) equation of state in its table for the surface (envelope) composition. It returns the density, the thermodynamic derivatives and the ionization fractions of hydrogen and helium. For any other composition it hands the work to EQSCVG, which combines the pure-hydrogen, pure-helium and metal tables.

How it fits

  • Who calls it: only EQSTAT2, when LSCV is set and $\log T <$ TSCUT, right after EQSAHA. If the point is outside the table (LCALC false), the routine returns without touching its outputs, so the EQSAHA values stand.

    Question 1 (eqstat2.f, lines 181–187↗; eqsaha.f, lines 194–196↗). Mixed EOS outputs. When SCV succeeds, EQSTAT2 keeps RMU, EMU and the second derivatives from EQSAHA, while the density comes from SCV. So $\mu$ is no longer consistent with $\rho = \beta P\mu/(\mathcal{R}T)$ (below the transition band, where EQSTAT2 does not recompute RMU). RMU is read later by hsubp.f, line 74↗ and EMU by sconvec.f, line 223↗. Is that intended?

  • Inputs: TL, T, P, BETA, X, Z. It compares X, Z with XENV, ZENV from /COMP/.

  • What it calls: KSPLINE and KSPLINT (a four-point natural spline), INTERP (four-point Lagrange) and EQSCVG.
  • Outputs: DL, D, QDT, QDP, QCP, DELA, FXION, LCALC.
  • Modules: SCVEOS_MOD holds the tables (TLOGX, TABLENV for the envelope mixture, TABLEX, TABLEY, TABLEZ, SMIX, NPTSX) and the last indices IDTSCV, IDP; it is filled by SETSCV and used also by EQSCVG and SETUPS. The flag LSCV is now in NMLPAR_MOD. COMP_MOD gives the envelope composition; CONSTANTS_MOD the constants.

The method

  1. The table is in $\log T$ and $\log P_\mathrm{gas}$, with $P_\mathrm{gas} = \beta P$. Out of table if $\log T$ is outside TLOGX, if $\log P_\mathrm{gas} < 4$, or if it is above the last pressure of the stencil's lowest-temperature row.

  2. Find the 4×4 stencil (IDTSCV, IDP), starting from the last one. For each of the 4 temperatures, a natural spline in $\log P_\mathrm{gas}$ gives five quantities (columns 2–6 of TABLENV: $\log\rho$, $Q_{\rho T}$, $Q_{\rho P}$, $c_P$, $\partial U/\partial T$); a second spline in $\log T$ gives their values at the point. Column 5, the tabulated $c_P$ (TEMPT(4), QCP0), is interpolated but never used, since step 4 rebuilds $c_P$ from $\partial U/\partial T$: unused? (line 384↗).

    One pressure grid serves all four temperatures. The pressure abscissae are always taken from the row IDTSCV, the lowest temperature of the stencil, also for the other three rows (lines 102–103↗; lines 164–166↗), and the ionization step (5) uses TABLENV's pressures, which are TABLEX's (setscv.f, line 165↗), for TABLEX and TABLEY too (lines 407–409↗). That is right: In input/eos/scv, every row of h_tab_i.dat and he_tab_i.dat (63 temperatures) is a prefix of one grid, $\log P_\mathrm{gas} = 4.00$, $4.20$, …, its length growing with $T$ from 30 to 76 points, so the row IDTSCV is the shortest of the stencil and its pressures are those of the three hotter rows; the metal table z_tab_i.dat, read in reverse order (setups.f, lines 388–389↗), has the same pressures row by row (checked from the files, Nov 10, 2026).

  3. Smoothing at stencil changes. When the point is within TOLST = 0.032 in $\log T$ (or TOLSP = 0.08 in $\log P$) of the edge of the middle interval, the routine also interpolates on the stencil shifted by one, and blends the two linearly (FST, FSP), so that the result does not jump when the stencil changes.

  4. Radiation. The tables hold the gas alone. With $Q_{\rho P,0}$ and $Q_{\rho T,0}$ from the table, $$Q_{\rho P} = \frac{Q_{\rho P,0}}{\beta},\qquad \chi_T = \beta\left(-\frac{Q_{\rho T,0}}{Q_{\rho P,0}}\right) + 4(1-\beta),\qquad Q_{\rho T} = -\chi_T\,Q_{\rho P},$$ $$\frac{\partial U}{\partial T} \mathrel{+}= \frac{4}{T}\cdot\frac{3P_\mathrm{rad}}{\rho},\qquad c_P = \frac{\partial U}{\partial T} - \frac{P}{\rho T}Q_{\rho T}\chi_T,\qquad \nabla_\mathrm{ad} = -\frac{P\,Q_{\rho T}}{\rho T\,c_P}.$$

  5. Ionization. From the pure-hydrogen table TABLEX and the pure-helium table TABLEY (columns 2 and 3, Lagrange interpolation on the same stencil and pressure abscissae as TABLENV), the particle fractions of H$_2$, H, He and He$^+$; charge and particle conservation give the rest, and $$x_{\mathrm{H}^+} = \frac{n_{\mathrm{H}^+}}{n_{\mathrm{H}_2} + n_\mathrm{H} + n_{\mathrm{H}^+}}, \quad x_{\mathrm{He}^+} = \frac{n_{\mathrm{He}^+}}{n_\mathrm{He} + n_{\mathrm{He}^+} + n_{\mathrm{He}^{++}}},$$ and likewise for He$^{++}$ (the code's formula for H$^+$; see bug 1).

    Question 2 (lines 403–425↗; lines 162–190↗). Spline and Lagrange. The thermodynamic quantities use splines, the ionization fractions Lagrange interpolation without the smoothing of step 3. Is the difference intended?

Suspected bugs, checked by running the code

Each bug is marked by what running the code showed: (changes results, large) or (small), the fix moving a run clearly beyond a null change; (stops the run); (wrong output), the fix changing only what is written; (harmless in the runs), within the noise; (never occurred), the code ran but the fault did not; (not reached); (cannot be reached), a guard prevents it; (withdrawn), the suspicion was wrong.

1. (harmless in the runs) H$_2$ counted as one hydrogen nucleus.

(line 463↗; setscv.f, lines 58–59↗) In step 5 the denominator XTF_H2 + XTF_H1 + XTF_HP counts each H$_2$ molecule once, but it holds two hydrogen nuclei, and the comment says the result is "the fraction XHP of hydrogen nuclei that are singly ionized" (line 460↗). SETSCV counts the nuclei with the factor 2 for the same table columns (its 1+3*TABLEX(I,J,2)+TABLEX(I,J,3) is twice $2x_{\mathrm{H}_2} + x_\mathrm{H} + x_{\mathrm{H}^+}$). So FXION(1) is too large wherever H$_2$ is present; it is read by the conductive opacity (condopacpint.f, line 39↗) and written to the outputs. Where H$_2$ is abundant, few H nuclei are ionized, so the absolute error is probably small; not traced. Only with LSCV (off by default, nmlpar_mod.f, line 258↗).

21def _stencil_spline(ismt, ismp, pp, tl):
22    """The interpolation block the Fortran writes out four times: for the
23    4x4 stencil shifted by ismt rows in T and ismp columns in P, a natural
24    spline in log Pgas at each of the 4 temperatures, then one in log T,
25    for columns 2-6 of TABLENV. The pressure abscissae always come from
26    the row idtscv (unshifted), as in the Fortran. Returns tempt[1..5]."""
27
28    scv = scveos_mod
29    idt = scv.idtscv
30    idp = scv.idp
31    qr = np.zeros(5)
32    ytab = np.zeros(5)
33    y2 = np.zeros(5)
34    temp = np.zeros((5, 6))
35    tempt = np.zeros(6)
36
37    # Interpolate in pressure at 4 different temperature points (Fortran
38    # lines 162–178, and 194–210, 236–252, 278–294 for the shifted
39    # stencils).
40    for i in range(1, 5):
41        ii = idt + i - 1 + ismt
42        for k in range(1, 5):
43            # Question (see the page): row idt's pressures for all 4 rows.
44            qr[k] = scv.tablenv[idt, idp + k - 1 + ismp, 1]
45        for j in range(1, 6):
46            for k in range(1, 5):
47                ytab[k] = scv.tablenv[ii, idp + k - 1 + ismp, j + 1]
48            kspline(qr, ytab, y2)
49            temp[i, j] = ksplint(qr, ytab, y2, pp, 0.0)
50
51    # Interpolate in temperature (Fortran lines 180–190, and 212–222,
52    # 254–264, 296–306).
53    for k in range(1, 5):
54        qr[k] = scv.tlogx[k + idt - 1 + ismt]
55    for j in range(1, 6):
56        for k in range(1, 5):
57            ytab[k] = temp[k, j]
58        kspline(qr, ytab, y2)
59        tempt[j] = ksplint(qr, ytab, y2, tl, 0.0)
60    return tempt

63def eqscve(tl: float, t: float, p: float, dl: float, d: float, x: float, z: float, beta: float, fxion: np.ndarray,
64           qdt: float, qdp: float, qcp: float, dela: float, lcalc: bool) -> tuple[float, float, float, float, float,
65           float, bool]:
66    """Interpolate the Saumon-Chabrier-Van Horn equation of state in its
67    table for the envelope composition (2D splines, smoothed where the
68    stencil changes), add radiation, and get the H and He ionization
69    fractions; any other composition goes to eqscvg.
70
71    Translates: eqscve.f#EQSCVE (7be4133)
72
73    Arguments: tl, t (log T, T), p (total pressure), x, z, beta (Pgas/P);
74    dl ... dela and lcalc are only set. Array changed in place: fxion (H+,
75    He+, He++ fractions, index 0 unused).
76
77    Returns (dl, d, qdt, qdp, qcp, dela, lcalc). Outside the table, lcalc
78    is False and the others are returned as passed in.
79
80    """
81
82    c = constants_mod
83    scv = scveos_mod
84
85    # Other compositions go to eqscvg (Fortran lines 45–50).
86    if (abs(x - comp_mod.xenv) > 1.0e-5
87            or abs(z - comp_mod.zenv) > 1.0e-5):
88        dl, d, qdt, qdp, qcp, dela, lcalc = eqscvg(
89            tl, t, p, dl, d, x, z, beta, fxion, qdt, qdp, qcp, dela, lcalc)
90        return dl, d, qdt, qdp, qcp, dela, lcalc
91
92    # The gas pressure is the tabulated quantity (Fortran lines 52–58).
93    betm1 = 1.0 - beta
94    pp = math.log10(beta * p)
95    # Is the point within the table?
96    if tl < scv.tlogx[1] or tl > scv.tlogx[NTS] or pp < 4.0:
97        lcalc = False
98        return dl, d, qdt, qdp, qcp, dela, lcalc
99
100    # Nearest 4 points in temperature, searching from the last stencil
101    # (Fortran lines 60–82).
102    if tl < scv.tlogx[scv.idtscv + 1]:
103        for i in range(scv.idtscv, 0, -1):
104            if tl > scv.tlogx[i]:
105                ii = i - 1
106                break                              # go to 10
107        else:
108            ii = 1
109    else:
110        for i in range(scv.idtscv + 2, NTS + 1):
111            if tl < scv.tlogx[i]:
112                ii = i - 2
113                break                              # go to 20
114        else:
115            ii = NTS - 3
116    scv.idtscv = max(1, ii)
117    scv.idtscv = min(NTS - 3, scv.idtscv)
118    idt = scv.idtscv
119
120    # Smoothing in T near the edges of the middle interval (Fortran lines
121    # 83–100).
122    lsmt = False
123    ismt = 0
124    fst = 0.0
125    if idt == ii:
126        dtabove = tl - scv.tlogx[idt + 1]
127        dtbelow = scv.tlogx[idt + 2] - tl
128        if dtabove < TOLST:
129            if idt > 1:
130                lsmt = True
131                ismt = -1
132                fst = (dtabove + TOLST) / (2.0 * TOLST)
133        elif dtbelow < TOLST:
134            if idt < NTS - 3:
135                lsmt = True
136                ismt = 1
137                fst = 0.5 * dtbelow / TOLST
138
139    # Nearest 4 points in pressure, searched in the row idt (the lowest
140    # temperature of the stencil, with the smallest range in P; Fortran
141    # lines 102–130).
142    nptsx = scv.nptsx[idt]
143    jjj = min(nptsx - 3, scv.idp)
144    if pp < scv.tablenv[idt, jjj + 1, 1]:
145        for j in range(jjj, 0, -1):
146            if pp > scv.tablenv[idt, j, 1]:
147                jj = j - 1
148                break                              # go to 30
149        else:
150            jj = 1
151        scv.idp = max(1, jj)
152        scv.idp = min(nptsx - 3, scv.idp)
153    else:
154        for j in range(jjj + 2, nptsx + 1):
155            if pp < scv.tablenv[idt, j, 1]:
156                jj = j - 2
157                break                              # go to 40
158        else:
159            # The point is above the table: return.
160            lcalc = False
161            return dl, d, qdt, qdp, qcp, dela, lcalc
162        scv.idp = min(nptsx - 3, jj)               # label 40
163    idp = scv.idp
164    lcalc = True
165
166    # Smoothing in P near the edges of the middle interval (Fortran lines
167    # 131–148).
168    lsmp = False
169    ismp = 0
170    fsp = 0.0
171    if idp == jj:
172        dpabove = pp - scv.tablenv[idt, idp + 1, 1]
173        dpbelow = scv.tablenv[idt, idp + 2, 1] - pp
174        if dpabove < TOLSP:
175            if idp > 1:
176                lsmp = True
177                ismp = -1
178                fsp = (dpabove + TOLSP) / (2.0 * TOLSP)
179        elif dpbelow < TOLSP:
180            if idp < nptsx - 3:
181                lsmp = True
182                ismp = 1
183                fsp = 0.5 * dpbelow / TOLSP
184
185    # Radiation pressure (Fortran lines 157–160).
186    y = 1.0 - x - z  # noqa: F841  (unused in the Fortran too)
187    prad = betm1 * p
188    pgas = beta * p  # noqa: F841  (unused in the Fortran too)
189
190    # Columns 2-6 of TABLENV: log rho, Q_rhoT, Q_rhoP, cP, dU/dT, on the
191    # stencil and, near its edges, on the shifted ones (Fortran lines
192    # 162–307).
193    tempt = _stencil_spline(0, 0, pp, tl)
194    tempt1t = np.zeros(6)
195    tempt2p = np.zeros(6)
196    if lsmt:
197        # Interpolate at the stencil shifted in T.
198        tempt1 = _stencil_spline(ismt, 0, pp, tl)
199        if ismt == -1:
200            tempt1t[1:] = tempt1[1:] + fst * (tempt[1:] - tempt1[1:])
201        else:
202            tempt1t[1:] = tempt[1:] + fst * (tempt1[1:] - tempt[1:])
203    if lsmp:
204        # Interpolate at the stencil shifted in P.
205        tempt2 = _stencil_spline(0, ismp, pp, tl)
206        if ismp == -1:
207            tempt2p[1:] = tempt2[1:] + fsp * (tempt[1:] - tempt2[1:])
208        else:
209            tempt2p[1:] = tempt[1:] + fsp * (tempt2[1:] - tempt[1:])
210    if lsmp and lsmt:
211        # Interpolate at the stencil shifted in both.
212        tempt3 = _stencil_spline(ismt, ismp, pp, tl)
213
214    # Blend the shifted stencils' results (Fortran lines 308–358).
215    if lsmt:
216        if lsmp:
217            # Blend in T at both pressures, then in P.
218            for j in range(1, 6):
219                if ismt == -1:
220                    chgt1 = tempt1[j] + fst * (tempt[j] - tempt1[j])
221                    chgt2 = tempt3[j] + fst * (tempt2[j] - tempt3[j])
222                else:
223                    chgt1 = tempt[j] + fst * (tempt1[j] - tempt[j])
224                    chgt2 = tempt2[j] + fst * (tempt3[j] - tempt2[j])
225                if ismp == -1:
226                    tempt[j] = chgt2 + fsp * (chgt1 - chgt2)
227                else:
228                    tempt[j] = chgt1 + fsp * (chgt2 - chgt1)
229        else:
230            tempt[1:] = tempt1t[1:]
231    elif lsmp:
232        tempt[1:] = tempt2p[1:]
233
234    # Density (Fortran lines 364–365).
235    dl = tempt[1]
236    d = math.exp(c.cln * dl)
237    # Q_rhoP: radiation adds pressure but no density, so divide by beta;
238    # then Q_rhoT, c_P and nabla_ad with radiation (Fortran lines
239    # 369–394).
240    qdp0 = tempt[3]
241    qdp = qdp0 / beta
242    # Q_rhoT = -chi_T Q_rhoP, with chi_T (qpt) corrected for radiation.
243    qdt0 = tempt[2]
244    qpt0 = -qdt0 / qdp0
245    qpt = qpt0 * beta + 4.0 * betm1
246    qdt = -qpt * qdp
247    qcp0 = tempt[4]  # noqa: F841  (unused in the Fortran too)
248    # dU/dT from the table, corrected for radiation.
249    qut = tempt[5]
250    ur = 3.0 * prad / d
251    qut = qut + 4.0 * ur / t
252    # cP corrected for radiation pressure, and the adiabatic gradient.
253    qcp = qut - p * qdt * qpt / d / t
254    dela = -p * qdt / d / t / qcp
255
256    # Ionization: particle fractions from the pure-H (TABLEX) and pure-He
257    # (TABLEY) tables, by 4-point Lagrange interpolation on the same stencil
258    # (Fortran lines 403–445).
259    # Question (see the page): Lagrange here, splines above.
260    qr = np.zeros(5)
261    ft = np.zeros(5)
262    ftd = np.zeros(5)
263    fp = np.zeros(5)
264    fpd = np.zeros(5)
265    temp = np.zeros((5, 3))
266    for k in range(1, 5):
267        qr[k] = scv.tlogx[k + idt - 1]
268    interp(qr, ft, ftd, tl)
269    for k in range(1, 5):
270        # Question (see the page): TABLENV's pressures for TABLEX, TABLEY.
271        qr[k] = scv.tablenv[idt, idp + k - 1, 1]
272    interp(qr, fp, fpd, pp)
273
274    def lagrange(col):
275        """Columns col of TABLEX and TABLEY at (tl, pp)."""
276        for i in range(1, 5):
277            ii = idt + i - 1
278            temp[i, 1] = sum(fp[k] * scv.tablex[ii, idp + k - 1, col]
279                             for k in range(1, 5))
280            temp[i, 2] = sum(fp[k] * scv.tabley[ii, idp + k - 1, col]
281                             for k in range(1, 5))
282        return (sum(ft[k] * temp[k, 1] for k in range(1, 5)),
283                sum(ft[k] * temp[k, 2] for k in range(1, 5)))
284
285    # Column 2: fractions of all particles that are H2, and neutral He.
286    xtf_h2, xtf_he = lagrange(2)
287    # Column 3: fractions that are neutral H atoms, and He+.
288    xtf_h1, xtf_hep = lagrange(3)
289
290    # Particle and charge conservation give the rest (Fortran lines
291    # 455–458).
292    xtf_h_e = 0.5 * (1.0 - xtf_h2 - xtf_h1)
293    xtf_hp = xtf_h_e
294    xtf_he_e = (1.0 / 3.0) * (2.0 - 2.0 * xtf_he - xtf_hep)
295    xtf_hepp = 1.0 - xtf_he - xtf_hep - xtf_he_e
296
297    # Fractions of H and He nuclei in each stage (Fortran lines 463–470).
298    # Suspected bug (see the page): H2 counted once in the denominator.
299    xhp = xtf_hp / (xtf_h2 + xtf_h1 + xtf_hp)
300    xhep = xtf_hep / (xtf_he + xtf_hep + xtf_hepp)
301    xhepp = xtf_hepp / (xtf_he + xtf_hep + xtf_hepp)
302    fxion[1] = xhp
303    fxion[2] = xhep
304    fxion[3] = xhepp
305    return dl, d, qdt, qdp, qcp, dela, lcalc
