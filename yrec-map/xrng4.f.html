xrng4.f

24 lines · 1 definitions · on GitHub (7be4133)

Python version: xrng4.py, 29 lines, on the right (switch to Python above the code).

Purpose

XRNG4 chooses four consecutive table indices around index JX in a table of NUMX entries, for 4-point interpolation: JX1 to JX2 = JX-1 to JX+2, shifted to 1..4 near the start and to NUMX-3..NUMX near the end.

How it fits

Called only by GTPURZ, the pure-Z opacity table's interpolation (GTLAOL and GTLAOL2, which also called it, are removed since rp_1 with the LAOL89 tables). No COMMON blocks.

Question 1 (lines 13–18↗). Short tables. The routine assumes NUMX ≥ 4; with fewer entries JX2 = 4 or JX1 = NUMX-3 falls outside the table. Its only caller passes NUMTZ, the pure-Z table's number of temperatures (line 72↗), which RDZLAOL reads from the table's header and checks only from above (NUMTZ.GT.52, lines 42–44↗). Should RDZLAOL also require NUMTZ ≥ 4?
