Purpose

WRTMIL writes one model's Milne (homology) invariants $U$ and $V$, with $W$ and the polytropic index $n + 1$, to the Milne output file, every NPRTPT shells and the last one.

How it fits

  • Inputs: the model (HCOMP, $\log\rho$, $L/L_\odot$, $\log P$, $\log r$, $m$ in grams HS1, M, MODEL), and through modules the energy rates SESUM and SEG and the actual gradient SDEL(2,·) (SCRTCH_MOD), the surface composition and total mass (COMP_MOD), NPRTPT (NMLPAR_MOD), the constants (CONSTANTS_MOD) and the unit IMILNE (IOUNITS_MOD).

  • Who calls it: PUTSTORE and WRTOUT, when LMILNE is set and other conditions hold: PUTSTORE only when LSTATM or LSTENV is set, and WRTOUT only in its pulsation branch (LPULSE on a model that is not stored). So LMILNE alone writes nothing.

    Question 1 (putstore.f, lines 342–343↗; wrtout.f, lines 683–684↗). LMILNE alone writes nothing. The calls also need LSTATM or LSTENV (PUTSTORE), or LPULSE on a model that is not stored (WRTOUT). Is the Milne output meant to depend on those switches?

  • Output: the unit IMILNE (21, fixed in PARMIN, parmin.f, line 674↗), opened by PARMIN in append mode (parmin.f, lines 956–959↗).

The method

At each printed shell: $$U = \frac{4\pi\rho r^3}{m},\qquad V = \frac{G m \rho}{P r},\qquad W = U\,\frac{m\,(\epsilon_\mathrm{nuc} + \epsilon_7)}{L},\qquad n + 1 = \frac{1}{\nabla},$$ where $\epsilon_\mathrm{nuc}$ is SESUM and $\epsilon_7$ is SEG(7,·) (the gravitational energy rate, by the column names stitch.f gives), and $\nabla$ = SDEL(2,·), the actual gradient.

Question 2 (line 76↗). $W$ includes the gravitational term. $W$ uses $\epsilon_\mathrm{nuc} + \epsilon_7$; is the gravitational energy meant to be in it?

15def _row(i: int, hcomp: np.ndarray, hd: np.ndarray, hl: np.ndarray, hp: np.ndarray, hr: np.ndarray,
16         hs1: np.ndarray) -> str:
17    """One shell's line (FORMAT 10): U, V, W and n + 1 = 1/nabla (the
18    Fortran repeats these lines at each shell: lines 71–79, 86–94, and
19    99–107).
20
21    """
22
23    c = constants_mod
24    s = scrtch_mod
25    d = math.exp(c.cln * hd[i])
26    p = math.exp(c.cln * hp[i])
27    r = math.exp(c.cln * hr[i])
28    u = c.c4pi * d * r**3 / hs1[i]
29    v = math.exp(c.cln * c.cgl) * hs1[i] * d / (p * r)
30    # Question (see the page): W includes the gravitational term seg[7].
31    w = u * hs1[i] * (s.sesum[i] + s.seg[7, i]) / (hl[i] * c.clsun)
32    np1 = 1.0 / s.sdel[2, i]
33    vals = (hs1[i], r, p, d, hcomp[1, i], hl[i], u, v, w, np1)
34    return f' {i:4d}' + ''.join(f'{x:11.3E}' for x in vals)

37def _d(x: float) -> str:
38    """Fortran's 1PD10.3: like 1PE10.3, with a D exponent.
39
40    """
41
42    return f'{x:10.3E}'.replace('E', 'D')

45def wrtmil(hcomp: np.ndarray, hd: np.ndarray, hl: np.ndarray, hp: np.ndarray, hr: np.ndarray, hs1: np.ndarray, m: int,
46           model: int) -> None:
47    """Write the model's header and U, V, W and n + 1 at the first shell,
48    every nprtpt-th shell and the last one, then close the unit.
49
50    Translates: wrtmil.f#WRTMIL (7be4133)
51
52    Arguments: the model hcomp[species, shell], log rho hd, L/Lsun hl,
53    log P hp, log r hr, m in grams hs1 (index 0 unused); m, the number of
54    shells; model, the model's number. None is returned.
55
56    """
57
58    c = constants_mod
59    io = iounits_mod
60    nprtpt = nmlpar_mod.nprtpt
61
62    # The header; Fortran's 1PD10.3 writes a D exponent (Fortran lines
63    # 66–69).
64    smtot = math.exp(c.cln * comp_mod.stotal) / c.cmsun
65    io.write(io.imilne,
66             f'{"":10}MODEL{model:5d}  XENV ={_d(comp_mod.xenv)}'
67             f'  ZENV ={_d(comp_mod.zenv)}  MASS(SOLAR UNITS) ={_d(smtot)}')
68
69    # The first shell, always written (Fortran lines 70–79).
70    io.write(io.imilne, _row(1, hcomp, hd, hl, hp, hr, hs1))
71
72    # Every nprtpt-th shell (Fortran lines 81–96).
73    iend = 1
74    if nprtpt <= m:
75        ibeg = max(2, nprtpt)
76        iend = m - m % nprtpt
77        for i in range(ibeg, iend + 1, nprtpt):     # loop 20
78            io.write(io.imilne, _row(i, hcomp, hd, hl, hp, hr, hs1))
79
80    # The last shell, if nprtpt does not divide m (Fortran lines 97–108).
81    if iend < m:
82        io.write(io.imilne, _row(m, hcomp, hd, hl, hp, hr, hs1))
83
84    # Suspected bug (see the page): closed after each model, opened only
85    # once (Fortran line 109).
86    io.close(io.imilne)
