## Explanation

**Purpose.** `main.f` is YREC's main program (it has no `PROGRAM` statement; the site lists it as `(file level)`). It reads the run's settings, sets up the physics tables, and then, for each "kind card" (one run of a job: a starting model and what to do with it), loads the starting model and evolves it model by model. Each evolutionary step does, in order: mass loss, mixing and nuclear burning, rezoning, the iterative solution of the structure equations, rotation, light-element burning, the next time step, and output. Around this loop sit optional drivers: automatic calibration of a solar model or of a star of given $L$ and $T_\mathrm{eff}$, and Monte Carlo runs over nuclear and solar parameters. This is the reader's starting point.

**How it fits.**
- **Inputs:** everything comes through [[parmin.f#PARMIN|`PARMIN`]] (the run's parameters, per kind card; it also opens files and returns the names of the table files) and [[setups.f#SETUPS|`SETUPS`]] (constants, and the opacity, EOS and atmosphere tables). The starting model is read by [[starin.f#STARIN|`STARIN`]] from the unit `IFIRST`. With `LMONTE`, the Monte Carlo parameters are read from unit `IDYN`.
- **Who calls it:** nobody; it is the program.
- **Outputs:** written by the routines it calls: headers by [[wrthead.f#WRTHEAD|`WRTHEAD`]], each model by [[wrtout.f#WRTOUT|`WRTOUT`]] (the output driver: short output `ISHORT`, track `ITRACK`, model printouts and so on), the last model of a run by [[putstore.f#PUTSTORE|`PUTSTORE`]] (unit `ISTOR`, for continuing a sequence), the model before a step by [[wrtlst.f#WRTLST|`WRTLST`]] (unit `ILAST`, for He-flash runs), pulsation output by [[pdist.f#PDIST|`PDIST`]], and calibration and Monte Carlo summaries to `ISNU` (with [[wrtmonte.f#WRTMONTE|`WRTMONTE`]]).
- **COMMON blocks:** main.f declares 60 of them, many of the code's global blocks, mostly so that it can set flags or keep state across the loop. The ones it actually uses: `CKIND` (`NUMRUN`, `NMODLS`, `IRESCA`, `RESCAL`, per kind card), `NEWXYM` (per-run $X$, $Z$, mixing length, envelope settings), `SETT` (stop conditions: `ENDAGE`, `LENDAG`, `END_DCEN`, `END_XCEN`, `END_YCEN`), `ENTROP` (the rates of change of $\log T$, $\log P$, $\ln L$, $\log r$ from the previous model; shared only with `HPOINT`, which moves them to the new grid), `OLDMOD` (the model at the start of the step), `PREVCZ`, `LIOV` (light-element burning with overshoot), `ORIGSTART` (start-of-step $j$ and composition when iterating between structure and rotation), `DIFUS` (`ITDIF1`), `CTOL` (`FCORR`, `NITER1`–`NITER3`), `NEWENG` (`NITER4`, `LNEWS`, `LSNU`), `CALSUN`, `CALS2`, `CALSTAR` (calibrations), `MONTE`, `MONTE2`, `CROSS` (Monte Carlo), `ACDPTH` (outputs at chosen ages), `ROTPRT`, `DISK` (`SAGE`), `CT3` (`LPTIME`), `ATMOS` (`KTTAU`), and `FLAG` (`LEXCOM`), `ROT` (`LROT`, `LINSTB`), `HEFLSH` (`LKUTHE`), `DPMIX` (`LOVSTE`, `ALPHAE`).

**The order of the run.**
1. **Settings and tables.** `IOWR` = 9; [[parmin.f#PARMIN|`PARMIN`]], then [[setups.f#SETUPS|`SETUPS`]] (MHP 8/25: the table file names are now passed as arguments instead of through COMMON).
2. **Monte Carlo loop** (`DO 500 NN`): with `LMONTE`, read up to 1000 parameter sets (factors for the pp, ³He+³He, ³He+⁴He and ⁷Be+p cross sections, $Z/X$, the settling efficiency, $L_\odot$, the solar age) and, for each, set `SSTANDARD`, `FGRZ`, `CLSUN` and `FACAGE`; otherwise the loop runs once.
3. **Calibration set-up:** [[setcal.f#SETCAL|`SETCAL`]] for a solar calibration (`LCALS`; it changes the kind cards, and `LPTIME`, `KTTAU` are saved to be restored at each cycle), [[setscal.f#SETSCAL|`SETSCAL`]] for a star of given $L$, $T_\mathrm{eff}$ (`LCALST`).
4. **Kind-card loop** (`DO 200 NK = 1, NUMRUN`): set the run's $X$, $Z$, mixing length and envelope options; [[starin.f#STARIN|`STARIN`]] reads (or keeps) the starting model and rescales it if asked; stop if `LROT` is set but $\Omega = 0$; disable stop conditions already met by the starting model; [[wrthead.f#WRTHEAD|`WRTHEAD`]]; for He-flash runs (`LKUTHE`) store the model with `WRTLST`; [[findsh.f#FINDSH|`FINDSH`]] (the H-burning shell and convection-zone edges); [[htimer.f#HTIMER|`HTIMER`]] (the first step); zero the entropy terms and the light-element rates of the surface zone.
5. **Model loop** (`DO 100 MODELN = 1, NMODLS(NK)`), the evolution step, below.
6. **End of a kind card** (label 110): `PUTSTORE` the last model if asked; for a solar calibration, every third kind card [[chkcal.f#CHKCAL|`CHKCAL`]] compares $L$, $R$ (and the surface $Z/X$) with the targets and either ends (`LSOL`) or starts another cycle; the counter `ICONV` starts at 1 and the calibration gives up when it reaches 15. The radius comes from $L = 4\pi R^2\sigma T_\mathrm{eff}^4$ (`RLL`, with `BL` = $\log(L/L_\odot)$):
$$\log\frac{R}{R_\odot} = \tfrac12\Bigl[\log\frac{L}{L_\odot} + \log L_\odot - \log 4\pi - \log\sigma - 4\log T_\mathrm{eff}\Bigr] - \log R_\odot;$$ for `LCALST`, end when the star is matched (`LSTAR`, on an even kind card).
7. **After the runs** (label 250): Monte Carlo and calibration summaries to `ISNU`, then `STOP`.

**The evolution step** (one pass of the model loop).
1. Output switches: rewind `ISHORT` if `LRWSH`; turn on pulsation output on the last model, at chosen ages (`AGEOUT`, JVS 02/11) or at the final age; [[pdist.f#PDIST|`PDIST`]] if `LPOUT`.
2. **After a failed model** (label 15). If the previous attempt diverged or did not converge (`LARGE`), call `STARIN` again. Despite the comment "STARIN called here for timestep cutting", STARIN does not cut the step: with `LARGE` set it prints "RUN STOPPED" and stops (`starin.f`, lines 137–144). So a failed model ends the run.
3. **Ageing?** `LAGE` is true when `MODEL` ≥ 0, unless the kind card only relaxes a rescaled model (`IRESCA` = 2, except for pre-main-sequence models with $\log T_c$ < 6.6).
4. **Mass loss and mixing** (if `LAGE`): [[massloss.f#MASSLOSS|`MASSLOSS`]]; save the composition in `HCOMPP`; [[mix.f#MIX|`MIX`]] (convective mixing, nuclear burning through [[kemcom.f#KEMCOM|`KEMCOM`]], settling through [[grsett.f#GRSETT|`GRSETT`]]); advance the age: `DDAGE` = $\Delta t$/`CSECYR`, `DAGE` += $10^{-9}$`DDAGE` (Gyr).
5. **Rezoning:** [[hpoint.f#HPOINT|`HPOINT`]] (not in He-flash runs, which only save the old model for `PTIME`).
6. **Light elements at the start** (if `LEXCOM`): the convection zone's base `JENV0`, the overshoot distance $\alpha_e H_P$ with $H_P = P r^2/(\rho G m)$ (`PSCAL0`), and [[lirate88.f#LIRATE88|`LIRATE88`]] (rates, `J` = 1).
7. **First guess of the structure.** If `LNEWS` and the step is positive, extrapolate each point from the previous model's rates of change:
$$\log T \mathrel{+}= \dot{(\log T)}_0\,\Delta t,\quad \log P \mathrel{+}= \dot{(\log P)}_0\,\Delta t,\quad L \mathrel{+}= L\,\dot{(\ln L)}_0\,\Delta t,\quad \log r \mathrel{+}= \dot{(\log r)}_0\,\Delta t;$$
otherwise zero these terms. A non-ageing step is made negative (a relaxation).
8. **Structure: four levels of [[crrect.f#CRRECT|`CRRECT`]]** (the Henyey iteration), each with its own iteration limit: level 1 (`NITER1`) with the previous envelope triangle; level 2 (`NITER2`) checking the surface boundary condition (`LSBC`); level 3 (`NITER3`); then, after storing the new rates of change
$$\dot{(\log T)}_0 = \frac{\Delta\log T}{\Delta t},\quad \dot{(\ln L)}_0 = \frac{2(L - L_\mathrm{old})}{(L + L_\mathrm{old})\,\Delta t},\ \dots$$
for the next step's guess, level 4 (`NITER4`), which repeats the iteration between mixing and structure (its comment: not for models where semiconvection matters; for high-precision work such as solar models). Any divergence (`LARGE`), or no convergence after level 4, goes back to step 2, which stops the run. With rotation, the block from level 4 through step 9 (level 4, the convergence test, `MIXCZ`, `GETW`, `FPFT`) can be iterated `ITDIF1` times, restoring the start-of-step composition `HCOMPP` and $j$ each time.
9. **After convergence:** [[mixcz.f#MIXCZ|`MIXCZ`]] (fully mix the convection zones; G. Somers 6/14 also computes the turnover time there); `SAGE` = age; for rotating models [[getw.f#GETW|`GETW`]] (the new $\Omega$: angular-momentum transport and wind loss) and [[fpft.f#FPFT|`FPFT`]] (the distortion terms).
10. [[findsh.f#FINDSH|`FINDSH`]] again.
11. **Light-element burning** (if `LEXCOM`, `MODEL` ≥ 0 and the step is positive, and not rotating with rotational mixing; in that case [[getw.f#GETW|`GETW`]] calls `LIRATE88`, `LIBURN` and `LIBURN2` itself): [[convec.f#CONVEC|`CONVEC`]] for the zone's base at the end, `PSCAL1`, `LIRATE88` (`J` = 2), [[liburn.f#LIBURN|`LIBURN`]].
12. **After accretion** (`LNEWFIT`): [[getnewenv.f#GETNEWENV|`GETNEWENV`]] restores the envelope fitting point, then `FPFT`.
13. **Next step:** [[htimer.f#HTIMER|`HTIMER`]]. When the final age is reached, the step written with the model is the step just taken, `DELTS = MAX(DELTS0, 1.0D-3*DAGE*CSECYR)`, instead of a zero one, so that the sequence can be continued (see question 7 on the floor).
14. `MODEL` += 1 (unless relaxing); [[wrtout.f#WRTOUT|`WRTOUT`]].
15. **Stop conditions** (MHP 10/24): end the kind card when the final age is reached, or the central D, $X$ or $Y$ falls below its threshold; for `LCALST`, [[chkscal.f#CHKSCAL|`CHKSCAL`]] on even kind cards from the second model on (on success, `LPASSR`, it jumps to label 200, which skips `PUTSTORE`).

**Which routines do what, in brief.** Settings: `PARMIN`, `SETUPS`. Starting model: `STARIN` (with `RSCALE`). Time step: `HTIMER`. Mass change: `MASSLOSS`, `MDOT`. Mixing, burning, settling: `MIX`, `KEMCOM`, `GRSETT`, `MIXCZ`, `CONVEC`. Rezoning: `HPOINT`. Structure: `CRRECT` (with `COEFFT`, `ENVINT`, `HSOLVE` and the physics: EOS, opacities, energy generation `ENGEB`). Rotation: `GETW`, `FPFT`, `MOMI`. Light elements: `LIRATE88`, `LIBURN`. Output: `WRTHEAD`, `WRTOUT`, `PUTSTORE`, `WRTLST`, `PDIST`. Calibration: `SETCAL`, `CHKCAL`, `SETSCAL`, `CHKSCAL`.

**Design.** The program is one long routine with `GOTO`s across loop levels (back to label 15 after a failed model, which stops the run, forward to 110, 200 and 250). The state of the evolution lives in local arrays passed to every routine, and in many COMMON blocks. A neutrino-flux table block (`LNUTAB`) is switched off by a hard-coded `.FALSE.`. The comment at the top still says to change the array size by a global change of "JSON=2000" (now 5000, set in 123 of the 254 files).

**KC's changes.**
- 2025-05-30: COMMON `ACDPTH` reordered (logicals after reals, as in the other units).
- 2025-05-31: unused arguments removed from the calls to `STARIN` (`DELTS0`, `JCORE`), `HTIMER` (`LC`, `QDT`, `QDP`), `MIX` (`QDT`, `QDP`), `HPOINT` (`BL`, `DELTS`, `SMASS`), `CRRECT` (`MODEL`, `MRZONE`, `NRZONE`, `NZONE`), `MIXCZ` (also noted 2025-05-30 as addressing compiler warnings), `GETW`, `GETNEWENV`, `ENGEB`, `LIBURN`, `WRTOUT` (`NK`), `WRTMONTE`; the unused `SUNAGE` removed.

## Questions for the experts

1. **Disabling the stop conditions.** When the starting central $X$ is already below `END_XCEN`, the code sets `END_DCEN(NK) = -END_XCEN(NK)` (not `END_XCEN`), so the $X$ stop stays active and the deuterium stop is altered. The messages for $X$ and $Y$ also print the central deuterium `HCOMP(12,1)` and `END_DCEN`. Copy-paste slips?
2. **The call to `MASSLOSS` and on to `MDOT`.** `MASSLOSS` passes one argument more than `MDOT` takes (see [[mdot.f|`mdot.f`]]), so mass loss cannot work as written.
3. **The Monte Carlo failure summary.** `ZTOX` is written to `ISNU` in the failure branch, but it is assigned only in the success branch, so the first failure writes an undefined value and later ones the value of an earlier parameter set. The same branch writes `TCENTER`, `PCENTER`, `DCENTER` as they are (logs), while the success branch converts them to $T_6$, $\rho$ and $P/10^{17}$. (Other variables passed without a value in main.f are set by the callees: `GL` by `WRTOUT`, `LMIX`, `LOCOND`, `LATMO`, `LDERIV` by `COEFFT` through `CRRECT`, `QDT`, `QDP` by `STARIN`.)
4. **The neutrino table block.** It is off (`LNUTAB = .FALSE.`); it writes to unit 76, which nothing opens, and after KC's 2025-05-31 change it passes `IU`, which is undefined in main.f, to `ENGEB` (it used to pass the loop index `I`). Remove the block, or repair it?
5. **Calibration limits.** The loop ends after 15 calibration cycles (`ICONV.GE.15`), but the failure branch tests `ICONV.GE.11` and its message says "did not converge within 10 attempts".
6. **Unused Monte Carlo values.** `FGRSET = FHE(NN)` is set and never used (the helium settling factor `FGRY` is not changed), and `FZDIF` is a copy of `FHE`, so the one settling factor read is applied to the metals only (`FGRZ`). Was `FGRY` meant? `ZX(NN)` (the $Z/X$ of each set) is read but only written out, and `TEFFI` is set and never used.
7. **The floor on the final step.** At the final age, `DELTS = MAX(DELTS0, 1.0D-3*DAGE*CSECYR)`: with `DAGE` in Gyr this is $10^{-3}$ times the age in Gyr, in years, i.e. $10^{-12}$ of the age, so the floor never acts. Was `1.0D-3*DAGE*1.0D9*CSECYR` ($10^{-3}$ of the age) meant?
8. **The He-flash copy to `ILAST`.** The comment says time-step cutting "requires a model stored in logical unit ILAST or it will crash", but the copy runs only if `LPUNCH`, which is false on the first kind card (and again after `PUTSTORE`); it also passes `JCORE` before `FINDSH` has set it for this kind card. Should the copy be unconditional, after `FINDSH`?
9. **Hard-coded values.** `IOWR` = 9; the solar luminosity `SUNL` = 3.844 × 10³³ erg/s and, in the Monte Carlo set-up, `ENDAGE(2)` = 10⁸ and `ENDAGE(3)` = 4.57 × 10⁹ yr; $\log T_c$ < 6.6 for pre-main-sequence relaxation; the "BP96" cross-section factors `SBP` (comment: "actual values set in PARMIN").
